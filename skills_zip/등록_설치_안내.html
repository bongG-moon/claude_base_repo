별도 MCP · 1개

스킬과 별도로 설치·연결하는 도구입니다. ZIP 안의 README.md에서 설치 범위를 선택하고 필요한 접속 설정을 준비하세요. 하네스 설치만으로 연결되지 않습니다.

도구 / ZIP사용 조건설명
제조 메타데이터 Oracle MCPMCP/ToolWindows 로컬 stdio MCP. Python 3.13에서 검증. Langflow 서버와 별도 LLM KEY 불필요.Claude Code가 기존 MongoDB 업무 기준을 읽고 등록된 Oracle 데이터를 조회하도록 연결합니다. 로컬 조회 결과와 적용 조건을 제공해 제조 데이터 분석에 활용합니다.

사용하기 전에

ZIP 안의 INSTALL.md를 읽고 현재 프로젝트 또는 내 계정 전체 중 설치 범위를 선택합니다. 기존 같은 폴더는 덮어쓰지 않습니다. Company Agent에 이미 있는 기능은 중복 설치할 필요가 없습니다.

하네스 필요 스킬의 ZIP에는 실행 엔진·후크·MCP 연결이 없습니다. 해당 기능을 제공하는 기존 설치가 필요합니다. 플랫폼 등록 검사 통과가 실제 사내 업무 실행 성공을 뜻하지는 않습니다.

원본 스킬·코드·참고자료를 보존했습니다. ZIP 안의 PACKAGE_SOURCE.json에서 파일별 출처와 해시를 확인할 수 있습니다. 단독형 두 스킬은 standalone-skills의 정본을 사용합니다.

다시 만들기

저장소에서 python -X utf8 scripts/build-skill-packages.py를 실행합니다. --check는 최신 여부만 검사합니다. 같은 입력은 같은 ZIP을 만들며 불필요하게 파일을 다시 쓰지 않습니다.
