등록하는 방법

  1. 아래에서 필요한 ZIP을 선택합니다.
  2. 플랫폼의 도구 등록 화면에 ZIP 자체를 올립니다.
  3. 채워진 설명·사용 조건·동작 흐름을 확인하고 조직·업무 분류·공개 범위를 직접 선택합니다.
  4. 업데이트는 기존 도구의 새 버전 등록을 사용합니다. 플랫폼은 최초 packageId를 유지하며 새 ZIP의 식별자가 달라도 등록할 수 있습니다. ZIP 내부를 수정할 필요가 없습니다.

하네스에서 사용하는 기능

아래 항목은 개별 업무 스킬 ZIP에 포함하지 않습니다. 필요한 경우 하네스를 설치합니다.

  • 전사 MCP 제작 이전 이름 호환 — asset-factory로 통합된 이전 이름입니다. 별도 MCP 서버가 아니며 중복 배포하지 않습니다.
  • Company Agent 업무 조율 — 회사 정책·모델 경로·작업자·후크를 연결하는 하네스 본체입니다.
  • 프로젝트 업무 하네스 제작 — 프로젝트의 하네스 설치·정책과 실행 환경을 관리하는 기능입니다.
  • 검증된 교정, 절차 학습 — 작업 후 자동 학습과 기록 적용은 하네스의 저장소·후크가 필요합니다.

사용하기 전에

ZIP 안의 INSTALL.md를 읽고 현재 프로젝트 또는 내 계정 전체 중 설치 범위를 선택합니다. 기존 같은 폴더는 덮어쓰지 않습니다. Company Agent에 이미 있는 기능은 중복 설치할 필요가 없습니다.

Skill은 AI가 따르는 작업 방법이며 필요한 Python 코드·참고자료를 함께 담았습니다. MCP는 별도 프로세스로 실행해 AI에 기능을 제공하는 연결 서버입니다. 스킬·도구 제작 도우미는 MCP를 만드는 스킬이며 서버 자체가 아닙니다.

여기 있는 Skill은 Company Harness 없이 사용할 수 있습니다. Python 패키지·Office·메일 연결 등 개별 의존성은 ZIP의 INSTALL.md를 확인하세요. 기억·지식 스킬은 요청 시 파일을 정리하며 상시 자동 학습을 추가하지 않습니다.

이전 square-company 이름으로 설치했다면 같은 범위에 두 사본을 설치하지 마세요. 설치기는 중복을 알리고 기존 자료를 보존합니다. 출처와 사용 코드 해시는 PACKAGE_SOURCE.json에 있습니다.

다시 만들기

저장소에서 python -X utf8 scripts/build-skill-packages.py를 실행합니다. --check는 최신 여부만 검사합니다. 같은 입력은 같은 ZIP을 만들며 불필요하게 파일을 다시 쓰지 않습니다.
