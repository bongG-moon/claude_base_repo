# HTML 보고서·발표 자료: 공개 사례 검토 기록

검토일: 2026-10-26. 스킬 제작자가 공개 원문과 브라우저 화면을 확인한 기록입니다.
**실행 단계가 아닙니다.** 평소 작성에는 디자인 문서에 요약된 원칙을 사용하며 이 링크를
다시 검색·열람하거나 외부 코드를 설치하지 않습니다. 다음은 인기 순위가 아니라 실제 내용을 확인한 사례입니다.

## 1. Benford's Law — 설명을 따라가며 이해하는 데이터 보고서

- 원문: https://benfords-law-explainer.netlify.app/
- 선정 근거: https://pudding.cool/pudding-cup/ 의 2025 수상작 목록에서 확인했습니다.
- 확인한 화면: 질문과 짧은 데이터 표로 시작하고, 분포 차트 뒤에 해석을 둡니다. 차트에 데이터 이름·출처·비율 기준을 표시하며 뒤에서 적용 조건과 한계를 설명합니다.
- 반영: 어려운 분석은 질문 → 예시 → 비교 → 해석 순서로 설명합니다. 차트와 해석을 가까이 두고 원자료·집계 기준을 남깁니다. 이 구성은 스크롤 보고서뿐 아니라 설명용 장표에도 적용합니다.
- 옮기지 않은 부분: 사례의 긴 스크롤 연출, 떠 있는 제목판, 전체 데이터 시뮬레이션. 업무 요약에 그대로 쓰면 읽기 시간이 늘고 본문을 가릴 수 있습니다.

## 2. State of JavaScript 2024 — 큰 조사 결과를 탐색하는 보고서

- 원문: https://2024.stateofjs.com/en-US/
- 확인한 본문: https://2024.stateofjs.com/en-US/demographics/
- 확인한 화면: 주제별 목차와 큰 장 제목, 응답자 수를 포함한 소개, 질문·해석·가로 막대 비교가 이어집니다. 비율과 응답 수를 함께 읽을 수 있습니다.
- 반영: 첫 결론·집계 범위와 세부 결과를 구분합니다. 긴 보고서는 주제별로 나누고, 지표만 던지지 않고 해석·기준·상세 자료를 함께 둡니다. 비교 항목 이름이 길면 가로 막대나 표를 고려합니다.
- 옮기지 않은 부분: 어두운 배경·영문 장식 폰트·대규모 질의 빌더·공유/구독 UI. 선택한 한국어 글꼴과 디자인을 유지하며 업무 보고에 필요한 탐색만 사용합니다.

## 3. Quarto Reveal.js 공식 데모 — HTML 발표 구성

- 원문: https://quarto.org/docs/presentations/revealjs/demo/
- 확인한 화면: 표지의 제목·부제 위계, 페이지 번호, Column Layout 장표의 짧은 설명과 더 넓은 표 영역을 확인했습니다. 원문에서 스크롤 보기·짧은 전환 등 지원 예제도 확인했습니다.
- 반영: 발표형은 한 장표의 메시지와 근거를 분리해 구성하고 표·차트가 읽힐 폭을 확보합니다. 설명이 길거나 표가 크면 다른 구획으로 나눕니다. 기존 스크롤/페이지 보기와 짧은 전환을 사용합니다.
- 옮기지 않은 부분: Quarto·Reveal.js 런타임, R 실행, iframe, 외부 플러그인. 현재 제작기의 지원 필드로 구현하며 발표용 라이브러리를 추가하지 않습니다.
