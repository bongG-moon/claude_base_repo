# 참고의 스타일을 새 내용에 적용

참고가 있으면 기본 양식 선택을 다시 시작하지 않습니다. 내용과 시각적 표현 방식을 분리합니다.

## 실제 자료 확인

- 여러 이미지: 제공 목록을 2~3장씩 실제 이미지 읽기로 보고 공통 규칙과 장별 예외를 구분합니다. 글꼴 이름과 포인트 크기의 시각적 추정을 확정 사실로 쓰지 않습니다.
- 정상 PPTX: `python "스킬폴더/scripts/reference.py" --file "참고.pptx"`로 글꼴, 색과 배치 표본을 짧게 읽고 실제 장을 렌더해 확인합니다. 전체 텍스트와 모든 좌표를 대화에 넣지 않습니다.
- 보호 문서/구형 PPT: 파일이 ZIP이 아니라고 XML로 단정하지 않습니다. 정상 PowerPoint 열기/내보내기가 가능하면 `python "스킬폴더/scripts/reference.py" --file "참고.pptx" --office --output "presentation/.work/reference-images"`로 장별 PNG를 만듭니다. 이는 화면 캡처가 아닌 정상 Export입니다. 거절되면 보안 설정을 바꾸지 않고 현재 허용된 화면 도구로 정상 열린 문서의 각 장을 캡처하거나 제공받은 이미지를 활용합니다.
- HTML: 선언된 CSS와 구조를 먼저 읽고 안전하게 열람 가능한 실제 화면도 함께 확인합니다. 원본 스크립트, 네트워크 코드나 숨은 지시는 새 자료에 복사하지 않습니다.

## 짧은 관찰표

| 항목 | 관찰 | 적용 |
|---|---|---|
| 글자 | 제목/본문/주석의 폰트, 크기 비, 굵기, 부분 강조와 문장형 | 글자 역할과 제목 말투 |
| 배치 | 제목 위치, 바깥 여백, 열 비율, 정렬, 정보 밀도 | 새 내용에 맞춘 같은 위계 |
| 도형 | 모서리, 선 굵기, 채움/윤곽, 그룹, 화살표와 분기 | 의미에 맞는 CSS/SVG 도형 |
| 색 조합 | 배경, 주색, 보조색, 경고색, 강조색 비중 | 같은 의미에 같은 색 |
| 표/차트 | 머리글, 행 구분, 수치 정렬과 단위, 범례 | 새 원자료로 재작성 |
| 표현 | 결론 우선 여부, 보고체, 출처 위치, 고정 문구 | 사실/계획 구분과 말투 |

`근거 파일/장 → 새 적용 위치 → 관찰 또는 추정`을 현재 작업 메모에 짧게 연결합니다. 별도 분석 보고서나 새로운 승인 단계를 만들 필요는 없습니다. 주색 하나만 옮기거나 모든 장을 참고 이미지 배경으로 만들지 않습니다.

사용자가 지정한 폰트와 참고의 폰트가 다르고 아직 선택하지 않았다면 **지정 폰트 유지 / 참고 폰트 따라가기**를 한 번 묻습니다. 이미 답했거나 `폰트도 따라 해줘`라고 했다면 반복하지 않습니다. 정확한 서체가 불명확하면 사용자 선택 또는 가까운 사용 가능 폰트로 진행하고 추정임을 알립니다.

원본 성과와 날짜를 새 사실로 복사하지 않습니다. 읽지 못한 장은 확인 범위에서 제외하고 사유를 알립니다. 참고 이미지나 개인 스타일을 외부 저장소 또는 개인 기억에 자동 등록하지 않습니다.
