# 화면과 동작을 함께 맞추기

## 디자인

- 원본의 주된 내용과 보조 내용의 비율을 유지합니다. 왼쪽의 작은 카드 때문에 오른쪽 절반이
  비어 보이면 컨테이너 폭과 열 배치부터 확인합니다. 원본의 의도적인 여백과 누락된 콘텐츠를 구별합니다.
- 제목, 본문, 숫자, 보조 문구를 적은 수의 단계로 나눕니다. 한글은 단어 단위로 자연스럽게 줄바꿈하고,
  긴 URL이나 식별자는 셀 밖으로 튀어나오지 않게 별도로 처리합니다.
- 공간은 같은 단위로 조정하고 관계있는 제목과 내용을 가깝게 둡니다. 표, 리스트, 설명을 모두
  비슷한 카드로 바꾸지 않습니다. 기능의 주종관계는 버튼 색과 위치로 드러냅니다.
- 원본 색과 글꼴이 확인되면 그대로 우선합니다. 접근성 보정이나 요청에 따른 의도적인 변경은 짧게 알립니다.
- 의미 있는 전환만 구현합니다. 관찰된 메뉴 열림, 필터 결과 변화, 탭 전환을 가벼운 CSS로 표현하고
  `prefers-reduced-motion`에서 움직임을 줄입니다. 정지 이미지에 숨은 애니메이션을 추측해 추가하지 않습니다.
- 입력에는 라벨, 아이콘 버튼에는 이름, 키보드에는 보이는 포커스를 둡니다. 모달은 닫기와
  포커스 복귀를 구현합니다. 구현하지 않은 버튼을 작동하는 것처럼 꾸미지 않습니다.

## 데이터가 보이는 화면

화면 재현과 함께 실제 데이터를 사용할 수 있는 결과를 요청했다면 다음을 기본으로 합니다.
원본을 그대로 맞추는 것이 우선인 요청에서는 원본에 없는 기능을 몰래 추가하지 않고 필요한 차이만 알립니다.

| 데이터 상황 | 적용할 동작 |
| --- | --- |
| 열이 많거나 긴 문장이 있음 | 표 전용 가로 스크롤, 고정 머리글, 의미 있는 최소 열 폭 |
| 행이 화면을 길게 밀어냄 | 표 안 세로 스크롤 또는 페이지 이동, 전체 건수와 현재 범위 |
| 목록에서 항목을 찾는 업무 | 실제 값으로 동작하는 검색, 필요한 필터, 정렬 표시, 초기화 |
| 데이터를 다시 사용하는 업무 | 현재 검색 결과와 전체 데이터의 다운로드 범위를 구분 |

- 검색, 정렬, 페이지 이동, 다운로드는 같은 원본 데이터와 필터 상태를 사용합니다.
  페이지 이동은 검색된 전체 목록 위에서 적용하고 검색 변경 시 유효한 페이지로 돌아갑니다.
  현재 검색 결과 다운로드는 현재 페이지뿐 아니라 필터에 맞는 전체 행을 뜻합니다.
- 실제 표의 순서, 열 이름과 숫자 단위를 내보내기에도 유지합니다. CSV에는 한국어용 UTF-8 BOM을 넣고
  쉼표, 따옴표, 줄바꿈을 정상 처리합니다. 문자 셀의 `=`, `+`, `-`, `@` 등 수식 시작값은
  스프레드시트에서 실행되지 않도록 안전하게 내보내고 원래 숫자값과 구분합니다.
- `검색 결과 없음`, `불러오는 중`, `가져오기 실패`를 구별합니다. 로컬 자료만 쓰는 화면에
  가짜 서버 로딩이나 성공 알림을 만들지 않습니다. 연결되지 않은 서버 기능은 데모라고 표시합니다.
- 행 수가 매우 많으면 전부 DOM에 붙이지 않습니다. 기존 프로젝트의 페이지 조회나 가상 목록을
  재사용합니다. 보기 편하게 만드는 요청만으로 새 서버와 큰 UI 라이브러리를 설치하지 않습니다.

## 비교와 완료

1. 같은 화면 폭, 같은 스크롤 위치와 선택 상태에서 원본과 결과를 비교합니다.
   먼저 구역 누락과 열 폭, 다음으로 글꼴과 간격, 마지막으로 테두리와 그림자를 봅니다.
2. 주요 입력과 버튼을 직접 실행합니다. 검색 뒤 페이지 이동, 필터 초기화,
   빈 결과, 긴 문장, 다운로드 행 수와 한글을 확인합니다. 숫자 정렬은 문자열 순서로 검사하지 않습니다.
3. 좁은 화면에서 페이지 전체가 가로로 넘치지 않는지 봅니다. 넓은 데이터 표의 내부 스크롤은 허용합니다.
4. 관련 빌드와 테스트를 한 번 실행하고 발견된 차이를 고칩니다. 같은 원인의 실패가 반복되면
   무작정 재시도하지 않고 확인하지 못한 부분을 정리합니다. 이미지 비교 점수만으로 동작 성공을 판단하지 않습니다.

실제 브라우저가 없어 실행 확인을 못했다면 코드 검토와 실행 확인을 구별합니다.
특정 브라우저 플러그인 설치나 회사 모델 호출은 이 확인을 위한 필수 조건이 아닙니다.
