# Mail mutations and capacity cleanup

Only supported corporate MCP operations can send, categorize, move or archive;
the local Classic Outlook pilot cannot. An answer grouping related mail does not
change Outlook. Preview the concrete selection/action and use real tool approval;
keep refusals binding and never retry an ambiguous send/move without its receipt.

PST cleanup needs supported archive tools, destination/period, protection-preserving
copy verification and separately approved original moves. Reuse prior choices.
Copy alone does not free quota; server quota and local OST/PST size differ. Do not
manipulate PST/OST bytes, attach new PSTs silently or report success from a plan.

Polish reply prose before its send preview, preserving facts, conditions, quoted
text, uncertainty and obligation strength. Do not rewrite approved content or
invent familiarity. Connection/search/selection belong to the same mail task;
no extra learning task or verification ritual for a read-only answer.
