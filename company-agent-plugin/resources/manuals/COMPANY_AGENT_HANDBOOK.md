# 하네스의 저장 공간과 동작

## 1. 회사 배포와 개인 공간

| 영역 | 소유와 역할 | 업데이트 영향 |
|---|---|---|
| 회사 하네스 | 기억 조회, 학습과 스킬 선택의 공통 실행 기반 | 새 버전 폴더로 교체 |
| 회사 지식 | 배포된 공통 정의와 기준 | 회사 원본 유지, 개인 보완과 구분 |
| 개인 전체 | 기억, 지식, 학습 결과와 내 스킬 | 기본 하네스 업데이트 후에도 유지 |
| 현재 프로젝트 | 해당 폴더에만 필요한 기억과 선택 | 다른 프로젝트에 자동 적용하지 않음 |
| 개별 업무 스킬 | 각자 설치한 업무 기능 | 하네스와 별도로 선택 및 업데이트 |

기본 사용자 상태 경로는 `%LOCALAPPDATA%/CompanyAgent/states/user`이며 실제 설치가 제공한 stateRoot를 우선합니다. 사용자 설치의 프로젝트 자료는 그 아래 `project-scopes/<folder-hash>`로 나뉩니다. 폴더를 옮기면 같은 범위라고 자동 추정하지 않습니다.

## 2. 어디에서 기록을 볼 수 있나요?

| 위치 | 내용 |
|---|---|
| memory | 추출한 선호와 업무 맥락 Markdown |
| knowledge | 개인 업무 정의와 출처 |
| learning | 학습 후보, 적용 결과와 되돌리기 기록 |
| personal-root | 예전 방식으로 저장한 개인 자산. 자동 이전하지 않음 |
| Claude 개인 skills 또는 프로젝트 .claude/skills | 새로 만드는 개인 스킬의 실제 원본 |

정확한 파일 위치는 조회 결과에서 확인합니다. 경로만 보고 저장 성공을 판단하지 않고 실제 저장 응답과 내용을 확인합니다. 회사 공용 원본과 사용자 개인 원본이 같은 파일이 되지 않도록 유지합니다.

## 3. 기본 스킬의 역할

| 스킬 | 역할 |
|---|---|
| company-agent | 현재 요청, 기억과 설치된 스킬 사용을 조율 |
| personal-memory | 개인 선호와 업무 맥락 저장 및 조회 |
| personal-knowledge | 업무 정의와 출처 저장 및 조회 |
| self-learning | 근거가 있는 교정과 반복 선택, 개인 절차 개선 기록 |
| asset-factory | 실제 업무 절차를 개인 스킬로 저장하고 같은 원본 수정 |

기본 하네스의 asset-factory는 개인 스킬 저장에 집중합니다. 개별 배포의 같은 이름 스킬은 실행 도구와 MCP 제작까지 지원하는 별도 기능입니다. 둘 다 설치돼 목적이 겹치면 실제 기능과 출처를 비교하고 선택합니다.

## 4. 자동 처리는 무엇을 하나요?

| 시점 | 필요한 처리 |
|---|---|
| 새 연결 | 현재 설치 범위와 실행 정보 준비 |
| 새 요청 | 관련 기억과 지식, 설치된 스킬 목록을 제한적으로 제공 |
| 도구 실행 전후 | 현재 선택과 실제 실행 상태를 연결하고 변경 근거 기록 |
| 업무 종료 | 실제 결과와 미완료 상태를 구분하고 필요한 학습 근거를 유지 |

기본 하네스는 HTML/PPT 제작기를 강제하지 않고 이미지 읽기를 별도 VLM으로 가로채지 않습니다. 일반 조회를 위해 학습 질문이나 추가 모델 호출을 만들지 않습니다. 도구 실행 가능 여부는 Claude와 기존 회사 권한을 따릅니다.

## 5. 경험이 학습으로 바뀌는 순서

사용자의 교정 또는 실제 작업 근거 → 작은 학습 후보 → 기존 항목과 중복 및 적용 범위 확인 → 적용 또는 보류 → 다음 업무에서 필요한 기억 조회 순서입니다.

“아직 독립된 업무의 반복 근거가 부족함”, “이미 반영된 내용”, “되돌린 내용의 재적용 방지”처럼 판단 이유를 기존 조회에서 설명합니다. 후보와 적용 완료는 다르고, 기억이 모델에 전달된 것과 실제 효과도 다릅니다. 판단 근거가 없는 작업을 억지로 학습하지 않습니다.

새 절차 전체를 자동으로 생성하는 기능은 아닙니다. 기존 등록 개인 스킬의 작은 점검 항목만 정해진 범위에서 수정하며 새 스킬은 사용자 요청이나 제안 수락 후 만듭니다. 회사 배포본과 정책, 권한 설정은 자동 학습으로 바꾸지 않습니다.

## 6. 기존 환경을 유지하는 업데이트

새 하네스를 설치해도 개인 기억과 지식, 스킬, 기존 모델과 MCP 설정은 보존합니다. 회사 기능 스킬은 새 기본 설치에 포함하지 않으며, 예전 회사 스킬을 가리키는 선택이 있으면 없는 후보를 자동 대체하지 않습니다. 필요한 기능은 개별 ZIP으로 선택합니다.

기존 대화에는 이전 지시가 남을 수 있으므로 설치 후 Claude를 새로 연결하고 새 대화에서 확인합니다. 이전 버전 캐시나 개인 자료를 수동으로 지워야 하는 절차는 아닙니다.

1.5.1의 설치 화면에서 **사용하지 않는 이전 설치 파일 삭제 (백업 없음)** 옵션을 선택하면 설치 성공 후 검증된 미사용 설치본과 Claude 플러그인 캐시를 정리합니다. 기본은 꺼져 있으며 개인 기억과 지식, 학습 기록, 스킬, 백업, 작업 파일과 설정은 삭제 대상이 아닙니다.

Claude가 실행 중이거나 다른 설치 범위에서 쓰는 버전, 원본 검증이 안 되거나 수정된 파일은 정리를 보류합니다. 로컬 MCP나 다른 플러그인이 있거나 프로젝트 또는 설정을 확인할 수 없는 경우에는 안전을 위해 정리를 보류할 수 있습니다. 일부만 정리돼도 설치 성공은 유지하고 남은 이유를 안내합니다. 정리용 새 백업은 만들지 않지만 기존 설치 전 개인 자료 안전 백업은 유지합니다.
