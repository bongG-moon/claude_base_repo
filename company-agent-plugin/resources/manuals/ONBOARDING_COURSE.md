# 시작하기

Company Harness는 Claude Code가 내 선호와 업무 맥락을 다음 대화에서도 필요한 만큼 참고하도록 돕습니다. 기억, 업무 지식, 반복 절차를 개인 공간에 남깁니다. 모델 자체를 학습시키는 기능은 아닙니다.

## 1. 기존 Claude 환경에 추가하기

하네스 설치 파일을 실행하고 개인 전체 또는 선택한 업무 폴더 범위를 고릅니다. 기존 모델, 로그인과 연결 도구 설정은 유지합니다. 설치 후 Claude Code를 새로 연결합니다. Workspace 앱은 같은 Claude Code를 쓰는 별도 화면이며 하네스와 다른 설치물입니다.

1.5.1의 **사용하지 않는 이전 설치 파일 삭제 (백업 없음)** 옵션은 선택 사항이며 기본은 꺼져 있습니다. 선택하면 설치 성공 후 확인된 미사용 설치본과 Claude 플러그인 캐시만 정리합니다. 개인 기억과 지식, 학습 기록, 스킬, 백업, 작업 파일과 설정은 유지합니다. 정리용 새 백업은 만들지 않으며 기존 설치 전 안전 백업은 그대로입니다. 사용 중이거나 원본 확인이 어려운 파일은 보류하므로 직접 지울 필요는 없습니다. 로컬 MCP나 다른 플러그인이 있거나 프로젝트 또는 설정을 확인할 수 없는 경우에는 안전을 위해 정리를 보류할 수 있습니다.

```text
내가 어떤 일을 하고 어떤 방식의 답변을 선호하는지 현재 저장된 내용만 알려줘.
새 기억을 만들거나 다른 프로젝트 자료를 합치지는 마.
```

처음에는 저장된 내용이 없을 수 있습니다. 하네스가 모르는 사실을 아는 것처럼 답하지 않는지 확인합니다.

## 2. 내 방식 하나 알려주기

```text
앞으로 업무를 설명할 때 결론을 먼저 짧게 알려주고, 확인한 사실과 아직 확인하지 못한 부분을 구분해줘. 이 선호를 기억해줘.
```

처음 영구 저장할 범위가 아직 정해지지 않았다면 개인 전체 또는 이 프로젝트 중 한 번 선택합니다. 저장된 내용과 범위를 확인하세요. 이번 답변만 짧게 해달라는 말은 장기 선호가 아닙니다.

## 3. 새 대화에서 다시 사용하기

같은 업무 폴더에서 새 대화를 열고 다음처럼 요청합니다.

```text
가상 업무 세 가지를 진행 중이야. 교육 준비는 완료, 신청자 확인은 진행 중, 결과 정리는 아직 시작 전이야. 내 설명 선호에 맞춰 정리해줘.
```

답변이 마음에 들지 않으면 구체적인 부분만 고칩니다. 저장됐다는 사실과 실제 답변에 적용됐다는 사실은 별개입니다.

## 4. 반복할 절차를 스킬로 남기기

```text
방금 진행한 업무 정리 순서를 다음에도 쓸 수 있게 내 스킬로 만들어줘. 입력할 자료, 처리 순서, 확인할 항목만 간단히 남겨줘.
```

이미 같은 목적의 개인 스킬이 있으면 같은 원본을 수정합니다. 새 스킬은 실제 사용 이름과 위치를 알려주며 Claude의 /스킬이름으로 사용할 수 있습니다. 목록에 바로 보이지 않으면 현재 버전의 새로고침 또는 새 연결에서 확인합니다.

## 5. 무엇을 배웠는지 확인하기

```text
지금까지 저장된 내 기억과 학습 결과를 보여줘. 실제 적용된 것과 아직 근거가 부족해 보류된 것을 구분해줘.
```

또는 `/company-agent:learning`을 입력합니다. 학습이 일어나지 않은 작업도 정상입니다. 조회, 인사나 한 번의 선택을 억지로 학습하지 않습니다. 원하면 자동 학습을 중지하거나 특정 변경을 되돌릴 수 있습니다.

## 6. 필요한 업무 기능만 더하기

HTML 보고서, PPT, Excel 구조화, 파일 정리, 웹 제작과 데이터 조회는 개별 스킬입니다. 하네스 설치에는 포함되지 않습니다. `Individual Skills` 안내에서 필요한 항목만 설치합니다. 하네스 없이 개별 스킬만 사용해도 됩니다.

```text
현재 설치된 스킬 중 이 업무에 사용할 수 있는 것을 찾아줘. 없으면 현재 도구로 가능한 범위를 알려줘.
```

기본 하네스는 비전 모델 전환, 브라우저 연결, 업무 도구 설치를 자동으로 하지 않습니다.
