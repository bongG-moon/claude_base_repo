회사 관리 영역

공통 정책, 부서별 업무 기준, 공통 스킬·지식·양식을 관리합니다. 부서 기준도 회사 기준 안에 포함됩니다.

필수 기준은 유지합니다. 회사 기본값은 허용된 범위에서 개인화합니다. 문서에 적힌 문장은 정책으로 자동 승격되지 않습니다.

개인 업무 영역

나의 표현 선호, 기억, 지식, 스킬과 업무별 작업 폴더를 사용합니다. 회사 업데이트가 개인 자료를 임의로 덮어쓰지 않습니다.

프로젝트는 일을 적용하는 범위입니다. 별도 팀팩을 설치하거나 세 번째 정책 체계를 만들지 않습니다.

1. 자료 하나 읽기2. 결과 만들기3. 원하는 방식으로 고치기4. 내 방식 하나 저장하기5. 새 업무에서 다시 쓰기

회사 공통 / 개인 전체 / 이 프로젝트를 먼저 구분합니다. 각 범위 안에서 기억·지식과 업무 구성을 확인합니다. 새 기억·스킬 저장은 개인 전체 또는 이 프로젝트를 선택합니다.

더 익숙해지면 전체 코스의 6–8단계에서 공통·내 기억 비교, 공통·내 하네스와 폴더 적용 범위의 차이, 개인 스킬·계산 도구 만들기도 실습할 수 있습니다. 확장 실습은 선택입니다.

통합 가이드 · 준비물 없이 시작하기

읽기만 해도 됩니다. 안내서를 여는 것만으로 AI 호출·설정 변경·업무 실행은 하지 않습니다. 이미 익숙하다면 아래 필요한 예문부터 바로 사용하세요.

회사 공통 / 개인 전체 / 이 프로젝트를 먼저 구분하고 기억·지식과 업무 구성을 확인하세요. 새 기억·스킬 저장은 개인 전체 또는 이 프로젝트 중 선택합니다. 예문은 입력창에만 넣으며 보내기 전에는 실행하지 않습니다. 저장 요청은 동의할 때만 보내세요.

1. 자료 하나 읽기

자료가 없어도 시작합니다. 가상 MD 파일부터 만들고 다음 요청에서 읽어 보세요. 자세한 PPT 생성·읽기 순서는 통합 가이드에 있습니다.

확인할 것 · 생성 후 아래 읽기 예문을 보내세요. MD 읽기와 Office 읽기 성공은 다릅니다. 기본 CLAUDE.md가 생겨도 업무 결과 파일과는 별개입니다.

잘 안될 때

파일 없이 세 달 수치를 대화에 붙여 넣어 요약 연습만 해도 됩니다. Office가 없으면 PPT 읽기 시험은 미실행으로 남깁니다.

2. 결과 만들기

원하는 결과와 확인 기준을 함께 알려주면, 무엇을 완성해야 하는지 더 분명해집니다.

확인할 것 · 선택 질문에서 실제로 기다리는지 확인하세요. 결과 파일을 열고 목표 300건·실적 330건·달성률 110%와 대조하세요.

잘 안될 때

입력한 선택을 반복해서 물으면 이미 정한 내용을 짧게 알려주세요. 질문 대기는 오류나 완료가 아닙니다.

3. 원하는 방식으로 고치기

이번 결과 수정과 앞으로 계속 적용할 선호 저장은 다른 일입니다.

확인할 것 · 요청한 순서가 바뀌고 원래 수치·출처가 유지되는지 확인하세요.

잘 안될 때

원하는 예시 한 줄을 보여주세요. 모든 내용을 처음부터 다시 실행할 필요는 없습니다.

4. 내 방식 하나 저장하기

기억은 다음 업무에도 필요한 짧은 선호입니다. 원본 문서나 대화를 통째로 저장하지 않습니다.

확인할 것 · 저장 범위 질문에 개인 전체 또는 이 프로젝트를 선택하세요. 기억·하네스 관리의 해당 범위 → 기억·지식에서 확인합니다. 회사 공통에 자동 공유되지 않습니다. 연습 후 사용 중단할 수 있습니다.

잘 안될 때

프로젝트 설치와 전체 사용자 설치의 기억은 다를 수 있습니다. 저장 위치를 바꾸거나 초기화하기 전에 범위를 확인하세요.

5. 새 업무에서 다시 쓰기

저장됨, 다시 조회됨, 실제 결과에 반영됨은 각각 확인해야 합니다.

확인할 것 · 같은 작업 폴더의 새 대화에서 조회하고 실제 저장 내용과 비교하세요. 말투가 비슷하다는 것만으로 통과하지 않습니다.

잘 안될 때

다른 설치 범위로 들어갔는지 확인하세요. 기억을 찾기 위해 PC 전체를 검색하거나 저장소를 자동 합치지 않습니다.

잘 안될 때는 초기화보다 상태 확인부터.

  1. 작업 폴더와 설치 범위가 같은지 확인하세요. 프로젝트 설치라면 해당 프로젝트에서 Claude를 열어야 합니다.
  2. 설치 압축파일을 푼 폴더의 Diagnose-CompanyAgent.cmd를 실행하고 문제가 발생한 작업 폴더를 입력하세요. 이 검사는 설정을 고치거나 업무를 재실행하지 않습니다.
  3. 목록 발견 → 본문 로드 → 실제 실행 → 결과 확인은 별개입니다. ‘미확인’은 곧바로 실패·권한 거절·스킬 없음이라는 뜻이 아닙니다.
  4. 담당자에게 단계별 진단 결과만 먼저 전달하세요. 사용량 분석은 별도로 지정한 로컬 로그에만 적용하며, 회사 단가가 없으면 비용을 계산하지 않습니다.

다른 역할의 스킬은 작업 단계별로 함께 사용할 수 있습니다. 같은 역할이 겹치면 기존 선택을 따르거나 사용자에게 묻습니다. 관련 스킬이 없으면 없는 스킬을 억지로 호출하지 않습니다.
