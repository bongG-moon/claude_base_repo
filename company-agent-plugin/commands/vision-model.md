# 이미지 전용 모델

사용자가 실제 모델 ID를 지정했으면 그대로 사용합니다. 지정하지 않았다면 한국어로 한 번만 묻습니다.
“이미지 확인에 어떤 모델을 사용할까요? 실제 모델 ID를 입력하거나 HCP-Vision-Latest를 선택해 주세요.
이 PC의 이미지 작업에 저장해 사용하며, 모델 호출 장애 때만 HCP-Vision-Latest로 한 번 재시도합니다.”
취소하거나 답하지 않았으면 저장·모델 호출을 하지 않습니다. 모델 목록 조회·연결 시험·설정 파일 탐색은 하지 않습니다.

답을 받으면 후크가 제공한 `company_agent_runtime.cliCommand` 뒤에
`vision configure --state-root "<stateRoot>" --model "<실제 모델 ID>"`를 붙여 한 번 실행합니다.
표시 이름으로 ID를 추측하거나 인증 정보·주소를 입력받지 않습니다.
이 명령은 전용 읽기 작업자 하나와 선택값만 관리합니다. 메인 모델, 기존 사용자 작업자, 권한, MCP는 변경하지 않습니다.
`restartRequired=true`이면 저장 완료를 알리고 Claude를 다시 열어 새 연결에서 사용하도록 안내합니다.
앱은 현재 작업을 마친 뒤 새 대화를 엽니다. 같은 연결의 다음 질문만으로 바뀌었다고 말하거나 재시도하지 않습니다.
설정만 요청했다면 이미지 시험은 하지 않습니다. 이후 `/company-agent:vision-model` 또는 “이미지 모델을 바꿔줘”로 변경할 수 있습니다.
현재 값만 물으면 `vision status --state-root "<stateRoot>"`를 실행합니다.
