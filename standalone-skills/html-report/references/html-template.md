# 첨부 HTML 양식 확인

HTML 양식이 있을 때만 읽습니다. 원본 전체를 모델에 넣거나 원본 스크립트와 외부 자원을 실행하지 않습니다.
참고 파일은 10MiB 미만(10,485,760바이트 미만)이며 이 크기는 로컬 처리 한도입니다.

```text
python "스킬폴더/scripts/report.py" reference --file "참고.html" --preview "작업폴더/양식-미리보기.html"
```

1. `previewCreated:true`인지 확인합니다. 분석만 실행한 결과를 미리보기가 만들어졌다고 말하지 않습니다.
2. 반환된 `previewLink`를 채팅에 그대로 보여주고 `previewPath`도 안내합니다. 링크가 열리지 않으면 해당 HTML을 파일 탐색기에서 두 번 클릭하도록 안내합니다. 자동으로 브라우저를 열었다고 주장하지 않습니다.
3. 이 파일은 색과 글꼴 등을 적용한 가상 내용 예시입니다. 원본 화면 전체를 복제한 미리보기와 구분합니다. `layoutHints`는 태그와 이름에서 얻은 목차, 카드, 단계 목록 단서이며 실제 화면을 확인했다는 증거가 아닙니다.
4. 링크 바로 다음에 `이 느낌으로 진행 / 수정할 부분 / 다른 양식`을 한 번 묻습니다. 기존에 같은 미리보기를 확인했다면 반복 질문하지 않습니다.
5. 반환된 `htmlTemplate`과 `templateReview`를 같은 job에 합치고, 실제 승인 뒤에만 `templateReview.confirmed:true`로 둡니다. 해시는 직접 만들지 않습니다. 이후 빠진 분량, 보기 방식, 글꼴만 확인합니다.

응답 예: `[양식 미리보기 열기](<반환된 절대경로>)`와 파일 위치를 먼저 제공하고 “색과 글꼴을 적용한 예시입니다. 이 느낌으로 진행할까요?”라고 이어갑니다. 예시 경로를 실제 결과처럼 쓰지 않습니다.
