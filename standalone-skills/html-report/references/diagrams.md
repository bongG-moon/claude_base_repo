# 요청한 작업 흐름·구조를 설명하기

요청이 작업 흐름·관계·구조 설명일 때만 씁니다. 단순 완료 보고나 일반 HTML 보고서에는 자동 추가하지 않습니다.
실제 파일·도구·입출력·수행 결과를 근거로, 확인하지 않은 실행은 예정/미확인으로 표시합니다.

현재 작업을 설명할 수 있는 5~9개 핵심 단계부터 구성합니다. 각 단계는 쉬운 한국어 이름과
입력→동작→결과 한 줄을 넣고, 분기·반복·순서가 실제로 있을 때만 화살표를 연결합니다.
기존 표가 더 명확하면 표를 사용합니다. 예쁜 관계도를 위해 존재하지 않는 단계를 만들지 않습니다.

복잡한 도식은 독립 HTML/SVG로 작성해 최종 보고서 하나 안에 넣을 수 있습니다. SVG text와 HTML
설명은 선택·검색 가능하게 남기고, Noto Sans KR 등 선택한 PC 글꼴을 사용합니다. 화면이 좁아지면
단계 목록으로 읽을 수 있게 합니다. 도형 장식보다 실제 내용과 순서를 먼저 검사합니다.

사용자가 흐름을 따라가는 데 도움이 될 때만 경로 강조·단계별 펼치기를 사용합니다. 모든 내용을 즉시 읽을 수 있고,
움직임 감소 설정에서 동작을 끌 수 있어야 합니다. 외부 이미지·폰트·스크립트는 승인 없이 불러오지 않습니다.
직접 만든 HTML은 내용·링크·좁은 화면을 확인한 뒤 최종 하나를 전달합니다. 별도 PNG나 애니메이션 파일은 요청할 때만 만듭니다.
