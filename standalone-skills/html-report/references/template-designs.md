# 10개 HTML 보고서 양식의 디자인 참고

## 언제 읽는가

사용자가 `style`을 선택한 뒤 **선택한 양식의 항목만** 읽습니다. 전체 문서는 10개 양식을 비교하거나 갤러리를 개선할 때 읽습니다. 이 문서는 실제 보고서 양식의 시각 설계를 다룹니다. 내용 배치를 선택하는 `reference-1`, `reference-2`, `reference-3`와는 별도입니다.

`assets/design-picker.html`은 10가지 디자인을 바로 비교하는 갤러리입니다. 카드의 **완성 예제 열기**에서 전체 자료를 확인하고, 디자인을 고른 뒤 선택 패널에서 글꼴과 조건을 조정합니다. **선택 내용 복사** 후 채팅에 붙여 넣으면 전달됩니다. 자동 복사가 제한되면 **전달할 문장 확인**이 열리므로 선택된 문장을 직접 복사합니다. 이미 정한 조건은 유지하며 이 화면이 별도 질문이나 설치를 추가하지 않습니다.

아래 링크는 2026-11-03에 확인한 공식 서비스 또는 제작자의 공개 자료입니다. 참고할 원리와 아래의 업무용 적용안은 구분합니다. 원본 사이트의 코드, 문구, 로고, 사진, 유료 폰트와 영상은 복제하지 않습니다. 참고 사이트를 열지 않아도 로컬 보고서는 완성되어야 하며, 링크나 선택 때문에 외부 자산을 불러오지 않습니다.

공통 기준은 제목, 핵심 판단, 근거의 위계입니다. 색만 바꾸지 말고 여백, 제목 크기, 카드 밀도, 구분선, 표와 차트의 배치를 함께 설계합니다. 사용자가 지정한 섹션 순서와 `layout`, `contentOrder`, 폰트와 보기 방식은 유지합니다. 실제 데이터에 없는 수치와 추세를 장식으로 만들지 않습니다. 본문과 수치는 충분한 대비를 유지하고, 색 외에 라벨로 차이를 구분합니다. 좁은 화면에서는 한 열로 읽히고 인쇄 시에는 효과를 줄여도 정보가 남아야 합니다.

## minimalism: 미니멀리즘

참고: [Linear — A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh)

- 참고한 요소: 보조 UI의 시각적 무게를 줄이고 본문을 먼저 보이게 하는 위계, 정렬, 부드러운 구분선입니다. Linear의 공식 설명은 모든 요소에 같은 강조를 주지 않는 원칙을 설명합니다.
- 업무용 조정: 밝은 중성 바탕과 한 가지 포인트 색을 사용합니다. 제목과 본문 사이의 간격을 분명하게 두고, KPI는 숫자의 크기와 기준선으로 묶습니다. 표와 차트는 두꺼운 상자보다 간결한 가로선과 직접 라벨로 읽힙니다.
- 업무 활용: 정기 실적, 경영진 브리핑, 여러 사람이 반복해서 읽는 운영 보고에 맞습니다.
- 복제 범위: Linear의 앱 화면을 재현하지 않습니다. 정돈된 정보 위계와 여백만 보고서에 적용합니다.

## editorial: 에디토리얼

참고: [The Pudding — Film Dialogue](https://pudding.cool/2017/03/film-dialogue/)

- 참고한 요소: 질문에서 출발해 데이터, 해설, 방법론으로 이어지는 편집 흐름입니다. 짧은 설명 사이에 넓은 그래픽을 두고 근거와 한계를 함께 제시합니다.
- 업무용 조정: 큰 제목, 짧은 도입문, 얇은 편집선과 구획을 사용합니다. 본문은 읽기 좋은 폭으로 제한하고 차트와 표는 더 넓게 펼칩니다. 명조 계열 제목은 선택 폰트가 허용하는 범위에서만 쓰며 본문 가독성을 우선합니다.
- 업무 활용: 원인 분석, 설문 해설, 개선 사례, 논거가 이어지는 성과 보고에 맞습니다.
- 복제 범위: 영화 데이터, 문구와 그래픽을 가져오지 않습니다. 지면의 리듬을 적용하며 사용자의 섹션 순서를 임의로 바꾸지 않습니다.

## bento-grid: 벤토그리드

참고: [Apple — iPad Pro](https://www.apple.com/ipad-pro/)

- 참고한 요소: 큰 핵심 문장과 대표 수치 아래에 관련 기능과 비교 근거를 묶어 설명하는 제품 페이지의 정보 위계입니다. 짧은 카드 제목과 보충 설명의 역할이 구분됩니다.
- 업무용 조정: 가장 중요한 KPI 또는 결론에 넓은 카드를 배정하고 나머지는 작은 카드로 묶습니다. 카드 내부 여백과 제목 기준선을 맞추고, 차트와 긴 표는 충분한 가로폭을 확보합니다. 모든 카드를 같은 크기와 같은 색으로 채우지 않습니다.
- 업무 활용: KPI 대시보드, 여러 과제 현황, 부문별 성과 비교에 맞습니다.
- 복제 범위: Apple의 제품 화면이나 자산을 재현하지 않습니다. 강조 수치와 보조 정보의 위계를 자체 격자 구성으로 번안합니다.

## glassmorphism: 글래스모피즘

참고: [Linear — A Linear spin on Liquid Glass](https://linear.app/now/linear-liquid-glass)

- 참고한 요소: 흐림, 마스킹, 빛과 윤곽으로 유리의 깊이를 만드는 방법입니다. 제작자는 전문적인 고밀도 화면의 읽기 품질을 위해 굴절을 재현하지 않았다고 설명합니다.
- 업무용 조정: 밝은 색 번짐 위에 유리 패널을 두되, 본문과 데이터가 놓이는 면은 충분히 밝고 안정적으로 유지합니다. 차트 눈금과 표 머리글은 배경과 분명히 구분합니다. 흐림을 지원하지 않거나 투명도 감소를 요청한 환경에는 불투명 표면을 제공합니다.
- 업무 활용: 디지털 서비스 소개, 기술 동향, 혁신 과제 브리핑에 맞습니다.
- 복제 범위: Liquid Glass의 동적 굴절이나 앱 조작을 모사하지 않습니다. 보고서의 가독성을 유지하는 정적인 유리 표면으로 적용합니다.

## neumorphism: 뉴모피즘

참고: [Kevin Al-Rizal — Neumorphism UI Kit](https://dribbble.com/shots/11652074-FREE-Neumorphism-UI-Kit)

- 참고한 요소: 제작자의 원본 UI 예시에서 같은 색의 배경과 표면, 밝고 어두운 방향 그림자, 솟음과 눌림의 구분을 참고합니다. 실제 서비스 운영 사례나 접근성 검증 사례라는 의미는 아닙니다.
- 업무용 조정: 넓은 패널에는 바깥 그림자, 소수의 지표에는 안쪽 그림자를 제한적으로 사용합니다. 표 셀마다 그림자를 넣지 않고 차트는 평평한 바탕에서 읽히게 합니다. 경계나 선택 상태는 그림자만으로 전달하지 않습니다.
- 업무 활용: 핵심 지표가 적은 운영 요약, 차분한 현황판에 맞습니다.
- 복제 범위: UI Kit의 파일과 컨트롤을 복제하지 않습니다. 깊이를 만드는 표면 원리만 자체 CSS에 적용합니다.

## brutalism: 브루탈리즘

참고: [Gumroad](https://gumroad.com/)

- 참고한 요소: 큰 타이포그래피, 분명한 블록 구획, 단색 면과 강한 테두리로 메시지를 강조하는 방법입니다.
- 업무용 조정: 제목과 핵심 판단에 굵은 활자를 사용하고, 검정 선과 한두 가지 강조색으로 구획을 만듭니다. 단단한 그림자는 표지와 대표 카드에 집중합니다. 긴 표와 본문은 장식을 줄여 읽을 수 있게 합니다.
- 업무 활용: 의사결정 제안, 캠페인 성과, 핵심 메시지가 분명한 발표에 맞습니다.
- 복제 범위: Gumroad의 캐릭터, 일러스트와 문구를 사용하지 않습니다. 강한 대비와 명확한 구획을 보고서에 적용합니다.

## gradient-mesh: 그라디언트 메시

참고: [Stripe](https://stripe.com/)

- 참고한 요소: 색이 흐르는 시각 영역과 큰 제목, 차분한 정보 영역의 대비입니다. 현재 페이지의 특정 그래픽 모양이나 렌더링 기술을 그대로 재현한다는 의미는 아닙니다.
- 업무용 조정: 자체 CSS 그라디언트를 표지와 주변 배경에 사용하고, 긴 본문과 표는 밝고 안정적인 면에 둡니다. 핵심 숫자에는 단일 강조색을 쓰고, 여러 차트의 계열 색은 같은 의미로 유지합니다.
- 업무 활용: 신규 전략, 미래 방향, 신사업과 기술 비전 소개에 맞습니다.
- 복제 범위: Stripe의 그래픽, 브랜드 색 조합과 애니메이션을 복사하지 않습니다. 풍부한 배경과 명료한 내용의 대비를 번안합니다.

## freeform: 자유양식

참고: [PORTO ROCHA — Design Threads](https://www.portorocha.com/design-threads)

- 참고한 요소: 조사, 질문, 인용과 시각 자료를 서로 다른 편집 구획으로 엮은 디지털 보고서입니다. 제작자 설명에는 네 개의 주제로 자료를 묶는 구조와 서로 다른 서체를 사용하는 구성이 소개되어 있습니다.
- 업무용 조정: 설명과 시각 자료의 폭을 다르게 두고 절제된 비대칭 여백으로 리듬을 만듭니다. 섹션의 기준선은 유지하고 본문이 읽는 순서를 잃지 않게 합니다. 긴 표는 전체 폭으로 배치하며 좁은 화면에서는 한 열로 돌아갑니다.
- 업무 활용: 현장 사례, 정성 조사, 복합 주제의 해설에 맞습니다.
- 복제 범위: 원본의 인용, 질문과 전시 이미지를 가져오지 않습니다. 자유로운 시각 배치가 임의의 내용 순서 변경을 허용하지는 않습니다.

## immersive-3d: 3D와 이머시브

참고: [Stripe — Connect: behind the front-end experience](https://stripe.com/blog/connect-front-end-experience)

- 참고한 요소: 구성 요소를 표현하는 CSS 기하 오브제, 공통 광원, 오브제와 바닥 그림자의 관계입니다. 원문은 그리드와 CSS 3D를 함께 사용하는 구현을 설명합니다.
- 업무용 조정: 표지의 제한된 영역에 자체 기하 오브제를 두고 일관된 빛과 그림자로 깊이를 만듭니다. 차트의 길이, 면적과 비교축은 평면으로 유지합니다. 실제 데이터와 관계없는 오브제를 차트처럼 보이게 만들지 않습니다.
- 업무 활용: 제품 개념, 공간 구조, 기술 제안의 도입부에 맞습니다.
- 복제 범위: 원본의 움직이는 큐브나 자산을 재사용하지 않습니다. 기본 보고서는 실제 3D 모델 뷰어가 아닌 정적인 입체 표현입니다.

## retro-y2k: 레트로와 Y2K

참고: [Poolsuite](https://poolsuite.net/)

- 참고한 요소: 공개 사이트에서 확인한 데스크톱 창 프레임, 메뉴 막대, 작은 상태 표시와 파스텔 바탕입니다. 복고적인 UI 틀과 콘텐츠 영역을 구분합니다.
- 업무용 조정: 창 제목 표시줄을 연상시키는 표제부와 절제된 크롬 효과를 사용합니다. 본문은 작은 픽셀 글꼴로 바꾸지 않고, 표와 차트는 읽기 쉬운 현대적인 크기를 유지합니다. 반짝임과 장식이 수치 위로 겹치지 않게 합니다.
- 업무 활용: 문화 동향, 브랜드 사례, 행사 결과와 창의적인 프로젝트 소개에 맞습니다.
- 복제 범위: Poolsuite의 오디오, 영상, 아이콘과 창 조작을 복사하지 않습니다. 복고적인 프레임을 보고서의 제목과 정보 구획에만 적용합니다.
