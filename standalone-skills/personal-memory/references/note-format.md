# 기억 파일 양식

```markdown
---
title: 주간 보고의 설명 순서
kind: preference
scope: project
status: active
updated: YYYY-MM-DD
---

## 적용할 내용
주간 보고는 결론, 주요 수치, 근거, 다음 조치 순서로 작성한다.

## 적용 범위
이 프로젝트의 주간 보고. 다른 프로젝트에 적용한다는 뜻은 아니다.

## 출처
사용자의 명시적인 저장 요청. 대화 원문은 보관하지 않음.
```

scope는 project 또는 personal, kind는 preference 또는 work-context를 씁니다.
한 파일에는 서로 함께 적용되는 사실만 담습니다. 비활성 항목은 status를 inactive로 바꾸고
조회 때 적용하지 않습니다. 이 표시는 검색 지침이며 자동 실행 장치가 아닙니다.
