# VBA 업무를 Python으로 옮기는 예제

이 예제는 **매크로에 들어 있는 업무 규칙을 읽고 Python으로 다시 구현하는 방식**을 보여줍니다. VBA 문장을 자동으로 번역하는 범용 컴파일러가 아닙니다. 제공한 `.bas`는 가상 업무의 원문이며 Excel 파일에 설치하거나 실행하지 않았습니다.

현재 Python은 사용자 요청에 따라 **대문자 자동 변환을 제거**했습니다. 앞뒤 공백만
제거하며 `c03`, `C03`, `c03A`를 서로 다른 식별자로 취급합니다. 기준표와 대소문자가
다르면 임의로 연결하지 않고 확인 필요로 남깁니다. 원본 `.bas`와 XLSM 내부 VBA,
원문 계약은 그대로 보존했으므로 원본의 `CodeOf/UCase`와 의도적으로 다릅니다.
계약 통과는 같은 원문을 확인했다는 뜻이지 Python과 원본 VBA가 동등하다는 뜻이 아닙니다.

## 같은 업무를 두 방식으로 처리

- `macro-only`: 입력 시트에 수식이 없어도 Python의 정규화·반복·조건·조인·금액·수료 판정·부서 집계를 실행합니다.
- `mixed`: 동일한 정규화·중복 제거·기준표 조인 후 금액과 수료 판정을 수식으로 계산하고, 그 결과를 Python으로 부서 집계합니다. 수식은 메모리에서 다시 계산하며 Excel의 저장 계산값은 쓰지 않습니다.

`mixed`도 파일에 있는 임의의 수식·VBA를 알아서 실행하지 않습니다. **이전에 검토한 계산 규칙과 실행 순서를 Python에 명시한 것**입니다. 새 회사 파일의 원문과 규칙이 다르면 해당 변환 코드를 검토하여 수정해야 합니다.

## 원문과 이전 코드의 대응

| VBA 원문 | Python 구현 | 보존한 업무 의미 |
|---|---|---|
| `ReadRows` | `source_rows` | 5행의 헤더, B열부터의 실제 입력, 빈 행 제외. 숫자형으로 망가진 사번은 추측 복원하지 않음 |
| `CodeOf` | `code` | 사용자 요청으로 UCase 제거. 앞뒤 공백만 제거하며 대소문자 보존·키 정확 일치. 원본과 의도적인 차이 |
| `IsoDate`, `NumericValue` | `training_date`, `number` | 날짜, 0과 누락, 허용 범위 구분 |
| `LatestApplications` | `deduplicate` | 신청ID별 갱신순번 최대, 동률 뒤 행. 제외된 이전 행도 기록 |
| `UniqueIndex`, `PrepareOne` | `unique_lookup`, `preprocess` | 사원·교육 기준 조인. 부서 불일치는 자동 수정하지 않고 확인 대상으로 보냄 |
| `AttendanceCount`, `Assessment` | `evidence` | 참석 차시 중복 제거, 마지막 평가 행 사용. 점수 누락과 0 구분 |
| `CalculateMacroOnly` | `calculate_macro_only` | 단가×수량×(1−할인율), 수동 0 우선, Excel ROUND 방식, 수료 조건 |
| `CalculateMixed` | `calculate_mixed` + 기존 `FormulaEngine` | 전처리 후 IF/ROUND/AND 재계산, 계산 후 집계 순서 |
| `AggregateDepartments` | `aggregate` | 승인 신청 건수·금액·수료 건수의 부서별 집계 |
| `TrainingButtonClick` | 명시적인 CLI 실행 | 버튼/이벤트 트리거를 입력 파일 1회 처리로 대체. 자동 이벤트는 등록하지 않음 |

`approved_count`와 `completed_count`는 **신청 건수**입니다. 같은 직원이 여러 과정에 신청하면 각각 1건입니다. 고유 직원 수로 임의 변경하지 않습니다. 부서별 고유 인원이 필요하면 별도 요구사항으로 집계 기준을 바꿉니다.

## 실행

독립 시험 폴더의 해당 스킬을 읽어 달라고 요청한 뒤 다음처럼 말할 수 있습니다.

> 이 복잡한 교육 신청 파일을 함께 있는 VBA 업무 규칙에 따라 Python으로 처리해줘. 매크로 자체는 실행하지 말고, 처리된 신청과 제외·확인 필요 항목을 나누어줘. 수식 없이 처리한 결과와 수식을 거친 결과가 같은지도 비교해줘.

개발자용 명령:

```text
python -X utf8 migrate_training.py INPUT.xlsx --output NEW_FOLDER --mode macro-only
python -X utf8 migrate_training.py INPUT.xlsx --output ANOTHER_NEW_FOLDER --mode mixed --include-exceptions
```

스킬 폴더의 `scripts/excel_pipeline.py`와 `scripts/formula_engine.py`를 사용하므로 `migrate_training.py`만 떼어서 복사하지 않습니다. 필요 패키지는 기존 시험판과 같은 `openpyxl`뿐입니다.

## 결과와 불명확한 부분

- `summary.json`: 처리 건수·금액·원본 SHA-256·실행 시간·매크로 미실행 표시.
- `records.json`, `departments.json`: 정산 상세와 부서 집계. 식별자는 문자열이며 누락값은 null입니다.
- `excluded.json`, `rejected.json`, `superseded.json`: 대기·취소, 확인 필요, 이전 갱신행을 구분합니다.
- `lineage.json`: 각 신청 결과가 사용한 신청·사원·교육·출결·평가의 원본 행.
- `formula_steps.json`: mixed 모드에서 실제 재계산한 수식과 결과. macro-only에서는 빈 목록입니다.

CSV를 Excel에서 더블클릭하면 사번 앞자리 0이 사라질 수 있어 기본 결과는 JSON입니다. 원본 파일과 기존 결과 폴더는 덮어쓰지 않습니다.

## 이 예제에서 자동으로 하지 않는 것

파일 삭제·외부 파일 저장·메일 발송·HTTP/DB 접속·인증 정보 추출·Shell 실행·COM 업무 자동화는 옮겨 실행하지 않습니다. 원래 매크로에서 발견되면 전처리 계산과 분리하고 별도 검토 대상으로 기록합니다. UserForm·ActiveX·Workbook_Open·Worksheet_Change·계산 이벤트의 호출 순서도 원문과 실제 사용 시나리오를 확인해야 합니다.

VBA의 `Round`는 은행가 반올림이며, Excel `WorksheetFunction.Round`와 다릅니다. 이 예제 원문은 후자를 사용하고 Python은 `Decimal(..., ROUND_HALF_UP)`로 옮깁니다. Excel/VBA의 부동소수점 계산과 소수 경계에서의 완전 일치는 실제 회사 파일로 추가 대조해야 합니다.

실제 Excel에서 이 `.bas`를 컴파일·실행한 결과와 대조하지 않았습니다. Python 경로끼리의 일치와 독립 기대값은 이전 구현의 확인 근거이지, 모든 VBA 기능이 자동으로 지원된다는 증거가 아닙니다.
