# 생성된 Python 프로젝트를 수정하거나 설명할 때

기본 생성은 스크립트가 수행합니다. 이 문서는 사용자 맞춤 처리, 표시 설명 수정,
DATA 재사용 검증에만 읽습니다. 생성할 때마다 추가 모델 호출을 넣지 않습니다.

## 수정 위치

| 위치 | 역할과 수정 범위 |
| --- | --- |
| `main.py` | DATA → PROCESS → outputs 실행 시작점 |
| `DATA/sources.py`, `DATA/load.py` | 입력 파일, 로더, 외부 Python이나 DB 연결 |
| `PROCESS/sheet_번호_시트명.py` | 계산 시트당 하나. 반복 행 수식과 `process_tables`의 정리, 결합, 집계 |
| `PROCESS/pipeline.py` | 수식 참조상 선행 시트부터 실행. 상호 참조는 셀 단위 평가, 실제 순환은 오류 |
| `tables/`, `outputs/` | 추출된 표와 재실행 결과 |
| `_support/`, `_details/` | 계산 지원과 입력 계약, 모델 요약, 근거, 검토 항목. 평소 편집 대상 아님 |

PROCESS에 파일 경로나 Excel 접근 코드를 섞지 않습니다. 수식은 Python 반복문과
SUM/IF/ROUND 등 Excel 의미를 보존하는 보조 함수로 표현합니다. 자동 생성이 모든 Excel을
pandas 업무 코드로 완전히 바꾼 것은 아닙니다. 미지원 수식 원문은 보존합니다.

## 한국어 설명

편집할 Python에는 역할, 어떤 값을 받아 무엇을 처리하는지, 수정 위치를 쉽게 설명합니다.
각 수식 묶음에는 결과 범위, 대표 Excel 원문, 참조 시트와 셀, 함수와 연산의 동작,
상대/고정 행 처리, 수정 주의점을 남깁니다. 계산을 바꾸면 주석도 갱신하되 업무 의미를
추측해서 채우지 않습니다. `README.md` 하나에 실행법과 입력 계약을 정리합니다.

`업무흐름.html`은 처음 생성할 때만 만들며 재실행 때 모델 호출이나 HTML 생성을 추가하지
않습니다. 표의 항목, 입력→계산→결과 연결, 대표식의 쉬운 설명을 보여줍니다. 반복식은
묶고 상세는 접으며 생략, 미지원, VBA 미분석을 구분합니다. 수식 의존성이 실제 업무나
매크로의 실행 순서 전체를 증명하지는 않습니다.

표 이름은 이미 읽은 시트와 열 정보로 정하고 실제 ID를 유지합니다. 예: 실제 ID가
`s01_t01`일 때 `교육 신청 현황 테이블 (s01_t01)`. 이 형식을 강제하거나 별칭으로 바꾸지
않습니다. 범위 계획이 필요하면 `--plan`의 tables 항목 `display_name`에 이름을 적습니다.
이름만 고칠 때는 HTML 표시만 수정하며 원본 재분석이나 추가 모델 호출은 하지 않습니다.
실제 행 값이나 모든 셀 수식을 HTML에 나열하지 않습니다.

## 재사용과 확인

같은 열 의미, 행 배치, 자료형의 DATA만 교체해 결과가 실제로 바뀌는지 확인하고
PROCESS 파일이 그대로인지 비교합니다. 행, 열, 수식 구조가 달라지면 입력 계약을
재검토하며 자동 확장을 주장하지 않습니다. 필요한 주요 결과만 원본과 대조하고
표본 검증과 전체 검증을 구분합니다.

누적 시간은 날짜와 구분합니다. Excel의 `[h]:mm:ss` 같은 기간값은 `26:00:00`처럼
24시간을 넘는 시간 수를 보존합니다. DATA를 Python이나 JSON으로 바꿀 때도 이 문자열을
사용할 수 있고, Python은 `datetime.timedelta`도 받습니다. 날짜 문자열이나 단위 없는
숫자를 기간으로 자동 변환하지 않습니다.

VBA 원문에 접근하면 `_details/vba/`, `_details/vba-index.json`,
`_details/migration_plan.json`에서 관련 절차만 찾습니다. 원문 탐색은 자동 번역이나
안전성 검사, 원본 매크로 실행 검증을 대신하지 않습니다.

## 보고서로 이어서 사용할 때

HTML이나 PPT로 결과를 전달할 때는 필요한 집계만 기존 job/summary에 담고 기간, 포함/제외 범위, 단위, 분모와 출처를 함께 유지합니다. 계산 범위가 다른 지표는 이름이 같아도 합치지 않습니다. 별도 인계 파일이나 모델 호출, 원본 전체 재분석은 추가하지 않습니다.
