# 지식 파일 양식

```markdown
---
title: 신청자 수 집계 기준
aliases: [유효 신청자, 교육 신청 인원]
scope: project
status: active
updated: YYYY-MM-DD
---

## 정의
선택한 회차의 유효 신청자 수. 같은 사번의 중복 신청은 1명으로 센다.

## 계산과 조건
상태가 취소인 행 제외 → 회차로 필터 → 사번 중복 제거 → 인원수 계산.
단위: 명. 사번이 비어 있으면 확인 필요로 분리한다.

## 출처와 적용 범위
사용자가 제공한 집계 기준 문서의 해당 절. 이 프로젝트에만 적용.

## 개인 보완·예외
회사 원본을 바꾼 것이 아니라 개인 분석에서 사용하는 보완 조건을 별도로 기록한다.
```

확인할 수 없는 출처를 만들어 넣지 않습니다. 원본 링크나 문서 제목·절을 알 수 있을 때만 적습니다.
상태는 active / draft / deprecated로 나누고 draft·deprecated는 확정 지식에 포함하지 않습니다.
