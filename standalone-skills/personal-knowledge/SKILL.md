# 개인 업무 지식

현재 호스트의 파일 읽기·쓰기만으로 동작합니다. 회사 지식 원본이나 다른 하네스의 저장소를
옮기거나 덮어쓰지 않습니다. 이 스킬은 요청 시 정리·조회하며 상시 수집·자동 주입을 하지 않습니다.

1. 정리할 사실과 출처를 확인합니다. 수치·단위·기간·분모·필터·예외를 그대로 보존합니다.
   불확실한 해석은 확인 필요로 표시하고 확정된 지식으로 사용하지 않습니다.
2. 저장 범위가 없으면 **이 프로젝트 / 내 여러 프로젝트** 중 한 번만 묻습니다.
   프로젝트는 `<업무폴더>/.work-notes/knowledge/`, 개인 전체는 사용자가 고른 개인 폴더의
   `knowledge/`를 사용합니다. 이미 지정한 범위와 기존 항목 위치는 유지합니다.
3. 해당 폴더에서 같은 용어·지표를 먼저 찾습니다. 같은 항목은 제자리에서 수정합니다.
   회사 정의를 보완하면 원본 출처와 개인 보완 내용을 나누고, 별도 계산법이면 차이를 명시합니다.
   정책·접근 권한을 개인 규칙으로 완화하지 않습니다.
4. [지식 양식](references/knowledge-format.md)으로 항목당 하나의 짧은 MD를 작성합니다.
   원본 자료 전체·세션 로그·비밀 값은 저장하지 않습니다. 수정 직전 현재 내용을 비교해 타인의 수정과 충돌하지 않게 합니다.
5. 저장 위치·적용 범위·확인 필요 항목을 전달합니다. 자동 검색 인덱스·기억 주입이 생겼다고 말하지 않습니다.

조회 시 제목·별칭을 검색한 뒤 관련 항목 최대 5개·합계 약 6,000자만 읽습니다.
active 항목만 적용하고 출처가 폐기·변경되었거나 확인되지 않은 항목은 함께 알립니다.
회사 원본과 개인 정의가 충돌하면 두 근거와 차이를 보여줍니다. 사용자 선택만으로 회사 정책을 변경하지 않습니다.

사용 예: “이번 프로젝트의 재작업률 정의와 제외 조건을 지식으로 정리해줘.”
“저장된 신청자 집계 기준을 찾아서 이번 표에 적용해줘.”
