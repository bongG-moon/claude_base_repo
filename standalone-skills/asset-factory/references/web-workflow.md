# 웹 반복 업무를 스킬로 남기기

웹페이지를 한 번 조회하는 요청에는 제작 절차를 시작하지 않습니다. 스킬을 만들거나 고쳐 달라는 요청에만 적용합니다.

1. 빠진 **사이트 / 가져올 항목 / 원하는 결과**만 묻습니다. 사용자에게 디버깅 포트·CSS 선택자·인증값을 찾게 하지 않습니다.
2. 실제 연결된 브라우저 도구와 스키마를 확인합니다. 기존 Chrome DevTools, Playwright 등 기능이 맞는 연결을 재사용합니다. 없는 도구 이름을 만들거나 화면 조작 도구로 조용히 전환하지 않습니다.
3. 지정한 사이트·탭의 실제 표 제목/열/버튼을 관찰합니다. 여러 대상이면 선택을 받습니다. 로그인은 사용자가 직접 하며 인증 헤더·쿠키·비밀번호·토큰을 수집하거나 저장하지 않습니다.
4. 필요한 항목 최대 5행으로 작은 조회를 시험합니다. 지원하지 않는 file 주소, 권한 거절, 로그인 실패는 그대로 보고합니다. 원문 네트워크 캡처에서 인증값을 꺼내 새 API로 호출하지 않습니다.
5. 실제 관찰한 입력·조건·결과·도구 기능을 스킬에 기록합니다. 위치가 바뀌면 새로운 화면 정보를 읽고 뜻이 같은 요소를 찾도록 작성합니다. 좌표/DOM 경로를 고정된 사실로 약속하지 않습니다.
6. 현재 도구가 없다면 업무 절차 초안은 작성할 수 있지만 실제 연결·조회는 미검증입니다. 설치나 전역 MCP 변경은 사용자의 별도 요청에 따릅니다.

같은 대화에서 연결 정보를 반복 조회하지 않고, 필요한 열·텍스트만 가져옵니다. 일시적 조회 오류는 최대 한 번 재시도하며, 제출·수정·삭제·발송은 조회 범위에 포함하지 않습니다.
