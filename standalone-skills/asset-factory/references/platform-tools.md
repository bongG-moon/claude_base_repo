# tools.py로 재사용 도구 만들기

개별 MCP 스킬이 아닌 **MCP를 만드는 스킬**입니다. 도구 생성만으로 연결되지 않습니다.

1. `python -X utf8 "<스킬폴더>/scripts/create_project.py" --destination "새 개발 폴더 절대경로"`로 포함된 템플릿을 복사합니다. `<스킬폴더>`는 이 참고자료의 상위 `SKILL.md`가 있는 실제 절대경로입니다. 기존 폴더·설정·등록을 수정하지 않습니다.
2. `src/mcp/tools.py`의 `def register_tools(mcp: FastMCP) -> None` 안에 타입 힌트와 설명을 가진 `@mcp.tool()` 업무 함수를 구현합니다. 함수 이름·설명·입력·출력을 실제 업무에 맞춥니다. 예제 함수의 통과를 새 업무 함수의 검증으로 보고하지 않습니다.
3. 설정은 `from config import cfg`에서 참조합니다. 제공되지 않은 사내 주소/인증/DB 구조를 추측하지 않습니다. 외부 연결에 필요한 항목명과 승인된 의존성을 명시하고 비밀값은 사용자의 설정 저장소에 둡니다.
4. **생성된 개발 폴더**의 `requirements-local.txt` 의존성이 승인된 Python 환경에 있는지 확인합니다. 없으면 준비물을 알려주며 자동 다운로드하지 않습니다. 생성된 개발 폴더를 작업 위치로 지정한 뒤 `python -X utf8 "<개발폴더>/test_tools.py"`를 실행합니다. `<개발폴더>`는 생성 결과의 `directory` 절대경로이며 스킬폴더와 다릅니다. 합성 입력의 in-process MCP/HTTP 시험으로, 실제 포트·인증·업무 시스템 성공과 구분합니다.
5. 로컬 서버는 요청한 경우 같은 생성 개발 폴더를 작업 위치로 지정하고 `python -X utf8 "<개발폴더>/local_server.py" --port 8765`로 시작합니다. `127.0.0.1`에만 연결되며 기존 MCP 등록은 바꾸지 않습니다. 연결 등록 요청 시 실제 클라이언트의 지원 형식과 범위를 확인합니다.

도구는 행/문자수/시간 한도를 두고 반환 텍스트를 데이터로 취급합니다. 로그에 본문·키를 남기지 않습니다. async 함수에 느린 동기 I/O를 직접 넣지 않고, 요청 간 상태를 전역 변수에만 의존하지 않습니다.

전사 제출은 `src/mcp/tools.py`와 업무 모듈·추가 의존성·필요한 cfg 항목명·입출력/시험 결과를 전달합니다. 로컬 서버/config/개인 경로·비밀값은 제출하지 않습니다. 포함된 계약은 `references/platform-contract.md`입니다. 전사 SDK/인증/권한 확인은 별도입니다.
