# 내 업무 스킬과 도구 만들기

이 스킬은 현재 에이전트의 파일·실행 도구로 사용합니다. 특정 하네스의 명령, 세션 ID, 후크, 작업자 등록이 필요하지 않습니다. **스킬은 업무 순서, 도구는 실행 코드**를 담당합니다. 설명만 요청하면 파일을 만들지 않습니다.

명령의 `<스킬폴더>`는 **지금 읽은 이 `SKILL.md`가 들어 있는 실제 폴더의 절대경로**로 바꿉니다. 현재 업무 폴더에서 `scripts/`를 추측해 찾지 않습니다. ZIP의 첫 안내 파일을 통해 읽었다면 `source/skills/asset-factory/SKILL.md`가 있는 폴더입니다.

1. 사용 목적·입력·결과와 관련 기존 스킬/도구를 확인합니다. 이미 제공된 정보는 다시 묻지 않습니다. 일회성 처리나 기존 도구로 되는 업무를 무조건 MCP로 만들지 않습니다.
2. 실제로 새 스킬을 저장할 때 범위가 미정인 경우만 **이 프로젝트 / 내 모든 프로젝트** 중 한 번 선택받습니다. 프로젝트는 `.claude/skills/<이름>/`, 개인은 현재 Claude 설정 폴더의 `skills/<이름>/`입니다. 다른 에이전트는 그 제품이 제공하는 스킬 위치를 사용합니다. 이미 있는 자산은 실제 원본 경로를 유지하며 복제하지 않습니다.
3. [작성과 수정](references/authoring.md)을 따라 짧은 `SKILL.md`와 꼭 필요한 코드·참고자료를 작성합니다. 실제 호출할 도구 이름과 입력 형식을 확인하고, 없으면 연결 준비가 필요하다고 표시합니다.
4. 새 MCP가 필요한 경우만 [표준 도구 제작](references/platform-tools.md)을 읽습니다. `src/mcp/tools.py`의 `register_tools(mcp)` 형식으로 만들고 포함된 로컬 서버로 독립 시험합니다. 새 서버 등록·전사 배포는 생성과 구분합니다.
5. 문서형 스킬은 참조 경로, 입력과 완료 기준을 확인합니다. 실행 코드가 있으면 합성 자료로 정상 입력과 잘못된 입력을 시험합니다. 사용법, 원본 경로, 실제 검증 범위를 알려줍니다. 코드는 입력/계산/출력을 분리하고 편집 위치에 쉬운 한국어 주석을 답니다.

크롬 반복 업무를 스킬로 만들 때만 [웹 업무 관찰](references/web-workflow.md)을 읽습니다. 현재 연결이 있으면 재사용하고, 새 포트·확장·프로필·MCP를 자동 설치하지 않습니다.

새 스킬은 지정된 기본 폴더의 **한 원본**을 수정합니다. Claude의 현재 목록에 보이지 않으면 사용 중인 버전의 스킬 새로고침 또는 새 대화에서 확인합니다. 다른 하네스에서도 파일 형식은 재사용할 수 있지만, 등록 위치와 실행 권한은 해당 환경의 규칙을 따릅니다.
