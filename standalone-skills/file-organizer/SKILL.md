# 파일 정리

Python 3.11 이상과 표준 라이브러리만 사용합니다. 별도 하네스·설정·후크는 필요하지 않습니다.

`<스킬폴더>`는 **지금 읽은 이 `SKILL.md`가 들어 있는 실제 폴더의 절대경로**로 바꿉니다. ZIP 안내를 통해 읽었다면 `source/skills/file-organizer/SKILL.md`가 있는 폴더이며, 현재 업무 폴더의 `scripts/`를 추측하지 않습니다. 계획·기록 파일도 절대경로로 지정합니다.

1. 빠진 대상 폴더만 확인합니다. `python -X utf8 "<스킬폴더>/scripts/organize.py" plan --folder "대상 절대경로" --output "새 계획.json의 절대경로"`으로 계획을 만듭니다. 원본 파일은 이동하지 않습니다.
2. `moves`의 실제 이전/이후 위치와 `skipped`를 간단히 보여줍니다. 실행 요청이 없으면 실행/수정/취소를 확인합니다. 이미 정확한 계획에 대한 실행 요청을 받은 경우 다시 묻지 않습니다.
3. `python -X utf8 "<스킬폴더>/scripts/organize.py" apply --plan "계획.json의 절대경로" --receipt "새 이동기록.json의 절대경로"`으로 이동합니다. 파일이 달라졌거나 목적지에 파일이 생기면 중단하며 다른 명령으로 강제 이동하지 않습니다.
4. 이동한 개수·남은 파일과 실패 이유를 알립니다. 원복 요청은 `python -X utf8 "<스킬폴더>/scripts/organize.py" undo --receipt "이동기록.json의 절대경로" --output "새 원복기록.json의 절대경로"`입니다. 수정된 파일과 충돌은 자동 복구하지 않습니다.

한 로컬 폴더의 **직접 포함 파일**을 문서/표자료/발표자료/이미지/압축자료로 분류합니다. 최대 500개 항목, 파일당 256 MiB입니다. 하위 폴더·실행 파일·분류 불명·동일 이름 목적지는 제외합니다. 내용·날짜·사용자 분류는 이 도우미의 기능이 아니므로 필요하면 별도 계획을 설명합니다.

Windows에서는 기존 목적지가 있으면 실패하는 이름 이동을 사용합니다. 다른 OS에서는 같은 파일시스템의 하드링크 생성 후 원래 이름을 제거하며, 지원하지 않는 파일시스템이면 이동하지 못했다고 보고합니다. 전체 작업이 하나의 트랜잭션은 아니며 실행 중 외부 변경·프로세스 중단까지 자동 복구하지는 않습니다. 빈 분류 폴더는 남을 수 있습니다. 기존 파일·폴더는 삭제하거나 덮어쓰지 않습니다.
