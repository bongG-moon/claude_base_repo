# GET JSON 페이지 조회

브라우저에서 확인한 **단일 엔드포인트의 JSON 배열**을 로컬 JSONL 파일로 수집할 때만 사용합니다. 조회 도구는 Python 표준 라이브러리이며 모델이나 브라우저를 실행하지 않습니다. 실제 사이트의 필드, 인증, 페이지 방식은 관찰한 계약으로 지정합니다.

```text
python -X utf8 "<스킬 폴더>/scripts/query_get.py" --url "https://example.test/api/items" --items-path "data.items" --page-param page --page-size-param limit --page-size 100 --max-pages 5 --output "<새 결과 폴더>/items.jsonl"
```

- `--param`으로 일반 필터를 반복 지정할 수 있습니다. 민감한 값은 URL이나 인자에 넣지 않습니다.
- Bearer 인증이 허용된 API만 `--bearer-env 업무용_환경변수이름`을 사용합니다. 사용자가 값을 직접 설정하고 코드는 값과 헤더를 출력하지 않습니다. 원격 인증은 HTTPS만 허용하며 로컬 시험에 한해 `127.0.0.1` 또는 `::1`의 HTTP를 허용합니다. 다른 인증 방식은 이 실행기가 지원하지 않습니다.
- 기본 상한은 5페이지, 페이지당 100행, 총 500행, 응답당 10MiB와 전체 응답 50MiB입니다. 숫자 페이지 방식은 빈 페이지나 페이지 크기보다 짧은 응답에서 종료하고, 꽉 찬 마지막 페이지에서 한도에 닿으면 `complete:false`로 보고합니다. 실제 API가 이 규칙을 따르지 않으면 별도 코드를 작성합니다.
- 응답에 숫자 페이지 대신 불투명 커서가 있다면 확인된 쿼리 이름과 JSON 필드 경로를 `--cursor-param cursor --next-cursor-path paging.next`로 지정합니다. 커서는 같은 원래 URL의 쿼리 값으로만 사용하고 응답의 URL을 따라가지 않습니다. 빈 커서는 종료, 반복 커서는 미완료로 중단합니다. 다음 페이지가 남은 상태에서 페이지/행 한도에 도달해도 미완료입니다. 커서가 아닌 다음 페이지 URL이나 다른 프로토콜은 지원하지 않습니다.
- URL의 인증 정보와 민감 쿼리 파라미터를 거절하고, 리다이렉트를 자동으로 따르지 않습니다. 서버 오류 본문과 행은 콘솔에 출력하지 않습니다. 401/403/429 등 오류 시 결과를 성공으로 저장하지 않고 중단합니다.
- 출력은 JSONL이며 업무 데이터의 저장 권한과 위치는 사용자가 정합니다. `password`, `api_key`, `access_token`, `cookie`와 결과 행 내부의 `cursor`처럼 명확히 식별되는 인증·페이지 토큰 필드는 중첩된 배열과 객체에서도 저장과 표본 모두 `[민감정보 숨김]`으로 대체합니다. `redacted_fields`는 가려진 필드 수이므로 파일을 원문 그대로라고 보고하지 않습니다. 모르는 이름의 비밀이나 개인정보를 모두 자동 탐지하는 기능은 아닙니다. Bearer 인증값 자체가 응답에 반사되면 전체 저장을 중단합니다. 표본은 `--preview 1`부터 최대 5행만 명시적으로 요청하고 민감 정보가 포함될 수 있으면 사용하지 않습니다.
- 쿼리 조건과 시점이 다르거나 실시간 데이터면 기존 결과를 자동 재사용하지 않습니다. 이 파일을 이용하는 코드를 고정 사이트 전용 조회 코드로 발전시키려면 관찰한 조건과 근거를 함께 기록합니다.
- HTTP GET이라는 이유만으로 서버의 상태가 바뀌지 않는다고 보장할 수 없습니다. 공식 계약이나 사이트 관리자 지침으로 조회 전용임을 확인한 엔드포인트에만 사용합니다.
