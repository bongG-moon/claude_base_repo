# Huashu 기반 한국어 발표자료

사용자의 내용과 참고 디자인에서 HTML 발표자료를 먼저 만들고, 요청된 PPTX를 같은 HTML에서 내보낸다. Huashu Design의 MIT 코드를 선별한 한국어 발표판이며 원본 전체 제품과 기능이 같지는 않다.

이 파일이 있는 폴더가 `<SKILL>`이다. 작업 파일은 사용자 프로젝트에 둔다.

1. [발표자료 제작](references/presentation-workflow.md)을 읽고 내용, 청중, 참고 자료와 기존 승인 범위를 확인한다. 원본의 참고 관찰, 방향 탐색, 대표 2장, 나머지 장 제작 순서를 따른다. 이미 선택한 방향이나 사용자의 즉시 제작 요청을 존중하고 승인 대화를 반복하지 않는다.
2. 고정 크기의 자유 HTML/CSS로 저작한다. 기본은 장별 HTML과 `scripts/build_index.py`로 만드는 발표 화면이다. 한 화면에 한 장을 표시하고 이전/다음 버튼, 좌우 키와 페이지 번호를 제공한다. 전체 보기는 별도로 열고 인쇄에는 전 장을 포함한다. JSON 페이지 역할이나 디자인 템플릿을 강제하지 않으며 원본 표, 단위와 수치를 보존한다.
3. PPTX가 필요하면 [실행과 검증](references/export.md)을 읽고 `scripts/export_pptx.py`를 실행한다. 이 어댑터는 [원본 pptx_from_rendered.py](upstream/scripts/pptx_from_rendered.py)의 DOM 추출, 도형 생성과 텍스트 대조를 그대로 사용한다. 별도 PPTX를 수작업으로 다시 그리지 않는다.
4. HTML 전 장을 실제 화면으로 확인하고, PowerPoint를 사용할 수 있으면 PPTX도 열어 숫자, 줄바꿈, 표와 흐름도를 비교한다. XML 텍스트 보존과 실제 화면 보존, 개체 존재와 편집 저장 검증을 구분해서 전달한다. 사용자가 첫 초안만 요청하면 수정 없이 관찰 결과를 보고한다.

HTML과 PPTX, 필요한 로컬 자원 및 확인한 한계를 함께 전달한다. SVG와 canvas는 이미지가 되며 네이티브 표나 데이터 차트를 생성하지 않는다. 브라우저에서 개체를 드래그하는 범용 편집기는 포함하지 않는다. 글꼴은 설치된 것을 사용하고 자동 다운로드하지 않는다.

원본 저작권과 선택 파일의 해시는 [출처 기록](upstream/provenance.json), 라이선스는 [MIT License](upstream/LICENSE)에 있다. `upstream/SKILL.md.txt`는 원문 바이트를 보존한 기록용 파일이다. 제작 시 전체 원문을 로드하거나 그 안의 다른 분야 기능, 개인 학습, 설치 및 후크 지시를 실행하지 않는다.
