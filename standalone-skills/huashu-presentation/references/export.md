# 실행과 검증

## 필요한 실행 환경

Python 3.11 이상과 [requirements.txt](../requirements.txt)의 Python 패키지가 필요하다. Playwright의 Python 드라이버와 이미 설치된 Chromium, Chrome 또는 Edge가 필요하다. Node 프로젝트, npm 패키지나 LibreOffice는 이 내보내기 경로의 필수 의존성이 아니다.

준비된 Python 환경을 우선 사용한다. 필요한 경우 사용자가 선택한 프로젝트 가상환경에 requirements를 설치할 수 있다. 패키지는 Playwright, python-pptx, Pillow이며 greenlet과 pyee, lxml 등은 각 라이브러리의 전이 의존성으로 함께 필요하다. Python 패키지 설치만으로 브라우저가 준비되는 것은 아니다. `--browser`에 기존 실행 파일을 지정하거나 설치된 Playwright Chromium을 사용한다. 스크립트는 브라우저, 글꼴, 개인 스킬 및 후크를 다운로드하거나 설치하지 않는다.

```powershell
python -X utf8 -B "<SKILL>/scripts/export_pptx.py" --check --browser "기존 브라우저 실행 파일"
```

`--check`는 의존 모듈과 브라우저 파일의 존재를 확인한다. 실제 브라우저 실행 또는 변환 성공의 보장은 아니다. Python을 실행한 셸과 동일한 환경에 패키지가 있어야 한다.

## HTML을 PPTX로 내보내기

새로 작성한 신뢰할 수 있는 로컬 HTML만 입력한다. 참고 HTML의 동작을 그대로 실행하는 도구가 아니다. 자원은 각 입력 HTML의 폴더 안에 두며 원격 CSS, 글꼴, 이미지와 스크립트는 사용하지 않는다. 로컬 이미지의 경로는 HTML 기준 상대 경로로 작성한다. 원본 엔진이 내보내지 못하는 data URI 이미지는 명시적으로 거절한다.

```powershell
python -X utf8 -B "<SKILL>/scripts/export_pptx.py" --source "발표자료/slides/01.html" --source "발표자료/slides/02.html" --output "발표자료/발표본.pptx" --font "Malgun Gothic" --browser "기존 브라우저 실행 파일"
```

단일 HTML이면 `--source "발표자료/저작원본.html"` 한 번만 지정한다. 기본 선택자는 `.slide`다. 다른 루트 클래스이면 `--selector`로 실제 슬라이드만 지정한다. 모든 장의 폭과 높이는 같아야 한다. `<iframe>` 모음 페이지나 숨겨진 장은 성공한 출력으로 처리하지 않는다.

출력 PPTX와 출력 옆 `<파일명>_assets` 폴더가 이미 있으면 덮어쓰지 않는다. HTML과 기존 PPTX는 보존한다. 결과 JSON에는 실제 산출물, 장 수, 입력 해시, 원본 텍스트 대조 결과와 한계가 들어간다. SVG/둥근 이미지 중간 파일은 해당 assets 폴더에 남는다.

사용자가 제공한 PPTX의 테마와 마스터를 기반으로 만들려면 `--template "공식양식.pptx"`를 추가한다. `--layout "실제 레이아웃 이름"`과 `--skip-class logo`도 지원한다. 원본 엔진은 출력에서 예시 슬라이드를 제거하고 새 장을 추가하며, 선택한 레이아웃의 전체 화면 단색 덮개를 제거할 수 있다. 템플릿 원본 파일을 저장하거나 덮어쓰지는 않는다. 템플릿 상속은 실제 결과를 열어 확인해야 한다.

## 보존되는 것과 제한

이 어댑터는 `upstream/scripts/pptx_from_rendered.py`의 `JS`, `Builder`, `verify_text`를 불러 쓴다. 도형 변환 알고리즘, 크기 계산과 텍스트 여유 폭을 수정하지 않는다. 어댑터가 추가한 것은 명시적인 브라우저 경로, 입력과 출력 보존, 여러 입력 장의 순서, 로컬 자원 경계와 한국어 결과 JSON이다.

- HTML 텍스트는 PPTX 텍스트 상자가 되고 단순 배경과 선은 도형이 된다.
- HTML 표는 네이티브 PowerPoint 표가 아니라 여러 텍스트 상자와 도형이 된다. CSS로 그린 그래프도 데이터 차트가 아니다.
- SVG와 canvas는 PNG 이미지가 된다. 그 내부 글자나 경로를 개별 편집할 수 있다고 안내하지 않는다.
- 배경 이미지, 복잡한 CSS 효과와 의사 요소는 완전한 재현을 보장하지 않는다. 화면과 소스에 해당 요소가 있으면 별도로 확인한다.
- 슬라이드 루트의 배경색은 원본 엔진이 자식 도형으로 추출하지 않는다. 공통 배경색이 필요하면 `--background 0B1422`처럼 명시하거나 장 내부에 배경용 자식 요소를 저작한다.
- 기본 한글 글꼴은 `Malgun Gothic`이며 `--font`는 출력 글꼴 이름만 정한다. 글꼴 파일을 포함하거나 설치하지 않는다. HTML 측 글꼴도 실제 설치 상태를 확인한다.
- 원본 텍스트 대조는 공백을 제거한 문구 비교다. 숫자 의미, 올바른 표 대응, 줄바꿈이나 가림, 글꼴 일치, 네이티브 개체 편집 저장까지 증명하지 않는다.

HTML은 브라우저에서, PPTX는 가능한 경우 실제 PowerPoint에서 전 장을 보고 비교한다. 파일을 열 수 없거나 실행 환경이 준비되지 않으면 해당 검증을 미확인으로 기록한다. 원본 엔진의 최상위 CLI를 직접 실행하는 경로도 보존돼 있지만, 그 CLI에는 이 어댑터의 출력 보호 및 로컬 자원 제한이 없으므로 일반 진입점으로 안내하지 않는다.
