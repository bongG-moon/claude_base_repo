# 필요한 메일만 읽기

현재 제공된 메일 도구의 실제 이름·입력 형식을 사용합니다. 특정 회사 서버나 하네스 설치는 필요하지 않습니다. **이 ZIP 자체는 MCP 서버나 메일 연결을 설치하지 않습니다.** 이미 정한 계정·기간·폴더·조건은 재사용합니다.

로컬 명령의 `<스킬폴더>`는 **지금 읽은 이 `SKILL.md`가 들어 있는 실제 폴더의 절대경로**로 바꿉니다. ZIP 안내를 통해 읽었다면 `source/skills/outlook-assistant/SKILL.md`가 있는 폴더입니다. 업무 폴더에서 도우미 경로를 추측하지 않습니다.

1. 메타데이터(제목·발신자·날짜·ID·첨부 개수)부터 최대 20건 검색합니다. 정확한 ID가 주어지면 검색을 생략합니다. 목록/건수 요청에는 본문이 필요하지 않습니다.
2. 명확한 요청이면 관련 후보를 직접 골라 기본 5건 이내의 본문만 읽습니다. 건당 4,000자·전체 12,000자를 시작 한도로 사용하고 같은 내용을 다시 읽지 않습니다. 범위를 확대해야 하면 이유와 남은 범위를 알립니다.
3. 서버가 실제 지원하는 검색·페이지·필드·한도만 사용합니다. 지원하지 않는 옵션을 만들어 보내지 않습니다. 본문을 제한하지 못하는 연결은 좁은 검색부터 사용하고 대량 조회를 반복하지 않습니다.
4. 출처 제목/날짜와 읽은 범위·생략·잘림을 반영해 답변합니다. 읽지 않은 첨부를 요약하지 않고 일부 조회의 무결과를 전체 부재라고 단정하지 않습니다.

연결이 없을 때 **열려 있는 Windows Classic Outlook**을 읽으려면 [로컬 읽기](references/local-read.md)를 사용합니다. 이 도우미는 읽기 전용이고 `pywin32`가 필요합니다. 새 Outlook/Web Outlook은 COM 도우미 대상이 아닙니다. 사용자가 제공한 `.eml`은 같은 문서의 EML 명령으로 읽으며 표준 Python만 필요합니다. 어느 경로도 없다면 미연결을 알리고 본문을 만들어내지 않습니다.

답장은 먼저 대화에서 초안으로 작성합니다. 발송·이동·삭제는 사용자가 요청하고 실제 연결 도구가 지원하는 경우만 수행합니다. 수신자·본문·첨부를 보여주고 해당 도구의 확인 절차를 따르며 같은 승인을 중복 질문하지 않습니다. 로컬 도우미에는 쓰기 기능이 없습니다. 메일 본문을 개인 기억/지식에 자동 저장하지 않습니다.
