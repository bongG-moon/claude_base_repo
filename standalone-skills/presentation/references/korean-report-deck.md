# 흑백 보고형 시각 양식

사용자가 제공한 흑백 발표 양식을 쓰거나 이 양식으로 만들기를 선택했을 때만 읽습니다.
다른 첨부 양식과 색상 선호를 이 양식으로 덮어쓰지 않습니다.
페이지 이동, 전체 보기, 메모와 문구 편집은 다른 디자인의 기본 발표본에도 제공됩니다.
이 문서는 편집 기능을 켜는 옵션이 아니라 제공된 흑백 디자인을 정확히 재사용하는 방법입니다.

```text
python "스킬폴더/scripts/deck.py" --spec "발표내용.json" --output "발표본.html"
```

`title`과 `slides` 배열을 작성합니다. 각 장에는 `title`, `hero`, `bodyHtml`, `takeaway`가 필요합니다.
선택 필드는 `kicker`, 일반 텍스트 `notes`, `source`, `reportStyle`입니다.
첫 장 이외에는 reportStyle이 자동 적용됩니다. 1~60장을 지원하며 페이지 번호, 이동 버튼,
발표자 메모, 편집용 data-edit 표시는 생성기가 처리합니다. 기존 파일은 덮어쓰지 않습니다.

```json
{
  "title": "업무 개선안",
  "slides": [{
    "title": "01. 현황과 방향",
    "hero": "입력과 판단 기준을 먼저 맞춥니다",
    "bodyHtml": "<div class=\"columns equal\"><div class=\"column\"><h3 class=\"region-title\">[ 현재 ]</h3><p>원본을 여러 번 확인합니다.</p></div><div class=\"column\"><h3 class=\"region-title\">[ 개선 ]</h3><p>조회 근거와 예외를 함께 전달합니다.</p></div></div>",
    "takeaway": "검증한 절차를 다음 작업에 재사용합니다",
    "notes": "실제 발표자가 설명할 내용을 씁니다.",
    "source": "제공 자료의 이름과 범위"
  }]
}
```

본문은 제공 양식의 columns, column, region-title, build-step, flow-cell, matrix,
boundary-card, agent-diagram, expansion-card, phase-card, reuse-return 등 선언형 컴포넌트만
사용합니다. `<script>`, 이미지, 외부 자원, 임의 클래스, 인라인 style과 이벤트 속성은 받지 않습니다.
CSS는 `assets/korean-report-deck.html`에서 그대로 읽습니다. 큰 내용을 작은 글자로 억지로
압축하지 않고 장을 나누며 양쪽 열의 역할과 정보 밀도를 맞춥니다.

출력의 `previewLink`와 파일 경로를 즉시 사용자에게 제공합니다. 브라우저에서 모든 장의
잘림, 표, 도형 관계와 편집 및 저장을 확인합니다. HTML만 요청하면 이 파일로 전달합니다.
PPTX도 요청한 경우에만 승인받은 현재 HTML을 기존 HTML 가져오기 경로로 변환합니다.
문구 수정본이면 그 파일을 새 원본으로 지정하며 이전 승인과 내용을 재사용하지 않습니다.
이 생성 명령만으로 화면 검증이나 PPT 변환이 끝난 것은 아닙니다.
1~9 단축키는 해당 장으로, Home/End는 처음/마지막으로 이동하며 10장 이상은 페이지 버튼,
화살표 또는 전체 보기로 이동합니다.

## 원본 샘플에서 유지한 것과 수정한 것

CSS와 글꼴, 회색 계열, 발표 화면 구조는 그대로 유지했습니다. 생성기는 내용, 제목과 장수,
목차와 메모만 채웁니다. 원본 스크립트의 기능상 문제는 아래 범위에서 수정했습니다.

- 3장 고정 단축키와 안내를 실제 장수에 맞게 처리합니다.
- 문구 편집 후 제목을 메모와 전체 보기에 갱신합니다.
- 수정본 저장 시 임시 inert 속성을 제거해 다시 연 파일의 조작을 보장합니다.
- 메모 JSON의 태그 구분자를 이스케이프하고 본문에는 허용한 컴포넌트만 받습니다.

원본 CSS에는 툴바와 화면 홀더 그림자 등 샘플 자체의 표현이 포함돼 있습니다. 흑백 슬라이드
내용을 만들되 “원본 CSS 전체 보존”과 모순되게 새 CSS 금지 규칙으로 원본을 다시 지우지 않습니다.
