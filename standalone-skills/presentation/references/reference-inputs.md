# PPTX·HTML·이미지 참고

## PPTX

`python "스킬폴더/scripts/presentation.py" reference --file "참고.pptx"`는 첫 3장의
개체·글자 스타일을 제한된 양으로 읽습니다. 필요한 장만 `--slides 1,4,7`처럼 지정할 수 있습니다.
본문 전체를 모델 입력에 넣지 않습니다. 실제 보이지 않은 화면을 보았다고 말하지 않습니다.

분위기 참고는 관찰한 색·폰트·내용 흐름을 `presentationTheme`·`presentationFont`와 새 내용에 반영합니다.
기존 배치 유지 요청은 원본 `--template` 및 `referenceMode:preserve`로 지원되는 플레이스홀더를 채웁니다.
복잡한 고정 개체·마스터·SmartArt는 완전한 재편집을 보장하지 않습니다. 원본은 수정하지 않습니다.

## HTML과 이미지

기존 HTML은 정적 구조·배치·폰트를 참고합니다. 직접 변환은 `htmlSource` 경로를 사용하되 현재 설치된
Chrome/Edge가 필요합니다. 사용자 코드·외부 주소·인증정보를 실행하거나 자동 수집하지 않습니다.
저장해 둔 대표 HTML 양식은 `--template`로 재사용할 수 있습니다.

이미지는 현재 호스트가 실제 지원하는 이미지 읽기 기능으로 대표 2~3장을 봅니다. 화면의 글꼴 이름을
읽을 수 없으면 시각적 추정으로 구분합니다. 텍스트·수치·레이아웃은 새 편집 개체로 재구성합니다.
추측을 실제 읽은 사실로 바꾸지 말고 `referenceImages`에 참고 경로와 관찰한 테마를 함께 기록합니다.

## 관찰을 간단한 프로필로 정리

- 배치: 제목 위치, 본문 열 수, 바깥 여백, 카드·선·표의 형태
- 글자: 선언된 폰트/크기/굵기/색과 시각적 추정의 구분
- 내용: 결론 우선인지 순서 설명인지, 지표·근거·출처가 어디에 놓이는지
- 한국어: 제목 문장/명사형, 존댓말/보고체, 강조 정도, 반복되는 고정 표현

이 프로필을 현재 작업에서 재사용합니다. 참고 자료를 다른 메모리·프로필에 자동 저장하지 않습니다.

`특징 / 근거 장·shapeId / 새 자료 적용 위치 / 추정 여부`를 짧게 연결합니다. 둥근 카드·테두리·선 굵기·
그림자·연결 방향까지 살피고, 제목/본문의 서체·굵기 차이는 `elements`의 font/size/bold/color로,
도형 차이는 shape/fill/border/borderWidth/group으로 반영합니다. 기본 색·글꼴 하나로 평준화하지 않습니다.
예를 들어 같은 색은 같은 의미에 사용하고, 병렬 관계를 이유 없이 화살표로 바꾸지 않습니다.

분석의 `declaredShapeStyles`는 장당 최대 12개, `declaredParagraphStyles`는 8개 고유 표본이며
shapeId로 원래 개체와 연결됩니다. widthEmu/12700은 pt, spcPts/100은 pt, spcPct/100000은 행간 배수입니다.
schemeClr·tint·alpha와 상속 서식은 최종 화면 색으로 해석된 것이 아닙니다. 지원하는 lineSpacing·align은
개체 명세에 반영하고 미지원 점선·문단 간격·복잡한 도형은 초안에 근사 범위를 알립니다.
이미지에서는 정확한 서체·마스터·차트 원본 값·숨은 내용·애니메이션을 복원했다고 말하지 않습니다.

최종 검토에서도 같은 프로필로 도형·글꼴 역할·색 의미·말투·정보 밀도를 비교합니다. 명시 요청이 참고
자료보다 우선하며 기존 HTML 확인 외의 새 질문·별도 모델 호출·분석 파일은 추가하지 않습니다.
DRM·권한 때문에 읽을 수 없으면 현재 허용된 화면 읽기/캡처 도구가 있는지 확인합니다. 허용 도구가
없으면 사용자가 제공할 수 있는 허용된 캡처나 요약으로 진행하고, 파일을 우회 해독하거나 보안 설정을 바꾸지 않습니다.
