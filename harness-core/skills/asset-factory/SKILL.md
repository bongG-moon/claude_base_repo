# 내 업무 절차를 스킬로 남기기

사용자가 요청하거나 제안을 수락한 재사용 절차만 저장합니다. 한 번의 단순 작업을 자동으로 스킬로 만들지 않습니다. 실제 입력, 처리 순서, 예외와 확인 방법을 짧게 정리하고 확인하지 못한 자동화는 가능하다고 쓰지 않습니다.

1. 기존 스킬은 제공된 목록과 정확한 이름으로 확인합니다. 같은 목적의 개인 원본이 있으면 새 사본 대신 원래 파일을 수정합니다.
2. 새 저장의 범위가 미정일 때만 개인 전체 또는 이 프로젝트를 한 번 묻습니다. 기존 항목은 원래 범위를 유지합니다.
3. [개인 스킬 저장과 수정](references/authoring.md)의 명령으로 저장합니다. 본문은 짧게, 필요한 참조만 분리합니다. 전체 대화와 업무 원본, 인증값을 넣지 않습니다.
4. 실제 원본과 검증 결과, 사용할 /스킬이름을 간단히 알려줍니다. 목록 반영 시점은 Claude 버전에 따르며 보이지 않으면 지원되는 목록 새로고침 또는 새 연결에서 확인합니다. 같은 파일을 다시 복사하지 않습니다.

새 스킬은 Claude 개인 skills 폴더 또는 프로젝트의 .claude/skills에 한 원본으로 저장됩니다. 회사 배포본과 기존 private 저장소를 자동 이전하거나 덮어쓰지 않습니다. 사용자 스킬의 도구 연결과 기존 frontmatter를 유지합니다.

이 기본 제작기는 개인 절차 저장용입니다. 새 MCP, 실행 도구, 웹 자동화 제작을 요청하면 설치된 개별 asset-factory 등 적합한 스킬과 실제 도구를 사용합니다. 기본 하네스에 브라우저 자동화나 회사 표준 MCP 제작기가 들어 있다고 안내하지 않습니다.
