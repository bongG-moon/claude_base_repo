이를 근거로 실제 DRM 차단이라고 단정하지 않았고, 권한 검사 제거·다른 추출로 진행하지 않았습니다.

## Excel 고정 xlwings 경로로 변경 (PPT/Word 전환 전 기록)

Excel/CSV는 미리 작성된 `Read-CompanyExcel.py`만 호출합니다. 새 Excel 인스턴스에
읽기 전용으로 열고, 사용 영역/선택 범위를 제한한 뒤 `options(pd.DataFrame,
header=False,index=False).value`로 읽습니다. 타 도구 실패 후 재시도 경로가 아닙니다.
선택적인 Office IRM API의 미지원과 실제 접근 거절을 구분하며, 전자를 회사 DRM
접근 허가로 표현하지 않습니다. PPT/Word는 위 기존 경로 그대로입니다.

개발 PC의 C:\Python313\python.exe에는 xlwings가 없습니다. 따라서 실제 Excel·
DRM 읽기 성공을 주장하지 않습니다. Excel 객체를 대체한 검사에서 고정 호출 순서,
한글/첫 행/첫 열 보존, 제한된 DataFrame 변환, 소유 문서만 종료, 명시적 거절 시 중단,
라이브러리 누락, 실제 격리 Python 입력 검사, PPT 경로 분리를 확인합니다.

변경 후 전체 Python 검사 **558개 통과, 실패 0개, 제외 0개** — 113.629초.
최종 Python 실행 옵션 조정 후 Office 읽기 13개와 xlwings 절차 11개도 다시 통과했습니다.
스킬 형식 검사와 설치 묶음 회귀 검사도 통과했습니다. 묶음 검사는 임시 산출물을
정리했으며, 직원용 ZIP 게시나 사용자 설치는 수행하지 않았습니다.

않고 선택된 사용자에게 설치된 패키지는 유지합니다. 이 실제 실행 조건에서
