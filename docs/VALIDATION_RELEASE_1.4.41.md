# Company Harness 1.4.41 배포 검증

검증일: 2026-10-13. 사내 HCP 모델·게이트웨이는 호출하지 않았습니다.

## 범위와 소스

- 비전 결과 안내, 선택 실행하는 입력 비교 키트, 회귀 시험, 버전·사용·배포 문서만 선택했습니다. 별도 Workspace 앱·Computer Use MCP 작업은 제외했습니다.
- Git 인덱스의 선택 소스를 별도 디렉터리에 추출해 시험·빌드했습니다. 변경하지 않은 기존 소스 610개는 HEAD와 바이트가 같음을 확인했습니다. 공개 대상 변경에서 인증정보 패턴은 발견하지 못했습니다.
- 비전 라우팅의 변경은 고정 안내 문자열입니다. 실행 분기·후크 등록·승인 정책·메인 모델은 유지하며 일반 작업에 추가 네트워크·프로세스·파일 조회·LLM 호출을 넣지 않았습니다.

## 회귀 시험과 문서

- 최종 배포 소스에서 비전·키트·Read 후크·설치·native runtime·컨텍스트·설치 EXE·GitLab 준비·안내서 계약 시험 **200개가 123.005초에 통과**했습니다. 운영 모델의 토큰 수나 업무 소요 시간 측정은 아닙니다.
- 일반 경로 무호출, 지정 대상·모델 유지, 오류·판독 실패와 정상 종료 구분, A/B 동일 이미지 바이트, 합성 tool_use/tool_result 연결, 명시적 전송 2회, 인증값 가림·리디렉션 차단·결과 덮어쓰기 방지를 확인했습니다.
- 안내서 생성 검사 통과: 6개 부분·52개 장·425,145바이트, 설치 사본과 동일합니다. 로컬 Chrome 1440/768/390px에서 45개 캡처·147개 목차 링크를 확인했고 외부 요청·페이지 오류·넘침은 없었습니다. 내장 Noto Sans KR과 모바일 화면도 확인했습니다.
- 초기 문서 시험에서 남아 있던 이전 버전 설치 안내를 발견해 수정한 뒤 위 200개를 다시 실행했습니다. 시험 조건은 완화하지 않았습니다.

## 설치·업데이트

- 직원 ZIP 생성 시 플러그인 strict 검사·회사 지식 검증·Python 구문 검사를 모두 실행했습니다. 긴 Python 캐시 경로로 한 번 실패한 뒤 임시 경로만 줄여 동일 검사를 통과했습니다.
- ZIP manifest의 **229개 파일** 길이·SHA-256을 확인했습니다(별도 manifest 포함 230개). 플러그인·설치 스크립트·문서 등 원본 대응 파일 216개는 Git 스냅샷과 바이트가 같습니다.
- EXE의 실제 내장 ZIP 추출·무결성 검사가 통과했습니다. EXE는 **코드 서명되지 않은 빌드**입니다.
- 실제 **1.4.40 → 1.4.41** 업데이트를 격리 프로필에서 실행했습니다. 개인 기억·스킬·지식·CLAUDE.md·MCP·모델·다른 플러그인 설정, 260자 초과 스킬 원본/백업, 이전 ZIP 보존을 확인했습니다.
- 업데이트 시험은 설치 진입점과 같은 **Windows PowerShell 5.1**에서 통과했습니다. 처음 PowerShell 7로 직접 호출한 시험은 기존 백업 ACL API 차이로 설치 전에 중단됐으며, 정상 실행 호스트로 다시 검증했습니다. PowerShell 7 직접 실행 호환성을 증명한 것은 아닙니다.
- 새 플러그인 등록과 Read 후크 경로를 확인하고 `claude --init-only`에서 SessionStart 한 번 실행을 확인했습니다. 실제 사용자 프로필이나 운영 모델을 시험에 쓰지 않았습니다.

## 별도 비교 키트

`VLM-Input-Check-20261013.zip`은 안내 HTML·README·스크립트·가상 PNG 2장의 **5개 파일**만 포함합니다. 소스 바이트와 모두 같고 캐시·결과·인증정보를 포함하지 않습니다. 다시 압축을 풀어 기본 실행의 `network_calls: 0`, `credentials_read: false`를 확인했습니다. 하네스 설치 ZIP에는 넣지 않았습니다.

A는 일반 이미지 입력, B는 합성 Read 도구 결과 형식입니다. B가 실제 CLI인 것은 아니며 C(실제 Claude Code Read)는 회사에서 별도로 시험해야 합니다. 작업자 정상 종료·모델 자기 보고만으로 판독 성공이나 모델 정상 여부를 확정하지 않습니다.
