# 1.4.36 변경·설치 안내

스킬을 이미 지정하거나 선택했는데도 같은 선택 확인에 반복해서 막히던 흐름을 개선했습니다. 회사 지식팩은 `2026.09.03`을 유지합니다. 별도 개발 중인 Workspace 앱·실습자료·Computer Use MCP는 이번 설치 ZIP에 포함하지 않습니다.

## 달라진 점

- “회사 asset-factory로 크롬 스킬을 만들자”처럼 정확한 이름·출처를 지정하면 해당 스킬 본문을 바로 불러옵니다. 이름 뒤에 “스킬”을 반드시 붙일 필요는 없습니다.
- 회사·개인에 같은 이름이 있으면 출처를 구분합니다. 새로 지정한 출처가 이전 선택에 덮이지 않으며, “그 스킬로 계속”은 앞선 선택을 이어갑니다. 명시 선택이나 저장된 우선순위로도 구분되지 않을 때만 질문합니다.
- 선택창의 실제 답변을 현재 질문·요청과 연결합니다. 앱이 답을 도구 입력에 덧붙여 반환하는 경우도 처리하며, 모델이 미리 넣은 답·취소·실패·이전 요청의 답은 선택으로 인정하지 않습니다.
- 선택 대기 중에도 `skill choose --help` 등 정확한 내부 도움말 명령은 조회할 수 있습니다. 실제 실행 권한을 자동 승인하는 변경은 아닙니다.
- 설명·비교·번역용 예문과 “사용하지 마”는 스킬 사용 지시와 구분합니다. 지정한 스킬이나 출처가 없을 때 다른 후보로 조용히 바꾸지 않습니다.
- 추가 분류 모델·질문 단계·상주 작업자를 만들지 않았습니다. 사용자 안내서에도 변경된 선택 흐름을 반영했습니다.

## 업데이트

1. 진행 중인 업무를 저장하고 Claude Code를 종료합니다.
2. `company-agent-1.4.36-2026.09.03.zip` 전체를 새 폴더에 풉니다. GitHub의 `Source code (zip)`은 직원 설치 파일이 아닙니다.
3. `Install-CompanyAgent.cmd`를 실행하고 기존과 같은 사용자/프로젝트 범위로 업데이트합니다.
4. 완료 후 Claude Code를 다시 실행합니다. 개인 기억·스킬·지식·모델·MCP·다른 플러그인 설정은 초기화하지 않습니다.

기존 Release·ZIP·설치된 PC를 자동 변경하지 않습니다. ZIP 뒤의 날짜는 회사 지식팩 버전입니다.
