# Company Harness 1.5.2

기본 하네스에 남아 있던 이전 Company Agent의 비전 모델 자동 선택과 이미지 읽기 강제
인계를 제거했습니다. 일반 이미지 읽기는 Claude의 기존 방식으로 진행하며, 사용자가
설정한 모델과 개인 MCP 연결은 변경하지 않습니다. 더 이상 필요하지 않은 이미지 읽기 전
`PreToolUse:Read` 후크와 예전 비전 공유 스킬 안내도 정리했습니다.

같은 범위에 업데이트할 때 개인 기억과 지식, 학습 기록, 개인 스킬과 기존 Claude 설정을
유지합니다. 이 배포는 사용자 PC에 자동으로 적용되지 않으므로 새 설치 파일을 직접 실행해
업데이트해야 합니다.

이전 버전 정리는 선택 기능입니다. 참조와 정리 대상을 안전하게 확인할 수 있는 환경에서만
실행하며, 로컬 MCP나 다른 플러그인이 있거나 프로젝트를 확인할 수 없는 경우에는 정리가
보류될 수 있습니다. 따라서 업데이트 후 예전 파일이 모두 자동으로 삭제되는 것은 아닙니다.
개인 자료와 확인되지 않은 파일은 정리 대상으로 취급하지 않습니다.

실제 회사 환경에서 모델과 이미지 읽기가 성공하는지, 작업 속도가 개선되는지는 운영 환경에서
별도 확인이 필요합니다. 이번 변경만으로 특정 모델의 사용 가능성이나 자동 속도 개선을
보장하지 않습니다.
