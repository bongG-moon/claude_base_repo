# 개별 스킬 갱신 안내 — 2026-11-03

기본 하네스는 1.5.1을 그대로 사용합니다. 이번 변경은 독립적으로 설치하는 발표자료 스킬과 공통 서식 처리에 적용하며, 하네스 재설치를 요구하지 않습니다. `presentation.zip`과 공통 모듈을 포함하는 `html-report.zip`을 비롯해 개별 스킬 묶음을 갱신했습니다.

## 달라진 점

- 기존 PPT나 이미지의 스타일을 참고할 때 사용자가 지정한 색을 우선하고, 별도 지정이 없으면 관찰한 색 조합을 우선합니다. 참고 배경색과 패널색이 서로 달라질 수 있는 점도 반영했습니다.
- 표와 차트, 도형과 연결선을 한 장에 사용하는 실행 예제를 제공합니다. 표 서식에 지원하는 항목과 지원하지 않는 셀별 속성도 구분합니다.
- 초안에서 연결선이나 작은 글씨가 의심되면 승인 전에 해당 경고를 검토하고, 확인된 문제만 보정하거나 확인하지 못한 범위를 알리도록 안내합니다. 평소 작업에 상시 후크나 추가 모델 호출은 넣지 않았습니다.

## 검증 범위와 한계

관련 자동 검사 60개 중 59개가 통과하고 1개는 격리 Python의 `python-pptx`가 없어 건너뛰었습니다. 개별 ZIP 최신성, 원본 해시, 플랫폼 배포 형식과 설치 구성을 확인했습니다. 기존 하네스 설치 ZIP, EXE, 사용 안내서와 GitLab 전달 자료는 1.5.1 공개본과 같은 파일입니다.

실제 Claude Code로 가상 자료 2장의 HTML 초안과 편집 가능한 PPT를 생성했습니다. HTML 화면은 이 시험에서 확인하지 못해 소스 수준의 시험 승인을 사용했습니다. PPT를 PowerPoint에서 검토해 한 화살표가 다음 단계에 닿지 않는 점을 발견했고, 그 피드백을 Claude에 전달해 별도 수정본을 생성했습니다. PowerPoint에서 수정된 연결을 확인했지만 다른 연결 의심 경고 1건은 남아 있습니다. 사용자가 HTML 화면을 확인해 승인한 시험은 아닙니다.

7장 초안 시험에는 약 5분 54초가 걸렸고, 2장 초안 시험에는 약 108초가 걸렸습니다. 요청과 시험 조건이 다르므로 속도나 토큰 사용이 일반적으로 개선됐다고 단정할 수 없습니다. 실제 운영 환경의 모델, DRM 자료, 화면 확인 품질은 별도 확인이 필요합니다.

사내 GitLab 전달 자료는 배포 담당자가 수동으로 사용하는 기존 하네스 1.5.1 파일이며, 이 릴리스 생성만으로 사내 GitLab이나 개인 PC에 게시·설치되지는 않습니다.
