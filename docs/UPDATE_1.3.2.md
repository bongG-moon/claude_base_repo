# Company Agent 1.3.2 설치 및 업데이트

1. `company-agent-1.3.2-2026.09.03-r2.zip`을 새 폴더에 모두 압축 해제하세요.
2. 그 폴더의 `Install-CompanyAgent.cmd`를 더블클릭하세요.
3. 기존에 사용한 범위(내 Windows 계정 전체 / 선택한 프로젝트)를 고르세요.
4. `기존 버전 → 1.3.2` 안내를 확인하고 백업 후 업데이트를 선택하세요.
5. 설치 완료 후 Claude Code를 닫았다 다시 여세요.

Python 3.11 이상과 Claude Code는 기존 설치를 사용합니다. 설치기가 필요한
조건과 실행 경로를 확인하며, 여러 후보나 프로젝트 폴더 선택이 필요하면 묻습니다.
모델 설정·MCP·개인 Memory·Knowledge·Skill은 유지합니다. 기존 버전 폴더를
수동 삭제하거나 동일 버전 충돌 검사를 우회하지 마세요. 새 ZIP을 기존 폴더에
덮어 풀지 마세요. ZIP 이름의 날짜는 회사 지식 묶음 버전이며 코어 버전은 1.3.2입니다.

## 추가 기능 사용 예시

### 시작할 때 `Python` 오류가 나오는 경우 — 설치기 r2 보완

Ouroboros가 설치되어 있을 때 Windows의 `python3` 별칭을 실행해 시작 오류가
날 수 있습니다. r2 설치기는 선택한 사용자 설정의 플러그인 등록 위치를 읽고,
해당 PC에서 실제 실행되는 Python 3.11 이상을 확인합니다. PATH의 여러 후보와
현재 사용자/PC의 Python 등록 정보를 확인하며, 찾지 못하면 경로 입력을 요청합니다.
다른 직원의 PC 경로나 개발자의 `C:\Python313` 경로를 고정해서 배포하지 않습니다.

활성화된 Ouroboros의 알려진 Python Hook 3개만 실제 Python 경로로 연결합니다.
변경 전 `hooks.json` 원본과 복원 위치 정보는 설치 백업의 `plugin-python-*` 폴더에
저장합니다. 임의로 수정된 다른 Hook·모델·MCP·개인 자료는 변경하지 않습니다.
프로젝트 설치는 다른 범위가 함께 사용하는 플러그인 캐시를 변경하지 않고 안내합니다.
계정 전체의 Ouroboros 문제는 **내 Windows 계정 전체** 범위에서 다시 적용하세요.

이 교정은 설치/다시 적용 시 수행됩니다. 이후 Python을 옮기거나 Ouroboros 업데이트로
캐시가 교체되면 설치기를 다시 실행해 연결을 갱신하세요. 알 수 없는 Hook 구조는
자동으로 바꾸지 않으며, 교정 실패는 설치 결과에 별도 경고로 표시합니다.
플러그인의 원래 외부 업데이트 확인 기능이나 회사 보안 정책은 변경하지 않습니다.

코어 버전과 코어 파일은 기존 1.3.2 그대로이고 **설치기만 r2로 보완**했습니다.
기존 1.3.2도 백업 후 같은 버전 다시 적용으로 사용할 수 있습니다.

### 다른 대화에서 이어가기

“현재 작업을 다른 대화에서 이어갈 수 있게 정리해줘. 아직 확인하지 못한 것도 남겨줘.”

Claude가 확인한 내용을 정리해 개인 상태의 `handoffs` 아래에 Markdown 파일을
만듭니다. 다음에는 같은 프로젝트에서 그 파일을 주고 “이 작업 이어서 해줘”라고
하세요. 원래 세션의 실패·미확인 기록은 유지됩니다. 다른 PC로 자동 이관하거나
파일·메일을 되돌리는 기능이 아니며, 실제 자료가 없어지면 먼저 확인을 요청합니다.

### 필요한 입력만 받는 도우미 만들기

“보고서 형식과 자료 폴더만 물어보는 Windows 입력 도우미 만들어줘.”

Claude가 `setup-helpers` 아래에 `helper.py`와 `spec.json`을 생성하고 실행 조건을
확인합니다. 두 파일을 같은 폴더에 둔 채 안내받은 Python 명령으로 실행하면 됩니다.
예: `python "C:\\...\\helper.py"`. Python 경로가 별도로 확인된 PC는 그 경로를 사용합니다.
취소는 `/cancel`, 재실행은 이전 값을 유지하거나 변경할 수 있습니다.

이 도우미는 **일반 설정값을 묻고 저장하는 기능**입니다. 소프트웨어를 설치하거나
Claude/MCP 설정을 자동 적용하는 기능이 아니며, 비밀번호·토큰·민감한 업무 정보는
입력하면 안 됩니다. 답변은 평문 파일에 저장되며 민감 정보 자동 탐지는 완전하지 않습니다.
회사 Agent 설치 자체는 위의 Install-CompanyAgent.cmd를 사용하세요.

기존 Skill 11개를 그대로 사용하므로 새 명령어를 외울 필요는 없습니다.
새 ZIP 생성과 GitHub 게시·개인 PC 적용은 별개입니다.
