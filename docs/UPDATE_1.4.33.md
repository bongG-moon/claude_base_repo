# 1.4.33 변경·설치 안내

DOTS 실사용 검토와 추가 통합 시험을 반영한 하네스 배포입니다. 회사 지식팩은 `2026.09.03`을 유지합니다. 별도 개발 중인 Workspace 앱은 이번 배포에 포함하지 않습니다.

## 달라진 점

- PPT: 별도 양식이 없으면 한국어 컨설팅형 구성으로 HTML 초안을 만든 뒤 검토하고 편집 가능한 PPT로 제작합니다. 요약·근거·비교·실행안 구성을 지원하며 사용자가 준 양식을 우선합니다.
- 웹 업무 확장: 초보자도 대상 화면·입력·결과·승인 범위를 정리할 수 있는 읽기 전용 `asset web-plan`을 제공합니다. Chrome 설치·디버깅 연결·로그인·인증키 추출·MCP 등록은 자동 실행하지 않습니다.
- 스킬·완료 안내: 업무 수행 스킬과 보조 지침을 구분합니다. 선택 질문의 응답 대기를 실패로 취급하지 않고, 명령별 미시도·실행 전 차단·실행 후 실패·완료를 기존 도구 결과에 연결해 설명합니다. 다른 명령의 권한 거절을 아직 하지 않은 작업에 옮기지 않습니다.
- HTML: 짧은 스크롤 보고서의 불필요한 여백과 모바일 장식 겹침을 줄였습니다. 행이나 의미를 삭제해 분량을 맞추지 않습니다. 원본 행 기준을 일관되게 사용하도록 안내합니다.
- 개인 MCP: 검증한 Python 실행 묶음과 수정 중인 소스를 분리했습니다. 초안 수정만으로 활성 도구의 코드가 바뀌지 않으며, 다시 시험하고 활성화해야 새 실행본이 적용됩니다. 활성화 중 메타데이터 저장 실패 시 기존 실행본을 보존합니다.
- 학습: 기존 조건부 `learning submit` 한 번 제출 흐름과 안내 문구를 맞췄습니다. 새 모델·상시 작업자·학습용 Stop 반복을 추가하지 않고 개인 저장 범위를 유지합니다.
- 안내서: 위 사용법과 한계를 단독 HTML 및 설치용 Markdown에 반영했습니다. Noto Sans KR을 내장해 오프라인으로 읽을 수 있습니다.

## 업데이트

1. 기존 업무를 저장하고 Claude Code를 종료합니다.
2. `company-agent-1.4.33-2026.09.03.zip` 전체를 새 폴더에 풉니다. GitHub의 자동 생성 Source code ZIP은 직원용 설치 파일이 아닙니다.
3. `Install-CompanyAgent.cmd`를 실행해 이전과 같은 사용자/프로젝트 범위를 선택합니다. 개인 기억·스킬·모델·MCP·다른 플러그인 설정을 초기화하지 않습니다.
4. 업데이트 완료 후 Claude Code를 다시 실행합니다. 별도 Workspace 설치는 자동 갱신하지 않습니다.

기존 직접 소스형 개인 MCP의 연결은 설치기가 자동 변경하지 않습니다. 해당 도구를 수정할 때는 변경 전 소스를 먼저 다시 시험·활성화하고, 해당 native 등록을 명시적으로 갱신한 다음 새 연결에서 사용하세요. 자동 이전이나 전체 MCP 재등록은 하지 않습니다. Python 코드가 실행 묶음에 들어 있어도 OS 격리나 인증정보 자동 제거를 의미하지 않습니다.
