# 세 범위와 저장 위치 선택 검증

2026-09-19 개발 소스 기준. 이전 4분류 화면 검증 이후의 변경입니다. 설치된 운영 환경, Git 게시, 설치 ZIP 및 Release는 이번 작업에서 변경하지 않았습니다.

## 구현 계약

- 화면은 회사 공통 / 개인 전체 / 이 프로젝트로 구분하고 각 범위에서 기억·지식과 업무 구성을 조회합니다. 회사 공통은 읽기 전용입니다.
- 새 기억·지식·스킬·도구는 개인 전체 또는 이 프로젝트를 선택합니다. 미지정일 때 한 번 질문하고, 이미 지정한 범위는 재질문하지 않도록 스킬 지침에 반영했습니다. 기존 항목 수정은 원래 범위를 유지합니다.
- UI는 범위 미선택 시 저장안을 생성하지 않습니다. CLI의 명시적 저장 명령은 범위가 없으면 파일을 열거나 쓰기 전에 `needs_scope_choice`를 반환합니다. 정상 질문 상태이며 권한 오류나 성공 저장으로 보고하지 않습니다.
- 이 질문 명령과 범위를 지정한 검색은 변경 검증 의무를 만들지 않습니다. 실제 저장 명령·복합 명령은 이 예외에 포함하지 않으며 도구 권한을 자동 승인하지 않습니다.
- User 설치는 기존 개인 전체 저장소를 보존하고 프로젝트 자료를 `project-scopes/<폴더 식별값>`에 분리합니다. Project 설치의 기존 저장소도 보존합니다. 해당 설치에서 개인 전체 저장소는 같은 Claude 설정을 사용하는 User 등록이 확인된 경우만 제공합니다.
- 프로젝트 전용 개인 자료는 공유 프로젝트 파일과 다릅니다. 작업 폴더를 공유해도 개인 저장소는 자동 전송되지 않습니다. Claude 자체 자동 기억·개인 설정·기존 외부 플러그인은 이동하거나 병합하지 않았습니다.
- 검색은 현재 프로젝트와 개인 전체의 최대 두 저장소만 확인하고 기존 전체 결과/문맥 한도를 유지합니다. 별도 분류 모델, 전체 PC 탐색, 타 프로젝트 자료 수집은 추가하지 않았습니다.
- 저장한 스킬은 실제 목록에서 발견합니다. 등록되지 않은 네이티브 호출명을 만들지 않습니다. 프로젝트 외부 플러그인의 설치 범위도 목록에 반영했습니다.
- 프로젝트 도구의 생성→시험→활성화→실행을 같은 저장소로 연결했습니다. 생성되는 도구 스킬은 자신의 확정된 저장소를 사용합니다. MCP는 기존 검증·충돌 보존 절차를 유지하고 프로젝트 선택 시 로컬 범위 등록을 사용합니다.

## 자동 학습의 현재 동작

자동 학습 엔진의 저장 범위는 이번에 임의 변경하지 않았습니다.

| 현재 설치 | 자동 학습 저장·수정 범위 |
| --- | --- |
| User | 해당 사용자의 개인 전체 설치 저장소 |
| Project | 해당 프로젝트 설치 저장소 |

명시적인 새 저장의 범위 선택과 자동 학습 설정은 별개입니다. User 설치의 별도 프로젝트 전용 자산은 명시적 저장·수정 대상이며 자동 학습의 수정 대상은 아닙니다. 화면에서 이 제한과 실제 학습 범위를 표시합니다.

학습은 피드백 후보를 모았다가 의미 있는 업무 완료·검증 후 짧은 선호 또는 실제 읽은 기존 개인 스킬의 제한된 점검 항목으로 반영합니다. 추정 선호에는 독립된 업무의 반복 근거가 필요합니다. 회사 원본·프로젝트 CLAUDE.md·도구 코드를 자동 수정하지 않으며 모델 가중치 훈련이나 종료 후 백그라운드 작업이 아닙니다. 기존 사용 중단·이력·되돌리기를 유지했습니다.

## 화면·문서 확인

- 격리된 등록/저장소와 가상 CLI에서 실제 관리 API를 사용했습니다. 실제 모델 요청 및 외부 요청은 0회입니다.
- `.smoke/three-scopes-qa-20260919-02/browser-result.json`: 세 범위 메뉴, 필수 저장 위치 선택, 기억 추가·수정·사용 중단·이력 복원안, 지식 조회·초안, 회사 읽기 전용, 프로젝트 지침 저장, 스킬·도구 요청의 범위 유지 및 자동 전송 없음 확인.
- 390/768/1440px에서 가로 넘침과 스크립트 오류가 없음을 검사하고 주요 화면을 직접 확인했습니다.
- 핸드북·온보딩·Cua 안내서 3종의 390/1440px 화면, 링크, 외부 통신 없음, 실행 스크립트 없음 확인. Cua 항목은 기존 안내 화면의 회귀 확인이며 실제 Driver 시험은 아닙니다.
- 문서 원본에서 배포용 HTML을 재생성했고 생성 결과 일치 검사와 `git diff --check`를 통과했습니다.
