# 관련 스킬 우선 실행 — 2026-09-17 검증

상태: 1.4.12 설치본에 반영합니다. 기존 1.4.11 ZIP과 운영 PC 설정은 변경하지 않습니다. 운영 PC에서는 새 설치본으로 같은 범위에 업데이트한 뒤 Claude Code를 다시 실행해야 합니다.

## 변경한 흐름

- 시작 시 제공하는 전체 스킬 목록과 요청별 후보를 함께 사용합니다.
- 후보가 하나로 명확하고 본문 전달에 적합하면 첫 모델 요청 전에 그 본문 전체를 제공합니다. 예: 스킬 이름 없이 PPT 읽기를 요청해도 `office-reader` 절차가 먼저 전달됩니다.
- 같은 역할의 후보가 겹치면 명시적 호출·저장된 선호를 존중하고, 미선택 상태에서는 사용자에게 묻습니다. 이름이 다른 후보도 임의로 제거하지 않습니다.
- 관련 후보가 없으면 제공된 목록/세션 스킬의 용도를 비교하고 일반 작업을 진행합니다. 별도 설치·목록 재조회·`skill route` 기록을 요구하지 않습니다. 목록 조회 실패는 스킬 부재와 구분합니다.
- 같은 대화의 변경 없는 본문은 재사용합니다. 짧은 이어서 요청은 직전 업무의 분야·행동 태그만 참고하며, 다른 업무로 바뀌면 이전 스킬을 강제로 유지하지 않습니다.

## 기존 기능과의 경계

- 실제 Read/Skill 도구 성공은 `lastBodyLoad`, Hook 본문 전달은 `body-provided`로 구분합니다. 본문을 제공한 것만으로 모델이 사용했다거나 문서를 읽었다고 기록하지 않습니다.
- 준비 안내는 전역 도구 차단이나 Stop 실패를 만들지 않습니다. 기존 승인·회사 DB·메일·문서 접근 정책은 유지합니다.
- fork·모델·도구 제한·동적 명령 같은 특별한 스킬 의미는 호스트가 처리합니다. 확인 가능한 Read/Skill 승인/거절 규칙 또는 스킬 override가 있어도 자동 본문 전달 대신 정상 로드 경로를 안내합니다.
- 본문 8,000자, 본문 포함 요청 9,800자 상한을 적용합니다. 넘으면 일부만 잘라 전달하지 않고 정확한 Skill/Read 로드 지시로 전환합니다.
- 추가 모델 호출 없이 기존 목록과 해시를 사용합니다. 재사용 기록은 최대 16개 ID/해시만 보관하며 원문 질문·문서·스킬 본문은 상태 파일에 저장하지 않습니다.
- 작업자는 자신의 문맥에서 선택 본문을 읽습니다. 부모가 전달받았다는 사실을 작업자의 읽기 증거로 바꾸지 않습니다.
- 새 세션·재개·컴팩트 때 전달 기록을 초기화합니다. 변경·삭제된 본문도 그대로 재사용하지 않습니다.

## 실제 확인

1. 전체 Python 회귀 테스트 **747개 통과**, 건너뛴 테스트 없음, 배포 전 재실행 141.119초. 격리된 실제 Claude 설정 검사를 포함했습니다.
2. 실제 Claude 실행 파일 → 격리된 로컬 응답 서버 연결 검사 **9/9 통과**, 배포 전 재실행 3.4초. 첫 API 요청에 전체 Office 스킬 본문이 도착했고, 별도 Skill 호출의 본문/성공 기록도 확인했습니다. 문서 내용이나 실제 업무 도구는 실행하지 않았습니다.
3. 단일 후보, 같은/다른 이름 중복, 저장된 개인 스킬 선호, 일반 실행, 조회 실패, 파일 변경, 긴 본문, 네이티브 옵션·동적 치환, 권한 규칙, 재개/컴팩트, 한글 입출력, 본문 전달/실제 로드 기록 분리, 작업자 전달을 검사했습니다.
4. 기존 HTML·PPT 선택/생성, 권한, 대기, 완료 확인 테스트도 전체 회귀에 포함했습니다.
5. 직원용 설치본 구성 검사 통과: 외부 승인 Python 3.11 이상을 사용하며 신규 모듈·변경 안내가 포함되고 개발용 시험 스크립트는 제외됩니다.
6. `Test-ReleaseUpgrade.ps1`로 변경하지 않은 1.4.11 ZIP을 설치한 뒤 1.4.12 ZIP으로 업데이트했습니다. 실제 Claude 등록, 신규 모듈의 캐시 일치, 개인 Memory·Knowledge·Skill과 모델·MCP·개인 지시 보존, 스킬 파일이 없는 일반 작업 폴더에서의 시작 Hook 실행을 확인했습니다. 두 입력 ZIP은 시험 전후 동일합니다.
7. `Test-ScopedInstallSmoke.ps1`로 1.4.12의 User/Project 설치·거절·복구·개인 상태 보존과 CP949 환경의 한글·이모지 경로를 확인했습니다. 이 검사의 상위 버전은 임시 1.4.13 시험용 복제본이며 실제 1.4.13 배포가 아닙니다.

업데이트 검증 중 기존 1.4.11 설치 진입점의 bare `throw`가 Windows PowerShell 5.1에서 원래 오류를 `ScriptHalted`로 가리는 문제를 확인했습니다. 1.4.12는 원래 오류 레코드를 전달하며 회귀 검사를 추가했습니다. 기존 1.4.11 ZIP은 수정하지 않았고, 구버전 → 신버전의 실제 양성 업데이트 검사와 신버전 자체의 오류·복구 검사를 분리했습니다.
