  실제 버전 업데이트를 검사했습니다. 실제 사용자 Claude 설정에 설치한 것은 아닙니다.
- 개인 Memory·Skill·Knowledge·학습 이력에 더해 handoffs/설정 도우미 답변
  보존용 파일을 추가하고, 업데이트 전후 전체 개인 상태 파일 기록을 비교했습니다.

경로·크기·SHA-256 일치 여부와 최종 ZIP 전체 무결성을 확인합니다.
