# 1.4.16 — 세 범위 관리·하네스 구성 지도·온보딩

## 설치·업데이트

[1.4.16 설치 ZIP](https://github.com/bongG-moon/claude_base_repo/releases/download/v1.4.16/company-agent-1.4.16-2026.09.03.zip)을 새 폴더에 모두 압축 해제한 뒤 `Install-CompanyAgent.cmd`를 실행하세요. 기존과 같은 내 계정/프로젝트 범위를 골라 백업 후 업데이트하고 Claude Code를 다시 여세요.

같은 [Release](https://github.com/bongG-moon/claude_base_repo/releases/tag/v1.4.16)의 `company-workspace-preview-0.4-*.zip`은 선택적인 로컬 업무 화면입니다. 기존 Workspace의 전원 버튼으로 종료한 뒤 새 ZIP을 별도 폴더에 풀고 `Company-Workspace.vbs`를 실행하세요. 새 구성 지도와 세 범위 관리는 **하네스 1.4.16과 Workspace 0.4를 함께 적용**해야 합니다. 원본 CLI만 사용한다면 Workspace ZIP은 필요 없습니다.

기존 개인 기억·지식·스킬·모델·MCP 설정과 이전 Release는 보존합니다. 설치된 PC는 자동으로 업데이트되지 않습니다. 회사 지식팩 버전은 `2026.09.03`을 유지하며 별도 로그인이나 모델 설정을 추가하지 않습니다. 승인된 Python 3.11 이상과 Claude Code는 미리 준비되어 있어야 합니다. GitHub의 `Source code (zip)`은 직원용 설치 파일이 아닙니다.

## 주요 변경

- **회사 공통 / 개인 전체 / 이 프로젝트**를 구분하고 새 기억·지식·스킬·도구 저장 전에 개인 전체 또는 이 프로젝트를 선택합니다. 회사 공통은 사용자 화면에서 읽기 전용입니다.
- **구성 한눈에**에서 현재 작업 폴더에 해당하는 스킬·후크·도구·지침·기억·학습 저장 위치와 설정 상태를 비교하고 정적 HTML로 저장합니다. 설정 켜짐·파일 발견·실제 본문 로드 기록을 구분하며 조회에는 모델 호출이나 설정 변경이 없습니다.
- 핸드북과 온보딩 코스를 Markdown·오프라인 HTML로 제공합니다. 공통/개인 기억 비교, 프로젝트 A/B 범위 비교, 개인 스킬·로컬 도구 실습과 설치 후 안내 연결을 포함합니다.
- 자동 학습이 현재 User/Project 설치 저장소에서 동작한다는 점과 명시적 저장 범위 선택의 차이를 안내합니다. 회사 원본·CLAUDE.md·도구 코드를 자동 수정하는 기능은 아닙니다.
- **Cua Driver 준비 확인**은 로컬 파일 후보와 현재 CLI가 보고한 연결·도구를 확인하는 선택 기능입니다. 자동 설치·연결 등록·화면 조작을 하지 않으며 예문도 사용자가 직접 보내야 실행됩니다.
- 현재 폴더의 개인 자료 격리, 스킬 우선 선택·발견, MCP 범위 연결과 읽기 전용 조회의 완료 확인 계약을 보완했습니다. 추가 분류 모델이나 외부 API는 넣지 않았습니다.

## 확인 범위

세 범위와 구성 지도의 자동 검사·브라우저 검증, 배포 파일 무결성 및 이전 버전 업데이트 검증 결과는 [배포 검증 기록](https://github.com/bongG-moon/claude_base_repo/blob/v1.4.16/docs/VALIDATION_RELEASE_1.4.16.md)에 정리합니다. 화면 검증은 격리된 자료와 가상 CLI를 사용하며 실제 모델 업무의 성공 판정과 구별합니다.

구성 지도 HTML에는 로컬 경로와 항목 이름이 포함되므로 공유 전에 검토하세요. 대화 원문·기억 본문·인증정보는 내보내지 않습니다. 실제 사내 HCP의 지침 적용, DRM Office, MCP 인증·연결, Cua 화면 조작 및 원본 CLI의 모든 TUI 기능 재현은 별도 운영 검증 대상입니다.
