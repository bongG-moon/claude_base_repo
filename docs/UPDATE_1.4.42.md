# Company Harness 1.4.42

Excel 분석용 `company-agent:excel-to-pipeline`을 기본 스킬로 추가합니다. 파일을 첨부하고 “표와 수식, 접근 가능한 매크로를 분석해서 Python 전처리 초안을 만들어줘”라고 요청하면 됩니다. 별도 개발 중인 Workspace 앱과 비전 설정 변경은 이번 배포에 포함하지 않습니다.

## 달라지는 점

- 일반 XLSX·XLSM의 OOXML 구조는 기존 직접 읽기를 유지합니다. 직접 해석할 수 없는 바이너리 파일 후보만 설치된 Excel·xlwings로 한 번 확인합니다. 확장자나 읽기 실패만으로 DRM이라고 확정하지 않으며, 접근 거절·손상·분석 한도 오류는 우회하지 않습니다.
- 한 시트의 여러 표, 수식, 접근 가능한 VBA 코드를 분석하고 표별 데이터와 재사용할 Python 초안을 만듭니다. 불명확한 영역·미지원 수식·VBA 접근 거절은 가능한 분석과 구분합니다. 임의 매크로 전체를 자동 변환하거나 원본과 같은 결과를 보장하는 기능은 아닙니다.
- 샘플 업무의 코드 정리에서 자동 대문자 변환을 제거합니다. 데이터 대소문자는 보존하고 앞뒤 공백 정리도 확인된 업무 규칙에만 적용합니다. 원래 수식에 명시된 `UPPER`는 임의 정리가 아닌 수식 의미이며, VBA의 대소문자 변환은 별도 확인 없이 동일하게 옮겼다고 처리하지 않습니다.
- Excel 읽기는 전용 인스턴스에서 원본을 저장하지 않고 수행합니다. 원본 VBA는 실행하지 않으며, VBA 프로젝트 접근이 막히면 표·수식 분석을 계속합니다. 보안 설정을 낮추거나 보호를 해제한 복사본을 만들지 않습니다. Excel의 외부 연결·열 때 새로고침을 모두 막는다고 보장하지 않으므로 회사에서 승인한 자료만 사용합니다.
- 모델용 요약은 기본 표별 5행·전체 12,000자이며 표본은 표별 최대 1,000행입니다. 표본을 늘려도 전체 문맥 상한이 적용됩니다. 로컬 계산·파일 분석에도 별도 한도를 적용하며, 모든 행을 모델에 보내지 않습니다. 요청하지 않은 업무에 Excel이나 추가 모델 호출을 실행하지 않습니다.

## 준비물과 사용

기존 하네스와 같은 범위로 설치한 뒤 Claude Code를 다시 엽니다. 실제 기본 목록에는 자동 호출 가능한 스킬 12개와 이전 이름 호환 안내 1개가 있습니다. 개인 스킬·기억·모델·MCP 설정을 초기화하거나 기존 개인 자료를 이동하지 않습니다.

승인된 Python 환경에 직접 읽기용 `openpyxl`을 준비합니다. VBA 파일 추출에는 `oletools`, Excel 경로에는 Windows Excel·`xlwings`가 필요합니다. 하네스 설치기는 이 라이브러리나 Excel을 자동 설치하지 않습니다. 필요한 준비물이 없으면 그 범위를 안내합니다.

```text
이 엑셀의 시트와 여러 표, 수식, 접근 가능한 VBA를 분석해줘.
대소문자는 바꾸지 말고 Python 전처리 초안과 확인하지 못한 부분을 알려줘.
```

실제 사내 DRM 파일, 회사 보안 설정, 원본 VBA 실행 결과와의 일치는 운영 환경에서 추가 확인해야 합니다. 로컬 가상 자료 시험이 이를 대신하지 않습니다. 구체적인 회귀·패키지 검증 결과는 릴리즈 검증 기록에 별도로 정리합니다.
