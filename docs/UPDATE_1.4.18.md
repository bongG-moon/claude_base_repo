# 1.4.18 변경·설치 안내

## 달라진 점

- 화면 조작 시험 메뉴, Driver 준비 확인, 시험 예문과 전용 안내서를 하네스·Workspace·설치 파일에서 제거했습니다. 기존 문서 읽기·HTML·PPT·일반 MCP 기능은 유지합니다. 개인이 별도로 설치한 프로그램이나 MCP 설정은 삭제하지 않습니다.
- 개인 스킬·스크립트·MCP 제작 요청은 `company-agent:asset-factory`에서 함께 처리합니다. 새 재사용 도구는 전사 표준 `tools.py`로 만들고 로컬 stdio 연결로 시험할 수 있습니다. 이전 제작 스킬 이름은 명시 호출용 호환 안내로 유지합니다.
- 스킬과 도구를 연결하기 전에 검증·활성화·소스 변경 여부를 확인합니다. 없는 도구를 임의 실행으로 대신하지 않으며, 현재 세션 연결 성공과 저장된 검증 기록을 구분합니다.
- 설치 백업에서 긴 경로를 처리하도록 보완했습니다. 실패 시에는 한국어 원인과 진단 위치를 안내하고 기존 개인 자료를 보존합니다.
- 시작하기, Claude Code 기본 개념·명령어·단축키, 업무별 사용법을 Markdown으로도 설치합니다. 통합 HTML은 오프라인 Noto Sans KR 글꼴과 작은 화면에 맞는 표·예문을 사용합니다.

## 설치·업데이트

1. 직원 설치 파일은 `company-agent-1.4.18-2026.09.03.zip`입니다. 마지막 날짜는 회사 지식팩 버전입니다. 기존 Python 3.11 이상을 사용하며 새 Python이나 Driver를 자동 설치하지 않습니다.
2. ZIP을 새 폴더에 풀고 `Install-CompanyAgent.cmd`를 실행합니다. 기존과 같은 User/Project 범위를 선택하고 백업 후 업데이트합니다.
3. Claude Code를 종료한 뒤 다시 실행합니다. 기존 로그인·모델·개인 기억·지식·스킬·별도 MCP 설정은 유지합니다.
4. Workspace를 쓰면 기존 앱을 먼저 종료하고 `company-workspace-preview-0.6-*.zip`을 별도 폴더에 풉니다. `Company-Workspace.vbs`로 실행합니다. 실행 중인 이전 버전은 자동으로 바뀌지 않습니다.

이전 Release 파일은 보존합니다. 새 설치와 회사 PC의 보안 프로그램·DRM·모델·MCP 호환성은 실제 운영 환경에서 확인해야 합니다. 로컬 검증이 모든 회사 환경의 성공을 보장하지는 않습니다.
