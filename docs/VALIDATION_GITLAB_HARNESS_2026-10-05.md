# 하네스 사내 GitLab 배포 준비 검증

검증일: 2026-10-05. 현재 게시된 하네스: 1.4.36.

## 반영 범위

- 담당자용 `deploy/New-GitLabHarnessDelivery.ps1`를 추가했습니다. 이미 승인한 직원 설치 ZIP을 읽고 전체 구성 파일의 크기·SHA-256·경로·중복 및 단독/설치 안내서 일치를 확인합니다.
- ZIP을 변경하지 않고 설치 ZIP·통합 안내서·두 해시 파일, GitLab 게시 설명과 담당자용 배포 순서를 만듭니다. 직원에게는 GitLab Release 주소 하나를 전달합니다.
- 사내 프로젝트 주소가 정해졌으면 `-ProjectUrl`로 버전별 배포 페이지 주소를 작성합니다. 주소 없이 자료만 준비할 수도 있습니다.
- 이 도구는 담당자가 필요할 때 실행합니다. 후크·스킬·작업 시작·종료에 연결하지 않았으며 네트워크 요청·토큰 저장·설치·자동 업데이트를 수행하지 않습니다.
- README, 설치 위임 안내, 배포 문서와 통합 사용자 안내서의 시작하기에 GitLab 다운로드 절차를 반영했습니다. 하네스 EXE 설치기는 이번 요청의 의견 검토 대상으로 유지하고 구현하지 않았습니다.

## 생성 자료

`dist/gitlab-harness-1.4.36/`와 담당자 전달용 `dist/Company-Agent-GitLab-배포자료-1.4.36.zip`을 생성했습니다. 설치 ZIP의 SHA-256은 공개 Release와 같은 `af4ba3a553644d235ed0f5285b34bff16b44e57b3a396d9f3de4b32fa75e4054`입니다. 직원에게는 이 담당자 전달 ZIP이 아닌 폴더 안의 `company-agent-1.4.36-2026.09.03.zip`을 게시합니다.

현재 게시된 1.4.36 ZIP과 그에 동봉된 HTML은 보존했습니다. GitLab 설치 안내를 추가한 소스의 HTML은 다음 새 버전 번들 제작 시 반영됩니다. 이번 준비 자료의 GitLab 게시 설명에는 설치 순서가 포함되어 있으므로 현재 1.4.36도 그대로 사내 반입·배포할 수 있습니다.

## 아직 확인하지 않은 것

실제 사내 GitLab 주소·서버 버전·접근 권한은 제공되지 않았습니다. 사내 업로드, 일반 직원 계정의 로그인·다운로드·파일 첨부 용량 제한은 현장에서 확인해야 합니다. 프로젝트 공개 범위나 인증 정보를 바꾸는 방식은 추가하지 않았습니다. 코드 수정·로컬 자료 생성과 Git 게시·사내 게시를 구분합니다.
