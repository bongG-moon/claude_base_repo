# Company Harness 1.4.38

이번 배포는 지식 색인 일관성, 일반 파일 읽기 준비 속도, 로컬 EML 한글 처리를 개선합니다. 별도 개발 중인 Workspace 앱·Computer Use MCP·실습 자료 변경은 포함하지 않습니다.

## 달라진 점

- 지식 자동 갱신 중 다른 작업이 파일을 바꾸거나 삭제하면 잘못된 색인을 저장하지 않습니다. 갱신한 파일만 다시 확인하며 기존 정상 색인과 캐시는 유지합니다.
- 새 설치본의 일반 `Read`는 설치 때 선택한 Python으로 가볍게 처리합니다. 문서·설정·세션·스킬 목록을 추가로 열지 않으며 기존 도구 권한을 허용으로 바꾸지 않습니다.
- 비전 인계나 입력 오류는 기존 검사 경로를 유지합니다. Python 경로 변경 후 다시 설치하면 연결을 갱신하고, 설치 실패 시 이전 연결로 복원합니다. 실행 오류를 다른 경로로 반복 실행하지 않습니다.
- 로컬 EML의 인코딩 정보가 없는 일반 텍스트 본문·TXT 첨부는 엄격한 UTF-8로 읽습니다. 명시된 인코딩은 그대로 따르며 잘못된 바이트를 임의로 고치지 않습니다. 읽지 못한 첨부에는 한국어 제외 사유를 표시합니다.

## 측정 범위와 제한

Windows 격리 시험에서 비전 설정이 있는 일반 텍스트 Read 후크의 중앙값은 424ms에서 135ms로 약 68% 줄었습니다. 각 경로를 15회 교대로 측정했고 실제 문서·모델은 호출하지 않았습니다. 전체 업무 시간이나 토큰 절감률을 측정한 것은 아닙니다.

이미지 비전 인계는 기존 검사를 유지하는 추가 프로세스 때문에 796ms에서 977ms로 약 0.18초 늘었습니다. 모든 경로가 빨라졌다고 주장하지 않습니다. 운영 HCP 모델·게이트웨이·회사 PC에서의 실제 동작은 별도 확인이 필요합니다.
