# Claude Code 필수 사용법 안내서 검증

확인일: 2026-09-13

## 산출물

- `Claude-Code-필수-사용법.html`: UTF-8 한국어 독립 HTML. 외부 라이브러리·폰트·서버 없음.
- 핵심 8개, 전체 20개. 상황 분류와 검색어를 조합하고 예시를 복사할 수 있다.
- `/` 검색 이동은 이 페이지의 기능이다. Claude 자체 단축키와 혼동하지 않도록 표시했다.
- 검색어를 보관/전송하지 않는다. 콘텐츠 보안 정책으로 네트워크 요청을 차단한다.
- 기존 하네스·Claude 설정·개인 상태·설치 ZIP을 변경하거나 재설치하지 않았다.

## 근거

공식 문서의 최신 본문과 로컬 Claude Code 2.1.270의 `--version`/`--help`를 확인했다.
HTML의 각 항목에 직접 근거 링크를 달았다.

특히 실행 중 일반 메시지는 Enter로 큐에 들어가도 도구 실행 뒤 같은 턴에
전달될 수 있으므로, 업무 완료를 보장하는 순차 예약이라고 설명하지 않았다.
실행 순서를 강제해야 하는 업무에는 현재 결과를 받은 뒤 보내도록 안내했다.
기본 단축키로 확인되지 않은 Tab/Shift+Enter 전용 예약 기능을 만들어 소개하지 않았다.

영상은 Anthropic의 `Mastering Claude Code in 30 minutes` (2025-05-22)를
검색해 제목·설명·링크만 확인했다. 영상 전체 시청이나 자막 분석을 했다고 주장하지 않으며
최신 키 동작의 근거는 공식 문서다. 업무 예시와 초보자 우선순위는 자체 작성했다.

## 검사

`node scripts/test-shortcuts-guide.mjs` — 16개 검사 통과.

- 20개 항목·8개 핵심·출처 키·고유 ID, 한국어/영문 대소문자 검색.
- `Ctrl+O`, `ctrl o` 표기 처리, 여러 검색어 결합, 상세 예시 안의 검색.
- 핵심 외 항목 검색, 분류 조합, 결과 없음과 전체 복귀, 초기화.
- 상황 바로가기, 검색 단축키·입력 중/한글 조합 보호.
- 인쇄 시 보이는 설명만 확장하고 종료 후 상태 복구.
- 클립보드 경로, 로컬 복사 대체 경로, 권한 실패 시 정직한 안내.
- 외부 리소스·네트워크 호출·브라우저 저장소 코드 없음.

이 검사는 Node의 제한된 DOM 대역을 이용한 논리 검사이며 실제 브라우저 렌더링이나
실제 OS 클립보드 검사가 아니다. 브라우저 UI 검증은 로컬 file URL 정책에서 거부되어
중단했다. 다른 주소·브라우저 자동화 경로로 우회하지 않았다. 따라서 화면 크기별 배치,
실제 인쇄/PDF 결과와 운영 환경의 키 입력 동작은 사용자 확인 대상이다.
