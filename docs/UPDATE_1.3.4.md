# Company Agent 1.3.4 · 완료 확인 안내 간소화

## 달라지는 점

기존의 긴 `Stop hook error` 안내에서 설치 경로, 세션 번호, 내부 기록 명령,
상태값 설명을 빼고 다음처럼 짧게 표시합니다.

> 결과물을 확인하고 있습니다. 완료 확인 지침에 따라 처리한 뒤 요청하신 결과만 전달하세요.

업무가 끝난 뒤 필요한 학습 검토는 다음처럼 표시합니다.

> 업무 마무리 내용을 정리하고 있습니다. 완료 확인 지침에 따라 처리한 뒤 요청하신 결과만 전달하세요.

Claude가 읽을 상세 절차는 공통 스킬의 별도 참고 문서로 이동했습니다.
일반 결과물을 최종 전달하기 전에 이 지침을 읽고 확인하도록 연결했습니다.
기존 검증 조건과 최대 두 번의 보정 제한은 그대로입니다. 단순 조회에는 새 검증을
요구하지 않으며, 확인할 수 없는 결과를 성공으로 처리하지 않습니다.
실제 실패나 승인 대기, 보호 자료 제외 등 사용자가 알아야 할 내용은 숨기지 않습니다.

이 변경은 하네스가 출력하는 **설명을 축약**합니다. Claude Code 자체가 표시하는
`Ran ... stop hooks`, `Stop hook error`, 도구 실행 줄을 완전히 없애는 기능은 아닙니다.
다른 플러그인의 Hook에도 영향을 주지 않습니다. '정상 안내를 숨김'이라는 이유로
검증을 비활성화하거나 완료 성공을 강제로 기록하지 않습니다.

## 적용 방법

1. `company-agent-1.3.4-2026.09.03.zip`을 새 폴더에 모두 압축 해제합니다.
2. `Install-CompanyAgent.cmd`를 실행합니다.
3. 기존과 같은 사용 범위를 고르고 **백업 후 업데이트**합니다.
4. Claude Code를 닫았다 다시 엽니다.

기존 1.3.3 버전 폴더에 직접 파일을 덮어쓰지 마세요. 코어 내용이 바뀌었기 때문에
내용 충돌 없이 업데이트할 수 있도록 1.3.4로 구분했습니다. 개인 Memory·Skill·Knowledge,
모델·MCP 설정은 기존 업데이트 절차대로 보존합니다. ZIP 이름의 날짜는 회사 지식팩 버전입니다.

## 간단히 확인하기

- '사용 가능한 스킬 목록만 보여줘. 설치나 설정은 바꾸지 마.' → 조회 결과 뒤에 새 검증을 강요하지 않음.
- 테스트 폴더에 작은 문서를 만들게 함 → 실제 내용 확인 후 파일을 전달. Stop 보정이 발생해도 짧은 안내만 표시.
- 실제 확인 실패 또는 승인 대기 → 성공으로 꾸미지 않고 필요한 제한을 설명. 내부 명령 전체를 사용자에게 실행하라고 넘기지 않음.

설치하지 않은 기존 세션에는 이 변경이 소급 적용되지 않습니다.

## 구현 참고

[Claude Code 공식 Hook 문서](https://code.claude.com/docs/en/hooks#stop-decision-control)는
Stop의 차단 사유와 최신 버전의 일반 피드백 출력을 구분합니다. 설치 최소 지원 버전
전체에서 새 피드백 방식의 동작을 검증하지 않았으므로, 이번 변경은 기존 차단 방식과
검증 동작을 유지한 채 사용자에게 노출되는 사유만 짧게 변환합니다.
`suppressOutput`으로 완전히 숨길 수 있다고 가정하지 않았습니다.
