# 비전 결과 안내 및 입력 비교 키트 검증

검증일: 2026-10-13. 실제 사내 HCP 모델·게이트웨이는 호출하지 않았습니다.

## 변경 범위

- 비전 작업자·호출 후 안내에서 정상 종료와 실제 이미지 판독을 구분합니다. 판독 실패는 미확인으로 반환하고 OCR로 조용히 대체하거나 원인을 추측해 확정하지 않도록 지시합니다.
- 지정 모델과 응답 모델명 차이를 fallback의 증거로 보지 않습니다. 모델 자기 보고·토큰 수·트랜스크립트의 이미지 존재만으로 서버 처리 여부를 확정하지 않습니다.
- 실행 분기·승인 정책·메인 모델·일반 요청 지침·후크 등록은 바꾸지 않았습니다. 상시 연결 시험, 추가 LLM 호출, 정확도 판정 서비스는 추가하지 않았습니다. 이 변경은 응답 지침이며 모델의 사실성이나 지침 준수를 보증하는 장치는 아닙니다.
- 비전 작업자 정의는 기존 2,105자에서 1,907자로 축약했습니다(마지막 줄바꿈 제외). 호출 시 추가 지침은 285자입니다. 문자량이지 실제 HCP 토큰 수·속도 측정은 아닙니다.
- 사용자 핸드북과 통합 HTML 및 설치 사본을 같은 내용으로 갱신했습니다.

## 별도 시험 키트

`standalone-guides/vision-input-check/`는 하네스에 자동 등록되지 않습니다. 배포 파일은 안내 HTML, README, 표준 라이브러리 Python 스크립트, 가상 PNG 2장의 총 5개입니다.

- 기본 실행: 이미지 크기·해시·요청 형식 확인만 하며 네트워크 0회, 인증정보 읽기 없음.
- 명시적 `--send`: 승인된 같은 게이트웨이·모델로 같은 이미지의 A/B 2회 요청만 전송. 각 응답 상한 600토큰. 자동 재시도 없음.
- A는 일반 이미지 입력, B는 합성 `Read` 도구 결과 형식입니다. B가 실제 CLI 실행인 것은 아닙니다. 실제 Claude 비전 작업자의 Read 시험 C는 가이드의 별도 예문으로 진행합니다.
- 정답표·스크립트를 모델에 주지 않고 PNG만 별도 폴더에서 읽도록 안내합니다. 영문·숫자·도형 시험이며 한글 업무 문서의 인식 품질까지 검증하지 않습니다.
- URL의 인증정보·쿼리를 거부하고 리디렉션을 따라가지 않습니다. TLS 검증은 유지합니다. HTTP는 명시적 선택이며 승인된 사내 주소에만 사용하도록 경고합니다.
- 원본 요청·base64·인증값·서버 오류 본문은 저장하지 않습니다. 보고서에는 제한된 답변·이미지 해시/크기·요청/응답 모델·사용량·UTC 시각·소요 시간만 남깁니다. 응답 수신과 정답 판정은 구분하며 공유 전 사람이 검토합니다.

## 실행한 검증

- 비전 인계·라우팅·키트 단위 시험: **71개 통과**(키트 15개 포함).
- 기존 Read 후크·설치·native runtime·컨텍스트 시험: **81개 통과**. 합계 **152개**.
- 일반 읽기와 안내 생성 시 네트워크·프로세스·파일 조회가 추가되지 않는 회귀 시험, 메인 모델 유지, 원본 오류 미노출 및 정상 종료를 판독 성공으로 취급하지 않는 안내 시험 포함.
- A/B 이미지 바이트 동일성, tool_use/tool_result 연결, 기본 무전송, 명시적 2회 호출, 인증값 가림, 리디렉션 차단, 결과 덮어쓰기 방지를 오프라인으로 확인했습니다.
- 통합 HTML 재생성/일치 검사 통과. 브라우저 1440/768/390px, 45개 캡처, 외부 요청·페이지 오류·넘침 0건.
- 별도 키트 HTML 1440/390px, 6개 캡처, 외부 요청·페이지 오류·넘침 0건. 가상 PNG 2장과 안내 화면을 육안 확인했습니다.
- `dist/VLM-Input-Check-20261013.zip`에는 배포 파일 5개만 포함했습니다. 다시 압축을 풀어 전 파일 SHA-256 일치 및 기본 오프라인 실행을 확인했습니다. 캐시·결과·인증정보는 포함하지 않았습니다.

첫 테스트는 샌드박스 임시 폴더의 접근 거부로 실패했습니다. 코드나 판정 조건을 완화하지 않고 저장소 전용 임시 폴더에서 재실행하여 통과했습니다.

## 남은 운영 확인

사내 모델의 실제 응답 정확도·멀티모달 활성화·게이트웨이의 변환 후 이미지 전달은 미검증입니다. 회사에서 A/B/C 결과와 승인된 서버 로그를 비교해야 합니다. 모델 계열의 비전 지원을 운영 환경의 정상 동작으로 설명하지 않습니다. 이번 작업에서 릴리즈·설치된 개인 프로필은 변경하지 않았습니다.
