# 1.3.7 · PPT를 읽기 쉬운 보고자료로

## 달라진 점

- 제목·글머리표·표를 기계적으로 세로 분할하던 방식에서 핵심 수치, 시각 자료,
  짧은 설명을 조합하는 배치로 변경했습니다. 표가 페이지 아래로 밀리지 않습니다.
- 핵심 수치는 크게, 본문은 18pt 이상, 표는 16pt로 표시합니다. 내용이 너무 많으면
  작은 글자로 억지로 채우지 않고 나누도록 안내합니다. 한글 글꼴도 명시합니다.
- 표·차트는 PowerPoint에서 편집할 수 있습니다. 이미지 생성 도구가 없어도 동작합니다.
- 원자료에서 계산한 수치를 제목·요약·지표에 재사용합니다. 선언한 총계와 기대값이
  다르면 파일을 만들지 않습니다. 이전 AI 요약의 잘못된 총계를 복사하지 않습니다.
- 기존 디자인 Skill은 사용자가 정한 우선순위에 따라 필요한 것만 참고합니다.
  새 Skill을 무더기로 설치하지 않으며 공통 Skill 수는 그대로입니다.
- 공통 PPT 지침에 모든 장의 실제 미리보기 확인을 추가했습니다. 파일 저장 성공이나
  자동 배치 검사를 디자인 검수 완료로 설명하지 않습니다.

## 직원 사용 예시

“이 자료로 부서장 보고용 PPT 3장을 만들어줘. 첨부한 양식의 밝은 배경과 남색 제목을
참고하고, 핵심 수치·편집 가능한 차트·표·후속 확인 사항을 구분해줘. 원자료 합계와
달성률을 다시 계산하고, 장마다 실제 화면도 확인해줘. 원본은 그대로 두고 새 파일로.”

목적·장수·양식을 이미 알려주면 다시 묻지 않습니다. 양식이 없으면 깔끔한 업무형으로
시작할 수 있습니다. 필요할 때만 원하는 구성이나 장수 변경을 쉬운 한국어로 묻습니다.

## 업데이트 적용

1. `company-agent-1.3.7-2026.09.03.zip`을 새 폴더에 압축 해제합니다.
2. `Install-CompanyAgent.cmd`를 실행하고 기존과 같은 사용 범위를 선택합니다.
3. 백업 후 업데이트하고 Claude Code를 닫았다 다시 엽니다.

개인 Memory·Skill·Knowledge·모델·MCP는 기존 설치기의 보존 절차를 유지합니다.
이번 작업은 소스와 설치 ZIP 제작이며 현재 PC 설치본을 직접 수정하지 않습니다.
동일 버전 파일을 수동으로 덮어쓰지 마세요. GitHub 게시 여부는 별개입니다.

이전 요약 문서·구성안 자체를 이번에 수정한 것은 아니므로 참고 시 주의하세요.

## 환경별 한계

회사 요청대로 기존 Python/PowerPoint 기반이며 제작 시 패키지를 다운로드하지 않습니다.
python-pptx가 없으면 기존 PowerPoint의 직접 생성 경로를 쓰지만 Office 자체의 차트
삽입 기능도 가능해야 합니다. 이 PC에서는 Python 생성 및 PowerPoint 미리보기는
성공했고, Office 직접 표 생성은 성공했으나 직접 차트 삽입은 실패했습니다.
그 경우 `office_chart_unavailable`로 해당 제작을 중단하고 이미지로 대체하지 않습니다.
실제 Office 2016/사내 DRM 환경은 별도 확인이 필요합니다.

복잡한 양식의 정확한 복제, 임의 SmartArt·애니메이션 재구성, 모든 디자인 테마는
지원하지 않습니다. 기본은 양식의 크기와 마스터를 보존하고 본문을 재배치하는 방식입니다.
선언한 계산 검사는 원자료의 진위·자유문장·인과관계의 검증을 대신하지 않습니다.
미리보기 권한이 없으면 화면 미검증을 명시하고 DRM·권한을 우회하지 않습니다.

개발 참고: Office 차트 삽입은 [Microsoft의 AddChart2 규격](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.shapes.addchart2)을 사용합니다. API 규격 준수가 개별 PC의 Office/보호 정책에서 성공을 보장하지는 않습니다.
