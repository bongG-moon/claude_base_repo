# 엑셀 구조화: 시트별 Python과 필요한 결과만 남기기

검증일: 2026-10-20. 소스 반영까지 완료했으며 설치·커밋·Release 게시 작업은 하지 않았다.

## 바뀐 사용 방식

- 기본 생성은 `main.py`, `README.md`, `DATA`, `PROCESS`, `tables`, `outputs`와 보조 폴더 두 개다.
- 계산이 있는 시트당 `PROCESS/sheet_번호_시트명.py` 하나에 수식과 추가 처리 함수를 모은다.
- 연속된 행의 같은 수식 패턴은 `for row in range(...)`로 묶는다. 중간 예외·고정 참조·다른 수식은 따로 남긴다.
- 산술식은 Python 연산으로, SUM/IF/ROUND 등은 기존 Excel 의미를 보존하는 Python 표현식 보조 함수로 작성한다. 이 표현식을 기존의 제한된 계산기가 평가한다. 임의 Excel 전체를 pandas나 독립적인 업무 코드로 완전 번역한 것은 아니다.
- 시트 의존성으로 선행 계산부터 실행한다. 상호 참조 시트는 셀 단위 의존성으로 계산하고 실제 순환 참조는 오류로 남긴다. 의존성을 확인하지 못한 함수도 별도 표시한다.
- `--target "집계!D8"` 또는 표 ID를 지정하면 필요한 입력과 선행 수식만 새 프로젝트에 포함한다. 여러 결과는 반복 지정한다.
- IF 양쪽 분기·고정 이름 범위·빈 참조·표시할 병합 셀의 기준 값도 보존한다. VBA·미지원/동적 참조·비셀 기능의 의존성을 확정하지 못하면 축소를 거절한다.
- 상세 셀별 JSON은 `--diagnostics`를 지정했을 때만 `_details`에 저장한다. 재사용 구조 검사에 필요한 원본 수식/입력 계약은 `_support` 내부에 남지만 사용자 편집 대상은 시트별 Python이다.
- 기존 상세 생성 방식은 `--layout detailed`로 유지한다. 기존 사용자 결과를 수정하거나 삭제하지 않는다.
- 새 후크·추가 LLM 호출·자동 패키지 설치는 없다.

1. 현재 수정 중인 핸드북의 작업자 목록에 기존 `vision-worker`가 빠져 있다.
