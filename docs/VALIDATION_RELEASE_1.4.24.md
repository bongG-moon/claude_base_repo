이번 변경은 안내서·버전·패키징과 검사에 한정했습니다. 전체 Python 회귀 1,154개를 이번에 다시 실행한 것은 아니며, 그 수치는 [1.4.23 검증](VALIDATION_RELEASE_1.4.23.md)의 이전 결과입니다. 이번 브라우저 화면 캡처 검사는 실행하지 않았습니다. 자동 검사 시간은 실제 업무의 응답시간·토큰 절감률이 아닙니다. 사내 HCP 모델·Office·DRM·업무 MCP의 성공은 운영 환경에서 별도로 확인해야 합니다.

각 파일의 `.sha256`도 함께 제공합니다. 별도 첨부 HTML은 로컬 `docs/Company-Agent-사용자-안내서.html`과 같은 바이트이며 GitHub 파일명 호환성을 위해 영문 이름을 사용합니다. 기존 `Company-Agent-Guide.html` 경로는 앱·설치 안내의 호환성을 위해 ZIP 안에 유지합니다.

기존 1.4.23 설치 ZIP과 Workspace ZIP은 덮어쓰지 않습니다. 같은 버전의 설치 내용이 달라지는 충돌을 방지하기 위해 코어만 1.4.24로 올리고, 실행 코드 변경이 없는 Workspace는 0.8을 유지하며 새 타임스탬프 ZIP으로 구분했습니다.

Release는 **초안**으로 준비하며 공개 게시와는 구분합니다. 이 검증 기록은 순환 해시를 피하기 위해 설치 ZIP 밖에 둡니다. 별도 `standalone-guides/` 시험 문서, 개인 설정·상태·실행 로그는 커밋·배포에서 제외합니다.
