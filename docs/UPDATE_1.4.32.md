# 1.4.32 변경·설치 안내

이번 버전은 1.4.31 사용 기록에서 확인한 지표 표현과 불필요한 완료 검증을 보완하고, 기존 자동학습의 세션 간 전달을 재검증한 배포입니다. 별도의 모델이나 학습 방식을 추가하지 않습니다.

## 달라진 점

### 계산값과 지표명·기간·단위를 함께 연결합니다

- HTML·PPT 제작 명세의 `facts`에 선언한 정보를 `{{fact:id.label}}`, `{{fact:id.unit}}`, `{{fact:id.valueWithUnit}}`로 참조할 수 있습니다. 선택 필드 `period`를 선언하면 `{{fact:id.period}}`로 기준 기간도 재사용합니다. 없는 기간을 참조하면 추측하지 않고 명세 오류로 안내합니다.
- HTML 제목·본문·표 머리글·KPI 표시명·차트 항목과 범례, PPT의 관련 텍스트에 적용합니다. 기존 숫자 참조 `{{fact:id}}`와 기존 콘텐츠 순서 명세는 유지합니다. 입력 원본과 명세를 고치거나 단위를 자동 변환하지 않습니다.
- 지표를 정정할 때 이름·기간·단위·분모도 대조하도록 제작 지침과 안내서를 보완했습니다. 이 기능은 **선언한 메타데이터의 재사용**입니다. 자유문장의 의미나 원본 수치의 진위를 판정하지 않으며 결과의 `metricMeaning=not_verified`로 그 한계를 표시합니다.

### 단순 조회가 불필요한 완료 검증을 만들지 않도록 합니다

- 완료 기록에서 제한된 읽기 전용 Bash 조회를 구분합니다. `cd`, 숫자 행 범위만 출력하는 `sed -n '1,80p'`, 제한된 조회 파이프 등을 단순 조회로 처리합니다. 파일 확인은 여전히 `Read/Glob/Grep`을 우선합니다.
- 출력 파일 생성, 변경 명령 혼합, 명령 치환, 알 수 없는 구문과 위험한 `sed` 옵션은 이 예외에 넣지 않습니다. 옵션으로 확장될 수 있는 `sed`의 따옴표 없는 glob도 예외에서 제외합니다.
- 단순 조회는 새 변경 검증을 만들지 않지만 앞서 실제 변경한 항목의 미완료 검증은 그대로 남깁니다. 이는 **완료 기록의 분류**이며 명령 실행 권한을 승인하거나 실행 파일·별칭의 안전을 보증하는 기능이 아닙니다.

### 기존 자동학습의 다음 세션 전달과 취소를 확인했습니다

임시 설치·개인 상태·Claude 설정·프로젝트만 사용해 실제 Windows PowerShell 실행기, 후크와 CLI를 별도 프로세스로 호출했습니다. 가상 교정 한 번 제출 → 다음 세션의 같은 기억 ID·버전·본문 제공 → 해당 자동 변경 취소 → 다음 세션에서 제외되는 흐름을 검사했습니다. 수동 기억 보존, 프로젝트 간 분리, 충돌 보류, 학습 중지·재개도 확인했습니다.

이 검사는 기존 기능의 실행 계약을 확인한 것입니다. 외부 LLM·개인 Claude 계정·회사 자료를 사용하지 않았으며 사내 HCP가 교정을 잘 추출하거나 답변에 실제 적용했다는 증거는 아닙니다. `hostReceipt/modelApplied=not-observable`을 유지합니다.

## 유지하는 범위와 실행 비용

- 새 후크·별도 검증 모델·필수 비전 호출·학습용 Stop 재시도·권한 자동 승인은 추가하지 않습니다. 매 답변마다 회고나 학습을 강제로 실행하지 않습니다.
- 개인/프로젝트 저장 범위는 자동 이동하거나 합치지 않습니다. 기존 기억의 조건부 수정·같은 범위 이력 복원은 유지합니다. 자동학습 선호의 취소는 **비활성화**이며 이전 기억 본문 복원과 다릅니다.
- 선택형 Workspace는 기존 **0.9** 실행 코드와 학습 카드를 유지하고 사용자 안내서만 갱신합니다. 별도로 개발 중인 Workspace UI·실행기·권한 변경은 포함하지 않습니다. WS-33 제한도 해결한 배포가 아닙니다.
- 실제 사내 HCP의 성공률·응답 시간·토큰 절감량과 회사 Office·DRM 통합 품질은 미검증입니다. 로컬 테스트 경과 시간을 사내 업무 개선율로 제시하지 않습니다.

## 설치·업데이트

1. Release에 게시되는 `company-agent-1.4.32-2026.09.03.zip` 전체를 새 폴더에 풉니다. 뒤의 날짜 **2026.09.03**은 회사 지식팩 버전입니다.
2. 기존과 같은 설치 범위를 선택하여 백업 후 업데이트하고 Claude Code를 다시 시작합니다. 개인 Memory·Skill·Knowledge·모델·별도 MCP·인증 설정을 보존합니다.
3. 안내서만 보려면 단독 `Company-Agent-User-Guide.html`을 엽니다. 설치본과 Workspace에는 `Company-Agent-사용자-안내서.html`로 같은 안내서를 포함합니다.
4. Workspace를 쓴다면 기존 창을 닫고 별도 0.9 묶음을 새 폴더에 풉니다. 기존에 설치하거나 풀어 놓은 파일을 자동 갱신하지 않습니다.

공개 파일 게시 여부는 [1.4.32 Release](https://github.com/bongG-moon/claude_base_repo/releases/tag/v1.4.32)에서 확인합니다. GitHub의 자동 `Source code (zip)`은 직원용 설치 ZIP이 아닙니다. 승인된 Python 3.11 이상과 Claude Code가 필요하며 설치 과정에서 새 런타임·모델·외부 도구를 다운로드하지 않습니다. 이전 태그·ZIP은 보존합니다.
