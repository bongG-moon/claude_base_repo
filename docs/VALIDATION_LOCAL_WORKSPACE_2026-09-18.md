# 로컬 업무 화면 검증 — 2026-09-18

## 구현과 확인 범위

- AionUi 공개 interactive demo의 업무 선택/대화/오른쪽 결과를 직접 확인. OpenCovibe 공개 제품 화면·설명을 함께 참고.
- 외부 앱의 계정에 로그인하거나 해당 앱을 설치·실행하지 않음. 타사 코드 복사 없음.
- stdlib Python + 로컬 HTML/CSS/JS. 설치된 Claude Code 자식 프로세스와 JSON 제어 채널 연결. 추가 추론/라우팅 모델 없음.
- 한국어 업무 홈, 요청 카드, 원본 경로 첨부, 질문/승인, 중지, 대화 이력/이어하기, 문서 목록/텍스트·이미지 미리보기 구현.
- 현재 폴더/사용자의 CLI 설정을 읽게 하며 모델/API 주소/MCP/회사 플러그인/개인 스킬을 재작성하지 않음.

## 보호 및 실패 경로 확인

- 토큰 없는 요청, 다른 Origin/Host, cross-site API 요청 거절.
- 작업 폴더 밖 파일 열기/경로 이동과 실행 파일 열기 거절.
- 질문 답변 누락·중복 응답·만료된 요청·동시 업무 실행 거절.
- 승인 전달은 원래 요청 입력을 유지하고, 사용자가 선택한 답변만 추가.
- 백그라운드 작업자의 중간 result를 전체 완료로 표시하지 않음.
- 한글/특수문자 프롬프트 왕복, 후속 대화, 실제 CLI 세션 ID 이어하기 인수 검증.
- `<DOCUMENT SAFER ...>` 표식이 있는 **가상 바이트**를 첨부해 원본 비변경·사본 미생성 확인. 이 테스트는 DRM 해독/읽기 성공을 증명하지 않음.
- CP949 자료를 UTF-8로 잘못 미리보기하면 오류를 반환하고 원본은 유지. 손실 디코딩/덮어쓰기 없음.
- 재시작한 대화는 작업 폴더 설정 실행 동의를 다시 확인.
- 승인 원문/표준 오류를 기록하지 않으며, 앱 대화 기록에는 사용자/assistant 메시지만 보관.

## 남아 있는 사내 검증

사내 HCP 인증·모델 매핑, 운영환경 Company Agent 실제 로딩/선택, Office·DRM 읽기, 네이티브 확인 창, 실제 보고서 생성, 조직의 VBS/PowerShell 실행 정책은 여기서 검증하지 못했습니다. 이 환경의 CLI 초기화 성공을 사내 환경의 전체 업무 성공으로 확대하지 않습니다.

원본 CLI의 로그인/일부 TUI 전용 슬래시 명령/작업 팀 UI는 GUI에 재구현하지 않았습니다. 고급 메뉴로 원본 CLI를 열 수 있지만 터미널을 전혀 보이지 않게 하면서 CLI의 모든 화면을 동일하게 제공하는 단계는 아닙니다.

HTML은 현재 안전한 소스 보기만 지원합니다. 실제 HTML 렌더링/스크립트 실행 및 Office 미리보기 이미지 생성은 다음 범위입니다. 정식 Company Agent 설치 ZIP/GitHub Release/커밋/푸시는 이번 요청에 포함되지 않았습니다.
