# 1.4.25 변경·설치 안내

## 달라진 점

- PPT 선택을 마친 정상적인 ‘HTML 초안 필요’ 상태를 실행 오류로 표시하던 문제를 수정했습니다. 선택 파일의 성공한 수정과 실제 결과물 변경도 구분하여 불필요한 완료 검증을 줄였습니다.
- PPT·HTML의 첫 질문 전에는 빈 선택 파일이나 준비 명령을 만들지 않습니다. 잘못된 선택값에는 수정할 항목·허용값과 다음 단계를 안내합니다.
- 공통·PPT·HTML 스킬 본문을 합계 약 43% 줄이고 단계별로 필요한 참조만 읽도록 정리했습니다. 문자 수 감소이며 실제 모델 토큰·업무 시간 절감률을 보장하지 않습니다.
- 정확히 확인된 실행 전 승인 분류기 시간초과에는 한 번의 재시도 안내 후 보류하도록 했습니다. 실제 권한 거절이나 보안 정책은 우회하지 않습니다.
- 기본 HTML·PPT 제작기는 최종 결과 게시를 확인한 뒤 자신이 생성·등록한 변경 없는 중간 파일만 정리합니다. 원본·최종 결과·대표 양식·개인 자료·미등록·사용자 수정 파일과 최종 HTML 의존성은 보존합니다. 범용 강제 삭제 차단은 유지합니다.
- 질문·선택지·추천 표시의 한국어 기본 처리를 보완했습니다. 흔한 문구는 추가 AI 호출 없이 처리하며, 임의 문장의 재질문은 턴당 한 번으로 제한합니다. 파일명·명령어·답변 연결 키는 보존합니다.
- 단독 HTML 사용자 안내서와 설치용 Markdown을 위 동작에 맞게 갱신했습니다. Noto Sans KR 내장 글꼴과 오프라인 읽기는 유지합니다.

## 설치·업데이트

1. `company-agent-1.4.25-2026.09.03.zip`을 새 폴더에 풉니다. 뒤의 날짜는 회사 지식팩 버전입니다.
2. 기존과 같은 설치 범위를 선택해 백업 후 업데이트합니다. 개인 기억·지식·스킬·모델·별도 MCP 설정을 보존합니다.
3. Claude Code를 종료하고 다시 실행합니다. 이미 실행 중인 대화가 이전 플러그인을 계속 사용하지 않도록 새 대화에서 확인합니다.
4. Workspace 사용자는 이번 Release의 새 `company-workspace-preview-0.8-*.zip`을 사용합니다. 실행 코드 버전은 0.8을 유지하며 이번 ZIP은 안내서를 갱신했습니다.

기존 1.4.24 ZIP은 덮어쓰지 않습니다. 승인된 Python 3.11 이상과 기존 Claude Code 환경을 사용합니다. 별도 첨부 `Company-Agent-User-Guide.html`은 전체 내용을 담은 단독 안내서입니다.

## 알려진 제한과 확인할 것

- 비전 모델 자동 선택·게이트웨이 설정은 변경하지 않았습니다. 텍스트 전용 모델에서 이미지 검사를 시도하면 여전히 모델 오류가 발생할 수 있습니다. 비전 사용 가능 여부는 별도 운영 확인이 필요합니다.
- 사내 승인 분류기 서비스 자체의 장애를 고치는 버전은 아닙니다. 반복 안내와 준비 단계의 잘못된 실패 판정을 줄였습니다.
- 로컬 가상 PPT 생성·내용·편집 가능 개체 검사는 통과했으나, 검증 PC의 PowerPoint 자동 실행 실패로 최종 화면 검사는 미완료입니다. 실제 회사 환경에서 글자 잘림과 배치를 확인해야 합니다.
- 중간 파일 정리는 기본 제작기가 새로 추적한 작업에 한정됩니다. 기존 폴더 전체, 다른 도구가 만든 파일, 게시 전 작업을 임의로 지우지 않습니다. 잠금·정리 실패는 이미 생성한 결과물의 재제작 사유가 아닙니다.
- 한국어 처리는 모델이 만드는 질문을 대상으로 하며 Claude 자체 메뉴·권한 버튼·외부 도구 원문까지 바꾸지는 않습니다.
- 기본 Office Reader 제거 상태를 유지합니다. 문서 읽기는 실제 설치된 개인·공통 스킬과 도구의 지원 범위에 따릅니다. CUA·Driver·별도 시험 가이드는 포함하지 않습니다.

상세 검사와 배포 파일 SHA-256은 저장소의 `docs/VALIDATION_RELEASE_1.4.25.md`에 기록합니다. 파일 무결성 검증 문서는 순환 해시를 피하기 위해 설치 ZIP 밖에 둡니다.
