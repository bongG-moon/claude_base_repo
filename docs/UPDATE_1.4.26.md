# 1.4.26 변경·설치 안내

## 달라진 점

- 시작하기·Claude Code 기본 사용법·업무 예문·기억/스킬/후크/학습·명령어/단축키·디자인 용어를 `Company-Agent-사용자-안내서.html` 한 파일로 통일했습니다. 6부·52장을 담고 Noto Sans KR 글꼴을 내장하여 오프라인에서도 읽습니다.
- 중복 HTML과 별도 첫 업무 HTML을 제거했습니다. 설치 완료 화면과 Workspace는 같은 안내서를 열고, Workspace의 예전 안내 URL은 해당 구역으로 연결합니다. 편집용·글 읽기용 Markdown 7개는 유지하고 과거 감사·변경 기록은 새 직원 ZIP에서 제외합니다.
- 작업 종류와 행동을 비교해 스킬 설치 요청에 무관한 읽기 스킬을 강제하지 않습니다. 같은 역할의 공통·개인 후보가 겹치면 실제 사용자 선택을 확인합니다. 세션에만 노출되는 외부 스킬은 성공한 로드와 현재 질문의 답변을 기준으로 처리하며, 선택 뒤 회사 스킬로 임의 교체하지 않습니다.
- “읽은 내용을 HTML 보고서로 만들어줘”에서 완료된 읽기를 새 읽기 작업으로 오해해 HTML 스킬 선택을 보류하던 회귀를 수정했습니다. “다시 읽고”처럼 실제로 새 읽기를 요청하면 읽기 단계를 유지합니다.
- 같은 작업의 대화 압축 후에는 확인된 로컬 스킬 선택 힌트만 짧게 복원하고 필요한 본문을 다시 읽습니다. 새 작업이나 변경된 스킬, 본문을 확인할 수 없는 원격 스킬에 기존 증거를 재사용하지 않습니다.
- 긴 설치·프로젝트 경로에서 문맥 크기 제한을 넘으면 필수 실행 정보까지 빠지던 결함을 수정했습니다. 6,000자 한도는 유지하고 중복 안내를 더 줄여 실행 명령·저장소·현재 세션 정보를 보존합니다.
- PPT·HTML 화면 검토는 최초 전체, 수정 후 영향 범위 중심으로 수행하도록 지침을 정리했습니다. 공통 테마 변경이나 영향 범위가 불명확하면 전체를 재검토합니다. 모델·자동 압축 설정은 바꾸지 않습니다.
- 작업 흐름·구조를 정리해 달라는 요청에는 기존 HTML 제작 기능에서 작은 설명 도표를 만들 수 있습니다. 일반 HTML 보고서나 업무 완료마다 자동으로 추가하지 않습니다. 선택적인 단계 강조 애니메이션과 사용자 클릭에 의한 SVG/PNG 저장을 제공하며 자동 재생·자동 다운로드·실제 업무 재실행은 하지 않습니다.
- 설명 도표는 기본 외부 연결 없이 동작합니다. Google Fonts는 명시적인 `fontSource:google` 선택일 때만 사용하며, 움직임 줄이기 설정과 정적 보기·인쇄를 고려합니다. 새 모델 호출·MCP·상시 후크를 추가하지 않습니다.
- Workspace 0.9에는 본인 계정·세션 확인, 일반 권한 재실행 조건, 한국어 시작 오류 안내와 단일 사용자 안내서 연결을 포함합니다. 별도 Workspace ZIP에서 빠져 있던 `Check-Workspace.cmd`·진단 스크립트·진단 안내도 포함했습니다.

## 설치·업데이트

1. `company-agent-1.4.26-2026.09.03.zip`을 새 폴더에 풉니다. 뒤의 날짜는 회사 지식팩 버전입니다.
2. 기존과 같은 설치 범위에서 백업 후 업데이트합니다. 개인 기억·지식·스킬·모델·별도 MCP 설정은 보존합니다.
3. Claude Code를 닫고 다시 실행한 뒤 새 대화에서 확인합니다.
4. Workspace 사용자는 별도 `company-workspace-preview-0.9-*.zip`을 새 폴더에 풀어 사용합니다. 하네스 업데이트만으로 기존 Workspace 폴더가 갱신되지는 않습니다.

기존 1.4.25 ZIP·태그는 덮어쓰지 않습니다. 기본 직원 ZIP은 이미 설치된 승인 Python 3.11 이상과 Claude Code를 사용하며 실행 파일을 다운로드하거나 사내 모델 연결을 변경하지 않습니다. 별도 첨부 `Company-Agent-User-Guide.html`은 위 한국어 파일명 안내서와 바이트가 같은 단독 HTML입니다.

## 알려진 제한

- 사내 HCP 모델의 실제 스킬 선택 정확도, 토큰 절감률과 업무 지연 감소를 보장한 결과는 아닙니다. 자동 검사와 실제 사내 모델 검증을 구분합니다.
- 일반 권한 연결 토큰이 없는 관리자 환경에서는 Workspace가 여전히 `WS-33`으로 중단될 수 있습니다. UAC를 끄거나 관리자 권한 실행을 허용하는 변경은 하지 않았으며 해당 환경 지원은 별도 미해결 항목입니다.
- 새 설명 도표의 브라우저 육안 검사·실제 이미지 다운로드·인쇄 결과 검사는 미실시입니다. 입력·배치 경계·출하 JavaScript의 단위 테스트를 실제 시각 검사로 대신 표현하지 않습니다.
- Office Reader·CUA와 별도 CUA 시험 가이드는 포함하지 않습니다. 비전 모델 자동 선택이나 게이트웨이 수정도 하지 않습니다.
- 권한·DB 쓰기 등 기존 회사 정책은 다른 스킬을 선택해도 유지됩니다. 없음·실패·거절을 성공한 로드나 완료 결과로 바꾸지 않습니다.

검사 결과와 배포 파일 SHA-256은 저장소의 [1.4.26 배포 검증](VALIDATION_RELEASE_1.4.26.md)에 기록합니다. 이 기록은 순환 해시를 피하기 위해 설치 ZIP 밖에 둡니다.
