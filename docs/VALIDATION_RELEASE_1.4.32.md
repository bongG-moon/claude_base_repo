## 검사 과정에서 구분한 사항

- 개발 단계의 첫 전체 실행은 안내서 용량 검사 1건이 실패했습니다. 중복 설명을 줄인 뒤 최종 전체 회귀를 다시 통과했습니다. 독립 검토에서 기본 KPI 이름 재치환과 sed glob 확장 위험도 수정하고 회귀를 추가했습니다. 상세 경과는 사용성 검증 문서에 있습니다.
- 버전 갱신 중 README의 현재 배포 문구가 기존 계약과 달라 handbook 검사 1건이 실패했습니다. 게시용 문구를 수정하고 같은 20건을 다시 통과했습니다. 테스트 조건은 완화하지 않았습니다.
- 최초 설치 시험을 PowerShell 7에서 시작했을 때 기존 설치기의 `Directory.SetAccessControl` API 차이로 설치 전 중단됐습니다. 실제 배포 실행기가 사용하는 `powershell.exe`(Windows PowerShell 5.1)에서 최종 ZIP을 다시 시험해 통과했습니다. PowerShell 7 설치 호환성을 검증했다고 주장하지 않습니다. 실제 사용자 프로필은 변경하지 않았습니다.
- Git 텍스트 줄바꿈 정규화와 ZIP 원본 바이트는 구분합니다. 패키지는 실제 선택 소스 바이트와 대조했고 기존 권한·기억 모듈의 줄바꿈만 다른 부분은 기능 변경으로 계산하지 않았습니다.
- 혼합 작업 파일 `state.py`는 완료 조회 분류 함수만, `docs/LOCAL_WORKSPACE.md`는 공개 0.9 기준의 배포 안내만 선택했습니다. 작업 폴더의 다른 변경·개인 자료를 삭제하거나 되돌리지 않았습니다.
