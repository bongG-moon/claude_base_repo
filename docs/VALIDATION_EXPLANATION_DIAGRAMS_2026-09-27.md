# 요청형 설명 도표 검증 기록

## 구현 범위

- 기존 `html-report`의 선택 기능. 작업 완료·일반 HTML 제작에 자동 첨부하지 않음.
- 흐름·구조·역할별 인계·상태 전이의 작은 도식. 최대 노드 9개, 연결 12개, 역할 4개.
- 기본 전체 정적 내용, 필요한 경우만 명시된 순서의 단계 강조. 자동 재생·실제 업무 재실행·실시간 진행률 없음.
- 관련 참조는 요청 시에만 읽음. 추가 LLM 호출·새 후크·플러그인·MCP·실행 서비스 없음.
- 기본 외부 연결 없음. `fontSource:google`일 때만 고정 Google Fonts 주소의 Noto Sans KR 사용. 연결 불가 시 시스템 글꼴.
- 사용자 클릭 시에만 SVG/PNG 저장. PNG 4096px/1200만 픽셀 이내. 상세 설명과 근거는 HTML에 남음.
- 기존 임시 작업·최종 발행 경로 사용. 설명마다 PNG/SVG 파일을 자동 추가하지 않음. PPT에서 도표를 몰래 생략하지 않고 미지원 안내.
- 개인 기억·스킬·MCP·모델 설정은 변경하지 않음. 사용자 안내 Markdown과 단독 HTML/설치용 사본 동기화.

## 확인한 결과

`python -X utf8 -B -m unittest discover -s tests -p 'test_explanation*.py' -v`

- 49개 통과: 입력 경계·정규화·삽입 방지·4가지 배치·긴 한글·연결 대상/번호·CSP·글꼴 선택·최종 파일 하나·정적 미리보기·PPT 생략 방지·요청 라우팅.
- 실제 출하 JS를 순수 Node VM에서 실행: 자동 재생/다운로드 없음, 유한 재생·단일 타이머·일시정지·단계·초기화, 움직임 줄이기·화면 숨김·인쇄, SVG/PNG 성공·실패·자원 정리.
- 648개 방향별 연결 경로 및 밀집 연결 번호의 기하 경계 검증. 번호가 노드·역할 제목·다른 번호와 겹치지 않는 배치 확인.

## 한계와 남은 확인

- 브라우저의 로컬 파일 접근 제한을 우회하지 않았으므로 **실제 화면·인쇄·실제 다운로드 저장의 시각/E2E 검증은 미실시**. Node VM·정적 검사·기하 테스트가 이를 대신 증명하지 않음.
- 노드가 많으면 가로 스크롤이 필요하고 연결선끼리 교차할 수 있음. 번호별 전체 관계 설명과 근거를 HTML에 유지. 긴 도표는 인쇄 높이를 제한하며 아래 글 설명을 함께 제공.
- 라우팅 테스트는 후보 판단 코드의 동작을 확인한 것. 운영 HCP 모델의 모든 자연어 요청 준수를 보증하지 않음.
- 초기 검사에서 발견한 PPT 검증 문구 불일치는 후속 배포 검사에서 해소했다. 처음에는 모든 장, 수정 후에는 변경·영향받은 장, 공통 변경·영향 범위 불명확 시에는 다시 모든 장을 확인하는 계약을 검사한다. 문서의 품질 기준은 낮추지 않았다.
- 이 문서는 기능 단위 검증 기록이다. 후속 전체 재검사와 배포 파일 결과는 [1.4.26 배포 검증](VALIDATION_RELEASE_1.4.26.md)에 구분하여 기록한다. 운영 PC 적용 결과는 포함하지 않는다.

가상 예제 입력: `company-agent-plugin/templates/business/explanation.spec.json`.
체험 요청: “방금 작업한 흐름을 HTML 한 파일로 설명해줘. 확인·미확인을 구분하고 단계별 설명 재생을 넣되 업무를 다시 실행하지 마.”
