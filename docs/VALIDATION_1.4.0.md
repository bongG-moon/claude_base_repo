# 1.4.0 검증 기록

## 실행 결과 (2026-09-14, Windows 개발 PC)

- Python 전체 검사 534개 통과, 실패 0개, 제외 0개 — 88.131초.
  `PYTHONUTF8=1`, `COMPANY_AGENT_TEST_REAL_CLAUDE=1`로 실행했습니다.
  실제 Claude 검사는 격리된 설정 등록 검사이며 사내 모델 대화 E2E 검사는 아닙니다.
- 새 PPT 검사 13개: 순차 질문·기존 답 보존·선택 전 파일 미생성,
  실제 PPT 원본 바이트 보존, 위치·폰트·색상 유지, 편집 가능한 표·차트 값 교체,
  잘못된 매핑/과다 분량 거부, 미리보기 차단 처리, 추가 검사기 응답 계약.
- 오류 진단 검사 5개: 안전 확인 지연과 업무 실패 구분, 이전 변경 확인 의무 보존,
  일반 시간 초과/거절 오분류 방지, 재시도 제한 지침, 실제 읽기 전용 Windows 진단.
- 스킬 목록 검사 12개 및 우선 설정 통합 검사 18개: 최초 MD 생성,
  설치·삭제·설명·본문·활성화·우선 설정 변경 감지, 무변경 파일 유지,
  정상 MD일 때 일치하는 키워드 카드도 주입하지 않음, 현재 resolve 우선 선택 보존.
- HTML 디자인 선택 검사 17개, 단축키 안내 동작 검사 16개 통과.
  브라우저 없는 동작 검사이며 화면 육안 검사가 아닙니다.
- 사용자 HTML 안내서 재생성: 20개 장, 예문 57개. 1.4.0 변경·한계 반영.
- Windows PowerShell 5.1 설치 묶음 회귀 검사 통과: 기존 Python 3.11 이상 사용,
  배포 도구 17개 및 새 기능·설명 파일 포함/무결성 검사. 원본 설정에 설치하지 않음.
- 새 진단 스크립트 구문 검사 통과. 진단 실행은 경로·버전 메타데이터만 조회하며
  Claude 실행·PATH 변경·래퍼 삭제를 하지 않았습니다.

## 검사에서 발견해 수정한 사항

- 추가 안내로 기본 컨텍스트 제한을 넘는 경우: 6,000자 제한은 유지하고 지침을 축약했습니다.
- 기존 테스트의 중복 추천 카드 기대값: 이제 MD에 선택 상태가 있고 현재 resolve와
  일치하는지 검증합니다. 우선 설정 검사를 제거하거나 제한을 완화하지 않았습니다.
- Windows PowerShell의 한글 경로 해석: 수정된 PowerShell 파일을 UTF-8 BOM으로 정규화했습니다.
- 양식 매핑에 사용되지 않은 개체 ID가 있어도 성공하던 경우를 거부하도록 보완했습니다.
- 추가 검사기의 종료값이 0이어도 JSON에 경고가 있으면 확인 필요로 처리합니다.

## 남은 운영 확인

실제 사내 모델 서버의 지연·DRM·Office 2016 조합은 이 개발 PC 검사로 보증하지 않습니다.
Ctrl+C 종료 오류 원인은 확정되지 않았고 읽기 전용 실행 경로 진단을 추가한 상태입니다.
PPT 파일의 구조·값·서식 보존 검사는 미적 완성도나 모든 슬라이드의 육안 검수를 대신하지 않습니다.
스킬 목록을 읽으라는 지침을 모델이 항상 준수한다는 보장이나 실제 토큰 절감률 평가는 아닙니다.
Archforge는 별도 사전 설치가 필요한 선택 기능입니다. 이 PC에서 실제 패키지 실행은
검증하지 않았고 미설치·경고 JSON 응답 경로를 격리 검사했습니다. 자동 다운로드하지 않습니다.
PowerPoint 렌더링의 보호 차단·실패는 테스트 대역으로 확인했습니다. 이번 변경에서
실제 Office 화면이나 생성 슬라이드의 미적 완성도를 육안 검수했다고 주장하지 않습니다.
네이티브 오류가 Hook에 전달되지 않으면 이번 분류 지침도 자동 적용되지 않을 수 있습니다.
현재 사용자 설치 등록은 1.3.9이며 새 버전을 자동 설치하거나 GitHub에 게시하지 않았습니다.
