# Company Harness 1.4.48 릴리즈 검증

2026-10-31. 하네스, 독립 스킬 원본과 `skills_zip`을 함께 배포한다. 별도 Workspace 앱, 실습 폴더와 개인 프로필 변경은 포함하지 않는다.

## 코드와 기능

- [스킬 개선 검증](VALIDATION_SKILL_IMPROVEMENTS_20261031.md)의 410개 통과, 3개 건너뜀을 유지했다.
- 배포에 포함되는 비전 설정과 이미지 전처리, 스킬 선택, 요청형 사용성 보고서, 설치 안내와 조회 스킬의 추가 회귀에서 438개 통과, 2개 건너뜀을 확인했다. 스킬 실행 26개를 포함하며 동일 시험의 재시도와 중복 실행은 합산하지 않았다.
- 합계 848개 통과, 5개 건너뜀이다. 건너뜀은 격리 Python의 python-pptx 미설치 2개와 Windows 심볼릭 링크 생성 권한 3개다. 일반 Python에서는 실제 독립 ZIP의 네이티브 PPT 생성과 비교를 별도로 확인했다.
- 기존 외부 Oracle MCP의 설치 및 통신 시험 1개는 이전 검증에서 시간 초과했으며 이번에도 미검증으로 남긴다. 원본 MCP ZIP은 변경하지 않았고 정적 패키지 보존 검사는 통과했다. 운영 DB에 접속하지 않았다.

배포 직전 일반 요청에 비전 안내가 반복되어 기존 컨텍스트 한도를 넘는 문제를 재현했다. 상세 안내는 SessionStart, 작업자와 실제 이미지 읽기 경로에 유지하고 일반 요청의 반복 문구 및 메타데이터만 줄였다. 같은 합성 HTML 요청에서 5,253자에서 4,922자로 줄어 기존 5,000자 기준을 통과했다. 실제 모델 토큰이나 응답 시간을 측정한 수치는 아니다. 추가 후크, 모델 호출과 질문을 넣지 않았다.

첫 추가 검사에서는 시험 Python의 import 경로 누락, 샌드박스의 PowerShell 로드 제한과 검사 묶음의 180초 제한을 확인했다. import 경로를 지정하고 격리 자료를 유지한 채 허용된 실행 환경에서 충분한 실행 시간으로 다시 검증했다. PC 실행 정책이나 실제 개인 설정은 바꾸지 않았다. 화면 검토 시험은 지침의 고정 단계 번호 대신 실제 조건부 검토 단계를 확인하도록 맞췄다.

## 소스와 패키지

- 최신 로컬 플랫폼 배포 정본을 읽고 개별 패키지 17개를 생성했다. 정본과 ZIP의 `--check`, Excel, 업무 분석 및 조회 스킬의 사본 동기화 검사가 통과했다.
- 통합 안내서는 6부분, 52장이고 Markdown, 설치 사본과 생성 결과가 일치한다. 이번 릴리즈에서 새로운 실제 브라우저 화면 검사는 수행하지 않았다.
- 설치 ZIP은 운영 파일 295개를 포함한다. manifest의 크기와 SHA-256, 현재 플러그인 원본 일치를 확인했다.
- 설치 EXE는 같은 ZIP을 내장하며 설치하지 않는 `--verify-only` 검사를 통과했다. 개별 묶음은 스킬 16개, 기존 MCP 1개와 catalog, 체크섬, HTML의 총 20개 파일이며 `skills_zip` 바이트와 일치한다.
- Windows PowerShell 5.1에서 실제 이전 공식 ZIP을 설치하고 1.4.48로 업데이트했다. 별도 임시 프로필의 개인 자료, 모델, MCP, 긴 경로 스킬 백업, 실제 Claude 등록과 SessionStart 및 Read 후크 등록을 보존했다. 원래 사용자의 Claude 프로필은 변경하지 않았다. 첫 PowerShell 7 실행은 이전 설치기의 API 차이로 초기 백업 단계에서 중단되어 지원 런타임으로 다시 검사했다.
- 소스 및 ZIP 내부 1,529개 항목의 경로와 알려진 토큰 및 비밀키 패턴을 검사해 해당 패턴의 실제 비밀정보를 발견하지 않았다. 패턴 검사만으로 모든 형태의 비밀정보 부재를 보증하지는 않는다.

## 운영 검증 경계

실제 사내 HCP 모델, DRM, Outlook, DB와 Excel의 전체 계산 동등성은 검증하지 않았다. 합성 승인과 더미 DB 시험을 사용자 승인이나 운영 업무 성공으로 표시하지 않는다. 실제 사내 GitLab 게시 및 직원 PC 적용은 별도이며 EXE에는 코드 서명이 없다.

이번 릴리즈의 파일별 SHA-256은 Release 첨부 `.sha256` 파일에서 확인한다. 게시 전후 검증의 원시 결과는 `.smoke/release-1.4.48/`에 보관한다.
