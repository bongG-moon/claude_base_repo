## 검사 중 확인한 사항

- 처음 전체 검사에서 발견한 후보 선택 회귀를 숨기거나 해당 검사를 제거하지 않았습니다. 실제 설명을 고친 뒤 기존 검사와 전체 검사를 다시 실행했습니다.
- 긴 `.smoke` 소스 경로에서는 Python 구문 검사 중 임시 캐시 파일의 Windows 경로 길이 오류가 발생했습니다. 동일한 선별 소스를 짧은 임시 경로로 복사하여 정상 검사·패키징했습니다. 사용자 PC 정책이나 설치 조건은 바꾸지 않았습니다.
- 수정 전 미게시 ZIP은 개발용 임시 보관 위치에 보존했습니다. 동일 버전의 다른 내용 덮어쓰기를 막는 포장 검사는 유지하며, 최종 ZIP만 게시합니다. 기존 공개 Release·태그·ZIP은 변경하지 않습니다.
- 안내서 재검사 중 필수 `--modules` 인수를 빠뜨린 호출은 실행 전에 거부되었습니다. 승인된 로컬 모듈 경로를 명시하여 재검사했고 다운로드·추가 설치는 하지 않았습니다.
- Git 정규화로 3개 파일의 CRLF/LF만 다르며 커밋 대상과 선별 소스의 정규화된 내용은 동일합니다. ZIP은 패키징 소스의 바이트와 직접 대조했습니다. 기존 실행기 진단 해시를 바꾸기 위한 일괄 줄바꿈 변환은 하지 않았습니다.

## 확인하지 않은 범위

실제 사내 HCP의 교정 추출 정확도·지침 준수·체감 속도·토큰 절감량, 회사 PC의 WS-33, 비전 모델·게이트웨이는 미검증입니다. 실제 Office·메일 업무나 새 브라우저 시각 검사는 수행하지 않았습니다.

절차 학습의 검증 조건은 현재 요청·업무에 연결된 모델의 검증 기록을 검사합니다. 하네스가 모든 실제 테스트 수행을 독립적으로 증명하는 기능은 아닙니다. 접수·실제 변경·모델 입력 제공·답변 적용을 같은 성공으로 간주하지 않습니다.

개인 자료와 별도 진행 중인 Workspace 작업은 보존합니다. 설치된 PC를 자동 갱신하지 않으며, 기존과 같은 범위로 설치 후 Claude Code를 다시 시작해야 합니다.
