# 보고서 선택 대기·실행 대기와 흰색 유리 디자인 수정

## 원인과 수정 범위

기존 HTML 스킬은 8개 디자인을 일반 채팅으로 나열한 뒤 선택받도록 했지만, 선택 도구를 반드시 사용하거나 대화를 마치고 기다리라는 지침이 명확하지 않았습니다. 선택 도구가 있는 환경은 1~4번 / 5~8번 / 미리보기 세 선택지를 거쳐 실제 디자인을 고릅니다. 전체 8개 목록을 함께 제공하며, 어느 단계에서든 번호나 이름을 직접 입력할 수 있습니다. 도구가 없으면 선택 대기임을 명시하고 턴을 끝냅니다. 미리보기 선택은 디자인 확정이 아닙니다.

완료 확인 로직은 변경 기록만 보고 보정을 시작했습니다. 따라서 작업이 백그라운드에서 실행 중인 Stop도 보정 기회를 소모했습니다. 이제 Claude의 Stop 입력에 있는 `background_tasks` 중 실행 중인 서브에이전트/셸 작업을 확인하면 조용히 반환합니다. 보정 횟수, 기존 검증 상태, 학습 상태를 바꾸지 않습니다. 작업이 끝나면 기존의 실제 산출물 검증 의무가 다시 적용됩니다. 작업 종료 자체를 성공으로 기록하지 않습니다.

해당 필드가 없는 구형 환경에서는 성공한 비동기 Agent/Task 시작 응답의 작업 ID와 시각만 보관하며 TaskOutput의 종료 상태로 해제합니다. 원문·작업 내용은 보관하지 않고, 누락된 종료 알림 때문에 영구 대기하지 않도록 30분의 유효기간과 32개 제한을 둡니다. 최신의 비어 있는 작업 목록은 오래된 기록보다 우선합니다. 모니터와 정기 예약만 있다는 이유로 완료 검사를 미루지 않습니다.

`prompt is required when stop is not true`는 필수 입력 누락 오류입니다. 제공된 로그에 원래 도구 호출 인자가 없어 정확히 어떤 호출이었는지는 단정할 수 없습니다. 실행 대기에 빈 Agent/resume 호출을 사용하지 말고 실제 제공되는 결과 조회 도구 또는 완료 알림을 사용하도록 공통 실행 지침과 보고서 스킬을 수정했습니다. 완료 후 결과 확인까지 수행하며, 자동 알림은 실제 지원되는 경우에만 약속합니다.

`Ran 2 stop hooks`는 둘 이상의 후크가 실행됐다는 뜻이지 모두 Company Agent라는 증거는 아닙니다. 다른 플러그인이나 회사 관리 후크는 이번 수정에서 변경하지 않습니다. 실제 검증 실패를 숨기거나 권한을 자동 해제하지 않습니다.

## 디자인

글래스모피즘은 흰색·연회색 배경과 반투명 흰색 표면, 배경 흐림, 밝은 테두리, 얕은 중립 그림자로 변경했습니다. 차트 계열도 무채색 명도와 레이블로 구분합니다. 여러 색이 섞이는 표현은 그라디언트 메시 양식에 남습니다. 첨부 양식의 명시적 색상은 기존처럼 우선합니다.

미리보기와 실제 보고서는 같은 테마를 사용합니다. 기존에 생성한 사용자 HTML 파일, 개인 PC 설치본과 이미 만든 1.4.4 ZIP은 자동 변경하지 않습니다. 설치본으로 적용하려면 새 버전 패키징이 필요합니다.

## 검증 방법

- `tests/test_background_completion.py`: 실행 중 반복 Stop, 기존 보정 예산 유지, 완료/실패 후 실제 검증 요구, 구형 응답, 오래된 기록, 메타데이터 보존 범위를 검사합니다.
- `tests/test_skill_workflow_native.py`: Windows 실행 진입점으로 실행 중 Stop을 반복하고, 작업 종료 후 완료 확인이 재개되는지 검사합니다.
- `tests/test_report_styles.py`: 질문당 최대 4개 선택지, 전체 8개 보존, 기존 분량 유지와 무채색 테마를 검사합니다.
- `scripts/test-lab/check-report-themes.mjs`: 격리된 Edge에서 8개 디자인의 1440/768/390px 표시, 실제 CSS 중립색, 미리보기 일치, 페이지 전환과 인쇄를 검사합니다.

공식 참고: [Claude Hooks](https://code.claude.com/docs/en/hooks), [사용자 선택 입력](https://code.claude.com/docs/en/agent-sdk/user-input). 실제 운영 모델이 선택 도구와 대기 도구를 따르는지에 대한 채팅 검증은 별도로 필요합니다.
