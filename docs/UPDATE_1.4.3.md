# 1.4.3 — 첫 업무 스킬 선택 연결 개선

## 기존 사용자의 업데이트

1. 진행 중인 Claude Code 작업을 마무리하고 종료합니다.
2. 새 ZIP을 **새 폴더에 모두 압축 해제**합니다. 예전 설치 폴더 위에 섞어서 풀지 않습니다.
3. 맨 위의 **Install-CompanyAgent.cmd**를 더블클릭합니다.
4. 기존과 같은 범위(Windows 계정 전체 또는 사용 중인 프로젝트)를 선택합니다.
5. `기존 버전 → 1.4.3`을 확인하고 **백업 후 업데이트**를 선택합니다.
6. 설치 완료 후 Claude Code를 다시 실행합니다.

처음 설치하는 경우에도 같은 파일로 진행하며 필요한 선택은 설치기가 안내합니다.
기존 Python 3.11 이상과 Claude Code를 사용합니다. Python·Office·회사 모델을 새로 설치하거나 다운로드하지 않습니다.
개인 Memory·학습 이력·Skill·Knowledge·모델 설정·MCP 연결은 유지합니다.
파일명 뒤의 `2026.09.03`은 회사 지식팩 버전이며 프로그램 버전은 **1.4.3**입니다.

## 달라진 점

- 처음 업무를 수행하기 전에 전체 스킬 목록과 선택한 스킬을 읽었는지 확인합니다.
- 개인·프로젝트별 우선 설정을 적용하고, 다른 출처의 스킬로 임의 대체하지 않도록 보완했습니다.
- 이미 읽은 목록·스킬은 재사용하고, 새 요청에서는 업무에 맞는 선택을 다시 합니다.
- 변경·삭제·컴팩트 이후에는 필요한 읽기 기록을 갱신합니다.
- 공통 조율 지침만 읽은 것을 실제 업무 스킬 선택으로 착각하지 않도록 했습니다.
- 작업자에게 선택한 스킬의 정확한 파일 위치를 전달합니다.
- 누락된 준비는 실행 전에 안내합니다. 이 확인을 업무 마지막의 검증 실패로 처리하지 않습니다.
- 표시되는 플러그인 버전과 내부 CLI 버전을 1.4.3으로 일치시켰습니다.

사용자는 평소처럼 “PPT 내용을 분석해줘”, “이 프로젝트 방식으로 업무 메모를 만들어줘”라고 요청하면 됩니다.
필요한 준비를 건너뛴 경우 짧은 내부 안내가 보일 수 있습니다. 실제 실행 승인·회사 정책은 그대로 적용됩니다.

## 검증 범위와 주의점

선택 연결 소스의 자동 검사 610개가 통과했습니다(제외 0개).
실제 Claude Code에서 PPT 읽기 스킬 선택과 프로젝트 전용 스킬을 이용한 메모 생성을 확인했습니다.
PPT의 실제 Office 실행은 테스트 승인 제한으로 수행하지 않았으므로 사내 문서 읽기 성공을 보장하지 않습니다.
모델이 첫 시도부터 항상 최적의 스킬을 고르거나 모든 내부 안내가 사라지는 것은 아닙니다.
기존 업무 결과 검증 안내와 이번 스킬 준비 확인은 별개입니다.
