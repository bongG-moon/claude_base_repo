# Company Harness 1.4.39

이번 배포는 스킬을 만들고 사용하고 수정하는 흐름을 Claude 기본 환경과 맞추고, PPT 참고와 메일 조회 범위를 줄이는 데 초점을 둡니다. 별도 개발 중인 Workspace 앱·Computer Use MCP·실습 자료 변경은 포함하지 않습니다.

## 새 스킬은 원본 하나로 사용합니다

- 개인 전체 스킬은 현재 Claude 설정 폴더의 `skills/<이름>/SKILL.md`, 프로젝트 스킬은 `<프로젝트>/.claude/skills/<이름>/SKILL.md`에 저장합니다. 관리용 정보만 하네스 저장소에 남기며 같은 이름의 실행 사본을 추가하지 않습니다.
- 새 스킬은 `/<이름>`으로 사용할 수 있는 위치에 생성합니다. 현재 CLI의 목록에 아직 없다면 지원되는 `/reload-skills` 또는 새 대화에서 확인합니다. 파일 생성과 현재 호스트의 발견·업무 실행 성공은 구분합니다. 이번 설치 파일이 별도 Workspace 앱의 새로고침 기능까지 갱신하는 것은 아닙니다.
- 기존 비공개 저장소의 스킬은 자동 이동·복제하지 않고 같은 경로에서 유지합니다. 기존 Claude 스킬도 원본과 frontmatter를 보존합니다. 프로젝트 스킬은 폴더 공유 시 함께 전달될 수 있지만 기억·도구의 비공개 저장 범위는 바꾸지 않습니다.
- 기존 스킬 수정은 `asset inspect`로 실제 원본과 해시를 확인한 뒤 `asset update`로 필요한 본문만 바꿉니다. 사용자에게 AssetSpec이나 제작 스크립트를 다시 쓰게 하지 않으며, 동시에 바뀐 파일이나 같은 이름의 다른 자산을 덮어쓰지 않습니다.

## 학습도 실제 원본을 기준으로 합니다

제작기에 등록된 새 스킬은 정확한 원본·전체 본문 로드·현재 검증 근거를 확인한 작은 절차 개선만 학습에 연결합니다. 기존 비공개 스킬의 학습은 원래 대상을 유지하고, 직접 설치한 기존 Claude 스킬을 임의로 자동 수정 대상으로 추가하지 않습니다. 같은 이름의 다른 파일로 학습 대상을 바꾸지 않으며 수동 편집과 충돌하면 덮어쓰지 않습니다. 매 답변마다 별도 학습 모델을 호출하거나 기존 학습 저장소를 자동 병합하지 않습니다.

## PPT 참고 입력을 구분합니다

- 보호 제한 없는 PPTX를 직접 첨부할 수 있습니다. 디자인 참고는 대표 2~3장, 전체 내용 참고는 요청한 장을 작은 묶음으로 확인합니다. 구조 미리보기만으로 전체 내용을 읽었다고 보고하지 않습니다.
- 정상 PowerPoint에서 볼 수 있고 화면 캡처·AI 처리·저장이 허용된 자료는 연결된 실제 화면 도구나 사용자가 제공한 허용된 캡처로 참고할 수 있습니다. `ppt-reference`의 화면 모드는 계획만 반환하며 화면 도구 설치·Office 열기·캡처·권한 부여를 수행하지 않습니다. 실제 거절 뒤 Export·OCR 등 다른 경로로 우회하지 않습니다.
- 기존 HTML·이미지 참고와 HTML 초안 확인 후 편집 가능한 PPT로 만드는 흐름은 유지합니다. 참고 이미지 한 장을 붙였다는 사실을 편집 가능한 도형·표·차트 제작으로 간주하지 않습니다.

## Outlook은 필요한 내용만 읽습니다

목록 최대 20건부터 검색하고 관련 본문은 보통 최대 5건, 건당 4,000자·합계 12,000자부터 사용합니다. 정확한 메일을 지정하면 검색을 생략하고, 목록·건수 요청에는 본문을 읽지 않습니다. 이미 확인한 계정·범위·본문은 재사용합니다.

로컬 Classic Outlook 조회에는 본문 합계와 최종 JSON 결과 크기 제한을 적용하며 잘리거나 제외한 내용·보호 제한을 별도로 남깁니다. 이 제한은 모델에 반환하는 양을 줄이는 것이지 Outlook 내부 본문 조회 자체를 스트리밍하는 것은 아닙니다. 회사 MCP에는 실제 스키마가 지원하는 제한만 사용하며, 같은 기능을 보장하지 않습니다. 계정이 확인되어도 메일 발송 승인을 대신하지 않으며 실제 수신자·본문·첨부 확인을 유지합니다.

## 설치·배포 경계

HTML의 추가 디자인은 CLI와 앱 모두 채팅 목록에서 번호로 선택할 수 있게 유지합니다. 앱 실행 표시만 보고 디자인 카드가 있다고 가정해 목록을 숨기지 않으며, 사용자가 추천대로 진행하라고 지정했다면 별도 선택 질문은 생략합니다.

기본 설치는 다른 플러그인의 Python 연결을 고치지 않습니다. 기존 Ouroboros 호환성 복구는 담당자가 `Install-ScopedCompanyAgent.ps1 -RepairOtherPluginPython`을 명시한 경우에만 실행합니다. 직원 ZIP의 설명 자료는 하네스 사용자 안내서·Markdown·운영 안내로 구성하고 별도 Workspace 전용 문서는 제외합니다. 원본 문서는 소스 저장소에 남습니다.

직원 설치 파일은 `Company-Harness-Setup.exe`, ZIP 대체 설치 파일명은 `company-agent-1.4.39-2026.09.03.zip`입니다. 뒤의 날짜는 변경하지 않은 회사 지식팩 버전입니다. 같은 설치 범위로 업데이트하면 기존 개인 자료·모델·MCP 설정을 유지합니다. 이전 Release는 보존하며 기존 PC를 자동 갱신하지 않습니다.

`Company-Harness-GitLab-Delivery-1.4.39.zip`은 담당자의 수동 사내 게시용입니다. GitHub 게시와 사내 GitLab 업로드는 별개입니다. 실제 시험·빌드·게시 결과는 별도 검증 기록을 기준으로 확인해야 하며, 이 변경 안내 자체가 완료 증거는 아닙니다. 사내 HCP·Outlook·PowerPoint·DRM 환경의 통합 동작과 전체 업무 시간·토큰 절감 효과는 운영 환경에서 별도 확인이 필요합니다.
