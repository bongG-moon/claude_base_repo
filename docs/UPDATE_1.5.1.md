# Company Harness 1.5.1

기억과 학습 중심의 기본 하네스와 HTML, PPT, Excel, 데이터 조회 등 개별 스킬을
설치 범위에서 분리했습니다. 기존과 같은 범위로 업데이트하면 개인 기억·지식·스킬,
학습 기록과 모델·MCP 연결 설정은 유지합니다. 개별 스킬은 필요한 것만 선택해 설치합니다.
VLM 자동 모델 선택과 이미지 읽기 강제 인계는 이번 기본 구성에서 제외했습니다.

PPT와 HTML 스킬은 참고 자료의 색상, 글꼴과 구조 단서를 활용하며 사용자 선택과 확인을
유지합니다. PPT에는 배치 오류 설명과 연결선·글자·주석에 대한 제한적인 경고,
참고 PPT의 짧은 구조 요약을 추가했습니다. HTML 참고 파일은 10MiB 미만을 지원하며
미리보기 승인 기록을 확인합니다. Windows 명령 출력의 한국어 인코딩도 보완했습니다.

데이터 조회 스킬은 별도 배포됩니다. 저장 쿼리 검증, 조회 오류 구분, 대량 결과의
제한된 미리보기, 연속 조회와 로컬 인증 흐름을 다룹니다. 실행 전 회사 환경의 권한과
연결을 확인해야 합니다. 자세한 검증 범위는 [개별 스킬 검증 기록](VALIDATION_INDIVIDUAL_SKILLS_20261102.md),
[하네스 구조](HARNESS_CORE_SPLIT.md)와 [PPT 검증 기록](VALIDATION_PPT_FLOW_20261102.md)을 참고하세요.

실제 사내 DB·DRM 환경, 개인 기억과 지식의 실제 운영 모델 수행, HTML의 실제 화면
유사성은 이번 모의·구조 검증만으로 보장하지 않습니다. 설치 EXE는 코드 서명되지 않았습니다.
