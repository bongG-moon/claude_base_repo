## 테스트 중 확인한 환경 차이

- 번들 Python에는 일부 플랫폼 검사 의존성이 없어, 해당 검사는 이미 의존성이 준비된 Python으로 재실행했습니다.
- 긴 임시 경로로 컴파일이 중단돼 저장소의 짧은 전용 임시 경로로 재실행했습니다. 설치 파일이나 PC의 권한 정책은 변경하지 않았습니다.
- 기존 native 테스트가 후크 마지막 줄을 JSON으로 가정했으나 프로젝트 시작 안내가 뒤에 붙을 수 있었습니다. 테스트가 실제 runtime 키를 찾도록 보정했으며 제품 후크에는 검증용 로직을 추가하지 않았습니다.
- CMD 실행 시험의 제한 환경 오류는 동일 격리 시험을 일반 실행 권한으로 재실행해 확인했습니다.
