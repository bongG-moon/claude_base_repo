# 현재 폴더의 하네스 구성 지도 검증

검증일: 2026-09-19

## 구현 범위

Workspace의 **기억·하네스 관리 → 구성 한눈에**에서 현재 작업 폴더에 해당하는 **회사 공통 / 개인 전체 / 이 프로젝트** 구성을 비교합니다. 스킬, 지침, 후크, 도구(MCP), 에이전트, 명령, 기억·지식 저장소와 자동 학습 범위를 표시합니다. 각 항목에는 출처·경로·상태·주의사항을 붙이며 조회 시점의 정적 HTML을 저장할 수 있습니다.

- 설치 등록과 해당 Claude 설정 위치를 확인하며 개발 저장소를 설치된 회사 하네스로 간주하지 않습니다.
- 설정 켜짐, 사용 가능, 정의 발견, 꺼짐/제외, 초안, 선택 필요, 확인 필요를 구분합니다. 파일 발견은 실제 CLI 로드·인증·실행의 증거가 아닙니다.
- 저장된 스킬 우선 선택과 현재 세션의 본문 로드 기록을 별도 표시합니다. 후자는 현재 폴더·세션·스킬 ID·본문 해시가 모두 맞는 기존 기록만 사용하며 의미상 적용 성공을 보장하지 않습니다.
- 요청할 때만 조회하며 모델 호출, MCP 연결, 네트워크 조회, 설치·설정 변경, 새 학습 기록 저장을 하지 않습니다.
- HTML은 스크립트 없이 만들며 Workspace에서는 빈 sandbox의 iframe으로 표시합니다. 항목 텍스트를 이스케이프하고 외부 자원과 스크립트를 CSP로 차단합니다.
- 내보내기에 대화·기억 본문, MCP 실행 명령·인증정보·환경변수를 넣지 않습니다. 로컬 경로와 항목 이름은 포함하므로 외부 공유 전에 검토해야 합니다.
- 링크/재분석 지점을 건너뛰고 파일·항목·출력 크기 제한에 도달하면 경고합니다. 다른 프로젝트의 세션이나 기록을 전수 탐색하지 않습니다.
- CLI 조회는 `context map --project "폴더 절대경로"`입니다. HTML 생성은 `--output "새 HTML 절대경로"`를 추가합니다. 기존 파일은 덮어쓰지 않습니다.
- HTML 저장 없는 단독 조회는 실행 계약에서 읽기 전용입니다. 출력 옵션·리다이렉션·복합 명령까지 읽기 전용으로 승인하지 않으며 기존 권한 판정을 변경하지 않습니다.

핵심 지도 검사는 프로필·프로젝트별 분리, 비활성 플러그인, 우선 선택과 충돌, 손상된 설정, 이전 본문 해시, 설치 미등록·버전 불일치, 프로젝트 설치의 학습 범위, 크기 제한, HTML 삽입 문자열, 파일 덮어쓰기 거절과 UTF-8 출력도 포함합니다.

브라우저 검사는 격리된 설치·설정 자료와 가상 CLI를 사용했습니다. 실제 계정 인증이나 모델 작업을 호출한 통합 시험은 아닙니다. 넓은 화면과 작은 화면의 캡처를 직접 확인했습니다.

재실행 예시:

```powershell
python -X utf8 -B -m unittest discover -s tests -p test_harness_map.py
python -X utf8 -B -m unittest discover -s tests -p test_execution_contract.py
node --check local_app/web/companion.js
node scripts/build-manuals.mjs --check
```

브라우저 검사는 `scripts/test-lab/check-harness-map.mjs` 및 기존 `check-workspace-companion.mjs`를 사용합니다. Playwright 의존성과 격리 fixture 서버가 필요하며 결과의 `modelRequests`, `externalRequests`, 오류 목록을 함께 확인합니다.

## 현재 폴더 조회 확인

현재 개발 폴더의 실제 로컬 등록·설정을 읽기 전용으로 조회하고 HTML로 생성했습니다. 이 샘플의 수집 시간은 **213ms**, 모델 호출은 **0**, 조회 경고는 없었습니다. 이 값은 한 번의 수집 측정이며 앱 전체 응답 시간이나 모든 PC의 성능 보장이 아닙니다.

해당 로컬 프로필에 등록된 Company Agent 버전은 **1.4.5**였습니다. 개발 소스와 별개로 표시했고 설치를 바꾸지 않았습니다. 사내 운영 PC의 설치 버전과도 별개입니다. 실제 경로가 포함된 조회본·캡처·브라우저 결과는 Git 제외 대상인 `.smoke`에만 보관했습니다.

## 배포 및 미검증 범위

이 기능은 현재 개발 소스에 반영했습니다. Workspace와 지도 관리 API가 포함된 Company Agent 코어를 함께 배포해야 앱에서 사용할 수 있습니다. 구버전 코어는 업데이트 필요 안내를 보여 주며 대신 설치하거나 다른 상태 저장소를 임의로 선택하지 않습니다. 기존 패키징은 플러그인 전체를 포함하므로 새 모듈도 다음 빌드에 포함됩니다. **이번 작업에서 설치 파일·공개 Release·사용자 설치를 갱신하지 않았습니다.**

서버/OS 관리 정책, 세션 실행 옵션, 동적·원격 도구, 모든 플러그인의 사용자 정의 구성 경로, 내장 스킬 전체, CLAUDE.md 참조 확장과 조건부 규칙의 실제 적용까지 판정하지 않습니다. 최종 적용은 같은 CLI의 상태 화면과 실제 업무로 확인해야 합니다. 사내 HCP, 실제 Office/DRM, MCP 인증·연결은 이번 검증 범위가 아닙니다.
