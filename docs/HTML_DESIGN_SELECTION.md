# HTML 보고서 디자인을 고르는 방법

## 처음에는 간단하게

Claude가 아직 디자인을 모를 때 다음 네 가지를 먼저 안내합니다. 이때는 **디자인만**
묻습니다. 분량이나 스크롤/페이지 질문으로 먼저 넘어가지 않습니다.

1. 깔끔한 업무형(추천)
2. 지표 중심형
3. 추가 디자인(미리보기)
4. HTML 양식 직접 첨부

처음부터 뉴모피즘·글래스모피즘 등 8가지 설명이 길게 나오지 않습니다.
‘추천대로’라고 하면 이미 알려준 조건을 유지하면서 빠진 선택만 추천값으로 채웁니다.
추천값은 깔끔한 업무형 / 보통 분량 / 스크롤입니다. 대답하지 않았다고 선택한 것으로
간주하지 않습니다. 선호나 이번 요청으로 이미 정한 조건은 다시 묻지 않습니다.

## 추가 디자인이 궁금할 때

‘추가 디자인’을 고르면 **즉시 채팅에 아래 목록이 나오고**, 선택을 기다립니다. 번호나 이름을 바로 입력할 수 있습니다. 선택 화면에서는 `1~4번 디자인 / 5~8번 디자인 / 미리보기` 중 하나를 고른 뒤 구체적인 디자인을 선택합니다. 선택 화면이 없는 환경에서는 “선택 대기 중입니다”라고 안내하고 답변을 기다립니다.

1. 미니멀리즘 — 여백이 있는 깔끔한 업무형
2. 벤토그리드 — 관련 지표를 카드로 묶는 지표 중심형
3. 에디토리얼 — 큰 제목과 차분한 지면의 잡지형
4. 글래스모피즘 — 반투명 유리 느낌
5. 뉴모피즘 — 부드럽게 솟거나 눌린 입체 느낌
6. 브루탈리즘 — 굵은 테두리와 강한 대비
7. 그라디언트 메시 — 여러 색이 자연스럽게 번지는 배경
8. 자유양식 — 설명과 시각 자료를 비대칭으로 구성

이 단계에서도 분량이나 보기 방식을 묻지 않습니다. 디자인을 확정한 뒤에만 아직
정하지 않은 분량·보기 방식을 묻습니다. 이미 ‘상세 / 스크롤’을 알려줬다면 그대로 유지하고
디자인 선택 후 바로 제작합니다. 처음 네 가지 선택의 번호와 세부 목록의 번호는 별개입니다.

`미리보기`를 선택하면 로컬 미리보기를 여는 요청을 보내고 파일 링크도 안내합니다. 이후 같은 디자인 선택으로 돌아옵니다. 미리보기나 번호 묶음을 골랐다고 보고서를 만들기 시작하지 않습니다.
브라우저 창이 나타나지 않으면 링크를 직접 열거나 채팅 목록에서 선택하세요.
파일을 반드시 열 필요는 없습니다. 채팅에서 바로 고를 수 있습니다.
파일 안 **추가 디자인 · 설명과 미리보기**를 누르면 8가지 카드가 펼쳐집니다.
보고서를 만드는 실제 테마 코드로 구성한 작은 가상 예시를 비교할 수 있습니다.
파일을 직접 열 때는 전체 카드가 접혀 있고, 채팅의 추가 디자인에서 열면 펼쳐집니다.

미니멀리즘, 벤토그리드, 에디토리얼, 글래스모피즘, 뉴모피즘, 브루탈리즘,
그라디언트 메시, 자유양식을 제공합니다. 각 카드에는 쉬운 설명이 있습니다.
자유양식도 준비된 비대칭 구성에서 시작하며 임의 웹사이트 완전 복제는 아닙니다.

1. 원하는 디자인의 ‘선택’ 버튼을 누릅니다.
2. 분량과 스크롤/페이지 넘김/둘 다 중 원하는 방식을 고릅니다.
3. **선택 내용 복사**를 누르고 Claude 채팅에 붙여 넣습니다.
4. 자동 복사가 제한되면 선택된 문장을 Ctrl+C로 복사하면 됩니다.

분량과 보기 방식의 초기값은 **기존 선택 유지**입니다. 디자인만 바꾸고 싶다면 그대로
두세요. 앞서 정한 분량·방식을 덮어쓰지 않으며, 아직 정하지 않았다면 Claude가 묻습니다.

버튼을 누르는 것만으로 Claude에 전송되거나 개인 설정이 바뀌지는 않습니다.
이 화면은 회사 자료를 읽지 않으며 인터넷·로그인·설치도 필요 없습니다.
브라우저에서 볼 수 없어도 이미 안내된 채팅 목록에서 고르면 됩니다.
처음부터 전체 디자인을 표시하지 않고 추가 디자인을 선택했을 때 표시합니다. CLI 화면에 이미지 버튼이 직접 생기는
방식은 아닙니다. 승인이나 DRM으로 열 수 없으면 다른 방법으로 우회하지 않습니다.

## 요청 예시

### 내가 가진 HTML 양식을 참고하고 싶다면

“HTML 양식 직접 첨부로 할게. 이 파일의 색상과 글꼴을 참고해서 보고서를 만들어줘.”

파일을 첨부하거나 PC의 파일 경로를 알려주면 됩니다. 먼저 양식의 색상·글꼴·모서리와
구역 개수를 확인해 가상 자료로 만든 미리보기를 안내합니다. 원하는 느낌인지 답하면
아직 정하지 않은 분량과 보기 방식만 물어보고 제작합니다.

현재는 **양식을 참고한 재구성**입니다. 원본 화면을 그대로 복제하지는 않습니다.
외부 CSS·이미지나 동적으로 움직이는 화면은 가져오지 않고, PC에 없는 글꼴은 기본
글꼴로 표시됩니다. 원본의 문구·실적 숫자가 새 보고서에 자동 섞이지 않습니다.

**정상 대화 순서**

- Claude: “디자인을 선택해 주세요. 깔끔한 업무형 / 지표 중심형 / 추가 디자인 / HTML 양식 직접 첨부”
- 사용자: “추가 디자인”
- Claude: 위 8가지 목록과 선택 화면을 표시하고 답변을 기다립니다. 화면이 없으면 “선택 대기 중입니다”라고 안내하고 멈춥니다.
- 사용자: “뉴모피즘”
- Claude: “분량과 보기 방식을 정해 주세요.” (아직 모르는 항목만)
- 사용자: “상세, 스크롤”
- Claude: 정한 조건으로 보고서 제작

앞서 ‘상세, 스크롤’을 말했다면 네 번째 줄 다음에 바로 제작합니다.

“지난번 자료로 HTML 보고서를 만들어줘. 추가 디자인에서 골라보고 싶어.”

“글래스모피즘으로, 보통 분량, 페이지 넘김으로 만들어줘. 원본은 그대로 둬.”

“뉴모피즘을 쓰되 이미 정한 분량과 방식은 유지해줘.”

## 실제 보고서에 적용되는 것

각 테마에 맞춰 배경·표지·지표 카드·표 머리글·차트와 범례 색상·테두리·그림자·
일부 제목 글꼴 및 배치를 함께 적용합니다. 자료의 숫자와 내용은 스타일 때문에 바꾸지
않습니다. 예시의 크기·화면과 실제 자료의 분량에 따라 결과 배치는 달라집니다.
외부 폰트나 이미지 효과를 다운로드하지 않습니다. 표·차트 가독성은 실제 보고서에서도
따로 확인해야 하며 작은 예시가 모든 화면의 완성도를 보증하지는 않습니다.

## 설치 담당자 참고

- 배포 자산: `payload/core/plugin/skills/html-report/assets/design-picker.html`.
- 질문 순서 확인: `business html-choices --spec "선택.json" --state-root "개인 상태 경로"`.
  이 명령은 보고서를 만들거나 개인 설정을 바꾸지 않습니다. 알려준 선택만 JSON에 넣고
  추가 디자인 요청 시 `designMenu:"additional"`을 사용합니다. `style`에 탐색 버튼명을 넣지 않습니다.
  `design` → `design_detail`(선택 시) → `format` → `ready` 중 현재 단계만 반환합니다.
  Claude는 응답을 기존 선택에 합쳐야 합니다. 이 도구가 대화 전체를 자동 저장하는 것은 아닙니다.
- 미리보기 열기: `business html-designs --open` (설치된 전체 명령 접두사 사용).
- 양식 참고: `business html-template --template "원본.html" --output "새 미리보기.html" --open`.
  첨부 분기는 `template_attach` → 양식 미리보기 확인 → `format` → `ready`입니다.
  승인한 양식의 `htmlTemplate:{path,sha256}`을 제작 JSON에 유지하며 변경된 양식은 다시 확인합니다.
- 필요하면 `--output "새 위치.html"`로 로컬 사본을 만들 수 있습니다. 기존 파일은 보존합니다.
- 미리보기만 조회하는 명령은 업무 변경으로 분류하지 않습니다. 복사 명령은 별개입니다.
- 실제 보고서 CLI에 style/length/mode가 빠지면 파일을 만들지 않고 필요한 선택을 반환합니다.
  기존 내부 Python API의 기본값은 자동화 호환용이며 사용자 선택을 생략할 권한은 아닙니다.
- 제작 담당자는 `scripts/build-report-design-picker.py`로 테마와 미리보기를 함께 갱신하고
  `--check` 및 회귀 검사를 실행해야 합니다. 사용자 PC에서는 빌드가 필요 없습니다.
