## 생성 위치와 시작점

## 구성

- 가상 월간 실적 XLSX, 동일 데이터의 읽기 대체용 JSON, 회의 메모와 작성 요청
- 편집 가능한 가상 PPT 양식 2장: 완성 보고서가 아닌 입력 서식
- 확정 일정이 변경되는 EML 6통과 텍스트 첨부 1개: 실제 발송·Outlook 가져오기 없음
- 종류별 파일 정리 대상 6개, 재귀적으로 건드리지 않아야 할 기존 하위 폴더
- 모의 보호 제한 상황: 실제 DRM 검증이라고 주장하지 않음
- 용어·테이블 초안, 후속 업무 메모
- 미설치 상태의 동일명 Skill 후보 2개, 빈 A/B 프로젝트
- 의도된 계산 오류 2개와 테스트 6개가 있는 Python 표준 라이브러리 프로젝트
- 빈 결과물 폴더, 사용자 전용 예상결과, 기록지, 최초 파일 해시 목록, 원본 보관 ZIP

정답은 업무 입력과 분리하고 처음부터 Claude에 읽히지 않도록 안내한다.
새 대화·새 프로젝트에서의 검증, 실제 산출물 확인, 미확인/미실행 구분을 포함한다.
스킬 목록 갱신은 다음 요청/새 세션 기준이며 백그라운드 상시 감시로 설명하지 않는다.
기억, 의미 있는 업무 종료 시 학습, 개인 스킬 개선은 각각 별도 증거로 평가한다.

## 준비 자료 검증 결과

- 원본 파일 33개와 원본보관 ZIP의 목록·크기·SHA-256 일치
- XLSX 재가져오기 데이터 일치, 수치 셀의 숫자형 검증, 렌더링 육안 확인
- PPTX 구조·레이아웃·폰트·재가져오기 검사 통과, 2장 모두 렌더링 육안 확인
- PowerPoint 앱에서 실제 열기·편집·저장은 수행하지 않음
- 메일 6통 날짜·헤더·본문 및 첨부 1개 파싱 확인
- 작은 계산기는 임시 사본에서 6개 검사 중 의도된 실패 3개·오류 1개·통과 2개 확인
- 대본의 존재해야 하는 입력 경로 확인, 설치 전 스킬 후보가 비활성 위치에 있는지 확인
- Edge 헤드리스로 1280/390px 화면, 22개 이동 링크, 65개 복사 버튼, 안내 머리말 제거,
  클립보드 불가 시 선택 복사 대안 확인. 외부 요청 0개, JavaScript 오류 0개

이는 **실습 자료의 준비 검증**이다. 실제 하네스가 22개 업무를 완료했다는 뜻이 아니다.
실제 Outlook/PST/발송/DB/DRM 강제 차단, 실제 모델 라우팅, 설치 업데이트 후 개인 상태
보존은 각 실행 환경에서 별도 확인해야 한다. 보안 제한을 우회하는 시험은 제공하지 않는다.

## 개발자용 재생성

`scripts/build-chat-practice-lab.py`는 검증된 Office 입력 2개를 받아 새로운 목적지에만
실습 자료를 생성한다. 기존 목적지가 있으면 덮어쓰지 않는다. 설치·네트워크 호출이 없다.
`scripts/validate-chat-practice-lab.py`는 해시·원본보관·메일·Office 구조·대본 경로를 검사한다.
의도된 실패 확인은 임시 사본에서만 실행하여 실제 실습 원본을 수정하지 않는다.

Office 제작·브라우저 검증 소스 및 보고서는 이 작업의 비공개 빌드 폴더
`build/chat-practice-artifacts`에 있다. 사용자 실습 폴더로 개발 도구를 복사하지 않았다.
