# Company Agent 1.4.5 설치·업데이트 안내

## 설치 방법

1. `company-agent-1.4.5-2026.09.03.zip`을 새 폴더에 모두 압축 해제합니다. 이전 설치파일 폴더에 덮어 풀지 마세요.
2. 압축을 푼 폴더의 `Install-CompanyAgent.cmd`를 더블클릭합니다.
3. 이전과 같은 설치 범위(내 Windows 계정 전체 또는 해당 프로젝트)를 선택합니다.
4. 기존 Company Agent가 있으면 백업 후 업데이트를 선택합니다. 처음 설치라면 화면의 안내대로 진행합니다.
5. 설치 완료 후 Claude Code를 닫고 다시 실행합니다.

Claude Code와 Python 3.11 이상이 이미 설치되어 있어야 합니다. 설치 과정에서 실행 위치와 조건을 확인하며, 여러 Claude가 발견되면 사용할 항목을 묻습니다. Python이나 별도 모델을 다운로드하지 않습니다.

개인 Memory·Skill·Knowledge·학습 이력, 모델 설정과 MCP 연결은 유지합니다. 설치 중 표시되는 백업 위치를 보관하세요. 오류 해결을 위해 기존 설정이나 개인 자료를 직접 삭제하지 마세요.

프로그램 버전은 **1.4.5**입니다. 파일명 뒤의 `2026.09.03`은 회사 지식팩 버전이며 제작 날짜가 아닙니다. 기존 1.4.4 ZIP은 변경하지 않고 새 버전으로 배포합니다.

## 달라진 사용 흐름

- **PPT:** 새 디자인을 선택해도 곧바로 기본 양식으로 제작하지 않습니다. 업무 보고형·흑백 간결형·따뜻한 설명형 중 선택하거나 기존 참고 양식으로 전환할 수 있습니다. 이미 알려준 용도·장수는 다시 묻지 않습니다.
- **PPT 확인:** 전체 구성과 실제 대표 슬라이드 1~2장을 먼저 준비합니다. 사용자가 확인한 뒤 전체 PPT를 제작합니다. 이후 내용이나 디자인을 바꾸면 미리보기도 다시 확인합니다. 세 디자인은 색상·표현 체계이며 서로 완전히 다른 배치 엔진은 아닙니다.
- **HTML:** 추가 디자인 선택은 실제 응답을 기다리는 단계로 처리합니다. 미리보기를 본 후에도 디자인을 선택할 수 있고, 세부 디자인을 고르기 전에 분량 질문으로 넘어가지 않습니다. 기존 HTML 양식 직접 첨부 기능도 포함합니다.
- **글래스모피즘:** 여러 색이 섞이는 배경 대신 투명한 흰색 유리 느낌으로 조정했습니다. 그라디언트 메시 디자인의 색상 효과는 별도로 유지합니다.
- **대기 처리:** 선택용 임시 기록을 최종 결과물로 잘못 판단하지 않도록 했습니다. 실제로 백그라운드 작업이 진행 중이면 완료 확인 재시도를 소모하지 않고 결과를 기다립니다. 실제 산출물 확인과 기존 실행 권한은 유지합니다.

## 업데이트 후 확인할 대화 예시

> 부서장에게 설명할 편집 가능한 PPT를 총 5장으로 만들어줘. 새 디자인으로 할게. 6월 목표 150, 실적 145 / 7월 목표 150, 실적 175 / 8월 목표 150, 실적 210이며 단위는 백만원이야. 먼저 디자인을 선택하게 하고, 전체 구성과 실제 대표 슬라이드를 보여줘. 내가 확인하면 제작해줘. 증가 원인은 추측하지 마.

디자인 선택 → 대표 슬라이드 확인 → 승인 → 전체 제작 순서인지 확인하세요. 참고 양식을 사용하려면 기존 PPT 파일을 첨부하고 해당 양식을 참고해 달라고 요청하면 됩니다.

> 같은 자료로 HTML 보고서를 만들어줘. 추가 디자인에서 글래스모피즘을 선택하고 싶어. 분량과 보는 방식은 선택하게 해줘.

## 확인 범위와 주의점

Office가 이미지 미리보기를 만들지 못하는 PC에서는 실제 초안 PPT 파일로 확인하도록 안내합니다. 이미지가 생성되지 않았는데 화면을 확인했다고 보고하지 않습니다. 회사의 Office·DRM·모델 환경에서 실제 렌더링과 대화 흐름은 별도 확인이 필요합니다. 다른 플러그인의 Hook까지 해제하거나 오류를 숨기는 업데이트는 아닙니다.
