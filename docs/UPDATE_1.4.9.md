# Company Agent 1.4.9 설치·업데이트 안내

## 달라진 점

- 전체 목록을 재사용하더라도 매 업무에 관련 스킬 설명과 정확한 경로를 짧게 전달합니다.
- 같은 일을 하는 스킬이 겹치고 기존 우선 설정이 없으면 한국어로 차이를 설명하고 선택을 묻도록 보완했습니다.
- 답한 선택은 이번 요청에만 적용합니다. 개인 기본값이나 프로젝트 우선 설정은 별도 요청이 있을 때만 저장합니다.
- Windows 실행은 UTF-8로 맞추고, 짧은 명령으로 호출해도 등록된 Python·설치 범위·개인 저장 위치를 사용합니다.
- 글자가 깨졌다는 이유로 메일 발송·파일 이동·산출물 생성을 다시 실행하지 않도록 보완했습니다.
- 기존 HTML/PPT 디자인, 개인 기억·학습, DB·Outlook 정책은 유지합니다. 새 스킬을 추가하지 않았습니다.

## 설치하기

1. Release의 **company-agent-1.4.9-2026.09.03.zip**을 다운로드합니다. `Source code (zip)`이 아닙니다.
2. 새 폴더에 압축을 풉니다. 이전 설치 폴더에 덮어쓰지 않습니다.
3. 맨 위의 **Install-CompanyAgent.cmd**를 실행합니다.
4. 기존과 같은 설치 범위(내 Windows 계정 전체 / 해당 프로젝트)를 선택합니다.
5. 백업 후 업데이트 안내에 따라 진행하고, 설치 완료 후 Claude Code를 닫았다 다시 엽니다.

Claude Code와 회사에서 사용하는 Python 3.11 이상이 이미 설치돼 있어야 합니다.
개인 Memory·Skill·Knowledge·학습 이력, 모델·MCP 설정은 유지합니다.
파일명 뒤 `2026.09.03`은 지식팩 버전입니다. 프로그램 버전은 **1.4.9**입니다.

## 확인하기

새 세션에서 스킬 이름을 지정하지 않고 `@테스트자료.pptx 내용을 읽고 MD 파일로 정리해줘`라고 요청하세요.
관련 스킬 본문과 등록된 문서 읽기 경로를 사용해야 합니다. 겹치는 스킬에 대한 질문이 나오면 이름이나 번호로 답하세요.

전체 자동 검사 688개(제외 0개)를 통과했고, 사내 모델의 실제 선택 정확도와 운영 Office/DRM 호환성은 별도 확인이 필요합니다.
자세한 범위는 [검증 기록](SKILL_SELECTION_ENCODING_VALIDATION_2026-09-16.md), 사용 예시는 [사용자 안내서](USER_GUIDE.md)를 참고하세요.
