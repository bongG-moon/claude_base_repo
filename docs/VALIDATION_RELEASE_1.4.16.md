1. `memory upsert --help`를 저장 위치 미선택 처리보다 먼저 판정하도록 변경했습니다. 도움말만 읽고도 변경 검증 의무가 생기지 않습니다. 리다이렉션·복합 명령은 읽기 전용으로 확대하지 않으며 권한을 자동 승인하지 않습니다.
2. Workspace 0.4 서버와 실행기의 재사용 버전 비교를 맞췄습니다. 같은 설치를 다시 열면 기존 서버를 재사용하고 다른 버전/폴더의 실행을 강제로 종료하지 않는 기존 검사를 유지합니다.

관련 회귀시험은 두 수정과 추가한 도움말 경계 검사를 포함해 다시 실행했습니다. 수정 후 전체 994개를 한 번에 다시 실행한 것은 아니며, 첫 전체 실행과 수정 후 관련 재실행을 중복 합산하지 않습니다.
