## 확인하지 않은 범위

실제 사내 HCP의 지침 준수·응답 시간·토큰 효과, 회사 PC의 WS-33, 비전 모델·게이트웨이 문제는 미검증입니다. 실제 Office·메일 실업무나 새 브라우저 시각 검사는 수행하지 않았습니다. 이번 변경은 필요한 검증을 없애거나 실패를 성공으로 처리하지 않습니다. Claude Code의 Stop 표시 자체가 모든 버전에서 사라진다고 보장하지 않습니다.

별도 작업 중인 Workspace 변경, `standalone-guides/`, `tmp/`, `.smoke/`, 개인 상태와 인증정보는 커밋·배포에서 제외합니다. 기존 Release·태그·설치 ZIP은 보존하며 설치된 PC를 자동 갱신하지 않습니다.
