# 1.4.21 변경·설치 안내

## 달라진 점

- Office 스킬을 실제로 불러온 직후 현재 설치 위치와 대화 정보가 담긴 실행 명령을 제공합니다. 명령을 다시 조립하거나 세션 환경변수·설치 폴더·도움말을 찾아다니는 일을 줄이도록 안내를 정리했습니다.
- 정상 Office 명령 뒤의 `2>&1` 때문에 대화 연결 정보 보완과 읽기 전용 분류가 빠지던 문제를 수정했습니다. 현재 후크의 누락 정보만 보완하며 파일·범위·명시한 다른 연결 정보는 바꾸지 않습니다.
- 잘못 입력한 파일 경로는 `source_not_found`와 요청한 경로로 구분합니다. 한글 인코딩이나 DRM 문제라고 추측하지 않으며 경로를 자동으로 바꾸지 않습니다.
- Excel 읽기 다음에 HTML 제작을 요청하면 현재 요청에 맞는 스킬 본문을 확인합니다. 이전 목록 읽기·다른 스킬·같은 명령 재시도로 본문 확인을 대신하지 않습니다. 관련 스킬이 없거나 후보가 불명확한 일반 작업은 막지 않습니다.
- 현재 요청에서 실제 선택·로드한 외부 스킬을 존중하고, 부정·코드 진단 요청에 관계없는 스킬을 강제하지 않도록 보완했습니다. 보조 지침을 읽어도 이미 읽은 업무 스킬 기록은 유지합니다.
- Excel의 제목·빈 행과 A1이 아닌 시작 위치를 오류로 오인해 임의 코드를 반복 실행하지 않도록 안내와 회귀 시험을 보완했습니다. 통합 가이드·Markdown도 갱신했습니다.

추가 모델 호출·세션 파일 검색·모든 Read에 대한 새 후크는 넣지 않았습니다. 문서·범위별 승인과 회사 정책·접근 권한은 그대로 유지합니다. 실제 사내 HCP의 지침 준수·전체 응답시간·보호 문서 호환성은 회사 PC에서 확인해야 합니다.

## 설치·업데이트

1. `company-agent-1.4.21-2026.09.03.zip`을 새 폴더에 풉니다. 파일명 뒤 날짜는 회사 지식팩 버전이며 기존 승인 Python 3.11 이상을 사용합니다.
2. `Install-CompanyAgent.cmd`를 실행하고 기존과 같은 User/Project 범위에서 백업 후 업데이트합니다. 개인 기억·지식·스킬·로그인·모델·별도 MCP 설정을 유지합니다.
3. Claude Code와 Workspace를 종료한 뒤 다시 열고 **새 대화**에서 시험합니다. Release 게시만으로 이미 설치된 PC가 바뀌지는 않습니다.
4. Workspace 안내서도 갱신하려면 이번 Release의 `company-workspace-preview-0.7-*.zip`을 별도 폴더에 풉니다. Workspace 실행 코드는 이번에 바뀌지 않았습니다.

## 업데이트 후 확인

민감하지 않은 시험 Excel을 첨부하고 스킬 이름 없이 아래 순서로 요청합니다.

1. `이 파일 내용을 읽고 어떤 정보가 있는지 확인해줘`
   - Office 스킬 → 현재 실행 명령 → 파일·범위 승인 → 고정 읽기로 이어지는지 확인합니다. 취소하면 문서를 열지 않아야 합니다.
2. `위 내용을 바탕으로 현황을 볼 수 있는 html을 만들고싶어`
   - HTML 보고서 스킬을 적용한 뒤 디자인 선택·제작으로 이어지는지 확인합니다.

반복적인 세션 탐색이나 임의 pandas/xlwings 재작성으로 넘어가면 단계·오류 코드·대기 시간을 기록해 담당자에게 전달하세요. 문서 본문·인증 정보는 공유하지 마세요.
