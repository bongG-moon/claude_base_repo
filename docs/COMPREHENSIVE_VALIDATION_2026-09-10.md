# Company Agent 전체 기능 검증 보고서

검증일: 2026-09-10 · 코드 기준: 1.2.0 / e834174 · 운영환경 실사용 검증은 별도

## 결론

요청하신 기능이 모두 완성된 상태는 아닙니다. 개인 자료 분리, 기억 저장·검색, 개인 스킬 개선과 후속 평가, 설치·업데이트 안전장치는 로컬 테스트에서 통과했습니다. 그러나 **공통 폴더 정리·Outlook 스킬을 쓰다가 자동으로 개인 개선본을 만들고 다음 업무에 적용하는 연결은 없습니다.**

자동 테스트 통과는 구현된 범위의 동작 확인입니다. 미구현 요구사항까지 충족했다는 의미가 아니며, 사내 모델이 실제 대화에서 지침을 잘 따르는지도 별도 확인해야 합니다.

## 개인 기억과 스킬이 저장되는 의미

사용자 설치의 개인 자료 기본 위치는 `%LOCALAPPDATA%\CompanyAgent\states\user`입니다. 프로젝트 설치는 별도 상태를 사용할 수 있으므로 실제 설치 등록을 기준으로 확인해야 합니다.

학습이 직접 수정하는 스킬 경로는 해당 상태 아래 `personal-root/.claude/skills/<이름>/SKILL.md`입니다. `learning.py`의 `_read_skill`과 수정 대상 검사가 이 경로 및 실제 읽은 파일 해시를 확인합니다. 공통 스킬 경로는 이 대상이 아닙니다.

따라서 “개인 스킬을 건드리지 않고 공통 배포를 업데이트한다”와 “공통 스킬 사용 경험으로 개인 스킬을 자동 개선한다”는 서로 다른 요구입니다. 전자는 검증됐지만 후자는 연결이 빠져 있습니다. 같은 대화에서 답변 형식이 바뀌었다고 영구 학습됐다고 판정하면 안 됩니다.

## 보완 우선순위

1. 공통 스킬을 수정하지 않고 개인 개선 규칙을 생성하여 공통 스킬 사용 시 연결하는 기능. 출처·기준 버전 기록, 프로젝트별 선택, 공통 업데이트 시 충돌 확인까지 필요합니다. 자동 학습이 임의로 권한을 늘리지 않게 해야 합니다.
2. 운영 PC에서 T05~T08과 T25~T27로 실제 기억·학습 연결 확인. 답변뿐 아니라 저장 경로, 변경 기록, 다음 대화 사용 근거를 수집합니다.
3. Outlook·DRM·PPT·모델 배정은 승인된 가상 자료로 확인. 미연결 MCP는 오류로 몰아가지 말고 환경차단으로 구분합니다.
4. 배포 문서 버전 표기 정리. 일부 보존 안내의 1.1.1 및 prerelease 설명은 현재 1.2.0 Latest 상태와 구분해서 읽어야 합니다.

이번 변경은 검증 문서와 개발용 재검증 스크립트입니다. 위 미구현 연결을 구현하거나 설치 ZIP을 변경한 것이 아닙니다. Git 커밋·푸시·Release 변경은 하지 않았습니다.
