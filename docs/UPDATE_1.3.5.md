# Company Agent 1.3.5 · 기본 한국어 안내

## 무엇이 달라지나요?

Company Agent가 만드는 질문 제목·선택지·선택지 설명·추천 이유·승인 요청·진행 안내·
최종 결과와 문서 본문을 기본 한국어로 작성하도록 공통 지침을 강화했습니다.
SMALL·MEDIUM·LARGE 작업자와 새 프로젝트 하네스에도 같은 원칙이 전달됩니다.

예를 들어 선택 화면은 다음처럼 안내하도록 합니다.

- 간단히 보기 — 핵심 내용만 짧게 정리합니다. (추천)
- 자세히 보기 — 근거와 세부 내용을 함께 정리합니다.

영어 스킬·메일·문서·도구 결과를 읽었다는 이유만으로 답변을 영어로 바꾸지 않습니다.
공통 스킬 11개, 작업자 3개, 명령 3개의 메뉴 설명도 한국어로 변경했습니다.
스킬 이름·명령 이름과 SMALL/MEDIUM/LARGE 모델 연결은 바꾸지 않았습니다.

설정 입력 도우미는 저장·취소 결과를 한국어 문장으로 안내합니다. 실행 조건을
검사하는 `--check`의 JSON 형식과 내부 상태값은 다른 기능과의 호환성을 위해 유지합니다.
일부 하네스 오류 안내도 한국어로 바꾸되 실제 실패나 확인 불가 사실은 숨기지 않습니다.

## 영어가 필요한 경우

“이 답장 초안만 영어로 작성해줘”처럼 명시하면 그 결과물만 영어로 작성하고,
주변 설명·질문은 기본 한국어를 유지합니다. 전체 대화를 다른 언어로 요청하는 것도 가능합니다.
파일명·경로·모델명·명령어·코드·API/JSON 키와 정확한 원문 인용은 번역하지 않습니다.
예를 들어 스킬 이름은 `html-report`로 유지하고 용도만 한국어로 설명합니다.

## 적용 방법

1. `company-agent-1.3.5-2026.09.03.zip`을 새 폴더에 모두 압축 해제합니다.
2. `Install-CompanyAgent.cmd`를 실행하고 이전과 같은 설치 범위를 선택합니다.
3. 백업 후 업데이트하고 Claude Code를 닫았다 다시 엽니다.

기존 개인 Memory·Knowledge·Skill·모델·MCP 설정을 그대로 보존합니다.
기존 1.3.3/1.3.4 설치 폴더에 직접 덮어쓰지 마세요. 1.3.4의 짧은 Stop 안내도 포함합니다.
설치 파일 생성은 현재 PC에 자동 적용하거나 GitHub에 게시한 것을 뜻하지 않습니다.

## 기존 프로젝트와 적용 한계

기존 프로젝트 하네스 파일을 설치 과정에서 일괄 수정하지 않습니다. 이전 생성 형식은
읽고 검증할 수 있도록 유지했습니다. 해당 프로젝트에서 “이 프로젝트 하네스를 최신
기준으로 업데이트해줘”라고 요청하면 변경 계획을 확인하고 기존 생성 파일을 백업합니다.
손으로 수정한 파일은 기본적으로 보존하고 충돌을 안내합니다.

한국어 응답은 모델이 따라야 하는 공통 실행 지침입니다. 모든 사내 모델이 언제나
완벽히 준수한다는 보장이나 결과물 자동 번역 필터는 아닙니다. Claude Code 자체의
권한 창·모델 선택 메뉴·외부 플러그인 화면·원본 도구 로그 언어는 이 하네스가 전부
바꿀 수 없습니다. 해당 내용을 전달할 때 한국어로 풀어서 설명하도록 안내합니다.

## 업데이트 후 확인할 채팅

1. “HTML 보고서를 만들고 싶어. 형식을 고를 수 있게 먼저 물어봐줘.”
   → 질문 제목·선택지·설명이 한국어인지 확인합니다.
2. “사용 가능한 스킬 목록과 용도를 보여줘.”
   → 정확한 스킬 이름은 유지하고 용도 설명이 한국어인지 확인합니다.
3. “아래 영문 메모를 요약해줘: The draft is ready. The owner and due date are not confirmed.”
   → 한국어 요약, 담당자와 기한은 미정으로 표시해야 합니다.
4. “방금 메모의 답장 초안만 영어로 작성해줘. 설명은 한국어로 해줘.”
   → 답장만 영어인지 확인합니다.

번역 때문에 승인 범위·경고·미확인 사항을 빼거나 명령과 식별자를 바꾸면 안 됩니다.
