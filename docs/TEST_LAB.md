# 바로 실행하는 로컬 연습실

Company Agent 1.3.0의 검증 질문에 필요한 가상 자료와 실행 메뉴를 준비하는 도구입니다. 실제 회사 자료를 복사하거나 Claude 설정을 자동 변경하지 않습니다.

## 사용자는 이렇게 시작합니다

1. 연습실 폴더의 `01_START_TEST.cmd`를 더블클릭하고 메뉴 **3**을 선택합니다.
2. 처음이면 테스트 프로젝트 설치 여부를 묻습니다. 설치할 때 **1**을 입력합니다. 설치 프로그램은 Python 3.11 이상, 기존 Claude 실행 파일, 계정/경로, 기존 설정과 스킬 충돌, 백업 등 기존 사전 검사를 수행합니다.
3. 설치 확인 후 열린 Claude에 질문 화면의 **T01부터 요청 하나씩** 복사합니다. 모델을 새로 설정하거나 회사 MCP를 새로 설치하지 않습니다.
4. 새 대화 시험에서는 `/exit` 후 메뉴 3으로 다시 시작합니다. 같은 `workspace`에서 실행해야 같은 연습 기억을 사용합니다.
5. 질문 화면에서 최초 응답과 실제 결과를 적고 **결과 내려받기**를 눌러 Markdown으로 저장합니다. 다운로드 폴더에 파일이 실제 저장된 것을 확인한 뒤 **파일 저장을 확인했어요**를 누르세요. 다운로드가 취소·차단되면 다시 내려받습니다. 화면을 닫으면 저장하지 않은 입력은 사라집니다.

브라우저에서 실행 파일 링크를 누르는 대신 탐색기에서 CMD를 더블클릭합니다. 스크립트 실행 자체가 회사 정책에 막히면 중단하고 담당자에게 문의합니다. 정책을 변경하거나 다른 확장자로 위장하는 방법은 제공하지 않습니다.

## 폴더 구성

```text
Company-Agent-Test-Lab-날짜/
  00_START_HERE.html       질문 복사·진행 안내·결과 다운로드
  01_START_TEST.cmd        준비 확인·프로젝트 설치·Claude 실행 메뉴
  02_INSTALL_PROJECT.cmd   프로젝트 설치만 별도로 실행
  03_CHECK_FILES.cmd       파일 위치·내용 및 설치 정보 읽기 전용 확인
  workspace/              Claude에서 여는 실제 연습 프로젝트
    01-folder-organize/   TXT·MD·ZIP, 제외할 JSON, 보존할 하위 폴더
    02-report-input/      가상 월별 실적 JSON·회의 메모
    03-presentation-input/  PPT 제작 요구 자료 (PPT 자체는 T13에서 생성)
    04-mail-samples/      발송되지 않은 로컬 EML 3개, 가상 TXT 첨부
    05-protection-simulation/  실제 DRM이 아닌 가상 오류 설명
    06-knowledge-input/   가상 용어·가상 테이블 설명
    07-project-factory/   프로젝트 하네스를 만들 빈 폴더
    outputs/             시험 중 생성하는 보고서 등
  personal-state/        설치 후 생기는 연습 기억·개인 스킬·지식
  operator/              정상 기준·원본 질문·빈 결과지·원본 파일 해시
  installer/             기존 검증된 설치 ZIP과 압축을 푼 설치 파일
```

`personal-state`에는 기억이나 성공 기록을 미리 넣지 않습니다. 정답과 원본 판정 기준은 Claude 작업 폴더 밖에 둡니다. 이는 우발적인 정답 참조를 줄이는 구조이며 파일 접근 자체를 차단하는 보안 샌드박스는 아닙니다.

## 실제 적용 범위

- 기존 34개 시험과 추가 L01 로컬 메일 파일 요약 시험, 55개 요청 상자를 제공합니다. T09는 새 자료를 생성하는 대신 준비된 TXT·MD·ZIP을 정리하는 변형입니다.
- 파일 정리·HTML·PPT 제작용 자료, 명시적 기억·업무 완료 후 학습·개인 스킬 제작·지식·모델 배정 질문을 바로 시작할 수 있습니다. PPT 제작 도구 유무 등 각 기능의 조건은 여전히 실제 환경에서 확인해야 합니다.
- 실제 Outlook 조회는 본인 Outlook에 AI 조회가 허용된 연습 메일이 있어야 합니다. EML 파일을 읽은 것만으로 Outlook 연결/검색 성공으로 기록하지 않습니다. 프로그램이 메일을 발송하거나 가져오지 않습니다.
- 실제 DRM, 사내 DB, 이미지 모델, 개인 MCP SDK는 가짜 연결로 대체하지 않습니다. 필요한 환경이 없으면 환경차단/미실행입니다. 다음 공식 업데이트 전후 보존 시험 T28도 실제 업데이트 때 진행합니다.
- 파일 비교는 최초 위치와 내용이 같은지 각각 확인합니다. 이동 뒤 위치 차이는 정상일 수 있습니다. 승인창, 실제 기억·학습·Outlook 동작까지 자동 합격 판정하지 않습니다.

## 설치와 보존

연습실 생성 자체는 설치하지 않습니다. 사용자가 실행 메뉴에서 동의한 뒤 기존 설치 프로그램으로 **Project 범위 / native local** 설치를 합니다. 개인 상태는 이 연습실의 `personal-state`로 지정합니다. 이 범위의 등록·활성화·버전·개인 경로가 맞지 않으면 실제 업무용 User 상태로 대체 실행하지 않습니다.

기존 모델 설정/MCP/개인 자료를 유지하지만, 프로젝트 설정과 Company Agent의 공유 배포 캐시·플러그인 목록은 정상 설치 절차에 따라 변경될 수 있습니다. 따라서 다른 Claude 작업을 마무리하고 설치합니다. 계정 확인과 스킬 충돌 질문, 기존 규칙 확인, 안전 백업은 생략하지 않습니다. 전역 규칙과 회사 정책은 계속 상속될 수 있습니다.

설치 전 폴더 전체를 회사가 허용한 경로로 다른 PC에 복사할 수 있습니다. 다른 PC에서도 그 PC의 Claude/Python을 찾아 프로젝트 설치를 진행합니다. 설치 후에는 경로에 등록 정보가 연결되므로 임의로 폴더를 이동·삭제하지 않습니다. 연습 기억 초기화와 자동 제거 기능은 제공하지 않습니다.

## 개발 환경에서 연습실 재생성

Python 표준 라이브러리만 사용하며 실행 시 패키지를 다운로드하지 않습니다. 새 대상 폴더 이름이 필요합니다. 기존 대상 폴더가 있으면 덮어쓰지 않고 중단합니다.

```powershell
python scripts/build-test-lab.py --destination "C:\Users\사용자\Desktop\Company-Agent-Test-Lab-새날짜"
```

다른 검증된 설치 ZIP을 지정할 때는 `--bundle`을 사용합니다. 원본 질문과 설치 묶음의 버전 일치를 별도로 검토한 뒤 사용하세요.

```powershell
python -m unittest discover -s tests -p test_test_lab.py -v
```

검증은 임시 가상 프로필과 파일만 사용합니다. 실제 계정에 설치하거나 실제 Outlook, 사내 모델을 호출하는 시험은 아닙니다.
