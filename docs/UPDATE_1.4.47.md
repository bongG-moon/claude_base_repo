# Company Harness 1.4.47

## 설치 파일 구분

GitHub의 **Code → Download ZIP**과 **Source code (zip)**은 개발용 소스입니다. 직원 설치는 Release의 **Company-Harness-Setup.exe**를 실행하세요. ZIP 설치를 원하면 **company-agent-1.4.47-2026.09.03.zip**을 모두 압축 해제한 뒤 **Install-CompanyAgent.cmd**를 실행합니다.

소스 ZIP에서 설치를 실행하면 이제 다시 압축을 풀라는 안내 대신 설치 파일의 이름과 다운로드 주소를 보여줍니다. 필수 파일이 누락된 설치 ZIP과 파일 무결성 오류는 별도로 안내합니다. 기존 설치 무결성 검사와 개인 설정 보존 절차는 유지합니다.

## 하네스와 개별 스킬 동기화

- 10월 26일 main에 반영한 HTML 참조 스타일 3가지, 화면 배치와 표, PPT 편집성, 한국어 설명과 업무 기록 분석 개선을 설치 배포본에 포함했습니다.
- 최신 플랫폼 배포 스킬의 규격과 등록 글 작성 기준으로 개별 스킬 11개를 다시 생성했습니다. 쉬운 이름과 설명, 실제 업무 흐름, 필요한 실행 환경을 안내하고 기존 packageId와 설치 이름은 유지합니다.
