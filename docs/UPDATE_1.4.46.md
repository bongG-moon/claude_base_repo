# Company Harness 1.4.46

## 필요한 스킬만 가져다 쓰기

`skills_zip`에서 Company Harness 없이 사용할 수 있는 개별 스킬 11개를 제공합니다. 파일명과 호출명은 `html-report.zip`, `/html-report`처럼 기능 이름을 사용합니다. 기존 플랫폼 항목의 갱신을 위해 내부 패키지 식별자는 유지합니다.

- HTML 보고서, PPT, Excel 구조화, 파일 정리, Outlook, 개인 기억·지식, 스킬·도구 제작, 업무 기록 집계, 웹 화면 지침, 간결한 코딩 지침을 각각 선택할 수 있습니다.
- 필요한 실행 코드·참고자료를 ZIP에 포함합니다. Python, Office, 브라우저 등 각 기능의 외부 조건은 개별 설치 안내에 표시합니다.
- 하네스 핵심·프로젝트 관리·자동 학습 후크는 하네스 설치로 제공합니다. 독립 기억 스킬은 요청할 때 Markdown을 저장·조회하며 자동 학습이나 상시 주입을 추가하지 않습니다.
- 제조 Oracle MCP는 스킬과 구분한 기존 외부 MCP 패키지 그대로 제공합니다. 자동 연결·설치하지 않습니다.
- 기존 개인 스킬과 같은 이름이 있으면 덮어쓰지 않습니다. 이전 패키지 이름도 인식하지만 사본을 임의로 지우지 않습니다.

## 업무 제작과 검색 보완

- HTML: Noto Sans KR·Pretendard·나눔스퀘어 네오·자동 추천·직접 입력 등 글꼴 선택과 배치 지침을 반영했습니다.
- PPT: 네이티브 글자색·굵기·글꼴과 의미 단위 그룹을 유지합니다. 그룹 해제 가능한 도형을 만들며, 표·차트는 별도의 편집 가능한 개체로 둡니다. 원본 참고 시 디자인과 내용·문체의 근거를 구분합니다.
- 기억 검색: 짧은 영문 단어의 부분 일치와 요청에 불필요한 한국어 표현으로 생기는 잘못된 검색을 줄였습니다.
- 스킬 선택: 인용된 예문과 실제 요청, 다른 스킬을 설명하는 문구를 구분하도록 보완했습니다.
- 학습 설명: `learning status --explain`으로 확인 가능한 근거를 요청할 때만 보여줍니다. 평소 업무에 새로운 후크·질문·모델 호출을 추가하지 않았습니다.
