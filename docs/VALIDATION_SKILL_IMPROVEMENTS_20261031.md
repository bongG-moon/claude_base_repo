# 개별 스킬 사용성 개선과 검증

2026-10-31, Company Harness 1.4.48 로컬 배포본. [개선 계획](INDIVIDUAL_SKILLS_IMPROVEMENT_PLAN_20261031.md)에서 재현된 문제와 조건부 보완을 적용했다. 공개 Release 게시나 사용자 PC 설치는 이번 작업에 포함하지 않았다.

## 수정한 동작

| 영역 | 변경 | 사용 부담 |
|---|---|---|
| 파일 정리 | 목적지 부모가 파일인 충돌을 계획에 표시하고 전체 목적지를 첫 이동 전에 검사. 실행 중 실패는 완료, 실패, 미시도를 구분하고 기존 undo 유지 | 이동할 때의 로컬 검사만 보강. 승인 질문 추가 없음 |
| 업무 분석 | 구체 업무명의 후속 저장을 직전 업무의 대상어와 요청 순서로 연결. 명시적 전환과 근거 부족은 분리. 결합 인사 제외와 JSON/HTML/MD 미분류 집계 일치 | 기존 요청형 수집 안에서 처리. 새 모델, 질문, 후크 없음 |
| HTML 재생성 | 반복 생성기를 만들 때만 쓰는 예제 추가. 새 실행 묶음을 완성한 뒤 현재 기록을 전환하여 이전 HTML/job/근거 보존 | 일반 보고서 제작 경로는 유지. 항상 재생성하지 않음 |
| PPT 보정 | 보정을 job/재생성 코드에 유지하는 지침과 선택형 비교 도우미. 텍스트, 표, 차트, 위치와 크기, 양식, 배경 비교 | 보정 또는 반복 제작 시에만 사용. 일반 제작을 두 번 실행하지 않음 |
| 보고서 수치 | 기존 fact에 기간, 포함/제외 범위, 분모, 출처를 선택적으로 보존하고 표와 주석에서 재사용 | 별도 명세 파일이나 원자료 재조회 없음 |
| 작성 지침 | 작업 내부 임시 경로, 정상본 보존, 오류 원인 검사, 기존 EML 파서 재사용, 확정 사실 보존, 요청한 응답 길이, 표의 ID/날짜와 KPI 범위 안내 | 해당 스킬과 작업에서만 적용하는 짧은 안내 |

Excel의 기간값 왕복과 공통 합계 정책, PPT의 boolean 승인 및 초안 해시 검사는 이미 수정돼 있어 유지 검사로 확인했다. 다른 개인 기억, 지식, 프로필, 사내 연결 설정은 변경하지 않았다.

## 실제 실행으로 확인한 범위

최종 회귀 결과는 **410개 통과, 3개 건너뜀**이다. 재시도 전후의 중복 실행은 합산하지 않았다.

| 검사군 | 실행 수 | 결과 |
|---|---:|---|
| 신규 수치 범위, 재생성, 파일 사전검사 | 24 | 통과 |
| 기존 제작 엔진, 지표, 표, 승인, 업무 실행 | 76 | 통과 |
| 패키지, 설치기, 독립 실행, 조회 패키지, 외부 ZIP 정적 보존 | 110 | 108 통과, 2 건너뜀 |
| 업무 분석 정본과 하네스 통합 | 171 | 170 통과, 1 건너뜀 |
| Excel 수식과 기간/숫자 회귀 | 32 | 통과 |

건너뜀은 격리 Python의 python-pptx 미설치 2개와 Windows 심볼릭 링크 생성 권한 1개다. 일반 Python 런타임에서는 실제 독립 ZIP의 네이티브 PPT 생성과 재빌드 비교를 별도로 통과했다. 이를 건너뛴 두 시험 전체의 통과로 바꾸어 세지 않았다.

별도로 기존 외부 Oracle MCP의 설치/재설치/stdio 통신 시험 1개는 포함 시험군의 360초 제한을 넘겼고, 단독 재실행도 종료되지 않아 중단했다. 정확한 지연 원인은 미확정이다. 이 MCP ZIP은 이번에 수정하지 않았으며 원본 해시와 배포 규격 등 나머지 4개 검사는 통과했다. 이를 스킬 기능 실패로 단정하거나 MCP 통신 검증 완료로 표시하지 않는다. 운영 DB 연결이나 실제 개인 설정을 변경하는 방식으로 재시도하지 않았다.

합성 자료와 임시 폴더만 사용했다. 단위 회귀 외에 새 ZIP을 풀어 HTML 범위 문구 생성 및 손상 입력 후 정상본 유지, PPT 미승인 차단 및 승인된 합성 job 2회 제작/비교, 파일 부모 충돌 시 0건 이동과 원본 해시 보존을 직접 실행했다. 이 실행은 하네스 설치 없이 수행했으며 개인 Claude 설정을 만들지 않았다.

HTML 재생성에는 잘못된 JSON, 분석 예외, HTML 작성 예외, 현재 기록 전환 실패와 동시/외부 변경을 주입했다. PPT 비교에는 76pt 위치 변경과 글자, 표, 차트, 배경 변경을 넣어 차이를 검출하고 ZIP 날짜 변화만으로는 실패하지 않음을 확인했다. 합성 승인값은 시험 자료에만 사용했다.

검사별 원시 로그와 JSON 결과는 `.smoke/individual-skills-improvement-20261031/`에 있다. `test-summary.json`은 각 시험군의 실행 수, 건너뜀, 종료코드와 로그를 기록하고 `bundle-verification.json`은 실제 ZIP 실행 결과를 기록한다. 별도 반복 실행을 합산해 시험 개수를 부풀리지 않는다.

## 검증 한계

- 실제 사내 모델의 스킬 선택률, 지시 준수율, 토큰과 응답시간은 이번 합성 회귀로 측정하지 않았다. 새 후크나 추가 모델 호출이 없다는 코드 범위와 실제 사용 성능은 구분한다.
- 실제 Excel 엔진 전체와 계산 동등성, 운영 Outlook 계정, 사내 DB 연결은 이번 시험 대상이 아니다. 기존 지원 범위와 미지원 수식 표시를 유지한다.
- PPT 구조 비교는 화면의 가독성이나 의미 정확성을 보증하지 않는다. 이번 작업에서 실제 PowerPoint 화면을 새로 렌더해 검사하지 않았다. HTML 배치 엔진은 변경하지 않았고 표 가독성은 작성 지침을 보완했다.
- 업무 연결은 보수적 대상어/순서 규칙이다. 모든 자연어의 의미를 판별한다고 설명하지 않는다. 수치의 범위 메타데이터도 선언된 설명을 보존하며 원자료와 자유문장 사실을 자동 보증하지 않는다.
- 플랫폼 검사에서 표시용 아이콘 누락 경고가 있었지만 plugin manifest 검증은 통과했다. 설치나 스킬 실행 실패 경고가 아니다.
