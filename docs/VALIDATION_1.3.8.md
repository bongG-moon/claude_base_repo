# 1.3.8 HTML 추가 디자인 검증 · 2026-09-13

## 변경 범위

공통 html-report Skill과 기존 생성기만 확장했다. 공통 Skill 수는 증가하지 않는다.
추천 두 가지와 접힌 추가 디자인, 전체 8가지 한국어 설명·축소 예시, 선택 내용 복사를
제공한다. 보고서와 예시에 같은 report_styles 테마 CSS를 사용한다.
기본 CLI는 style/length/mode가 빠지면 input_required로 반환하며 결과를 만들지 않는다.
기존 내부 API 기본값은 자동화 호환용으로 남았으며 선택을 생략하는 대체 실행은 금지한다.

## 검증 항목

- 전체 Python unittest **505개 통과, 실패 0, 제외 0**, 92.911초.
  `COMPANY_AGENT_TEST_REAL_CLAUDE=1`로 기존 래퍼 검사도 실행했다. 합성 응답을 포함한
  자동 검사이며 사내 모델과 505회 실제 대화했다는 뜻은 아니다. 이후 선택 유지 UI를
  보완하고 영향 범위 Python 13개와 JavaScript 17개를 다시 통과했다.

- 신규 Python 검사 13개: 최초 선택지 3개, 빠진 항목만 요청, CLI 미선택 출력 차단,
  8가지 명시적 스타일 생성, 추가 디자인 문자열 오용 차단, 보호 입력 우선 차단,
  내부 API 호환, 배포 미리보기/테마 동기화, 접힌 카드·고유 ID·외부 요청 없음,
  정확한 스크립트 CSP 해시, 상태 무변경 조회, 사본 생성/덮어쓰기 거절,
  차트 팔레트·표지·표·카드의 공통 테마.
- 명령 분류 검사: html-designs 조회는 읽기 전용, --output 사본 생성은 읽기 전용이
  아니다. 어느 쪽도 새 자동 실행 승인을 추가하지 않는다.
- JavaScript 상호작용 단위 검사 17개: 첫 표시, 접힌 전체 목록, 8개 선택/상태 표시,
  분량/보기 반영과 기존 조건 유지, 복사 성공, 복사 거절/기능 부재 시 수동 복사 안내.
- 기존 단축키 안내 JavaScript 검사 16개 재통과.
- `scripts/build-report-design-picker.py --check`: 배포 HTML과 현재 생성기/테마 일치.
- `Test-OfflineBundle.ps1` 통과: 외부 Python 3.11 이상, 설치 항목 17개,
  report_styles 및 선택 화면/사용 안내/업데이트 안내 포함과 manifest 무결성 검사.
- 최종 문구/선택 유지 보완 후 초보자 안내 2개, 명령 분류 14개, 기존 보고서/PPT
  회귀 검사 19개도 재통과했다.

## 사용자 파일과 환경

실습 결과물 폴더에 `HTML_디자인_선택_1.3.8_최종.html`을 새로 복사했다.
기존 보고서·PPT·개인 설정·현재 설치본은 변경하지 않았다. 선택 페이지는 업무 원문을
포함하지 않으며 개인 파일 읽기/네트워크/자동 전송/설치/설정 저장을 하지 않는다.
원본 보고서의 스타일도 소급 변경하지 않는다. 새 버전으로 재작성할 때 적용된다.

## 검증 한계

이전 로컬 HTML 브라우저 접근 제한을 우회하지 않았다. 이번 상호작용 검사는
브라우저를 띄운 화면 검수가 아닌 JavaScript 실행·DOM 모사 검사다.
8가지 화면의 실제 렌더링·인쇄·브라우저별 블러 지원·실제 사내 Claude 질문 흐름은
추가 확인이 필요하다. 미리보기 CSS/마크업 일치나 코드 검사를 시각 검증으로 주장하지 않는다.
선택한 버튼을 Claude가 자동 수신하지 않는다. 사용자에게 복사/붙여넣기가 필요함을 표시한다.
