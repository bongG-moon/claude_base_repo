# 통합 가이드 검증 기록 — 2026-09-19

대상: Company Agent 1.4.17 / Workspace 0.5. 코어·GUI 코드는 별도 회귀시험과 배포 기록에서도 확인합니다.

## 구현과 문서 일치

5개 Markdown 원본을 하나의 `Company-Agent-Guide.html`로 생성합니다. 목차는 45개 절, 원본별 SHA-256을 기록하며 문서와 설치된 사본을 대조합니다. 예전 설명용 HTML 5개는 본문을 중복 보관하지 않는 호환 안내입니다. 이전 온보딩 절 번호 링크도 목적지 링크를 제공합니다.

사용자 안내의 오래된 버전별 소개를 업무별 예문으로 정리하고, 핸드북에서 새 폴더 기본 CLAUDE.md 생성 관련 모순을 수정했습니다. Claude Code 명령과 Company Agent의 3개 명령을 구분하며 공식 명령·입력·기억·세션 문서를 참고했습니다. 명령 존재는 실제 CLI 설치에서 확인하도록 안내합니다.

## 실행한 검사

- 매뉴얼 계약 시험 10개 통과: 스킬 13개·후크 7개·명령 3개·작업자 3개가 소스와 일치, 원본 해시·설치 사본·오프라인 정책·내부 앵커·배포 목록·안내 진입점·가상 자료 프롬프트 확인.
- 명령어 정적 시험 통과: 주요 명령·키·한계 문구와 스크립트/외부 리소스 없는 구조 확인.
- 독립 HTML 브라우저 시험 통과: 통합 파일 하나만 다른 폴더에 복사하고 1440/768/390px에서 7개 주요 위치 확인, 페이지 가로 넘침 없음, 내부 링크 70개 유효, 기존 링크 5개 및 설치 안내 진입 성공, 예문 전체 선택과 인쇄 PDF 생성 확인. 외부 요청·페이지 오류 0.
- 첫 화면·가상 자료 생성 실습·모바일 명령어 화면을 직접 시각 확인했습니다. 45개 절 전체의 모든 문장을 시각 검수한 것은 아닙니다. 작은 화면의 넓은 표는 표 영역 안에서 가로 스크롤합니다.
- 격리 Workspace 서버/브라우저 시험 통과: 통합 가이드와 기존 경로 3개, 390/1440px, Cua 준비 패널 390/768/1440px 확인. 안내 열기·준비 확인의 모델 전송 0, 외부 요청·페이지 오류 0. Cua 상태는 합성 자료이며 실제 Driver 조작이 아닙니다.

검사 원본: `tests/test_handbook_contract.py`, `scripts/test-shortcuts-guide.mjs`, `scripts/test-lab/check-unified-guide.mjs`, `scripts/test-lab/check-manuals-cua.mjs`. 화면·로그는 Git 제외된 `.smoke`에만 보관합니다.

## 검증 경계

가상 자료 생성·읽기 예문은 실제 사용 가능한 절차·자료·승인 순서에 맞춰 점검했습니다. 사내 모델에 모든 예문을 전송해 성공률을 측정한 것은 아닙니다. Office가 없는 PC는 텍스트·MD·HTML 연습으로 시작하며 PPT 생성과 Office 읽기는 각각 별도 준비·승인·검증이 필요합니다. 전체 가이드를 후크 문맥으로 주입하지 않습니다.
