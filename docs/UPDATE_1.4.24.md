# 1.4.24 변경·설치 안내

## 달라진 점

- `Company-Agent-사용자-안내서.html`에 시작하기, Claude Code 기본 사용법, 업무별 예문, 저장공간·스킬·후크·자가학습, 명령어·단축키 전체 5부 43장을 담았습니다. 다른 HTML로 이동해야 하는 목차 파일이 아니라 혼자 열리는 완전한 안내서입니다.
- Noto Sans KR 글꼴과 스타일을 내장했습니다. 안내서를 읽을 때 외부 서버 접속이나 AI 호출이 필요하지 않습니다. 외부 참고 링크는 사용자가 선택할 때만 엽니다.
- 예전 사용자 안내서의 `#section-1`~`#section-10` 책갈피와 앱에서 여는 기존 `Company-Agent-Guide.html` 경로를 유지합니다. 두 안내서는 같은 Markdown 원본으로 생성합니다.
- 직원 설치 ZIP의 `docs`와 설치 후 `resources/manuals`, Workspace ZIP에도 전체 사용자 안내서를 넣었습니다. 별도 Release HTML은 GitHub 파일명 호환성을 위해 `Company-Agent-User-Guide.html`로 제공하며 내용은 같습니다.

1.4.23과 비교하면 안내서·검사·포장 버전 변경이며 실행 정책이나 학습 조건을 추가하지 않았습니다. 기본 Office Reader 제거와 스킬 선택·학습 개선은 그대로 유지합니다. 1.4.23의 [알려진 제한](UPDATE_1.4.23.md#알려진-제한과-검증-범위)도 계속 적용됩니다. Workspace 실행 코드 버전은 0.8이며 이번 ZIP 변경은 안내서 갱신입니다.

## 설치·업데이트

1. `company-agent-1.4.24-2026.09.03.zip`을 새 폴더에 풉니다. 기존과 같은 설치 범위를 선택하고 백업 후 업데이트합니다. 뒤의 날짜는 회사 지식팩 버전입니다.
2. 개인 기억·지식·스킬·모델·별도 MCP 설정은 보존합니다. Claude Code를 종료한 뒤 다시 열어 새 대화에서 확인합니다.
3. Workspace는 이번 Release의 `company-workspace-preview-0.8-*.zip`을 새 폴더에 풉니다. 실행 중인 앱을 먼저 종료합니다.
4. 안내서만 필요하면 별도 HTML 한 파일을 내려받아 엽니다. 안내서 다운로드가 하네스를 설치하거나 기존 PC를 자동 갱신하지는 않습니다.

같은 버전 안에 서로 다른 설치 내용을 넣지 않도록 1.4.24로 올렸습니다. 기존 1.4.23 ZIP은 덮어쓰지 않습니다. 승인된 Python 3.11 이상과 기존 Claude Code 환경을 사용하며 별도 CUA 시험 문서·Driver·MCP는 포함하지 않습니다.

## 확인할 것

- 안내서 한 파일을 다른 빈 폴더로 옮겨도 5개 부와 전체 목차를 읽을 수 있어야 합니다.
- Ctrl+F 검색과 Ctrl+P 인쇄, 각 목차 이동을 확인합니다. 예문은 선택 후 Ctrl+C로 복사합니다.
- 자동 검사와 ZIP 무결성 검사는 회사 모델의 실제 지침 준수·속도·보안 환경 호환성 검증과 다릅니다.

이 버전의 검사 결과와 첨부파일 SHA-256은 저장소의 `docs/VALIDATION_RELEASE_1.4.24.md`에 기록합니다. 파일 무결성 검증 문서는 순환 해시를 피하기 위해 설치 ZIP 밖에서 관리합니다.
