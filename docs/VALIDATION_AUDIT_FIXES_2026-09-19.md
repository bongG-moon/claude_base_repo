# 외부 감사 후 수정·검증 기록 — 2026-09-19

요청한 순서대로 수정하고 해당 회귀시험을 실행했다. 이후 전체 시험과 실제 로컬 브라우저 흐름을 다시 확인했다. 기존 사용자 변경·설정·실제 회사 자료는 초기화하지 않았다.

## 수정한 범위

| 순서 | 수정 | 검증한 경계 |
|---|---|---|
| 1 | HTML 선택 준비 파일을 실제 보고서 변경과 분리. 별칭·번호·한글 스타일 및 정상 Edit에도 같은 정규화 적용 | 제한된 tmp 경로와 선택 필드만 예외. 실제 보고서·이전 미검증 변경은 계속 확인 대상 |
| 2 | 첨부 HTML 양식에 미리보기 → 사용자 확인 단계 추가. 디자인 변경 시 기존 분량·보기 유지 | 원본/미리보기 해시 대조, 변경 시 재확인. 명시 확인 전 최종 생성 중단. 기본 디자인에 불필요한 확인 추가하지 않음 |
| 3 | 지원 보고서·디자인 목록을 앱 안에서 정적 미리보기 | 모든 구역 표시, 원본 불변. 일반 첨부 HTML은 소스 보기. iframe 격리·CSP·활성 태그/외부 리소스 제거 |
| 4 | 관리 화면을 선택한 탭만 조회. 기억·지식은 20개씩 목록, 본문은 선택 시 조회 | 따라 하기/현재 사용 현황은 하네스 프로세스 없음. 변경된 목록 커서·범위 이탈·잘못된 상세 경로 거절 |
| 5 | 시작 시 지식 인덱스 중복 생성과 문서 이중 읽기 제거 | 인덱스 1회, 문서별 읽기 1회. 실제 오류 진단은 유지 |
| 6 | 전체 대화 파일 재저장 대신 대화별 파일과 작은 목록 파일로 분리 | 갱신된 대화만 저장. 기존 원본 보존 이전, 손상/저장 실패 시 기존 파일 보존, 경로 및 크기 제한 |

추가로 회귀시험에서 드러난 Windows의 거절 응답 연결 초기화도 수정했다. 허용하지 않는 요청은 작은 선언 본문만 제한 시간 내 버리고 계속 403으로 거절한다. 권한 허용 범위는 넓히지 않았다.

## 실행 결과

- 전체 Python 회귀시험: **919개 실행, 917개 통과, 2개 건너뜀**, 206.603초.
- 최종 HTML 미리보기 보안 보완 후 관련 HTML 시험: **20개 통과**. 전체 시험과 별도로 다시 실행했다.
- 디자인 선택기: **21개 검사 통과**, 생성된 자산과 생성기 일치 확인.
- 실제 Edge 브라우저: **390 / 768 / 1440px**에서 전체 페이지와 대화상자 가로 넘침 없음. 브라우저 실행 오류 0건, 외부 리소스 요청 0건, 모델 호출 0건.
- 브라우저 흐름: 예문 자동 전송 방지, 보고서 전체 구역, 디자인 10개 미리보기, 일반 HTML 소스, 외부 URL/스크립트 포함 문서 격리, 기억 검토·저장·비활성화·이력, 지식 다음 페이지/상세/초안, 폴더 지침, 질문·승인·완료, 미제공 사용량, 선택 로그, 자기 확인 기록.
- 거절 요청 연속 시험: 30회 모두 403, 업무 대화 생성 없음.
- GUI 묶음 검사는 파일 목록과 각 파일 바이트가 현재 소스와 일치하는지, 실행 상태·인증 정보가 포함되지 않는지 확인한다.

브라우저는 실제 로컬 앱·관리 API를 사용하되, Claude 연결만 모형 CLI로 대체했다. 시험용 설치 등록·기억·지식·기록은 분리된 임시 폴더에 두었다.

`scripts/test-lab/measure-audit-fixes.py`의 합성 데이터 결과다. 실제 업무 지연 시간이나 모델 토큰 절감률을 측정한 것은 아니다.

## 남은 운영 확인

- 사내 HCP 모델의 실제 스킬 선택과 승인, DRM Office 열기, 실제 계정 인증은 이번 로컬 모형 시험으로 입증하지 않았다.
- 새 관리 API가 포함된 Company Agent와 UI를 함께 배포해야 관리 개선이 적용된다. 기존 공개 1.4.14 설치에 UI ZIP만 바꾸어 관리 API가 생기는 것은 아니다.
- 미리보기는 정적이다. 원본 스크립트나 외부 리소스 실행을 허용하지 않는다. 선택은 채팅으로 전달한다.
- 회사·개인 정책/지식 구분, 기존 CLI 로그인·모델·MCP·스킬 설정은 유지했다. 모든 터미널 환경과 모든 CLI 기능의 GUI 동등성을 보장하는 검증은 아니다.
- 이번 단계는 로컬 소스 수정과 검증이며 Git 커밋·푸시·GitHub Release 갱신은 수행하지 않았다.
