# Company Agent 1.4.8 설치·업데이트 안내

## 달라진 점

- HTML 디자인을 참고 이미지의 색감·질감에 맞췄습니다. 글래스모피즘은 연한 하늘색·라벤더 배경과 반투명 흰 유리판, 파랑·보라 강조색을 사용합니다.
- 기존 8가지 디자인에 3D·이머시브, 레트로·Y2K를 추가했습니다. 기존 번호는 유지하며 새 디자인은 9번과 10번입니다.
- 추가 디자인에서 전체 목록을 한 번에 보여주고 `4번`처럼 번호나 이름 하나로 선택받습니다. 1~4번/5~8번 묶음을 거치거나 같은 선택을 재확인하지 않습니다.
- 기존에 정한 분량·보기 방식과 HTML 양식 첨부 기능을 유지합니다. 미리보기의 모바일 크기와 그래프 잘림, 인쇄 시 지표 대비도 보완했습니다.
- 스킬 선택 목록 자동 전달·재사용 등 이전 개선을 그대로 포함합니다.

3D·Y2K의 입체 장식은 오프라인 CSS로 표현한 추상 장식입니다. 실제 3D 모델이나 이미지 생성 서비스를 사용한 결과는 아닙니다. 이번 디자인 변경은 HTML에 대한 것이며 PPT에 같은 효과가 추가됐다는 의미는 아닙니다.

## 설치 방법

1. Release의 **company-agent-1.4.8-2026.09.03.zip**을 다운로드합니다. 자동 생성된 `Source code (zip)`이 아닙니다.
2. 새 폴더에 전부 압축 해제하고 **Install-CompanyAgent.cmd**를 실행합니다.
3. 기존과 같은 설치 범위를 선택해 백업 후 업데이트합니다.
4. Claude Code를 닫고 다시 실행합니다.

기존 Claude Code와 Python 3.11 이상을 사용합니다. 실행 조건과 위치는 설치 중 확인합니다. 개인 Memory·Skill·Knowledge·학습 이력과 모델·MCP 설정을 보존합니다. 기존 파일이나 개인 자료를 삭제할 필요가 없습니다. 파일명 뒤 `2026.09.03`은 회사 지식팩 버전입니다.

이미 만든 HTML은 자동으로 바뀌지 않습니다. 새 디자인은 기존 파일을 보존하고 새 파일로 생성해 주세요.

> 같은 자료로 HTML 보고서를 새로 만들어줘. 추가 디자인 목록에서 고를게. 기존 분량과 보기 방식은 유지하고 기존 파일은 덮어쓰지 마.

전체 목록이 나오면 `4번` 또는 `글래스모피즘`이라고 답하면 됩니다. 처음부터 원하는 이름을 지정하면 목록을 다시 고를 필요가 없습니다.
