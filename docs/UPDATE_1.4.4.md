# Company Agent 1.4.4 설치·업데이트 안내

## 설치 방법

1. `company-agent-1.4.4-2026.09.03.zip`을 새 폴더에 모두 압축 해제합니다. 이전 설치파일 폴더 위에 덮어 풀지 마세요.
2. 압축을 푼 폴더의 `Install-CompanyAgent.cmd`를 더블클릭합니다.
3. 이전에 설치한 것과 같은 범위(Windows 계정 전체 또는 해당 프로젝트)를 선택합니다.
4. 기존 Company Agent가 있으면 버전 변경 안내를 확인하고 백업 후 업데이트를 선택합니다. 새 설치라면 화면의 안내대로 진행합니다.
5. 설치 완료 후 열려 있는 Claude Code를 닫고 다시 실행합니다.

Claude Code와 Python 3.11 이상은 PC에 설치되어 있어야 합니다. 설치 과정에서 실행 위치와 조건을 확인하며, 여러 Claude가 발견되면 사용할 항목을 묻습니다. Python 실행파일을 이 ZIP에 포함하거나 자동 다운로드하지 않습니다.

기존 개인 Memory·Skill·Knowledge·학습 이력, 모델 설정과 MCP 연결은 업데이트 시 유지합니다. 설치 중 표시되는 백업 위치를 보관하세요. 설치 오류를 해결하려고 개인 자료나 기존 설정을 직접 삭제하지 마세요.

파일명 뒤의 `2026.09.03`은 회사 지식팩 버전입니다. 프로그램 버전은 `1.4.4`이며, 1.4.3의 내용을 덮어쓰는 동일 버전 재배포가 아닙니다.

## 이번에 반영한 내용

- 스킬 목록·본문을 읽도록 안내하는 준비 단계가 도구 실행을 반복 차단하지 않도록 수정했습니다. 기존 실행 권한과 업무별 보호 정책을 자동 해제하지는 않습니다.
- HTML 디자인 선택용 임시 파일 저장을 실제 업무 결과 변경과 구분해 불필요한 완료 확인을 줄였습니다. 실제 산출물 확인 절차는 유지합니다.
- HTML 양식 직접 첨부, 참고 양식 미리보기, 추가 디자인 선택을 지원합니다. 추가 디자인을 선택하면 세부 디자인을 먼저 선택한 뒤 분량과 보기 방식을 정합니다.
- 글래스모피즘의 반투명·배경 흐림, 뉴모피즘의 같은 색 표면·양방향 그림자 등 8가지 HTML 디자인과 미리보기를 개선했습니다. 작은 화면과 인쇄용 표시도 조정했습니다.
- 참고 HTML은 색상·폰트 등 제한된 디자인 정보를 읽습니다. 원본의 스크립트를 실행하거나 외부 자원을 가져오지 않으며, 원본 화면을 완전히 동일하게 복제하는 기능은 아닙니다.

이번 유리·음영 효과 개선은 HTML 대상입니다. PPT에 같은 시각 효과가 모두 구현되었다는 의미는 아닙니다. 운영 PC의 Office·DRM·모델 환경에서의 실제 결과는 별도로 확인해야 합니다.

## 업데이트 후 간단히 확인하기

새 Claude Code 대화에서 다음처럼 요청하세요.

> 월별 실적 145, 175, 210과 매월 목표 150을 이용해서 HTML 보고서를 만들어줘. 먼저 디자인을 선택하게 해줘.

`추가 디자인`을 골랐을 때 8가지 디자인을 바로 안내하는지 확인하세요. 글래스모피즘과 뉴모피즘을 각각 선택해 결과의 재질 표현이 다른지 확인할 수 있습니다. 기존 양식을 시험할 때는 `HTML 양식 직접 첨부`를 선택하세요.

더 자세한 변경 범위와 검증 기록은 `HTML_AND_SKILL_PREPARATION_FIX_2026-09-15.md`, `HTML_THEME_REVIEW_2026-09-15.md`, 사용 방법은 `HTML_DESIGN_SELECTION.md`를 참고하세요.
