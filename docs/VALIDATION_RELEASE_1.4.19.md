## 격리 설치 시험의 정리 오류와 보완

첫 일반/CP949 시험은 설치·업데이트·보존 확인까지 성공했지만, 새 Claude가 생성한 긴 Hook 결과 경로를 PowerShell 5.1 `Remove-Item`으로 정리하는 마지막 단계에서 종료 코드 1을 반환했습니다. 성공 출력만 보고 전체 통과로 계산하지 않았습니다.

개발용 `Test-ScopedInstallSmoke.ps1`의 정리만 보완했습니다. 내부 생성한 시험 폴더가 임시 경로 아래인지 확인하고 root reparse를 거부한 뒤 확장 경로 API로 삭제하며, 실제 정리 완료도 검사합니다. 사용자 설치 프로그램과 ZIP의 실행 코드는 이 변경으로 바뀌지 않습니다.

최종 일반 인코딩 재시험은 종료 코드 0, 84.80초, CP949 재시험은 종료 코드 0, 80.28초로 정리 단계까지 통과했습니다.

## 확인하지 않은 범위

- 실제 사내 HCP의 스킬 선택·지침 준수, DRM Office, 회사 MCP 인증·연결, 보안 제품 탐지 여부와 실업무 성공은 회사 PC에서 별도 확인해야 합니다.
- Cua를 설치·등록·시험하지 않았습니다. 사용자가 별도로 등록한 MCP·앱·권한도 변경하지 않습니다.
- 로컬 자동 시험 통과는 모든 외부 프로그램·셸 문법·HTML CSS·도구 스키마의 완전 지원을 뜻하지 않습니다. 구현별 제한은 감사 기록과 해당 스킬 안내를 참고하세요.
- 새 Release 게시가 기존 직원 PC의 자동 업데이트를 뜻하지 않습니다. 기존과 같은 범위로 업데이트하고 Claude Code·Workspace를 재시작해야 합니다.
