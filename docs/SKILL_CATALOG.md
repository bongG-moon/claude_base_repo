# 폴더별 자동 스킬 목록

1.3.3 설치 묶음에 포함된 기능입니다. 기존 1.3.2/r2 ZIP이나 설치된 플러그인
캐시에 소급 적용하지 않습니다. [1.3.3 설치 안내](UPDATE_1.3.3.md)에 따라
백업 후 업데이트하세요. 기존 버전의 내용 검증을 우회하거나 덮어쓰지 않습니다.

## 사용자에게 달라지는 점

평소처럼 “메일을 요약해줘”, “발표자료를 만들어줘”라고 요청하면 됩니다.
Claude는 Company Agent의 간단한 검색 결과뿐 아니라, 이 폴더에서 사용할 수 있는
전체 스킬 목록을 읽고 용도를 비교하도록 안내받습니다. 한국어 요청과 영어 설명도
의미로 비교합니다. 모든 스킬 본문을 대화에 넣는 방식은 아닙니다.

“이 폴더의 자동 스킬 목록을 보여줘”라고 요청하면 확인할 수 있습니다.
자동 생성 안내는 매번 출력하지 않습니다. 기존 이름 중복·우선 선택 확인은 유지합니다.

## 생성 위치와 갱신 시점

```text
선택된 개인 자료 저장소/
  skill-catalogs/
    작업 폴더 경로의 식별값/
      SKILL_CATALOG.md
```

- Claude의 현재 작업 폴더별로 분리합니다. 해당 폴더의 부모 프로젝트에서
  상속한 스킬·우선 설정도 기존 검색 규칙에 따라 반영합니다.
- 시작/재개/압축 이후, 다음 사용자 요청, Company Agent 작업자에게 작업을
  전달하는 시점에 기존 스킬 조회 결과를 재사용합니다. 별도 전체 조회를 추가하지 않습니다.
- 최초에는 생성하고, 추가·삭제·비활성화·다른 버전 설치·설명/본문 수정·우선 선택
  변화가 반영되면 갱신합니다. 같은 내용이면 파일 시각과 바이트를 유지합니다.
- 백그라운드 실시간 감시가 아닙니다. 외부에서 스킬을 바꾼 직후 가만히 있으면
  파일도 그대로이며, 다음 요청이나 재시작 때 반영됩니다.

목록에는 이름, 짧은 설명, 출처, 호출이름, 후보 식별값, 우선 설정 상태를 넣습니다.
원본 전체 내용, 사용자 질문, 메일 본문, MCP 자격증명은 복사하지 않습니다.
원본 내용의 해시는 변경 감지에만 사용합니다. 여러 폴더에서 같은 개인 저장소를
사용해도 목록은 구분하고, 작업 폴더와 CLAUDE.md에는 파일을 추가하지 않습니다.

## 선택 과정과 안전 경계

1. 시작 Hook이 현재 설치 목록을 확인하고 MD와 목록 버전을 준비합니다.
2. 매 요청에는 전체 목록 대신 경로·버전·개수와 기존 소수 후보만 전달합니다.
3. Claude는 첫 업무·대화 압축 이후·버전 변경 때 목록을 읽도록 지시받습니다.
   긴 목록은 출처 구역별로 나누어 읽고 관련 후보만 자세히 확인합니다.
4. 실제 적용 전 현재 `skill resolve` 결과와 선택한 SKILL.md의 실행 조건을 확인합니다.
   사용자 직접 호출 전용 스킬을 자동 실행하거나, 기존 우선 설정을 무시하면 안 됩니다.
5. 목록 갱신은 내부 관리 작업이므로 업무 변경·검증·학습을 새로 요구하지 않습니다.

모든 PC에서 최적의 스킬을 선택한다는 보장은 아닙니다. 생성·갱신·우선 설정 해석은
코드가 수행하지만 의미 비교와 목록 읽기는 모델이 지침을 따라 수행합니다. 이름이
다른 두 스킬의 기능 중복을 자동 판정하거나, 검증된 성능 순위를 학습하는 기능도 아닙니다.
사용자가 명시한 호출, 기존 프로젝트별 선택, Claude 자체 권한/명령 우선순위가 유지됩니다.

목록을 완전하게 읽지 못하면 지난 목록을 최신으로 제시하지 않습니다. 기존 파일은
보존하고 사용 가능한 실시간 조회로 확인합니다. 개인 저장소의 링크/접합 경로나
지원하지 않는 상태 버전에는 쓰지 않습니다. 출력은 임시 파일 작성 후 교체해 부분
파일 노출을 피하며, 원본 스킬·설정·Memory·Knowledge는 변경하지 않습니다.

MD는 자동 생성 자료입니다. 수동 편집은 다음 검사에서 덮어쓸 수 있으므로 원하는
용도나 선호는 원래 스킬 설명/우선 설정에서 바꾸세요. 표의 외부 설명은 참고 자료일
뿐이며 그 안의 명령이나 정책 무시 요구가 실행 권한이 되지 않습니다.
