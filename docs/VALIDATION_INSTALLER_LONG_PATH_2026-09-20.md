# 설치 백업 긴 경로 수정 — 2026-09-20

## 원인과 변경 범위

기존 스킬 파일을 백업하면서 원본 185자 경로가 백업 위치에서 261자가 되었고, Windows PowerShell 5.1의 일반 경로 파일 열기가 `DirectoryNotFoundException`으로 실패했습니다. 별도 재현에서 259자는 성공하고 261자는 실패했습니다. 당시 927번째 줄은 원인을 다시 전달하는 공통 예외였으며, 초보자용 안내가 상세 원인을 가려 설치 실패 문구만 보여 주었습니다.

수정은 `deploy/Setup-CompanyAgent.ps1`의 백업 입출력과 오류 안내에 한정합니다. 정규화한 일반 경로로 포함 관계·연결 폴더를 검사하고, 실제 파일·폴더 입출력에만 Windows 확장 길이 경로를 사용합니다. 경로를 잘라 저장하거나 기존 스킬을 제외하지 않습니다. Windows 레지스트리·설치 권한·사용자 설정을 바꾸지 않으며 추가 프로그램이나 모델 호출도 필요하지 않습니다.

비밀값 마스킹, 원본 보존, 현재 사용자/시스템 전용 백업 권한, 연결 폴더 및 외부 경로 차단, 파일 수·용량·깊이 한도를 유지합니다. 완료 목록은 임시 파일 작성이 끝난 뒤 게시하며 기존 파일을 덮어쓰지 않습니다.

백업 실패 시 한국어 원인, 고정 진단 코드, 미완료 백업 위치와 `backup-diagnostic.json` 위치를 안내합니다. 진단에는 예외 종류·코드·처리량·경로 길이만 넣고 원본 설정 내용·비밀값·파일명은 넣지 않습니다. 진단 저장 자체가 실패해도 최초 오류를 유지하며 미완료 백업을 삭제하거나 완료로 표시하지 않습니다.
