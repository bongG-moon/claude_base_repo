# 1.4.35 변경·설치 안내

하네스의 반복 준비 비용과 후속 요청의 공통 안내를 줄이는 배포입니다. 회사 지식팩은 `2026.09.03`을 유지하며 별도 개발 중인 Workspace 앱·실습자료·Computer Use MCP는 포함하지 않습니다.

기존 로컬 1.4.34 작업 ZIP과 혼동되지 않도록 새 버전을 사용합니다. 공개 1.4.33에서 1.4.35로 업데이트할 수 있으며 기존 ZIP은 덮어쓰지 않습니다.

## 달라진 점

- 후크 시작: Python 버전 확인과 실제 진입의 중복 기동을 줄입니다. 승인된 실행기 선택·최소 버전·경로 검사는 유지하며, 업무가 시작된 뒤 실패하면 다른 실행기로 같은 업무를 재시도하지 않습니다.
- 일반 명령: 하네스 관리 명령이 아닌 것이 명확하면 Python·PowerShell 경로를 반복 검색하지 않습니다. 권한 승인과 위험 명령 차단을 생략하는 변경은 아닙니다.
- 대화 안내: 정상 후속 요청은 변하지 않은 공통 안내를 축약하고 현재 요청의 스킬·선택·검증 정보를 유지합니다. 시작·복원·대화 압축·지침 또는 실행 정보 변경·기록 손상에는 필요한 지침을 다시 제공합니다. 출력 기록을 모델 수신이나 스킬 본문 읽음으로 간주하지 않습니다.
- 지식 목록: 원본과 검색용 결과가 바뀌지 않으면 다시 생성하지 않습니다. 변경·삭제·손상 시 갱신하고, 백업 등 제외 폴더는 처음부터 탐색하지 않습니다. 변경 확인을 위한 원본 읽기까지 없어지는 것은 아닙니다.
- 스킬 안내: 기존 브라우저 도구로 업무를 수행하는 요청과 도구·스킬을 만드는 요청을 구분합니다. 무관한 스킬 후보를 제외할 때 현재 요청에 맞는 완전한 명령을 안내하여 같은 준비 확인에 다시 막히는 일을 줄입니다.
- 사용자 안내서: 재사용·복구·성능 측정의 범위를 단독 HTML과 설치용 Markdown에 반영했습니다.

## 업데이트

1. 진행 중인 업무를 저장하고 Claude Code를 종료합니다.
2. `company-agent-1.4.35-2026.09.03.zip` 전체를 새 폴더에 풉니다. GitHub의 자동 생성 `Source code (zip)`은 직원 설치 파일이 아닙니다.
3. `Install-CompanyAgent.cmd`를 실행하고 기존과 같은 사용자/프로젝트 범위로 업데이트합니다.
4. 완료 후 Claude Code를 다시 실행합니다. 개인 기억·스킬·지식·모델·MCP·다른 플러그인 설정은 초기화하지 않습니다.

기존 Release·설치본은 자동 변경하지 않습니다. 새 후크·외부 모델·상시 학습 작업자·학습용 Stop 반복을 추가하지 않습니다.

## 검증과 한계

[배포 검증](VALIDATION_RELEASE_1.4.35.md)에 실제 검사와 로컬 성능 비교를 기록합니다. 안내 글자 수는 토큰 수가 아니며 후크 준비 시간은 전체 업무 시간과 다릅니다. 실제 사내 HCP의 지시 준수·시간·토큰 절감률, DRM·Office·전사 API 연동은 별도 확인이 필요합니다. 작업 성공률이나 안전 확인을 낮춰 성능을 확보하지 않습니다.
