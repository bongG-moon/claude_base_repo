# 1.3.5 한국어 기본 안내 검증 · 2026-09-13

## 결과

- 전체 자동 검사 465개 통과, 실패 0개, 제외 0개. 실행 시간 167.630초.
  `COMPANY_AGENT_TEST_REAL_CLAUDE=1`로 실행했다. 실제 Windows Hook 호출과
  합성 응답 검사가 함께 포함되며 사내 모델과 465번 대화한 결과는 아니다.
- 신규 한국어 기본 정책 검사 7개 통과: 공통 안내, 작업자 전달, 메뉴 설명,
  신규 프로젝트 생성, 이전 생성 형식 호환, 사용자 수정 보존, 실제 실패 경고 유지.
- 설정 입력 도우미 11개 검사 통과. 사용자에게는 한국어 저장·취소 안내를 내보내고,
  자동 실행 조건 확인용 JSON 계약은 유지한다.
- 이전에 제작한 1.3.4 ZIP의 실제 생성 코드를 불러와 6가지 프로젝트 형식에서
  이전 형식 출력이 바이트 단위로 일치함을 확인했다. 읽기/검증만으로 기존 파일을
  바꾸지 않으며 명시적 업데이트 시 백업과 충돌 검사를 유지한다.
- 공통 스킬 길이 제한 검사 7개와 긴 Windows 경로의 실행 컨텍스트 크기 검사 통과.
- `Test-OfflineBundle.ps1` 통과: 기존 Python 사용, 최소 3.11 조건,
  배포 항목 17개와 신규 한국어 정책·업데이트 안내 포함 확인.
- 최종 ZIP 129개 파일의 manifest 무결성 검사 통과. 별도 폴더에 압축을 풀어
  한국어 정책, 실행 지침, 프로젝트 생성기, 대표 메뉴 파일의 소스/배포 해시 일치 확인.
