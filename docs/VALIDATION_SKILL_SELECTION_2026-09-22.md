# 스킬 선택·이미지 검토 효율 개선 검증

이 문서는 2026-09-22 작업 시점의 기록입니다. 2026-09-27의 추가 회귀 수정·전체 재검사·배포 파일 검증은 [1.4.26 배포 검증](VALIDATION_RELEASE_1.4.26.md)을 확인하세요.

## 검토 범위

스킬 설치와 업무 실행 의도를 구분하고, 제작/디자인 스킬의 선택 충돌을 준비 단계에서
해결하며, 이미지 작업 후 불필요한 재입력을 줄이는 변경이다. 이 문서는 실제 변경과
검증 결과를 통합해 기록하며, 사내 모델의 실사용 성능을 확인한 것처럼 표현하지 않는다.

## 스킬 선택 변경

- 작업 종류와 행동이 맞는 후보만 필수 본문 로드 대상으로 삼는다. 약한 단어 일치의
  단일 후보는 목록 비교 안내에 머물며, 없는 스킬이나 무관한 읽기 스킬을 강제하지 않는다.
- `@image-reader.zip 여기에 이미지 읽는 스킬도 있는데 이것도 설치해줘`를 설치 요청으로
  구분한다. 설치 기능이 실제 목록에 있을 때만 후보로 사용하며 별도 모델은 호출하지 않는다.
- HTML만 만드는 스킬과 HTML·PPT를 함께 만드는 스킬도 이번 HTML 요청에는 같은 역할로
  비교한다. 표시용으로 짧게 자르기 전 설명을 사용하고, 생략된 후보가 있으면 일부 목록을
  전체인 것처럼 강제 선택하지 않는다.
- 목록에서 역할 중복이 확인되면 Skill 본문 로드 전에 사용자 선택을 확인한다. 새로
  추가한 Skill 실행 전 확인은 선택 점검일 뿐, 기본 도구 권한을 승인하지 않는다.
- 세션 전용 스킬은 실제 성공한 로드를 확인한 뒤 로컬 제작 후보와 선택을 묻는다.
  실제 AskUserQuestion 답변을 현재 요청에 연결한다. 외부 스킬 선택 뒤 공통 스킬로
  강제 교체하지 않으며, 공통 스킬을 선택하면 해당 본문 로드를 요구한다.
- 외부 스킬 이름만으로 로컬 파일·해시·재사용 증거를 만들지 않는다. 실패·취소·가짜
  질문 답변·무관한 이전 본문은 선택 완료가 아니다. 새 작업에는 이전 선택을 넘기지 않는다.
- 같은 작업의 압축 뒤 변경 없는 로컬 스킬 선택만 짧은 힌트로 복원한다. 본문 기록은
  지우고 해당 본문만 다시 읽는다. 변경된 스킬·새 작업·시작/재개에는 복원하지 않는다.

사용자 환경의 `artifact-design`·`goodocs-api` 실제 본문은 이 저장소에 없다.
보고된 호출 패턴과 대표 메타데이터로 재현했으며 해당 외부 스킬 자체를 검증한 것은 아니다.

## 이미지·미리보기 검토 지침

- PPT와 HTML은 첫 검토에서 모든 장/구간을 확인한다. 작은 묶음과 개요를 활용하되
  작은 글자·표는 원본 크기나 확대 화면으로 확인한다. 축소판만 보고 전체 통과하지 않는다.
- 수정 후에는 변경·영향받은 장/구간을 재검토한다. 공통 폰트·테마·배치 변경이나
  영향 범위 불명확 시에는 전체를 재검토한다. 내용·수치·편집 가능성 확인은 그대로 유지한다.
- 반복된 전체 이미지·OCR 전문·base64 출력 대신 파일 버전, 검토 범위, 문제와 미확인
  범위만 짧게 요약한다. 별도 필수 명령, 외부 호출, 권한 변경은 추가하지 않았다.
- 압축 이후 현재 작업에 필요한 스킬 본문/참조만 다시 읽는다. 경로가 남았다고 본문이
  남은 것으로 취급하지 않고, 확인 기록과 파일 버전이 불명확하면 검증 성공도 재사용하지 않는다.
- 모델이나 자동 압축 기준은 변경하지 않는다. 이미지 미지원은 실제 미검증으로 알린다.

지침 파일: `company-agent-plugin/skills/presentation/references/image-review.md`.
PPT/HTML Skill은 실제 화면 확인 단계에서만 이 짧은 참조를 읽는다.

## 실사용 확인 예시

1. HTML 제작 대안 두 개가 있는 새 대화에서 “HTML로 정리해줘”를 요청한다.
   실제 이름·차이를 묻고 선택한 절차 하나로 작업하는지 확인한다. 세션 전용 스킬은
   성공 로드 뒤 선택될 수도 있으며 이를 무조건 로컬 목록 누락으로 오판하지 않는다.
2. 이미지 읽기 스킬 ZIP 설치를 요청한다. 이미지·스프레드시트 읽기 스킬을 불필요하게
   로드하지 않고 설치 범위·허용된 절차를 따르는지 확인한다.
3. 5장 PPT 초안을 만들고 5장 모두 검토한 기록이 있는지 확인한다.
4. 3장 표의 내용만 수정한다. 3장과 연결된 요약/합계만 재검토하는지 확인한다.
5. 공통 글꼴을 바꾼다. 5장 전체가 재검토 대상이 되는지 확인한다.
6. 압축 후 이어간다. 확정된 선택은 유지하되 본문이 없으면 필요한 지침만 다시 읽고,
   없는 검토 기록이나 변경된 파일을 이미 검증했다고 주장하지 않는지 확인한다.
