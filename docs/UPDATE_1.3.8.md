# 1.3.8 · 필요한 때만 펼치는 HTML 추가 디자인

처음에는 **깔끔한 업무형 / 지표 중심형 / 추가 디자인**만 안내합니다.
추가 디자인을 선택하고 로컬 선택 화면을 펼치면 8가지 한국어 설명과 작은 예시를
비교할 수 있습니다. 선택 문장을 복사해 Claude 채팅에 전달하는 방식입니다.
선택 화면과 실제 보고서는 같은 테마 코드를 사용합니다. 배경만 바꾸지 않고 표지,
지표 카드, 표, 차트·범례, 테두리·그림자도 함께 맞춥니다.

새 보고서 CLI는 디자인·분량·보기 방식이 빠지면 임의로 미니멀리즘 결과를 만들지 않고
필요한 선택만 안내합니다. 이미 받은 조건이나 명시적으로 수락한 추천은 다시 묻지 않습니다.
기존 HTML은 자동 변경하지 않습니다. 재작성할 때는 새 파일명으로 요청하세요.

[선택 화면 사용 안내](HTML_DESIGN_SELECTION.md)

## 적용 방법

1. `company-agent-1.3.8-2026.09.03.zip`을 새 폴더에 압축 해제합니다.
2. `Install-CompanyAgent.cmd` 실행 후 기존과 같은 사용 범위를 선택합니다.
3. 백업 후 업데이트하고 Claude Code를 닫았다 다시 엽니다.

개인 Memory·Skill·Knowledge·모델·MCP는 기존 보존 절차를 유지합니다.
이번 제작은 현재 설치본을 직접 바꾸거나 GitHub에 게시하는 작업과는 별개입니다.
기존 1.3.7 내용은 덮어쓰지 않으며, PPT 개선도 함께 포함합니다.

## 한계

Claude 터미널 안에 브라우저 버튼을 직접 삽입하는 기능은 아닙니다. 로컬 HTML을
별도로 열거나 추가 요청 후 채팅의 설명을 이용합니다. 화면에서 클릭한 내용은
사용자가 채팅에 붙여 넣기 전까지 하네스가 자동으로 읽거나 학습하지 않습니다.
권한이 제한된 브라우저 열기·클립보드는 우회하지 않으며, 자동 복사가 안 되면
사용자가 직접 복사할 문장을 제공합니다. 실제 화면 및 사내 모델 응답은 운영환경에서
추가 확인해야 합니다. 구현 코드/상호작용 단위 검사를 시각 검증으로 설명하지 않습니다.
