# Company Harness 1.4.38 배포 검증

검증일: 2026-10-08. 지식 색인·읽기 후크·EML 개선분과 배포 버전·안내서만 선별했습니다. 별도 개발 중인 Workspace 앱, HTML 디자인, Computer Use MCP와 실습 자료 변경은 포함하지 않았습니다.

## 소스와 시험

- 선별한 Git index를 `core.autocrlf=false`로 분리하여 Git에 저장되는 바이트 그대로 검사하고 빌드했습니다. 작업 폴더의 다른 변경은 보존했습니다.
- 최종 배포 소스에서 회귀·설치 EXE·GitLab 포장·안내서 계약 **165개 테스트가 통과**했습니다. 안내서 버전 링크 보완 후 해당 20개도 별도로 재확인했습니다(165개에 포함된 중복 실행).
- 지식 자동 갱신 직후 파일 교체, 읽는 중 교체, 삭제, 권한·디코딩 오류를 검증했습니다. 잘못된 색인과 캐시는 게시하지 않고 기존 상태를 보존하며, 변경하지 않은 파일에 추가 재읽기를 하지 않습니다.
- 실제 CMD 및 Node exec-form 호출, 한글·특수 경로, Python 교체 후 재적용, 기존 캐시의 경로 연결을 확인했습니다. 원본 설치기와 격리된 CLI 모형으로 설치 실패를 주입해 runtime-selection·launcher·metadata·hooks의 이전 바이트 복원을 검증했습니다. 실제 사용자 설치나 운영 CLI 업그레이드는 수행하지 않았습니다.
- 인코딩 정보 없는 UTF-8 본문·TXT 첨부, 명시된 CP949, 잘못된 바이트·알 수 없는 인코딩, 본문과 첨부의 독립적 실패, 보호 유형·출력 한도를 검증했습니다. 원본 수정·인코딩 추측·손실 대체·외부 접속은 없습니다.
- 별도 Read 진입점은 빈 후크 결과만 반환하며 도구 권한을 자동 허용하지 않습니다. 이미지 인계·오류 입력·런타임 복구는 기존 검사 경로를 유지합니다.

## 성능 확인

Windows 11 / Python 3.12.14, 격리한 등록 정보와 가상 Read 입력으로 기존 PowerShell 진입점과 설치형 진입점을 교대로 측정했습니다. 경로당 준비 3회 후 15회 측정한 중앙값이며 각 호출은 새 프로세스입니다. OS 캐시는 비우지 않았습니다.

| 경우 | 기존 | 변경 후 |
| --- | ---: | ---: |
| 비전 설정 없음, 일반 텍스트 Read | 454.63ms | 137.13ms |
| 비전 설정 있음, 일반 텍스트 Read | 423.96ms | 135.31ms |
| 비전 설정 있음, 이미지 인계 | 795.65ms | 976.55ms |

일반 텍스트 준비 시간은 약 68~70% 감소했습니다. 이미지 인계는 기존 PowerShell 검사를 유지하는 추가 프로세스 때문에 약 181ms 증가했습니다. 모든 비교의 후크 결정 결과는 같았습니다. 재현 도구는 `scripts/test-lab/benchmark-read-hook.py`입니다.

이는 실제 문서 읽기·LLM 호출·전체 업무 시간·토큰 사용량의 측정이 아닙니다. 운영 HCP 모델이나 게이트웨이는 호출하지 않았으며 회사 PC 성능을 보장하지 않습니다.

## 배포 파일

- 기본 번들 빌드의 strict 플러그인 검증, 회사 지식 검증, Python 구문 검증을 생략하지 않았습니다.
- 안내서 재생성과 `--check`가 일치합니다. 단독 HTML과 설치 사본은 동일합니다.
- 실제 EXE의 `--verify-only`가 내장 ZIP 추출·해시 검증을 통과했습니다. 실제 설치는 하지 않았습니다.
- GitLab 배포 준비 도구가 직원 ZIP의 222개 manifest 파일과 EXE 내장 ZIP 일치를 검증했습니다. ZIP은 manifest 자체를 포함해 223개 파일입니다.
- 다음 네 파일과 각각의 `.sha256`을 제공합니다.

EXE의 Authenticode 상태는 `NotSigned`입니다. 해시는 파일 일치 확인이며 회사 배포 승인·코드 서명을 대신하지 않습니다. GitHub 게시와 사내 GitLab 게시·운영 PC 업데이트는 별개입니다. GitLab ZIP은 담당자의 수동 게시용이며 이 작업에서 사내 서버에 접속하거나 업로드하지 않았습니다. 기존 Release와 사용자 PC는 자동으로 변경되지 않습니다.
