# 1.4.12 — 관련 스킬 우선, 없으면 일반 실행

## 설치·업데이트

[1.4.12 설치 ZIP](https://github.com/bongG-moon/claude_base_repo/releases/download/v1.4.12/company-agent-1.4.12-2026.09.03.zip)을 모두 새 폴더에 압축 해제한 뒤 `Install-CompanyAgent.cmd`를 실행하세요. 이전과 같은 내 계정/프로젝트 범위를 선택해 백업 후 업데이트하고, Claude Code를 닫고 다시 엽니다.

개인 Memory·Knowledge·Skill·선호, 모델·MCP와 기존 사용자 규칙·Hook은 유지합니다. 기존 1.4.11 설치 ZIP을 덮어쓰지 않으며 이미 설치된 PC가 자동으로 바뀌지는 않습니다. 파일명 뒤 `2026.09.03`은 회사 지식팩 버전입니다.

## 바꾼 점

- 사용 가능한 목록에서 관련 스킬이 명확하면 첫 실행 전에 그 지침을 제공합니다. 스킬 이름을 사용자가 매번 지정할 필요를 줄였습니다.
- 같은 역할의 후보가 겹치면 기존 선호를 따르거나 사용자에게 묻습니다. 관련 스킬이 없으면 일반 작업으로 진행하며 별도 선택 기록 명령을 요구하지 않습니다.
- 변경 없는 본문은 같은 대화에서 재사용합니다. 짧은 이어서 요청은 직전 업무의 분야·행동 태그만 참고하며 원문 질문·문서 내용은 상태에 저장하지 않습니다.
- 큰 본문이나 별도 모델·도구 제한·동적 명령이 있는 스킬은 정상 Skill/Read 로드 경로를 사용합니다. 본문 일부를 잘라 절차가 누락되게 하지 않습니다.
- 전체 실행을 막는 준비 단계나 추가 모델 호출을 넣지 않았습니다. 기존 권한·회사 정책은 유지합니다.
- Hook 본문 전달과 실제 Read/Skill 성공 기록을 구분합니다. 전달 안내만으로 실제 문서 읽기나 모델 적용 성공을 주장하지 않습니다.
- 자동 설치·업데이트 점검 시 원래 오류가 `ScriptHalted`로 가려지던 문제를 수정했습니다. 간편 설치의 한국어 오류 안내는 유지합니다.

## 확인 범위

전체 회귀 검사 747개와 격리된 실제 Claude 전달 검사 9개 항목을 통과했습니다. 전달 검사는 로컬에서 정해진 응답을 사용하며 사내 HCP 모델의 자율 판단 검증은 아닙니다. 세부 내용은 [관련 스킬 우선 실행 검증](https://github.com/bongG-moon/claude_base_repo/blob/v1.4.12/docs/SKILL_FIRST_EXECUTION_2026-09-17.md)을 참고하세요.

변경하지 않은 1.4.11 설치 ZIP에서 1.4.12로 실제 업데이트해 새 버전 등록, 개인 자료·설정 보존, 일반 작업 폴더에서의 시작 Hook 실행을 확인했습니다. 새 설치본의 계정/프로젝트 설치·복구·거절 검사와 CP949 환경의 한글·이모지 경로 검사도 통과했습니다. 검사는 격리된 임시 프로필에서 진행했으며 실제 사용자 PC의 설치나 설정을 변경하지 않았습니다.

설치 후 평소처럼 `@테스트자료.pptx 내용을 읽어줘`라고 요청해 회사 Office 읽기 절차가 사용되는지 확인하세요. 별도 Skill 호출이 표시되지 않더라도 본문이 미리 제공됐을 수 있습니다. 실행 결과와 실제 읽기 경로를 함께 확인해야 하며 모든 사내 모델의 지침 준수를 보장하지 않습니다. 사내 Office·DRM·메일·DB 통합 확인은 해당 환경에서 별도로 진행해야 합니다.
