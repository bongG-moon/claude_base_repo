# Company Agent 1.4.17 업데이트

이전 요청으로 반영한 제작·승인 흐름과 이번 통합 가이드를 함께 배포합니다. Workspace는 0.5 미리보기 ZIP을 사용합니다. 기존 Release와 개인 설치를 자동 변경하지 않습니다.

## 처음 쓰는 사람을 위한 한 파일

`Company-Agent-Guide.html` 하나에 온보딩, 업무별 사용자 안내, 기억·스킬·후크 설명, Claude Code 명령어, 선택적 Cua 시험 안내를 합쳤습니다. 5개 주제·45개 절이며 기존 파일명은 통합본으로 연결하는 호환 안내만 유지합니다. 설치 완료 화면·첫 업무 안내·Workspace도 같은 통합본을 엽니다.

참고 PPT가 없어도 가상 MD 생성 → 실제 파일 읽기 → 가상 HTML/PPT 생성으로 연습합니다. 새 디자인은 참고 캡처를 요구하지 않습니다. PPT는 HTML 초안 확인 후 제작하고 완성된 PPT로 Office 읽기를 별도 시험합니다. Office가 없으면 MD·HTML까지 진행하고 PPT 읽기는 미실행으로 남깁니다.

가이드는 인터넷 없이 열리며 Ctrl+F 검색·예문 선택 복사·Ctrl+P 인쇄를 지원합니다. 전체 내용을 후크에 주입하거나 문서를 여는 것만으로 AI·설정 변경·업무 실행을 시작하지 않습니다. 자료에 없는 원인·연도 추가, 원본 덮어쓰기, 기억 자동 저장, 라이브러리 자동 설치는 실습에 포함하지 않습니다.

## 문서 읽기·질문·프로젝트 시작

- Office 읽기는 별도 Windows 팝업 대신 Claude 대화에서 파일·범위·AI 처리 안내와 승인/취소를 받습니다. 동일 대화·폴더·파일 상태·범위에 15분 이내 1회 승인만 유효하며 실제 권한 검사는 유지합니다.
- 하네스의 질문·선택지·피드백은 기본 한국어입니다. CLI 자체 메뉴나 Windows/Office UI 번역은 아닙니다.
- 실제 작업 요청 시 지침이 없는 안전한 작업 폴더에 기본 `CLAUDE.md`를 한 번 만듭니다. 기존/상위 지침, 계획·변경 금지 요청, 홈·시스템·설치/설정 경로를 보존합니다. 별도 AI 호출이나 `/init` 분석은 하지 않습니다.
- 전사 표준 구조의 MCP 초안 제작을 돕는 `platform-mcp-builder` 스킬을 추가합니다. 연결 등록·계정·배포·권한 승인을 자동 처리하지 않습니다.

## HTML-first 편집형 PPT와 결과 전달

- 전체 HTML 초안 확인 후 편집 가능한 PPT를 만듭니다. 카드·둥근 모서리·그림자·태그·자유 배치·이미지 맞춤을 네이티브 개체로 처리합니다.
- 정적 HTML을 로컬 브라우저에서 측정해 텍스트·도형·단순 표로 옮깁니다. 승인 후 같은 장면을 재사용하므로 최종 내보내기에서 브라우저를 다시 실행하지 않습니다. 소스 스크립트·외부 연결은 실행하지 않습니다.
- HTML 대표 양식은 업무 문구·숫자·참고 캡처를 제거한 추상 배치를 저장합니다. 저장 위치는 개인 전체/이 프로젝트 중 선택합니다.
- 기존 PPT 그림 크기 수정은 원본을 보존하고 새 결과를 만듭니다. 가운데 자르기/비율 유지/늘이기를 구분하고 여러 그림이 있으면 대상 확인이 필요합니다.
- 한 요청의 초안·재시도·검사 이미지는 내부 작업 공간에 두고 검증한 최종 결과 하나만 전달합니다. 다음 요청의 별도 결과와 명시적인 다중 결과 요청은 허용합니다. 기존 파일은 자동 삭제하지 않습니다.

## 설치 방법

1. Release의 `company-agent-1.4.17-2026.09.03.zip` 전체를 새 폴더에 풉니다. 뒤 날짜는 지식팩 버전입니다.
2. `Install-CompanyAgent.cmd`를 실행하고 기존과 같은 User/Project 범위로 업데이트합니다.
3. Claude Code를 완전히 종료하고 다시 시작합니다. 모델·MCP·개인 기억·스킬·지식은 보존합니다.
4. Workspace 사용자는 기존 앱의 전원 버튼으로 종료하고 같은 Release의 `company-workspace-preview-0.5-*.zip`을 새 폴더에 풀어 실행합니다.
5. 가이드만 보려면 Release의 `Company-Agent-Guide.html` 단독 파일을 열어도 됩니다. HTML 열기만으로 설치가 바뀌지는 않습니다.

## 확인해야 하는 한계

사내 HCP의 실제 자동 스킬 적용, 인증·DRM Office, 회사 MCP 연결은 운영 PC에서 추가 확인해야 합니다. 가상 실습 프롬프트 검토와 브라우저/코드 시험을 사내 모델의 실제 성공으로 기록하지 않습니다.

HTML과 PPT가 모든 CSS 효과·웹 동작·글꼴을 완전히 동일하게 재현하지는 않습니다. 줄/서식별 텍스트는 편집 가능하나 웹 문단처럼 자동 재배치되지 않습니다. CSS 막대는 도형이며 수치 연결 차트와 다릅니다. 변환은 python-pptx가 필요합니다. 개발 PC에서는 Chrome 측정·실제 PowerPoint 렌더링을 확인했으며 특정 Edge 빌드의 빈 DOM 출력이 관찰돼 Edge만 설치된 회사 PC는 별도 시험이 필요합니다. 미지원 기능을 숨기거나 자동 설치·권한 변경으로 대체하지 않습니다.
