# 1.4.1 — 사내 Office 문서 읽기

이번 배포는 1.4.0의 PPT 제작 선택·양식 유지, 스킬 목록 우선 읽기, 승인 지연
구분을 모두 포함합니다. Office 읽기는 시범 기능입니다. 일반 PPT·Word는 실제
읽기를 확인했으며 Excel은 개발 PC에 xlwings가 없어 실제 읽기는 아직 미검증입니다.
사내 DRM 호환성까지 검증된 배포라는 뜻은 아닙니다.
[실행 결과](VALIDATION_1.4.1.md)를 확인하세요.

## 무엇이 추가되나요?

`office-reader` 하나가 공통 스킬 목록에 추가됩니다. 기존 PPT 제작·보고서·메일
스킬을 대체하지 않습니다. 전체 목록에는 이름과 설명만 들어가고 문서 읽기 업무에서만
상세 지침을 읽습니다. 기존 개인 스킬과 같은 이름이면 기존 중복·우선 선택 기능을 따릅니다.

Excel/CSV는 `xlwings → 새 Excel → app.books.open → used_range → DataFrame`
순서를 고정 실행합니다. 다른 읽기 방법을 먼저 시도하거나 매번 코드를 생성하지 않습니다.
하네스가 사용하는 Python에 xlwings와 pandas, PC에 Excel이 필요합니다.
누락된 라이브러리는 자동 다운로드하지 않습니다. PPT/Word는 pywin32로 실제
PowerPoint·Word를 여는 고정 Python 경로입니다. 일반 파일과 DRM 적용 파일 모두
같은 파일 종류별 경로를 사용합니다. PowerShell/직접 파일 파서로 재시도하지 않습니다.
DRM 암호 해독·보호 해제 기능은 아닙니다. 회사에서 Office 자동화·내용 추출·AI 처리와
대화 기록 보존을 허용하는 경우에만 사용합니다. 이를 Office 열기 성공으로 판단하면 안 됩니다.

## 이렇게 요청하세요

- “이 xlsx 파일의 첫 번째 시트 A1:F50을 읽어서 실적을 요약해줘.”
- “이 csv 파일을 Excel로 읽고, 우선 A1:F20의 한글과 숫자가 정상인지 확인해줘.”
- “이 PPT의 1~5장 내용을 읽고 핵심만 요약해줘.”
- “이 Word 문서의 처음 20개 본문 문단을 읽어서 할 일을 정리해줘.”

실행 전 파일·범위·AI 전달 내용을 보여주는 Windows 확인 창이 나옵니다.
확인하지 않으면 Office를 열지 않습니다. 클릭이 회사 정책을 대신하거나 접근 거절을
무효화하지는 않습니다. 인증·보안 창은 자동으로 누르지 않으며 필요한 창이 있으면
사용자가 확인해야 합니다. 문서 내용을 보기 위한 별도 계정·비밀번호 수집은 하지 않습니다.

## 지원 범위와 제한

- xlsx/csv/pptx/docx만 지원합니다. 구형/매크로 포함 형식은 초기 범위에서 제외합니다.
- Excel: 기본은 첫 시트의 사용 영역, 최대 200행·20열·2,000셀을 동시에 적용합니다.
  첫 행·첫 열을 제목/인덱스로 소비하지 않고 값으로 보존합니다. 별도 범위도 지정할 수 있습니다.
  CSV의 구분자/형 변환/입력 인코딩은 Office 영향을 받으므로 원본과 대조해야 합니다.
- PPT: 지정한 슬라이드의 최상위 글자 칸·표. 그룹·그림 속 글자·SmartArt·노트·차트
  수치는 완전 수집하지 않습니다.
- Word: 본문 문단 번호 기준입니다. 페이지 번호가 아니며 머리말·주석·텍스트 상자 등은 제외됩니다.
- 한 번에 최대 20,000자. 일부만 읽었으면 전체 문서를 확인했다고 표현하지 않습니다.
- 파일이 읽는 중 변경되거나 실제 파일 열기·읽기가 거절되면 내용을 반환하지 않습니다.
- 제한이나 시간 초과 후 다른 도구로 재추출하지 않습니다. 원본을 저장·복사·변환하지 않습니다.
- 하네스의 별도 원문 TXT/로그/Memory/Knowledge는 만들지 않지만 Office 자체 캐시,
  자동 복구 자료·OS 메모리·Claude 대화 기록까지 삭제하거나 통제하지는 않습니다.
- 잠긴 Office 호출은 60초 뒤 대기 결과로 처리합니다. 강제 종료하지 않으므로 Office
  창/빈 실행 환경이 남을 수 있고, 강제 중단 시 닫기·설정 복원이 완료됐다고 보장하지 않습니다.

Excel의 선택적 Office IRM 속성이 없거나 미지원 오류(E_FAIL 등)를 반환하는 경우는
실제 문서 접근 거절과 구분하여 `unavailable`로 표시합니다. 이 경우에도 Excel의
정상 열기/읽기만 사용하며, 명시된 제한 또는 접근 거절은 무시하지 않습니다.
PPT/Word도 동일하게 부가 권한 정보 미지원과 실제 접근 거절을 구분합니다.
Office 권한 속성은 모든 제3자 DRM을 판별하지 않습니다. 열기 성공을 회사의
자동화·내용 추출·AI 처리 허가로 간주하지 마세요.

## 적용

1. [1.4.1 설치 ZIP](https://github.com/bongG-moon/claude_base_repo/releases/download/v1.4.1/company-agent-1.4.1-2026.09.03.zip)을 받아 새 폴더에 모두 압축 해제합니다.
2. 열려 있는 Claude Code를 닫고 `Install-CompanyAgent.cmd`를 실행합니다.
3. 기존과 같은 사용자/프로젝트 범위를 선택하고 백업 후 업데이트합니다.
4. 완료 후 Claude Code를 다시 열고 “이 폴더의 스킬 목록을 보여줘”로 확인합니다.

파일명 뒤의 `2026.09.03`은 회사 지식팩 버전입니다. 설치 프로그램의 버전은 1.4.1입니다.
1.4.0과 파일 내용이 달라 1.4.1로 구분합니다. 1.4.0 ZIP을 덮어쓰지 않습니다.
새 설치 묶음을 사용할 때 기존과 같은 범위를 골라 백업 후 업데이트하고 Claude를
다시 여세요. 개인 Memory·Skill·Knowledge·모델·MCP 설정을 초기화하지 않습니다.
다운로드만으로 기존 설치가 바뀌지는 않습니다. Office 라이브러리는 하네스가 실제로
선택한 Python 환경에 별도 준비해야 합니다. 없으면 해당 읽기 작업만 중단하고 안내합니다.
