# 1.4.50 변경 내용

이번 변경은 독립 데이터 조회 스킬과 배포 파일을 대상으로 합니다. 진행 중인 별도 Workspace 앱과 하네스 구조 개편은 포함하지 않습니다. 개인 인증정보, 저장 쿼리, 결과와 기존 모델 및 MCP 설정은 보존합니다.

## Datalake 조회

- 사용자 제공 원본에 맞춰 `lakes.client.LakeHouse`를 사용합니다. 사번, JWT, S3 Access Key와 S3 Secret Key를 전달하고 `execute_pd(query=...)`로 조회합니다.
- SQL의 `lake_catalog.스키마.테이블` 경로가 조회 대상을 정합니다. Oracle처럼 DB를 등록하거나 DB 이름, 호스트, 포트와 DSN을 따로 입력하지 않습니다.
- 저장된 인증정보가 있으면 처음 스킬을 사용해도 그대로 재사용합니다. 없거나 불완전할 때만 로컬 설정창을 엽니다. 기존 인증정보가 여러 개면 임의로 다른 계정을 선택하지 않습니다.
- 키가 없거나 인증이 거절되면 사용자 제공 My Key 발급 위치를 안내합니다. 인증값을 채팅으로 요청하지 않습니다. `.env` 가져오기는 명시한 현재 작업 폴더만 사용합니다.
- 새 테이블과 컬럼, 파티션이 아직 확인되지 않았을 때만 짧은 메타데이터를 탐색합니다. 기존 쿼리마다 같은 탐색을 반복하거나 0건 결과의 날짜를 임의로 바꾸지 않습니다.
- 기본 50,000행, 파일 용량과 본 조회 시간의 기본 제한 없음, 큰 조회의 실제 승인, 결과 파일 저장과 짧은 응답을 유지합니다. SDK가 결과를 DataFrame으로 메모리에 먼저 받는 한계는 안내합니다.

## Oracle 연결 실패 안내

실제 접속 호출이 실패하면 다음을 안내합니다.

> HyDAP(Chakra)실행 여부 및 MyAccess권한 확인 부탁드립니다

SQL 오류, 결과 수신 실패, 조회 시간 초과나 드라이버 미설치는 각각의 진단을 유지합니다. 같은 실패를 자동 반복하지 않습니다.

## 설치와 배포

개별 스킬은 `Individual-Skills-1.4.50.zip`에서 필요한 ZIP을 선택합니다. 하네스 없이도 사용할 수 있으며 해당 Python 패키지와 실제 접근 권한은 별도로 필요합니다. 사내 SDK는 사용자 제공 회사 Nexus 경로에서 준비하고 공개 PyPI의 동명 `lakes` 패키지를 대신 설치하지 않습니다.

기본 하네스의 업무 동작에는 새 후크, 추가 모델 호출이나 반복 질문을 넣지 않았습니다. 하네스 설치 EXE와 ZIP은 같은 릴리즈 버전으로 다시 만들며 기존 개인 자료 보존 절차를 유지합니다. 실제 사내 SDK 설치, 인증과 운영 조회는 이번 로컬 모의 검증으로 보증하지 않습니다.
