# 1.4.11 — 가벼운 스킬 선택과 PC별 진단 보완

## 설치하는 분께

[1.4.11 설치 ZIP](https://github.com/bongG-moon/claude_base_repo/releases/download/v1.4.11/company-agent-1.4.11-2026.09.03.zip)을 사용하세요. 소스나 Release가 갱신되어도 기존 PC는 자동으로 업데이트되지 않습니다.

1. `company-agent-1.4.11-2026.09.03.zip` 전체를 새 폴더에 압축 해제합니다.
2. `Install-CompanyAgent.cmd`를 더블클릭합니다.
3. 이전과 같은 **내 계정 전체 / 프로젝트** 범위를 선택합니다. 프로젝트면 이전과 같은 폴더를 선택합니다.
4. 이전 버전 → 1.4.11 안내에서 백업 후 업데이트를 선택합니다.
5. 완료 후 Claude Code를 닫고 다시 엽니다. 개인 기억·스킬·지식·모델·MCP 설정은 유지합니다.

설치 파일 뒤 `2026.09.03`은 회사 지식 묶음의 버전이며 생성 날짜가 아닙니다.
같은 버전인데 내용이 다르다는 오류를 피하기 위해 기존 1.4.10 파일은 덮어쓰지 않습니다.

## 바꾼 점

- 스킬 안내는 업무별 후보와 정확한 사용 경로를 짧게 전달합니다. 개인·외부 스킬과 겹치면 선택을 유지하며, 무조건 회사 스킬로 고정하지 않습니다.
- 변경 없는 스킬의 설명·해시는 로컬 캐시를 재사용합니다. 파일 추가·삭제·수정, 활성 상태와 우선 설정은 계속 확인합니다. 본문은 캐시에 넣지 않습니다.
- 캐시의 유효 시간은 최대 5분입니다. 파일 속성 변경은 다음 검사에서 감지하며, 캐시가 손상되거나 저장되지 않아도 원래 파일을 읽습니다. 실제 사용 시 본문 검증은 별도로 유지합니다.
- `Diagnose-CompanyAgent.cmd`는 프로젝트 설치 기록과 공유 실행 설정도 확인해 Python을 찾습니다. 진단의 개인 저장 위치 선택은 실제 실행부와 같은 규칙을 사용합니다.
- 스킬 안내 생성과 실제 본문 읽기를 구분해 한국어로 표시합니다. 이전 요청의 성공을 현재 요청의 성공으로 표시하지 않습니다.
- 더블클릭 설치의 시작·결과·주요 오류를 한국어로 안내합니다. 취소·유지·추가 입력 대기는 설치 성공과 구분합니다. 제3자 Claude 자체의 안내까지 번역하는 것은 아닙니다.
- 진단과 업무 점검에 Office·Python 추가 준비물 확인을 통합했습니다. 준비 여부 확인은 앱 실행·계정 연결 성공을 의미하지 않으며 자동 다운로드하지 않습니다.

## 성능과 데이터 보존

추가 모델 호출, 전체 스킬 본문 주입, 스킬 미선택에 따른 실행 차단을 추가하지 않았습니다.
재생성 가능한 메타데이터만 개인 상태의 `cache/skill-metadata-v1.json`에 저장하며 원본 Memory·Knowledge·Skill은 변경하지 않습니다.
진단은 원문 대화·문서·인증정보를 출력하거나 설정을 수정하지 않습니다.

## 회사 PC에서 확인할 것

`@테스트자료.pptx 내용을 읽고 MD로 정리해줘`처럼 스킬 이름 없이 요청하고, 실제로 문서 읽기 스킬을 불러오는지 확인합니다.
놓치면 진단 파일을 실행해 해당 작업 폴더를 입력하고 문제 세션의 시각을 확인하세요.
“안내 생성 완료”만으로 Claude 수신·사내 모델의 사용 성공을 단정하지 않습니다.

지원 전제는 Windows 로컬 PC, 이미 설치된 지원 버전의 Claude Code와 Python 3.11 이상입니다.
회사 보안 정책·Office·DRM·사내 모델·MCP에 따른 실제 업무 성공은 그 환경에서 확인해야 합니다.
네트워크 공유 폴더, 타인 계정, 지원하지 않는 상태 형식 등을 임의로 우회하지 않습니다.
이번 보완은 자동 선택의 신뢰성과 점검 가능성을 개선한 것이며 모든 사내 모델에서 자동 선택을 보장하는 것은 아닙니다.

## 개발 PC에서 확인한 범위

- 전체 Python 검사 727개 통과, 제외 없음. 실제 Claude 등록 검사 포함.
- 이후 진단 경로와 안내 위치 표기 보완에 대한 관련 20개 검사 재통과.
- Windows PowerShell 5.1: 진단 실행 파일 선택 12개, CP949·한글 경로 42개, 사용자 확인 63개, Claude 탐색 17개 통과.
- 격리 환경에서 실제 1.4.10 ZIP → 1.4.11 업데이트, 사용자/프로젝트 범위, 기존 개인 자료·규칙·Hook·스킬 우선 설정 보존 확인.
- 업데이트된 실제 Claude의 SessionStart, 올바른 개인 저장 위치와 메타데이터 캐시 생성 확인. 실제 사용자 설치는 변경하지 않음.
- 스킬 안내·본문 전달 8개 확인은 정해진 로컬 응답을 사용하며, 사내 HCP 모델의 자율 선택 검증은 아님.
- 안내 문자 수 36.5% 감소. 기본 12개 스킬 목록은 캐시 재사용 시 본문 파일 읽기 12회 → 0회, 후보 수 유지. 전체 업무 시간이나 실제 모델 토큰 수 측정은 아님.

별도 사내 Office·DRM·메일함·DB에 연결한 통합 검사는 이 결과에 포함하지 않았습니다.
