# 1.4.23 변경·설치 안내

## 달라진 점

- 기본 `office-reader` 스킬과 `business office-read` 명령, Office 전용 승인·세션 연결·읽기 실행 코드를 제거했습니다. 설치된 실제 스킬·도구로 문서를 읽으며, 필요한 Office 읽기 절차는 운영 환경에서 별도 개인 스킬로 구성합니다. 하네스가 문서 읽기 기능을 대신 제공한다고 가정하지 않습니다.
- 공통·개인 스킬의 관련 후보 확인과 겹침 선택을 보강했습니다. 명시한 스킬, 다른 이름의 경쟁 후보, 실제 본문 로드 근거를 구분하며 없는 스킬을 실행하도록 만들지 않습니다. 관련 스킬이 없으면 일반 실행합니다.
- 개인 학습에서 나눠 읽은 본문의 전체 확인과 버전을 추적하고, 같은 선호·점검 항목의 A → B → A 교정과 이전 값 재활성화를 보완했습니다. 같은 업무의 반복 요청을 독립 학습 근거로 늘리지 않습니다.
- 회사 공통·개인 전체·현재 프로젝트의 저장 위치, 기본 스킬 11개와 호환 이름 1개, 후크 7개, 자동 학습의 조건·제어·한계를 통합 HTML과 Markdown에 정리했습니다. 백업과 PC 간 이사의 차이도 설명합니다.
- Workspace 0.8은 제거된 Office 읽기 결과 전용 연결을 정리하고 준비물 없는 가상 자료·보고서 제작 실습과 안내서를 갱신했습니다. HTML/PPT 제작·파일 정리·Outlook 등의 기존 기능과 회사 보호 정책은 유지합니다.

안내서 전체를 매 요청의 모델 입력에 추가하지 않습니다. 새 외부 모델 서비스나 상시 학습 프로세스도 추가하지 않습니다. 다만 업무 회고와 교정 해석에는 기존 모델의 처리 시간과 토큰이 필요합니다. 새 스킬 생성은 요청·동의를 받은 별도 제작 흐름이며, 모델 자체를 훈련하는 기능이 아닙니다.

## 설치·업데이트

1. `company-agent-1.4.23-2026.09.03.zip`을 새 폴더에 풉니다. 뒤의 날짜는 회사 지식팩 버전입니다. 기존 회사 승인 Python 3.11 이상을 사용하며 Python을 자동 설치하지 않습니다.
2. `Install-CompanyAgent.cmd`를 실행하고 기존과 같은 User/Project 범위에서 백업 후 업데이트합니다. 개인 기억·지식·스킬·모델·별도 MCP 설정은 보존합니다.
3. Claude Code를 종료하고 다시 연 뒤 새 대화에서 시험합니다. Release 게시만으로 이미 설치된 PC가 바뀌지는 않습니다.
4. Workspace 사용자는 별도 `company-workspace-preview-0.8-*.zip`을 새 폴더에 풀어 사용합니다. 기존 앱을 먼저 종료합니다.

사용자가 별도로 만든 Office 관련 개인 스킬·원본 문서는 삭제하지 않습니다. 이전 Release와 설치 ZIP도 보존합니다. 별도 CUA 시험 문서·Driver·MCP는 이 배포에 포함하지 않습니다.

## 업데이트 후 확인

- `/company-agent:skills`에서 공통·개인 스킬을 확인합니다. 내장 Office Reader는 목록에서 빠져야 하며 개인 스킬은 유지돼야 합니다.
- 민감 자료 없이 HTML 보고서 제작을 요청하여 관련 스킬을 적용하는지 확인합니다. 같은 역할의 후보가 겹치면 선택을 받고, 관련 스킬이 없는 요청에는 없는 스킬을 요구하지 않아야 합니다.
- `/company-agent:learning`으로 관찰·적용 상태를 확인합니다. 자동 학습 일시 중지는 기존 기억이나 스킬 삭제가 아닙니다.
- 통합 가이드의 저장 범위와 시작하기 실습을 확인합니다. 설치 ZIP과 플러그인 안에는 Markdown 안내서도 포함됩니다.

## 알려진 제한과 검증 범위

- 자유로운 자연어 선택 답변을 전부 이해하거나 임의 이름의 유사 스킬 전체를 항상 정확히 분류한다고 보장하지 않습니다. 특히 번호를 문장으로 답하는 경우와 Workspace 답변 기록 연결에는 앞선 감사의 보완 과제가 남아 있습니다.
- 개인 전체 설치의 프로젝트별 지식 인덱스가 공통 지식 변경 후 모두 즉시 재조정된다는 보장은 없습니다. 공통 지식을 바꿔 배포할 때는 프로젝트별 적용 결과도 확인합니다.
- 한 미완료 업무에서 같은 개인 스킬의 서로 다른 학습 항목을 연이어 교정하면 앞 후보가 대체될 수 있습니다. 여러 항목이 모두 학습됐다고 보고하지 않습니다.
- 사내 HCP의 실제 지침 준수·체감 속도·회사 보안 환경 호환성은 운영 PC에서 별도 확인해야 합니다. 자동 회귀 시험 시간은 업무 응답시간이나 토큰 절감률이 아닙니다.

검증 수치와 배포 파일 해시는 [1.4.23 배포 검증](https://github.com/bongG-moon/claude_base_repo/blob/main/docs/VALIDATION_RELEASE_1.4.23.md)에 기록합니다. 이전 감사의 모든 제한이 이번 버전에서 해결됐다는 뜻은 아닙니다.
