# 1.4.20 변경·설치 안내

## 달라진 점

- Office 문서 읽기에 필요한 대화 정보가 포함된 실행 명령을 제공합니다. 세션 정보를 환경변수에서 찾다가 `NOT SET`을 문서 접근 거부로 오인하는 경우도 짧게 보완합니다. 세션 정보는 로그인이나 DRM 권한이 아니라 해당 대화의 문서·범위 승인을 연결하는 내부 정보입니다.
- 누락된 실행 정보는 현재 후크의 정보로만 보완합니다. 다른 대화의 세션을 찾거나 임의 ID를 만들지 않습니다. 빈 작업자 ID와 실제 ID의 정규화를 바로잡고, 정상적으로 따옴표 처리한 괄호·대괄호 파일명을 지원합니다.
- 짧고 범위가 제한된 읽기·요약은 현재 대화에서 진행하며 불필요한 작업자 호출을 줄입니다. 명시적 위임, 작성·분석·고위험 작업과 프로젝트 조율은 기존 기준을 유지합니다.
- 버전 조회와 내부 검증 기록을 실제 파일 변경으로 잘못 세는 경우를 수정했습니다. 완료·학습 정보가 없으면 그 내부 기록만 보류하고 이미 확인된 업무 결과를 실패로 바꾸지 않습니다. 실제 변경의 미완료 검증 의무는 보존합니다.
- Office 읽기 스킬의 일반 절차를 짧은 본문으로 통합하고 상세 참고 문서는 필요할 때만 읽습니다. 일반 읽기의 필수 지침은 기존 12,767자에서 4,098자로 약 68% 줄었습니다. 이는 문자 수 비교이며 토큰·실행시간 실측치가 아닙니다.
- 통합 HTML·사용 안내 Markdown을 수정된 절차에 맞췄습니다. Workspace 0.7 묶음은 안내서만 갱신하며 실행 코드는 변경하지 않습니다.

실제 문서·범위 승인은 그대로 필요합니다. 승인 전 Office를 열거나, 승인 거절을 우회하거나, 세션 오류 때문에 ZIP·다른 파서로 전환하는 기능은 추가하지 않았습니다. 존재하지 않는 스킬을 강제 호출하지 않습니다.

## 설치·업데이트

1. `company-agent-1.4.20-2026.09.03.zip`을 새 폴더에 풉니다. 마지막 날짜는 회사 지식팩 버전이며 기존 Python 3.11 이상을 사용합니다.
2. `Install-CompanyAgent.cmd`에서 기존과 같은 User/Project 범위를 선택해 백업 후 업데이트합니다. 개인 기억·지식·스킬·로그인·모델·별도 MCP 설정을 유지합니다.
3. Claude Code와 Workspace를 종료한 후 다시 실행하고 **새 대화**에서 시험합니다. 기존 설치본은 Release 게시만으로 자동 갱신되지 않습니다.
4. Workspace의 갱신된 안내서도 필요하면 이번 Release의 `company-workspace-preview-0.7-*.zip`을 별도 폴더에 풉니다.

## 업데이트 후 짧은 확인

민감하지 않은 시험 Excel로 `이 파일 첫 시트 A1:F50 내용을 읽고 정리해줘`를 요청합니다. 스킬 이름은 미리 알려주지 않습니다.

- Office 스킬을 적용한 뒤 환경변수·세션 폴더·도움말 탐색 없이 범위 승인 질문으로 이어지는지 확인합니다.
- 취소하면 문서를 열지 않고, 승인하면 같은 파일·범위의 결과를 읽는지 확인합니다.
- `NOT SET`만으로 DRM 또는 문서 접근 실패라고 판단하면 해당 단계의 도구명·오류 코드만 담당자에게 전달합니다. 문서 본문이나 인증 정보는 공유하지 않습니다.

자세한 검사 결과와 측정 한계는 Git 저장소의 [실행 효율 개선 기록](https://github.com/bongG-moon/claude_base_repo/blob/main/docs/VALIDATION_EFFICIENCY_2026-09-21.md)과 [배포 검증 기록](https://github.com/bongG-moon/claude_base_repo/blob/main/docs/VALIDATION_RELEASE_1.4.20.md)을 참고하세요. 실제 사내 HCP의 지침 준수·전체 속도, DRM Office와 보안 제품 호환성은 회사 PC에서 별도로 확인해야 합니다.

기존 Release는 보존하며 Cua 시험용 독립 문서·Driver·MCP는 하네스와 설치 ZIP에 포함하지 않습니다.
