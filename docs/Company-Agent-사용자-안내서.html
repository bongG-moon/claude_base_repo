01

시작하기

Company Harness는 Claude Code가 내 선호와 업무 맥락을 다음 대화에서도 필요한 만큼 참고하도록 돕습니다. 기억, 업무 지식, 반복 절차를 개인 공간에 남깁니다. 모델 자체를 학습시키는 기능은 아닙니다.

1. 기존 Claude 환경에 추가하기

하네스 설치 파일을 실행하고 개인 전체 또는 선택한 업무 폴더 범위를 고릅니다. 기존 모델, 로그인과 연결 도구 설정은 유지합니다. 설치 후 Claude Code를 새로 연결합니다. Workspace 앱은 같은 Claude Code를 쓰는 별도 화면이며 하네스와 다른 설치물입니다.

1.5.1의 사용하지 않는 이전 설치 파일 삭제 (백업 없음) 옵션은 선택 사항이며 기본은 꺼져 있습니다. 선택하면 설치 성공 후 확인된 미사용 설치본과 Claude 플러그인 캐시만 정리합니다. 개인 기억과 지식, 학습 기록, 스킬, 백업, 작업 파일과 설정은 유지합니다. 정리용 새 백업은 만들지 않으며 기존 설치 전 안전 백업은 그대로입니다. 사용 중이거나 원본 확인이 어려운 파일은 보류하므로 직접 지울 필요는 없습니다.

요청 예문선택 후 Ctrl+C로 복사
내가 어떤 일을 하고 어떤 방식의 답변을 선호하는지 현재 저장된 내용만 알려줘.
새 기억을 만들거나 다른 프로젝트 자료를 합치지는 마.

처음에는 저장된 내용이 없을 수 있습니다. 하네스가 모르는 사실을 아는 것처럼 답하지 않는지 확인합니다.

2. 내 방식 하나 알려주기

요청 예문선택 후 Ctrl+C로 복사
앞으로 업무를 설명할 때 결론을 먼저 짧게 알려주고, 확인한 사실과 아직 확인하지 못한 부분을 구분해줘. 이 선호를 기억해줘.

처음 영구 저장할 범위가 아직 정해지지 않았다면 개인 전체 또는 이 프로젝트 중 한 번 선택합니다. 저장된 내용과 범위를 확인하세요. 이번 답변만 짧게 해달라는 말은 장기 선호가 아닙니다.

3. 새 대화에서 다시 사용하기

같은 업무 폴더에서 새 대화를 열고 다음처럼 요청합니다.

요청 예문선택 후 Ctrl+C로 복사
가상 업무 세 가지를 진행 중이야. 교육 준비는 완료, 신청자 확인은 진행 중, 결과 정리는 아직 시작 전이야. 내 설명 선호에 맞춰 정리해줘.

답변이 마음에 들지 않으면 구체적인 부분만 고칩니다. 저장됐다는 사실과 실제 답변에 적용됐다는 사실은 별개입니다.

4. 반복할 절차를 스킬로 남기기

요청 예문선택 후 Ctrl+C로 복사
방금 진행한 업무 정리 순서를 다음에도 쓸 수 있게 내 스킬로 만들어줘. 입력할 자료, 처리 순서, 확인할 항목만 간단히 남겨줘.

이미 같은 목적의 개인 스킬이 있으면 같은 원본을 수정합니다. 새 스킬은 실제 사용 이름과 위치를 알려주며 Claude의 /스킬이름으로 사용할 수 있습니다. 목록에 바로 보이지 않으면 현재 버전의 새로고침 또는 새 연결에서 확인합니다.

5. 무엇을 배웠는지 확인하기

요청 예문선택 후 Ctrl+C로 복사
지금까지 저장된 내 기억과 학습 결과를 보여줘. 실제 적용된 것과 아직 근거가 부족해 보류된 것을 구분해줘.

또는 /company-agent:learning을 입력합니다. 학습이 일어나지 않은 작업도 정상입니다. 조회, 인사나 한 번의 선택을 억지로 학습하지 않습니다. 원하면 자동 학습을 중지하거나 특정 변경을 되돌릴 수 있습니다.

6. 필요한 업무 기능만 더하기

HTML 보고서, PPT, Excel 구조화, 파일 정리, 웹 제작과 데이터 조회는 개별 스킬입니다. 하네스 설치에는 포함되지 않습니다. Individual Skills 안내에서 필요한 항목만 설치합니다. 하네스 없이 개별 스킬만 사용해도 됩니다.

요청 예문선택 후 Ctrl+C로 복사
현재 설치된 스킬 중 이 업무에 사용할 수 있는 것을 찾아줘. 없으면 현재 도구로 가능한 범위를 알려줘.

기본 하네스는 비전 모델 전환, 브라우저 연결, 업무 도구 설치를 자동으로 하지 않습니다.

02

Claude Code 기본 사용법

Claude Code가 처음인 분을 위한 설명입니다. 명령어를 외우기 전에 어느 폴더에서, 어떤 자료로, 무엇을 만들지 정하면 됩니다. 작은 실습은 시작하기, 키와 명령은 명령어·단축키에서 확인하세요.

1. Claude Code와 Company Agent는 무엇이 다른가요?

Claude Code는 요청을 이해하고 파일 읽기·수정·명령 실행 같은 도구를 사용할 수 있는 프로그램입니다. 대화만 하는 것과 달리 실제 파일이나 외부 시스템에 영향을 줄 수 있습니다. 실행할 수 있는 범위는 연결된 도구와 권한에 따라 달라집니다. 공식 소개

구분 하는 일
AI 모델 요청을 해석하고 답이나 작업 계획을 만듭니다. 사내에서는 승인된 모델을 사용합니다.
Claude Code 모델과 대화하면서 파일·명령·도구를 연결합니다.
Company Agent 개인 기억, 업무 맥락, 학습과 설치된 스킬의 재사용을 돕습니다. 업무 기능은 개별 스킬로 선택합니다. 별도의 AI 계정을 만드는 기능은 아닙니다.
Workspace 기존 Claude Code를 사용하는 별도 입력·파일 선택·확인 화면입니다. 원본 CLI의 모든 메뉴와 단축키가 같은 것은 아닙니다.

이미 회사 환경에서 Claude Code가 된다면 개인 API 키·모델·로그인을 새로 설정하지 않습니다. 연결 문제를 해결하려고 기존 설정 전체를 초기화하지 마세요.

2. 작업 폴더부터 확인하세요

작업 폴더는 이번 업무의 출발점입니다. 처음에는 빈 연습 폴더를 사용하고 회사 문서·메일·공용 폴더는 넣지 않습니다. CLI·VS Code·Workspace 중 회사에서 허용한 화면으로 그 폴더를 선택하세요.

폴더를 선택했다고 PC의 다른 경로에 접근할 수 없게 되는 것은 아닙니다. 요청에 대상과 제외 범위를 적고, 승인 화면의 실제 경로를 확인합니다.

요청 예문선택 후 Ctrl+C로 복사
지금 선택한 연습 폴더가 어디인지 알려줘.
바로 아래 파일 이름만 확인하고, 다른 폴더나 파일 본문은 읽지 마.
파일·설정·기억을 만들거나 변경하지 마.

파일을 지정할 때는 CLI의 @ 목록이나 사용 중인 화면의 파일 선택을 이용합니다. 파일을 첨부한 것과 전체 내용을 실제로 읽은 것은 다릅니다. 페이지·시트·읽은 범위를 결과에서 확인하세요.

3. 요청하고 확인하는 기본 순서

  1. 요청: 목적, 자료, 결과 형식, 하지 말아야 할 일을 적습니다.
  2. 선택: 디자인·저장 위치처럼 필요한 질문에 답합니다.
  3. 확인: 파일 읽기·변경·발송 안내가 나오면 대상과 범위를 봅니다.
  4. 실행: 같은 요청을 다시 보내지 말고 결과나 추가 질문을 기다립니다.
  5. 검증: 실제 결과 파일과 숫자를 열어 확인하고 미확인 부분을 구분합니다.

설명·계획만 원하면 실제 변경을 하지 말라고 적으세요. 실제 작업을 원하면 확인한 계획의 어느 범위를 실행할지 말합니다.

요청 예문선택 후 Ctrl+C로 복사
가상 실적 3개월치를 설명할 보고서를 만들고 싶어.
먼저 필요한 자료와 진행 계획만 알려줘.
아직 파일 생성, 프로그램 설치, 설정 변경은 하지 말고 내 답변을 기다려줘.

Company Agent는 관련 스킬이 있으면 설명서 본문을 읽어 적용하고, 없으면 허용된 일반 방식으로 진행합니다. 스킬이 둘 이상 같은 역할을 한다면 기존 우선 선택이나 내 답변을 따릅니다. “스킬 사용”이라는 말뿐 아니라 실제 본문 로드와 업무 결과를 따로 확인합니다.

4. 승인·중단·되돌리기는 다릅니다

상황 먼저 확인할 것
자료 전달 어떤 파일의 어느 범위인지, 본문이 AI 대화에 전달되는지
변경·실행 승인 원본 보존 여부, 저장 위치, 외부 연결이나 설치 여부
메일·업로드 초안·미리보기인지 실제 발송·전송인지
중단 멈추기 전에 이미 생성·변경·전송된 것이 있는지
되돌리기 실제 복구 가능한 대상과 복구되지 않는 외부 작업이 무엇인지

Claude Code의 실행 승인과 Company Agent의 업무 범위 확인은 별도 절차일 수 있습니다. 하나를 승인했다고 모든 후속 작업을 허용한 것은 아닙니다. 자주 묻는다는 이유로 회사 정책이나 승인 절차를 끄지 않습니다.

Esc로 응답을 멈추거나 /rewind를 열어도 모든 작업이 취소되는 것은 아닙니다. 특히 이미 보낸 메일, 외부 변경, 일부 명령 실행은 별도로 확인해야 합니다. 공식 되돌리기 안내

Workspace의 작업 중지도 이미 수행한 일을 되돌리지 않습니다. 앱이 시작한 CLI의 종료 확인을 기다리며, 종료를 확인하지 못하면 중지 성공으로 표시하지 않습니다. 직접 시작한 CLI가 끝나도 모든 하위 프로그램의 종료를 보장하지는 않습니다. 같은 요청을 다시 보내기 전에 실제 결과와 남은 작업을 확인하세요.

5. 대화·프로젝트 지침·기억을 구분하세요

종류 언제 쓰나요? 주의할 점
현재 대화 이번 작업의 자료와 수정 요청을 이어갈 때 긴 대화는 필요한 내용 중심으로 정리합니다.
프로젝트 CLAUDE.md 해당 프로젝트의 목적·실행법·완료 기준을 알려줄 때 회사 공통 정책 전체나 원본 문서를 복사하는 곳이 아닙니다.

Company Agent 개인 기억 다음 업무에도 쓸 선호·맥락을 저장할 때 개인 전체 / 이 프로젝트 중 범위와 내용을 확인합니다.

/compact는 대화 요약, /clear는 새 대화, /resume는 이전 대화 이어가기입니다. 영구 기억 저장이나 파일 복구를 대신하지 않습니다. 공식 대화 관리

Company Agent의 기본 프로젝트 안내 생성과 개인 자동 학습도 서로 다릅니다. 자동 학습이 회사 규정이나 프로젝트 CLAUDE.md를 마음대로 고치는 것은 아닙니다. 저장·적용 범위의 비교는 하네스 이해하기를 참고하세요.

6. 사용량을 줄이고 완료를 확인하세요

  • 필요한 파일과 읽을 범위만 지정합니다. 같은 안내서나 전체 대화를 매번 붙이지 않습니다.
  • 이미 고른 디자인·분량은 유지해 달라고 말합니다. 대기 중에 같은 결과 생성을 다시 요청하지 않습니다.

personal-root 예전 방식으로 저장한 개인 자산. 자동 이전하지 않음
Claude 개인 skills 또는 프로젝트 .claude/skills 새로 만드는 개인 스킬의 실제 원본

정확한 파일 위치는 조회 결과에서 확인합니다. 경로만 보고 저장 성공을 판단하지 않고 실제 저장 응답과 내용을 확인합니다. 회사 공용 원본과 사용자 개인 원본이 같은 파일이 되지 않도록 유지합니다.

3. 기본 스킬의 역할

스킬 역할
company-agent 현재 요청, 기억과 설치된 스킬 사용을 조율
personal-memory 개인 선호와 업무 맥락 저장 및 조회
personal-knowledge 업무 정의와 출처 저장 및 조회
self-learning 근거가 있는 교정과 반복 선택, 개인 절차 개선 기록

기본 하네스의 asset-factory는 개인 스킬 저장에 집중합니다. 개별 배포의 같은 이름 스킬은 실행 도구와 MCP 제작까지 지원하는 별도 기능입니다. 둘 다 설치돼 목적이 겹치면 실제 기능과 출처를 비교하고 선택합니다.

4. 자동 처리는 무엇을 하나요?

시점 필요한 처리
새 연결 현재 설치 범위와 실행 정보 준비
새 요청 관련 기억과 지식, 설치된 스킬 목록을 제한적으로 제공
도구 실행 전후 현재 선택과 실제 실행 상태를 연결하고 변경 근거 기록
업무 종료 실제 결과와 미완료 상태를 구분하고 필요한 학습 근거를 유지

기본 하네스는 HTML/PPT 제작기를 강제하지 않고 이미지 읽기를 별도 VLM으로 가로채지 않습니다. 일반 조회를 위해 학습 질문이나 추가 모델 호출을 만들지 않습니다. 도구 실행 가능 여부는 Claude와 기존 회사 권한을 따릅니다.

5. 경험이 학습으로 바뀌는 순서

사용자의 교정 또는 실제 작업 근거 → 작은 학습 후보 → 기존 항목과 중복 및 적용 범위 확인 → 적용 또는 보류 → 다음 업무에서 필요한 기억 조회 순서입니다.

“아직 독립된 업무의 반복 근거가 부족함”, “이미 반영된 내용”, “되돌린 내용의 재적용 방지”처럼 판단 이유를 기존 조회에서 설명합니다. 후보와 적용 완료는 다르고, 기억이 모델에 전달된 것과 실제 효과도 다릅니다. 판단 근거가 없는 작업을 억지로 학습하지 않습니다.

새 절차 전체를 자동으로 생성하는 기능은 아닙니다. 기존 등록 개인 스킬의 작은 점검 항목만 정해진 범위에서 수정하며 새 스킬은 사용자 요청이나 제안 수락 후 만듭니다. 회사 배포본과 정책, 권한 설정은 자동 학습으로 바꾸지 않습니다.

6. 기존 환경을 유지하는 업데이트

새 하네스를 설치해도 개인 기억과 지식, 스킬, 기존 모델과 MCP 설정은 보존합니다. 회사 기능 스킬은 새 기본 설치에 포함하지 않으며, 예전 회사 스킬을 가리키는 선택이 있으면 없는 후보를 자동 대체하지 않습니다. 필요한 기능은 개별 ZIP으로 선택합니다.

기존 대화에는 이전 지시가 남을 수 있으므로 설치 후 Claude를 새로 연결하고 새 대화에서 확인합니다. 이전 버전 캐시나 개인 자료를 수동으로 지워야 하는 절차는 아닙니다.

1.5.1의 설치 화면에서 사용하지 않는 이전 설치 파일 삭제 (백업 없음) 옵션을 선택하면 설치 성공 후 검증된 미사용 설치본과 Claude 플러그인 캐시를 정리합니다. 기본은 꺼져 있으며 개인 기억과 지식, 학습 기록, 스킬, 백업, 작업 파일과 설정은 삭제 대상이 아닙니다.

Claude가 실행 중이거나 다른 설치 범위에서 쓰는 버전, 원본 검증이 안 되거나 수정된 파일은 정리를 보류합니다. 일부만 정리돼도 설치 성공은 유지하고 남은 이유를 안내합니다. 정리용 새 백업은 만들지 않지만 기존 설치 전 개인 자료 안전 백업은 유지합니다.

Claude Code 명령어·단축키

원본 Claude Code CLI 기준입니다. Workspace·VS Code의 메뉴와 키는 다를 수 있습니다. 현재 설치에서 /를 입력해 보이는 항목을 먼저 확인하세요. 없는 명령을 억지로 실행하거나 명령 하나 때문에 재설치하지 않습니다. 아래 기능은 별도 표시가 없으면 Claude Code 기능이며 Company Agent가 새로 만든 명령이 아닙니다.

처음에는 @로 파일 선택, Ctrl+J로 줄바꿈, Esc로 중단, /help로 도움말만 익혀도 됩니다. 전체 사용 흐름은 Claude Code 기본 사용법을 먼저 읽으세요.

입력 위치를 구분하세요. /help는 Claude 대화 입력칸, claude --continue는 운영체제 터미널에 입력합니다. 설치 명령이나 터미널 명령을 자연어 질문처럼 보내지 마세요. 사용량 값이 없거나 사내 가격과 연결되지 않으면 실제 청구액을 추측하지 않습니다.

기본 하네스 명령은 /company-agent:skills, /company-agent:learning, /company-agent:usability-report입니다. 각각 설치된 스킬 선택, 자동 학습 관리, 요청형 사용성 점검에 씁니다. 업무 제작기와 비전 모델 설정 명령은 기본 설치에 포함되지 않습니다.

사용 중 느림이나 반복 질문을 점검하려면 /company-agent:usability-report를 입력합니다. 현재 폴더의 최근 7일 기록에서 주요 후보 최대 3개를 HTML로 정리하며, 기록이 부족한 부분도 알려줍니다. 요청할 때만 실행하며 자동 압축이나 설정 변경은 하지 않습니다.

3. 작업 중 다음 질문과 제안 문장

실행 중 보낸 메시지는 대기하다가 도구 실행 경계 등에 전달될 수 있습니다. ‘지금 작업을 보완’하는지 ‘다음 업무’인지 명확히 적으세요. 반드시 완료 후 시작해야 한다면 결과를 받은 다음 보냅니다. Tab은 다음 업무를 예약하는 키가 아닙니다.

요청 예문선택 후 Ctrl+C로 복사
현재 요청 보충: 원본을 보존하고 실제 확인한 범위만 알려줘.

입력칸에 제안 문장이 보이는 것과 메시지를 전송하는 것은 다릅니다. 제안은 CLI·조직 설정에 따라 없을 수 있고, Company Agent가 자동으로 후속 질문을 보내지는 않습니다. 공식 실행 중 메시지·제안 안내

4. 압축·기억·프로젝트 지침은 다른 일

큰 작업이 끝났다고 매번 압축할 필요는 없습니다. 먼저 결과 파일과 남은 일을 확인합니다. 대화가 길어졌을 때 원본 CLI에서 아래처럼 중요한 조건을 남길 수 있습니다.

요청 예문선택 후 Ctrl+C로 복사
/compact 현재 목표, 원본 보존 조건, 최종 파일 경로, 검증한 범위와 미확인 사항을 남겨줘

압축에도 처리가 필요하며 비용 절감률을 보장하지 않습니다. 회사 모델의 자동 압축 지원은 운영 환경에서 확인합니다. 이 하네스는 매 작업 후 강제 /compact를 실행하지 않습니다. 공식 대화 관리

이미지 작업 후 압축이 잦다면 같은 이미지·긴 출력이 반복되는지 /context에서 먼저 확인합니다. 최초 검토 범위는 유지하고 수정 후 변경·영향 부분만 다시 봅니다. 압축 후에는 유효한 현재 작업의 로컬 스킬 선택만 이어가고 필요한 본문은 다시 불러옵니다. 압축을 막거나 조직의 모델·자동 압축 설정을 임의로 바꾸지는 않습니다.

Claude의 CLAUDE.md와 자동 기억은 대화 요약과 다릅니다. Company Agent 개인 기억도 별도입니다. 기본 CLAUDE.md 자동 생성은 짧은 시작 안내이며 /init의 코드 분석을 대신하지 않습니다. 자동 학습 역시 프로젝트 지침을 몰래 고치는 기능이 아닙니다. 공식 기억 안내

5. 되돌리기·여러 세션·종료

원본 CLI의 /rewind는 되돌릴 대상을 확인하는 메뉴입니다. 모든 외부 작업·명령 실행·메일 발송을 취소하는 기능은 아닙니다. 중단 후에는 실제 파일과 실행 기록을 먼저 확인하세요. 공식 되돌리기 한계

서로 독립적인 업무만 별도 폴더·대화로 나눕니다. 같은 파일을 동시에 수정하면 충돌할 수 있습니다. 하나의 회사 계정 사용량이 세션별로 독립되는 것도 아닙니다. 폴더 간 이동과 새 대화는 기억·권한 범위를 다시 확인할 기회입니다.

터미널에서 다시 시작할 때 claude는 새 실행, claude --continue는 최근 대화 이어가기 용도로 사용할 수 있습니다. 인증은 기존 회사 안내를 따릅니다. 이 명령들은 대화 입력칸의 슬래시 명령과 다릅니다. 공식 CLI 실행 옵션

Workspace는 전원 버튼으로 종료하세요. 창의 X만 닫으면 프로그램이 계속 실행될 수 있습니다.
