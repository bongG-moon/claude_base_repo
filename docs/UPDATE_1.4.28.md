# 1.4.28 변경·설치 안내

## 달라진 점

- HTML·PPT의 기존 디자인 지침에 목적에 맞는 배치, 읽기 순서와 여백, 실제 자료에 필요한 표·차트만 사용하는 원칙을 통합했습니다. 사용자 양식·글꼴 선택이 우선이며 요청형 설명 다이어그램은 별도 요청에서만 사용합니다.
- 한국어 문장 작성 원칙을 공통 하네스, 기존 작업자와 HTML·PPT·메일 초안에 통합했습니다. 번역투·과장·반복은 줄이되 수치·날짜·인용·부정·조건·추정·의무 강도와 회사 고정 문구를 보존합니다. 승인본을 임의로 다듬지 않습니다.
- 새 스킬·후크·모델 호출·추가 승인·중간 결과물은 만들지 않습니다. 공통 안내 증가는 319자이며 기존 문맥 예산과 스킬 선택·승인 흐름을 유지합니다. 문체 지침은 AI 작성 여부 판별이나 사람 작성 보증이 아닙니다.
- 단독 사용자 안내서와 설치용 Markdown을 같은 내용으로 갱신했습니다. 외부 원칙의 선별 적용 출처와 Apache-2.0/MIT 고지를 포함합니다. 외부 스킬 설치·스크립트·추가 에이전트 파이프라인은 도입하지 않습니다.
- [LLM Wiki 검토](LLM_WIKI_FUTURE_REVIEW.md)는 소스의 추후 검토 문서입니다. 직원용 설치 ZIP에는 넣지 않으며 Obsidian 설치·자동 수집·위키 생성·기억 이전 기능을 추가하지 않았습니다.

## 설치·업데이트

1. `company-agent-1.4.28-2026.09.03.zip`을 새 폴더에 풉니다. 뒤의 날짜는 회사 지식팩 버전입니다.
2. 기존 설치와 같은 범위에서 백업 후 업데이트하고 Claude Code를 다시 시작합니다. 개인 기억·스킬·지식·모델·별도 MCP 설정을 보존합니다.
3. Workspace 실행 코드는 0.9를 유지하며 새 안내서와 버전 링크를 넣은 별도 묶음을 제공합니다. 기존 창을 닫은 뒤 새 폴더에서 실행하세요.

기존 태그와 설치 ZIP을 덮어쓰지 않습니다. 승인된 Python 3.11 이상과 Claude Code가 필요하며 외부 실행 파일은 내려받거나 동봉하지 않습니다. 이미 설치된 PC는 자동 갱신되지 않습니다.

## 확인 범위

지침 전달·문맥 예산·기존 산출물 계약과 설치/업데이트를 검증합니다. 실제 사내 HCP의 문장 품질·응답 속도·토큰 효과, 회사 PC의 WS-33·비전 모델·게이트웨이 문제를 검증하거나 해결했다고 주장하지 않습니다.

최종 검사 결과와 배포 파일 해시는 [1.4.28 배포 검증](VALIDATION_RELEASE_1.4.28.md)에 기록합니다. 이전 버전 기록은 보존합니다.
