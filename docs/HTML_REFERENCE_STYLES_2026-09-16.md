# 참고 이미지 기반 HTML 디자인 개선

## 적용 기준

사용자가 2026-09-16 전달한 두 묶음의 참고 이미지를 기준으로 HTML 스킬·생성기·미리보기를 수정했습니다. 이전 무채색 글래스모피즘 기본값보다 이번 이미지의 하늘색·라벤더·반투명 흰색 표면을 우선합니다. 원본 사진 파일은 수정하거나 배포 자산에 복사하지 않았습니다.

기존 번호 1~8은 유지하고 9번 3D·이머시브, 10번 레트로·Y2K를 추가했습니다. 색상뿐 아니라 표면 그림자·글꼴 위계·강조 카드·표지 장식에 차이를 둡니다. 3D·Y2K·에디토리얼의 추상 조형은 CSS 장식이며 업무 데이터나 실제 제품, WebGL 모델을 뜻하지 않습니다. 참고 화면의 전체 앱 UI를 그대로 복제하는 기능은 아닙니다.

## 선택 흐름

첫 질문은 기존처럼 깔끔한 업무형 / 지표 중심형 / 추가 디자인 / HTML 양식 직접 첨부입니다. 추가 디자인을 고르면 전체 10가지 번호 목록을 한 번에 표시하고 응답을 끝내 사용자 입력을 기다립니다. 질문 도구의 4개 옵션 제한 때문에 번호 묶음이나 다음 페이지를 선택시키지 않습니다.

다음 메시지에 `4번` 또는 `글래스모피즘`을 받으면 이미 정해진 분량·보기 방식을 유지한 채 다음 단계로 진행합니다. `html-choices`는 추가 디자인 단계의 정수·숫자 문자열·`4번` 형식도 지원합니다. 초기 메뉴의 4번(HTML 양식 첨부)을 글래스모피즘으로 바꾸지 않습니다. 묶음 문자열은 스타일로 인정하지 않습니다.

미리보기에서는 전체 카드가 펼쳐지고 원하는 카드를 바로 선택합니다. 모바일에서는 미리보기를 카드 폭에 맞춰 축소하고, 그래프 밑부분이 잘리지 않게 높이도 조절합니다. 클릭만으로 Claude에 자동 전달되는 것은 아니며, 선택 문장을 복사해서 붙여 넣거나 채팅에서 직접 이름을 입력합니다.
