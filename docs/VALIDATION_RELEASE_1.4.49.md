# Company Harness 1.4.49 검증 기록

검증일: 2026-11-02. 기준: 공개 v1.4.48 → 이번 v1.4.49 원본과 배포 ZIP. Outlook 제거와 재검증 보고서에서 남은 개선만 반영했습니다. 별도 Workspace 앱과 플랫폼 작업은 이번 커밋에 포함하지 않습니다.

## 변경과 확인 범위

| 항목 | 반영 내용과 확인 |
|---|---|
| Outlook 제거 | 기본 스킬, 개별 ZIP, 로컬 메일 읽기 코드와 CLI를 제거했습니다. 기존 개인 Outlook 스킬과 MCP 설정을 보존하는 회귀 및 실제 업데이트 시험을 통과했습니다. |
| HTML 반복 보고서 | 분석, 집계, HTML 생성, 게시를 이어가는 실행 예제와 고정 진입 파일을 제공합니다. JSON 오류, 렌더 실패, 마지막 교체 실패, 외부 변경, 깊은 JSON, 동시 실행에서 마지막 정상본과 job/data/evidence 보존 및 복구를 확인했습니다. |
| 업무 흐름 | “위 결과” 대사 후 업무 스킬 저장까지 원래 대상과 순서를 유지합니다. 참조 제외, 실제 주제 변경, 모호한 참조는 구분합니다. 요청한 순서를 실행 성공으로 추정하지 않습니다. |
| PPT 차트 | 음수 막대 색, 축 바깥 범주명, 8개와 12개 범주 표시, 선 차트 마커 및 값 위치를 확인했습니다. 실제 개별 ZIP으로 3장 생성, 편집 가능한 내장 차트와 값, 개인 프로필 미변경을 확인했습니다. |
| 숫자 설명 | 작성자가 명시한 기준명과 계산값을 함께 사용하는 statement와 기존 응답의 factHandoff를 제공합니다. 자동 요약은 최대 12개 완전한 항목, 직렬화 JSON 4,000자 이내입니다. 초과한 개수는 표시하며 전체 계산과 바인딩은 그대로 유지합니다. 임의의 설명 문장 의미까지 검증하는 기능은 아닙니다. |
| 모바일 표와 기억 | ID, 날짜와 기간은 짧은 값에서 한 줄을 유지하고 긴 설명은 줄바꿈합니다. 정렬과 CSV 값 보존을 검사했습니다. 기억 저장 완료 문구는 사용자가 요청한 길이를 지키도록 간결화했습니다. |
| 사용 부담 | 새 상시 후크, 추가 일반 요청 모델 호출, 반복 승인 질문, 자동 압축을 넣지 않았습니다. 긴 조건부 자산 생성 참조는 필요한 때 읽는 파일로 분리했습니다. |

## 자동 검사

관련 42개 테스트 묶음에서 **790개 중 786개 통과, 4개 건너뜀**, 실패 0개입니다. 동일 테스트 재실행은 마지막 결과만 집계했습니다.

- 건너뜀: Windows 심볼릭 링크 권한 2개, 격리 Python의 python-pptx 미설치 2개. 일반 Python에서 개별 ZIP을 풀고 초안 → 합성 승인 → PPT 생성을 별도 실행했습니다. 사내 사용자 승인을 대신한 시험은 아닙니다.
- 업무 분석 169개(1개 건너뜀), HTML 재생성 14개, 표 12개, PPT 및 공통 수치 관련 검사, 기억과 스킬 라우팅, Outlook 제거, 설치 코드 검사를 포함합니다.
- Excel 누적 기간 재실행과 수식 합계 회귀 32개를 통과했습니다. 이미 해결된 Excel 계산 및 PPT 승인 로직을 다시 작성하지 않았습니다.
- 개별 패키지 생성 후 `build-skill-packages.py --check` 통과: **스킬 15개와 외부 Oracle MCP 1개**, 총 16개 ZIP. Outlook ZIP은 없습니다.
- Excel, 업무 분석, 조회 스킬 동기화 검사 및 통합 HTML 안내서 최신성 검사 통과. 안내서는 453,384바이트입니다. 안내서 크기 검사는 이전 버전도 초과하던 450,000바이트 대신 512KiB 한도로 정리했고, 글꼴의 별도 150KB 제한은 유지했습니다.

## 설치와 실제 실행

Windows PowerShell 5.1로 배포 ZIP을 만들고 290개 구성 파일의 해시와 원본 일치를 확인했습니다. 설치 EXE 내장 무결성 검사와 `--verify-only`가 통과했습니다. 사내 GitLab용 전달 묶음은 생성했으며 사내 서버에 업로드하지 않았습니다.

실제 v1.4.48 ZIP으로 설치한 격리 프로필에 v1.4.49 ZIP을 업데이트했습니다. Claude 등록, SessionStart, Read 후크 등록, 개인 자료와 모델 설정, MCP 설정, 개인 스킬과 긴 경로 백업이 보존됐습니다. 개인 Outlook 스킬 파일도 보존됐고 새 회사 기본 Outlook 구성은 없습니다. 실제 사용자 프로필은 변경하지 않았습니다. 설치 ZIP 오류 처리 회귀도 통과했습니다.

Python으로 만든 차트 3장을 설치된 PowerPoint 16.0에서 열어 렌더했습니다. 음수 막대, 범주명 표시와 선 차트 숫자 위치를 확인했습니다. COM으로 새 차트를 만드는 별도 경로는 변경한 스타일 적용 전 기존 AddChart2 호출에서 `office_chart_unavailable` / HRESULT -2147467259로 실패해 끝까지 검증하지 못했습니다.

## 확인하지 않은 부분

- 실제 사내 모델의 자동 Skill 선택률, 응답 지침 준수율, 응답 시간과 토큰 사용량은 이번 로컬 회귀 검사의 판정 대상이 아닙니다.
- 모바일 390px 실브라우저 화면 검증은 연결된 브라우저가 없어 수행하지 못했습니다. 의미별 열 표식, CSS, 정렬과 CSV는 코드 시험으로 확인했습니다.
- 반복 보고서의 고정 진입 파일은 일반 브라우저에서 여는 용도입니다. 스크립트와 이동을 제한하는 앱의 정적 미리보기에서는 기본 앱으로 열기를 사용합니다. 기존 실제 report 경로도 반환합니다.
- 기존 외부 Oracle MCP 원본 ZIP은 변경하지 않았습니다. 이전 배포에서 시간 초과였던 설치/통신 시험을 이번 통과 수에 포함하지 않았습니다. 운영 DB, DRM, 전체 Office 호환성도 검증한 것으로 표시하지 않습니다.
