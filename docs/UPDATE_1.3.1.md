# Company Agent 1.3.1 업데이트

1.3.0 수정본을 같은 버전 번호로 다시 배포하여 설치가 거부되던 문제를
1.3.1 패키지로 정정했습니다. 사용자 계정·Python·Claude 버전 문제가 아닙니다.
같은 버전의 서로 다른 내용을 막는 설치 보호 검사는 그대로 유지합니다.

## 설치 방법

1. Claude Code를 닫습니다.
2. `company-agent-1.3.1-2026.09.03.zip`을 **새 폴더**에 풉니다.
3. 새 폴더의 `Install-CompanyAgent.cmd`를 실행합니다.
4. 기존과 같은 설치 범위를 선택합니다.
5. **Company Agent: 1.3.0 → 1.3.1**인지 확인하고 백업 후 업데이트합니다.
6. Claude Code를 다시 열고 `/company-agent:skills`로 목록을 확인합니다.

다시 1.3.0 → 1.3.0이라고 나오면 이전 압축 해제 폴더의 설치 파일을 실행한
것입니다. 새 1.3.1 폴더에서 실행하세요. 기존 설치 폴더나 release.json,
개인 Memory·Skill·Knowledge, Claude 설정을 삭제해서 해결하지 마세요.

개인 자료·학습 이력·기존 모델·MCP 연결은 보존 대상이며 업데이트 전에
백업합니다. GitHub 게시와 실제 회사 운영환경 검증은 별도입니다.

## 포함된 수정

- 프로젝트 범위 Skill 목록·중복·검색 조회를 변경 작업으로 잘못 분류하지 않습니다.
- 조회 후 불필요한 Stop 검증 대신 한국어 목록을 최종 결과로 유지합니다.
- Skill 개수는 실제 조회한 목록에서 계산합니다.
- 이전 독립 업무 사용 시험의 학습·작업자 실행 경로·승인 대기 보완을 포함합니다.

## 배포 담당자 주의

`CoreVersion`은 설치되는 전체 payload의 불변 식별자입니다. 코드·기본 Skill·
포함된 회사 지식 등 payload가 달라지면 새 CoreVersion으로 배포해야 합니다.
`-Force`로 같은 이름의 ZIP을 다시 만드는 것은 설치된 코어를 덮어쓸 수 있다는
뜻이 아닙니다. 새 패키지를 배포할 때는 구버전에서 실제 업데이트와 개인 자료
보존을 함께 검증하세요.
