## 미수행/한계

- 현재 PC 설치 등록은 여전히 1.3.3 User이며 직접 업데이트하지 않았다. GitHub에 게시하지 않았다.
- 이전 브라우저 자동화에서 로컬 파일 정책이 거부된 뒤 해당 제한을 우회하지 않았다.
  새 디자인의 실제 화면/인쇄 육안 검수와 사내 모델의 Skill 선택 행동은 미검증이다.
- facts/checks는 선언한 입력과 연산만 검증한다. 자유문장에 직접 쓴 숫자, 원자료의 진위,
  미확인 원인의 추론까지 자동 판단하지 않는다. 이 한계를 validation과 Skill에 명시했다.
- 외부 디자인 Skill 설치/임의 코드 실행/승인 무시는 추가하지 않았다. 필요한 기존
  Skill을 catalog에서 찾아 현재 우선순위에 맞게 활용하는 지침을 보강했다.
