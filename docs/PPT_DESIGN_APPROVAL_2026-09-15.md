# PPT 디자인 선택·대표 미리보기·승인 대기 개선

## 사용자에게 보이는 순서

1. 제작 방식: 새 디자인 / 기존 PPT·회사 양식 첨부 / 저장한 내 양식. 이미 말한 항목은 다시 묻지 않습니다.
2. 첨부 방식은 실제 파일을 받은 뒤 분위기 참고 / 기존 배치 유지 중 선택합니다. 필요한 목적·대상·총 장수만 추가로 묻습니다.
3. 새 디자인은 깔끔한 업무 보고형 / 흑백 간결형 / 따뜻한 설명형 중 선택합니다. 참고 PPT 첨부 방식으로 변경할 수도 있습니다. 이 후보는 실제 적용되는 색상 조합이며 서로 다른 복잡한 배치 엔진이라는 뜻은 아닙니다.
4. 전체 구성과 첫 1~2장의 실제 대표 PPT를 준비합니다. 이미지 출력이 가능하면 실제 슬라이드 미리보기를 보여주고, 불가능하면 대표 PPT를 직접 확인하도록 링크와 제한을 안내합니다. 글로 색상을 설명한 것만으로 미리보기를 보여줬다고 하지 않습니다.
5. 이대로 제작 / 수정 요청 / 참고 PPT로 변경을 묻고 기다립니다. 승인 전에는 전체 슬라이드를 만들거나 전체 제작 담당자를 실행하지 않습니다.
6. 승인한 명세로 전체 파일을 만들고 실제 확인한 범위와 결과 파일을 전달합니다.

## 코드에서 바뀐 점

- `ppt-choices`는 새 디자인을 선택한 것만으로 ready가 되지 않습니다. design → design_preview → design_confirm → ready 단계가 추가됐습니다.
- `ppt-design-preview`는 전체 명세의 수치 연결을 먼저 계산한 뒤 첫 1~2장만 생성합니다. 별도 새 파일로 저장하므로 기존 파일은 덮어쓰지 않습니다.
- 대표안 결과에 `designReview`가 포함됩니다. 전체 명세·참고 PPT·로컬 이미지·대표 PPT가 달라지면 이전 확인 정보를 재사용할 수 없습니다. 사용자에게 해시나 내부 명령을 입력하도록 요구하지 않습니다.
- 이 기록은 작업 흐름의 일관성 확인용이며 인증된 사용자 동의의 증명서는 아닙니다. 실제 채팅에서 승인받았을 때만 confirmed를 true로 기록하도록 스킬이 지시합니다. 외부 게시나 발송을 허가하지 않습니다.
- 기존 Python 내부 API의 선택적 검사 모드는 호환성을 유지합니다. 직원용 최종 CLI는 승인 정보 검사 경로를 사용하며, 미리보기 CLI는 대표안만 생성합니다.
- `<stateRoot>/tmp/ppt-choices-*.json`의 제한된 선택 필드는 내부 준비로 분류합니다. 전체 job·슬라이드·결과 파일이나 다른 경로의 파일은 이 예외에 해당하지 않습니다. 이전에 남은 실제 변경의 검증 의무도 지우지 않습니다.
- 대표안도 실제 산출물이므로 내용 확인은 필요합니다. 대표안 확인을 마친 뒤 승인 질문을 하되 전체 업무를 끝났다고 기록하거나 학습을 마감하지 않습니다.

## 검증 범위

`test_ppt_design_approval.py`는 디자인 단계, 미승인 최종 생성 차단, 2장 대표안 → 5장 최종 파일, 명세/대표안 변경 검출, 표·차트 편집 가능성과 수치 연결, 임시 선택 파일 예외를 검사합니다. `test_skill_workflow_native.py`는 Windows 실행 진입점에서 새 디자인 질문을 반환하고 Stop 오류 없이 기다리는지를 검사합니다.

구조 검사는 가상 자료를 사용합니다. 실제 Office 이미지 출력은 환경에 따라 사용할 수 있으며, 출력이 거절된 경우에도 생성된 대표 PPT를 보존하고 이미지 검토를 수행했다고 주장하지 않습니다. 사내 모델의 실제 선택 도구 사용과 운영 PC의 렌더링은 별도 채팅 확인이 필요합니다.

이번 변경은 소스에 반영했습니다. 기존 설치본과 1.4.4 설치 ZIP은 변경하지 않았으며 새 버전 패키징 후 적용해야 합니다.

## 실행 결과

- 전체 자동 검사 655개 통과, 제외 0개(232.182초).
- 이후 이미지 내용 변경 감지·구성 제목 계산값 반영·미리보기 준비 상태 구분을 보완한 최종 코드에서 PPT 승인 검사 8개, 기존 PPT 검사 13개, Windows 실행 진입점 검사 5개를 다시 실행해 모두 통과했습니다.
- 가상 5장 명세로 승인 전 2장 대표 PPT만 생성되는 것과 승인 후 5장 생성, 원자료의 누적 실적 530, 편집 가능한 표·차트 값을 확인했습니다.
- 미리보기 이미지 출력 거절 상황은 테스트에서 명시적으로 재현했습니다. 이 경우 partial이며 실제 이미지를 봤다고 표시하지 않습니다. 운영 PC의 실제 PowerPoint 렌더링/모델 채팅은 이번 자동 검사에 포함하지 않았습니다.
- 스킬 형식 검사, Claude 플러그인 엄격 검사, 변경 파일 공백 검사 통과. 개인 설정·회사 원본 파일·기존 설치 ZIP은 변경하지 않았습니다.
