# Company Agent 1.4.6 설치·업데이트 안내

## 이번 변경

흰색 글래스모피즘이 불투명한 카드처럼 보이는 문제를 보완했습니다. 무채색 배경의 곡선과 명암이 유리판 뒤로 비치며, 얇은 흰색 반사광으로 경계를 표현합니다. 보라색·파란색 등 여러 색을 다시 넣지 않았습니다.

- 본문 유리판의 흰색 농도 약 44% → 18%, 내부 카드 약 33% → 14%.
- 표지의 흰색 농도 약 67~27% → 34~10%, 배경 흐림 22px → 14px.
- 미리보기와 실제 보고서에 같은 스타일을 적용합니다. 글자 자체를 투명하게 만들지 않습니다.
- 인쇄 화면은 흰색으로 유지합니다. 투명 효과를 지원하지 않거나 접근성 설정에서 줄인 경우 읽기 쉬운 불투명 화면을 유지합니다.

1.4.4~1.4.5에서 로컬 설치본에 반영한 개선도 함께 포함합니다.

- HTML 양식 직접 첨부, 추가 디자인 → 세부 선택 → 분량·보기 방식 순서.
- PPT 새 디자인 선택 또는 기존 양식 참고, 실제 대표 슬라이드 확인 후 전체 제작. 제작 중인 작업을 완료 실패로 취급하지 않도록 대기 처리 개선.
- 선택용 임시 기록과 실제 산출물 구분, 스킬 목록 준비 안내가 업무 도구를 반복 차단하는 문제 보완.

## 설치 방법

1. Release의 **company-agent-1.4.6-2026.09.03.zip**을 다운로드합니다. GitHub의 자동 생성 `Source code (zip)`이 아닙니다.
2. 새 폴더에 모두 압축 해제한 뒤 **Install-CompanyAgent.cmd**를 더블클릭합니다.
3. 기존과 같은 설치 범위를 선택하고 백업 후 업데이트합니다.
4. Claude Code를 닫고 다시 실행합니다.

이미 설치된 Claude Code와 Python 3.11 이상을 사용하며, 실행 위치와 조건은 설치 과정에서 확인합니다. 개인 Memory·Skill·Knowledge·학습 이력과 모델·MCP 설정을 보존합니다. 이전 설치 ZIP이나 개인 자료를 삭제할 필요가 없습니다. 파일명 뒤 `2026.09.03`은 회사 지식팩 버전입니다.

**이미 생성된 HTML 파일은 설치만으로 바뀌지 않습니다.** 기존 파일을 보존하고 새 파일로 다시 생성해 주세요.

> 같은 자료를 새 글래스모피즘 디자인으로 다시 만들어줘. 흰색 투명 유리 느낌으로, 기존 HTML은 덮어쓰지 말고 새 파일로 저장해줘.

## 검증 방법과 범위

가상 보고서로 8가지 디자인의 화면 크기 1440·768·390px, 미리보기 일치, 페이지 전환, 인쇄 표시를 검사합니다. 유리판과 내부 카드의 흰색 농도 상한, 무채색 여부 및 배경 명암 차이도 검사하고 데스크톱·모바일 이미지를 직접 확인합니다. 외부 폰트·이미지·웹 연결은 필요하지 않습니다.

사내 모델의 실제 대화 및 운영 PC의 Office·DRM 렌더링은 이 디자인 검사의 범위 밖입니다. 자세한 PPT 사용 흐름은 `PPT_DESIGN_APPROVAL_2026-09-15.md`, 대기 처리 변경은 `REPORT_WAIT_AND_WHITE_GLASS_2026-09-15.md`를 참고하세요. 과거 문서의 22px 등 스타일 값은 당시 기록이며 현재 유리 디자인 값은 이 문서가 기준입니다.
