# Company Harness 1.4.45

엑셀 계산 구조를 설명하는 HTML과 업무 기록을 모아 보는 요청형 스킬을 추가했습니다.

- 엑셀 Python 프로젝트에 `업무흐름.html`을 함께 만듭니다. 표의 의미와 실제 표 ID, 선행 데이터·처리·결과의 연결을 보여줍니다.
- 데이터 열의 역할, 대표 수식과 입력·결과 범위, 함수가 하는 일을 쉬운 한국어로 설명합니다. 반복 행 수식은 묶고 다른 조건·고정 참조는 구분합니다.
- HTML에는 실제 행 값·계산값·문자 상수를 싣지 않습니다. Noto Sans KR를 내장해 오프라인에서 열 수 있습니다. 미지원·오류·표시 한도는 숨기지 않습니다.
- `company-agent:work-context-catalog`로 지정한 폴더의 스킬·기억·지식과 현재 사용자의 알려진 Claude·Codex 세션 저장소를 집계합니다. 현재 대화나 현재 프로젝트에만 한정하지 않습니다.
- 인사·빈 기록은 제외하고 실패·불명확한 업무는 남깁니다. 기본 보고서에는 질문 원문·도구 인수와 결과·생각 과정·이미지를 넣지 않으며, 확인 범위와 누락 이유를 표시합니다. 검토해 내보낸 목록끼리도 합칠 수 있습니다.
- 집계는 요청할 때만 실행합니다. PC 전체 검색·중앙 업로드·개인 평가·새 상시 후크·추가 모델 호출은 넣지 않았습니다. 엑셀 설명 HTML도 최초 프로젝트 생성 시만 만들고 일반 재실행에는 다시 만들지 않습니다.
- 사용자 안내서와 Markdown 설명, 설치 사본을 갱신하고 CLI 버전 표기를 맞췄습니다.

직원 설치 파일은 `Company-Harness-Setup.exe`, ZIP 대체 설치 파일은 `company-agent-1.4.45-2026.09.03.zip`입니다. 단독 안내서는 `Company-Agent-User-Guide.html`입니다. 각 파일의 SHA-256도 제공합니다.

기존 개인 스킬·기억·모델·MCP 설정은 유지합니다. 기존과 같은 범위로 설치한 뒤 Claude Code를 다시 열어 주세요. 이전 릴리즈는 보존하며 별도로 개발 중인 Workspace·비전 변경은 이번 배포에 포함하지 않습니다.

집계 분류는 기록에서 확인한 활동의 요약이지 전체 업무 절차 복원이나 성공률·직원 성과 판정이 아닙니다. 실제 직원 기록은 수집하지 않고 가상 기록으로 검증했습니다. 사내 DRM·원본 VBA 실행 동등성·운영 기록의 모든 형식과 규모는 별도 검증이 필요합니다. [검증 내용](VALIDATION_WORKFLOW_CATALOG_20261022.md)을 참고하세요.
