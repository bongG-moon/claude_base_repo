# 1.4.19 변경·설치 안내

## 달라진 점

- 스킬을 읽은 작업자와 부모 대화의 기록을 분리했습니다. 작업자만 읽은 지침을 부모도 읽었다고 처리하지 않습니다. 사용 가능한 스킬 우선, 없는 스킬 강제 실행 금지, 겹치는 역할의 사용자 선택은 유지합니다.
- 일부 셸·Git 변경의 완료 확인 누락을 보완했습니다. 실행하지 않은 권한 거절과 실제 변경을 구분하고 이전 미확인 변경은 보존합니다.
- 직접적인 강제 Git 변경·재귀 강제 삭제를 실행 전에 거절하는 보호를 보완했습니다. 기존 권한을 확대하지 않으며 모든 셸 문법을 통제하는 보안 샌드박스는 아닙니다.
- 개인 전체와 프로젝트 기억을 관련도 순으로 함께 검색합니다. 두 저장소는 계속 분리하며 회사 공통을 자동 수정하지 않습니다.
- 새 도구의 입력·출력 조건과 검증 기록을 더 엄격하게 확인합니다. 지원하지 않는 JSON 조건을 성공으로 처리하지 않으며 필요한 기존 도구는 재시험 후 활성화·연결합니다.
- HTML→PPT에서 원래 flex/grid 배치를 보존합니다. 숨김·변형 등 지원하지 않는 상태는 명시적으로 알립니다.
- Workspace 0.7은 자신이 실행한 CLI의 종료를 기다리고, 종료를 확인하지 못하면 성공으로 표시하지 않습니다.
- 시작하기·사용법·명령어·스킬 안내와 오프라인 Noto Sans KR HTML을 실제 구현에 맞췄습니다. 유명 스킬의 원칙은 필요한 부분만 선별 반영했으며 외부 플러그인을 통째로 설치하지 않습니다.

자세한 재현과 한계는 [하네스 감사 기록](AUDIT_HARNESS_2026-09-20.md), 이번 게시 전 검사 결과는 Git 저장소의 [배포 검증 기록](https://github.com/bongG-moon/claude_base_repo/blob/main/docs/VALIDATION_RELEASE_1.4.19.md)을 참고하세요. 배포 검증 기록은 설치 ZIP의 구성 파일이 아니라 별도 게시 기록입니다.

## 설치·업데이트

1. 직원 설치 파일 `company-agent-1.4.19-2026.09.03.zip`을 새 폴더에 풉니다. 마지막 날짜는 회사 지식팩 버전입니다. 기존 Python 3.11 이상을 사용합니다.
2. `Install-CompanyAgent.cmd`를 실행하고 기존과 같은 User/Project 범위를 선택해 백업 후 업데이트합니다.
3. Claude Code를 종료한 뒤 다시 실행합니다. 기존 로그인·모델·개인 기억·지식·스킬·별도 MCP 설정은 유지합니다.
4. Workspace를 사용하면 기존 앱을 종료하고 `company-workspace-preview-0.7-*.zip`을 별도 폴더에 풉니다. `Company-Workspace.vbs`로 실행합니다.

기존 Release·ZIP·사용자 설치본은 자동 갱신하거나 삭제하지 않습니다. 실제 사내 HCP·DRM Office·MCP 인증·보안 제품 호환성은 운영 환경에서 별도로 확인해야 합니다.

## Cua는 이번 하네스에 포함하지 않습니다

별도 요청으로 만든 Cua/HCP 시험 안내서는 로컬의 독립 문서로 유지하며 이번 소스 게시에서도 제외합니다. 하네스 스킬·후크·메뉴·설치 ZIP·Workspace ZIP에 통합하지 않습니다. Driver 설치, MCP 등록, 화면 조작 또는 사용자 설정 변경을 실행하지 않습니다.
