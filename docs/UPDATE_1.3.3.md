# Company Agent 1.3.3 설치 및 업데이트

## 설치 방법

1. `company-agent-1.3.3-2026.09.03.zip`을 **새 폴더**에 모두 압축 해제하세요.
2. 폴더 안의 `Install-CompanyAgent.cmd`를 더블클릭하세요.
3. 이전과 같은 설치 범위(내 Windows 계정 전체 / 선택한 프로젝트)를 고르세요.
4. 기존 Company Agent가 있으면 백업 후 **1.3.3으로 업데이트**를 선택하세요.
5. 설치 완료 후 Claude Code를 완전히 닫았다 다시 여세요.

기존 Python 3.11 이상과 Claude Code를 찾아 사용합니다. 필요한 경로를 확인하지
못하거나 후보 선택이 필요하면 입력을 요청합니다. 회사 모델을 다시 설정하거나
Python을 새로 다운로드하지 않습니다. 개인 Memory·Skill·Knowledge·학습 이력과
모델·MCP 설정, 업데이트 전에 추가한 개인 규칙·Hook은 유지합니다.

## 이번에 포함한 기능

처음 사용하는 작업 폴더에서 회사·개인·프로젝트·플러그인 스킬의 용도, 출처와
우선 설정을 정리한 `SKILL_CATALOG.md`를 만듭니다. 스킬 설치·삭제·수정 또는
활성화/우선 설정 변경은 다음 요청이나 재시작 때 반영합니다. 바뀐 내용이 없으면
다시 쓰지 않습니다. 목록은 개인 자료 저장소의 `skill-catalogs` 아래에 폴더별로
보관하며 프로젝트나 기존 CLAUDE.md를 덮어쓰지 않습니다.

평소처럼 업무를 요청하면 됩니다. 확인할 때는 “이 폴더의 자동 스킬 목록을 보여줘”라고
말하세요. Claude는 목록의 설명을 비교하고 필요한 스킬 본문만 읽도록 안내받습니다.
목록 갱신만으로 업무 검증·학습을 요구하지 않습니다. [자세한 설명](SKILL_CATALOG.md).

기존 1.3.2-r2의 PC별 Python 탐색과 Ouroboros 시작 오류 교정도 포함합니다.
Ouroboros의 알려진 연결을 바꾸는 경우에는 기존 파일을 별도로 백업합니다.
Python을 옮기거나 플러그인 캐시가 업데이트된 뒤에는 필요시 설치기를 다시 실행하세요.

## 버전과 주의사항

코어 내용이 바뀌었으므로 버전은 **1.3.3**입니다. 예전에 받은 1.3.2 ZIP이나 설치된
버전 폴더에 파일을 덮어 풀거나 내용 충돌 검사를 우회하지 마세요. ZIP 이름의 날짜는
회사 지식팩 버전이며 생성일이 아닙니다. 실제 사용 위치·실행 권한·회사 정책 때문에
확인하지 못한 항목은 자동 우회하지 않습니다.

목록을 만드는 기능은 로컬에서 작동하지만, 스킬 선택의 의미 판단은 기존 사내 모델이
수행합니다. 최적 선택이나 모든 외부 플러그인의 정상 동작을 보장하는 기능은 아닙니다.
이 설치 파일 생성은 GitHub Release 게시나 현재 PC에 자동 설치한 것을 뜻하지 않습니다.
