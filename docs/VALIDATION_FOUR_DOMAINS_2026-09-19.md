# 공통/개인 기억·하네스 구분 검증

2026-09-19 개발 소스 기준. Git 게시·설치 ZIP 재생성·사내 배포는 이 작업에 포함하지 않았습니다.

## 변경 범위

- 관리 화면을 공통 기억 / 내 기억 / 공통 하네스 / 내 하네스로 분리했습니다. 프로젝트는 별도 종류가 아닌 적용 범위입니다.
- 공통 지식과 개인 지식은 저장소를 먼저 분리하고 각각 페이지 조회합니다. 다른 영역의 항목 키·페이지 커서를 혼용하면 거절합니다. 기존 memory/knowledge/brief API는 유지합니다.
- 공통 기준·스킬·후크는 읽기 전용입니다. 내 하네스의 외부 플러그인·프로젝트 스킬은 출처만 안내하며 개인 소유로 자동 판정하지 않습니다. 개인 도구는 이름·유형·등록 상태만 표시합니다.
- 내 기억의 저장·수정·사용 중단·이력 복원과 내 하네스의 폴더 지침 저장은 기존 검토·확인·충돌 검사를 유지합니다. 기존 자료·모델·MCP·외부 플러그인 이동이나 자동 병합은 없습니다.
- ‘기억’이라는 단어만으로 personal-memory를 먼저 지정하던 요청 안내를 제거했습니다. 공통 지식 조회와 개인 선호 저장을 설명하고 실제 목록과 용도를 비교하게 합니다. 관련 스킬이 없으면 강제 호출하지 않습니다.
- 온보딩·핸드북·첫 업무 안내와 선택 시 읽는 스킬 설명에 같은 용어를 적용했습니다. 안내서 전체를 매 요청에 넣거나 별도 분류 모델을 호출하지 않습니다.

## 자동 검사

- Workspace 서비스·클라이언트·관리 화면 연결: 초기 31개 통과. 구버전 안내 검사를 추가한 후 해당 32개를 재검증했습니다.
- 문서 계약·실습·Workspace·Cua 준비 확인·회사 기준·개인 기억·학습 안내: 94개 실행, 93개 통과, Windows 심볼릭 링크 생성 권한이 없는 시험 1개 제외.
- 이후 추가된 공통 지식/다른 개인 저장소 비교와 구버전 안내를 포함하여 Native Runtime·실습·문서 계약·Workspace 75개 통과.
- 작업별 스킬 안내 14개 통과. 공통 기억 조회가 개인 저장 강제 안내로 바뀌지 않는지와 실제 목록에 지식 스킬 후보가 있는지 확인했습니다.
- 위 묶음은 일부 검사를 중복 실행했으므로 개수를 단순 합산하지 않습니다.
