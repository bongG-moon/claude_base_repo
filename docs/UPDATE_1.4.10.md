# Company Agent 1.4.10 설치·업데이트 안내

## 달라진 점

- 업무 시작 안내의 앞부분에 관련 스킬의 용도와 정확한 호출 방법을 제공합니다. 전체 스킬 본문을 매번 넣지는 않습니다.
- 스킬 선택 → 필요한 본문 읽기 → 작업자 위임 → 실행 순서로 통일했습니다. 작업자에게도 선택한 본문을 전달합니다.
- 개인/프로젝트 스킬과 겹치면 기존 우선 설정을 존중하고, 결정되지 않은 후보는 사용자에게 선택을 묻도록 안내합니다.
- HTML 디자인 선택만 요청한 단계에서는 불필요한 명령·파일 생성 없이 질문을 먼저 합니다.
- 스킬 안내를 만들었는지와 실제 본문을 읽었는지를 구분하는 로컬 진단 기록을 추가했습니다. 질문 원문·문서 내용은 이 진단에 저장하지 않습니다.
- 새로운 실행 차단이나 권한 자동 허용을 추가하지 않았습니다. 개인 기억·학습·지식·스킬·모델·MCP 설정은 유지합니다.

## 설치하기

1. Release의 **company-agent-1.4.10-2026.09.03.zip**을 받습니다. `Source code (zip)`이 아닙니다.
2. 새 폴더에 압축을 풀고 **Install-CompanyAgent.cmd**를 실행합니다.
3. 이전과 같은 범위(내 Windows 계정 전체 / 해당 프로젝트)를 선택합니다.
4. 백업 후 업데이트를 진행합니다. 완료되면 Claude Code를 닫았다 다시 엽니다.

Claude Code와 Python 3.11 이상이 설치되어 있어야 합니다. 파일명 뒤 `2026.09.03`은 회사 지식팩 버전이고 프로그램 버전은 **1.4.10**입니다. 이전 버전의 개인 저장 폴더나 Claude 설정을 지우지 마세요.

## 확인하기

새 세션에서 스킬 이름 없이 `@테스트자료.pptx 이 자료 내용을 읽고 파악해줘`라고 요청하세요. 문서 읽기 스킬과 등록된 읽기 명령을 사용하는지 확인합니다. `/skills`의 `locked by plugin` 표시는 사용 불가를 뜻하지 않습니다.

전체 자동 검사 696개(제외 없음)를 통과했습니다. 로컬 실제 모델에서 스킬 이름 없는 PPT 요청이 `office-reader` 호출로 연결되는 것을 확인했습니다. 이 검사는 제한된 실행 권한에서 읽기 명령 호출까지 확인했으며, 사내 HCP 모델·Office·DRM 문서 읽기 완료를 검증한 것은 아닙니다. 안내 개선이 모든 모델의 자동 선택을 보장하지는 않습니다.

자세한 검증 범위는 [스킬 자동 선택 검증 기록](SKILL_AUTO_SELECTION_FIX_2026-09-16.md), 일반 사용법은 [사용자 안내서](USER_GUIDE.md)를 참고하세요.
