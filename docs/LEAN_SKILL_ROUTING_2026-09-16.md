# 스킬 선택 경량화와 읽기 전용 진단

## 배포 상태

1.4.11 소스와 [직원용 설치 ZIP](https://github.com/bongG-moon/claude_base_repo/releases/tag/v1.4.11)에 포함합니다. 기존 PC에는 같은 범위로 업데이트해야 적용됩니다. 기존 1.4.10 설치 ZIP을 덮어쓰지 않습니다.

## 바꾼 점

- 매 요청의 첫 안내에 후보 ID·용도·호출 방법·정확한 본문 경로를 함께 제공합니다. 전체 목록은 재사용하지만 이번 후보의 경로를 이전 대화에서 찾을 필요는 없습니다.
- 후보 상세와 긴 선택 지침을 앞뒤에 두 번 보내던 중복을 줄였습니다. 후보 묶음이 크면 일부만 보여주어 임의로 선택하지 않고 전체 목록으로 안내합니다.
- 파일 종류와 읽기/제작 목적을 함께 비교하고 한국어 두 글자 일치만으로 후보를 올리지 않습니다. 회사 스킬 이름으로 고정 배정하지 않으며 개인·외부 스킬, 수동 전용 조건과 우선 설정을 유지합니다.
- 본문 로드 미관찰·응답 형식 차이·이름 중복·경로 불일치·부분 읽기 등을 구분합니다. 성공 증거가 없는 호출을 성공으로 만들지 않습니다. 일반 문서를 읽을 때는 스킬 목록 파일을 다시 열지 않습니다.
- 스킬 사용 기록은 최신 요청 기준입니다. 이전 요청의 성공을 새 요청의 성공으로 표시하지 않습니다.
- 추가 모델 호출, 본문 자동 주입, 새 실행 차단, 권한 자동 허용, Hook 제한 시간 변경은 없습니다.
- 변경 없는 SKILL.md의 메타데이터·해시는 최대 5분간 재사용하며 원문 본문은 캐시하지 않습니다. 추가·삭제·수정과 활성/우선 설정은 계속 확인합니다. 실제 본문 로드 검증은 유지합니다.
- 프로젝트에만 설치했거나 PATH 밖 Python을 사용하는 경우에도 설치 기록과 공유 실행 설정을 먼저 확인합니다. 진단의 상태 선택은 실행부와 동일한 함수를 사용합니다.

## 진단하기

압축파일 전체를 푼 뒤 맨 위의 **Diagnose-CompanyAgent.cmd**를 실행하고 문제가 발생한 작업 폴더 경로를 입력합니다. 소스 폴더에서도 같은 파일을 실행할 수 있습니다.

진단은 Python 3.11 이상을 사용하며 설정을 변경하거나 모델·문서·메일·DB를 호출하지 않습니다. 설치 기록과 최근 세션의 허용된 진단 필드만 읽습니다. 원문 대화·문서 내용·인증정보는 출력하지 않습니다. 파일 저장 없이 화면에 표시하므로 필요한 결과만 복사하세요.

최근 세션은 다른 작업의 기록일 수 있습니다. 시각과 세션 ID를 확인하세요. 특정 세션 지정이 필요하면 PowerShell에서 다음과 같이 실행합니다.

```powershell
powershell.exe -NoProfile -File .\deploy\Diagnose-CompanyAgent.ps1 -ProjectRoot "C:\업무폴더" -Session "세션-ID"
```

- **안내 생성 완료**: 하네스 내부 출력 준비 증거입니다. Claude 수신·모델 적용 성공을 뜻하지 않습니다.
- **기록 없음**: 이전 버전, 다른 저장 위치, 미실행 또는 기록 실패 가능성이 있습니다.
- **본문 일부만 읽음**: 전체 본문을 읽었다고 처리하지 않았습니다.
- **응답 형식 확인 필요**: 도구 이벤트는 관찰했으나 기대한 성공 형식을 확인하지 못했습니다.
- 진단은 현재 조직 정책·Claude 명령줄 설정을 완전히 재구성하지 않습니다. 시간 값은 Python 내부 처리 시간이며 전체 Hook 실행 시간과 다릅니다.

## 성능 비교

`python -X utf8 -B scripts/test-lab/benchmark-skill-routing.py`로 공개 v1.4.10과 오프라인 비교합니다. 파일 수·PC에 따라 수치가 달라집니다.

대표 PPT 읽기 요청, 같은 캐시 조건에서 추가 안내 7,791자 → 4,951자(36.5% 감소). 가상 스킬 1,000개, 7회 중앙값 기준 최종 비교에서 후보 검색 38.35ms → 20.80ms. 기본 12개 스킬 목록의 본문 파일 읽기는 캐시 미사용 12회 → 재사용 시 0회였고, 후보 수는 12개로 동일했습니다. 폴더·파일 속성·설정 확인은 계속합니다. **문자 수이지 모델 토큰 수가 아니며 전체 응답 시간도 아닙니다.** 실제 HCP 모델 토큰 수·선택 행동·운영 Hook 전달 성공은 별도 확인해야 합니다.

검증에는 개인 스킬 충돌, 명시 호출, 부분 읽기, 오래된 성공 기록, UTF-8/CP949, 진단 전후 파일 내용·수정 시각 보존과 실제 Claude CLI의 격리된 본문 전달 검사를 포함합니다. 정해진 로컬 모델 응답을 사용하는 전달 검사는 HCP 모델의 자율 선택 검증을 대신하지 않습니다.

최종 검사: 전체 Python 727개 통과(제외 없음, 실제 CLI 등록 테스트 포함). 이후 진단 경로 점검과 안내 위치 표기 보완 후 관련 20개 재검사 통과. 진단 Python 선택 12개, CP949·한글 경로 42개, Windows 사용자 확인 63개, Claude 탐색 17개 점검 통과. 실제 Claude CLI로 1.4.10 → 1.4.11 업데이트와 개인 상태·규칙·Hook·우선 선택 보존, 업데이트 후 SessionStart 및 메타데이터 캐시 준비를 격리 환경에서 확인했습니다. 정해진 로컬 응답을 사용한 전달 검사 8개와 오프라인 묶음 구성 검사도 통과했습니다. 검사는 격리 환경에서 수행했으며 실제 사용자의 설치는 변경하지 않았습니다.
