# 1.4.2 — Office 구조 읽기와 실행 지연 개선

## 설치 파일

[company-agent-1.4.2-2026.09.03.zip 받기](https://github.com/bongG-moon/claude_base_repo/releases/download/v1.4.2/company-agent-1.4.2-2026.09.03.zip)

GitHub의 `Source code (zip)` 대신 위 설치 ZIP을 사용하세요.

1. ZIP을 **새 폴더에 모두 압축 해제**합니다. 예전 설치 폴더 위에 섞어서 풀지 마세요.
2. Claude Code에서 진행 중인 작업을 마무리하고 종료합니다.
3. 압축을 푼 폴더의 **Install-CompanyAgent.cmd**를 더블클릭합니다.
4. 기존과 같은 사용 범위(Windows 계정 전체 또는 해당 프로젝트)를 선택합니다.
5. 기존 Company Agent를 발견하면 **백업 후 업데이트**를 선택합니다.
6. 설치 완료 후 Claude Code를 다시 실행합니다.

개인 Memory·학습 이력·Skill·Knowledge·기존 모델 설정·MCP 연결은 유지합니다.
1.4.1을 같은 버전으로 덮어쓰는 것이 아니라 새 코어 1.4.2로 업데이트합니다.
Python 3.11 이상과 Claude Code는 기존 설치를 사용하며 자동 다운로드하지 않습니다.
파일명 뒤의 `2026.09.03`은 회사 지식팩 버전이며 이번 프로그램 버전은 **1.4.2**입니다.

## 반영한 수정

- PPT의 표 행·열, 개체 좌표·크기, 그룹 내부 글자를 함께 읽습니다.
- Word의 표 ID·셀 행·열·문단 위치 및 제공 가능한 페이지 정보를 함께 읽습니다.
- Excel은 빈 칸을 생략해도 원래 행·열 좌표를 유지합니다.
- 파일 경로를 직접 전달하므로 일반 읽기에는 JSON 임시 파일과 사전 doctor가 필요 없습니다.
- 실행 명령을 찾느라 PC 전체를 탐색하는 일을 줄이고, 긴 안내 때문에 실행 경로 정보가 빠지는 문제를 보완했습니다.
- 모듈 실행이 출력 없이 끝나던 문제와 설정 입력 도우미의 UTF-8 출력을 수정했습니다.
- 슬라이드 수가 다르다는 사실만으로 DRM 차단을 단정하지 않습니다. 원본 비교용 해시·경로·실행 환경·소요 시간을 반환합니다.

## 업데이트 후 시험

> 이 PPT는 4장입니다. 지정한 원본만 읽어 표의 행·열과 배치를 반영해 요약해줘.
> 다른 사본으로 대체하지 말고, 읽힌 장수가 다르면 원인을 단정하지 말고 알려줘.

자세한 비교 방법은 [Office 읽기 재시험 안내](OFFICE_READ_TROUBLESHOOTING.md)를 확인하세요.

## 검증 범위와 한계

수정 코드의 Python 테스트 588개가 제외 없이 통과했습니다. 합성 문서를 실제
Office로 열어 PPT 4장·그룹·표와 Word 표를 읽었고 원본 SHA256이 유지됐습니다.
개발 PC의 하네스 읽기는 PPT 약 2.9초, Word 약 3.2초였습니다. 이 수치는 Claude의
생각·실행 승인 대기 시간을 포함하지 않으며 사내 DRM 환경의 성능 보장은 아닙니다.

Excel 실제 재시험은 개발 PC의 xlwings 미설치로 미실시이며 자동 테스트로 검증했습니다.
회사 Office/DRM 원본은 별도 운영 시험이 필요합니다. 그림 속 글자·SmartArt·차트
내부 데이터·완전한 병합 셀/디자인 해석은 지원하지 않습니다.

PDF 오류 진단은 저장소의 독립 시험 파일 `scripts/office_read_test.py`에 들어 있습니다.
이번 설치본에 PDF/Acrobat 읽기 Skill을 새로 추가한 것은 아닙니다. PDF가 실제로
열리도록 해결됐다고 보장하지 않으며 접근 거절 뒤 다른 방법으로 반복 추출하지 않습니다.
