# Company Harness 1.4.48

파일 정리, 업무 분석과 산출물 재생성의 사용성을 개선하고 하네스와 독립 스킬 배포본을 동기화했습니다. 기존 개인 스킬, 기억, 지식과 모델 및 MCP 설정을 보존하는 설치 방식을 유지합니다.

## 설치 파일

- `Company-Harness-Setup.exe`: 일반 사용자용 설치 프로그램입니다.
- `company-agent-1.4.48-2026.09.03.zip`: ZIP 전체를 압축 해제한 뒤 `Install-CompanyAgent.cmd`를 실행하는 대체 설치 파일입니다.
- `Individual-Skills-1.4.48.zip`: 하네스 없이 선택해서 설치하는 스킬 16개와 기존 별도 Oracle MCP 1개, 설치 안내서의 묶음입니다. 조회 스킬 4개를 포함하며 필요한 Python 패키지와 연결 환경은 각각 안내합니다.
- `Company-Agent-User-Guide.html`: 설치 후에도 읽을 수 있는 통합 사용자 안내서입니다.
- `Company-Harness-GitLab-Delivery-1.4.48.zip`: 담당자가 사내 GitLab에 올릴 설치 파일과 설명의 묶음입니다. 이 파일을 만든 것만으로 사내 게시가 이루어지지는 않습니다.

GitHub의 Code → Download ZIP과 Source code는 개발용 소스입니다. 직원 설치에는 위 설치 파일을 사용하세요. 설치 후 Claude Code를 다시 연결합니다.

## 변경 내용

- 파일 정리는 첫 파일을 이동하기 전에 전체 목적지 충돌을 확인합니다. 실행 중 오류가 나면 완료, 실패와 미시도를 구분하고 기존 원복 기능을 유지합니다.
- 업무 분석은 구체 업무명을 포함한 후속 스킬 또는 지식 저장 요청을 해당 업무 흐름과 연결합니다. 근거가 부족하면 별도 요청으로 남기고, 인사만 있는 기록과 미분류 집계를 정리합니다.
- HTML 반복 생성은 새 결과 묶음을 완성한 뒤 현재 결과를 전환하는 선택형 예제를 제공합니다. 실패했을 때 이전 정상본을 보존합니다.
- PPT 보정은 재생성 원본에 반영하도록 안내하고, 필요할 때만 텍스트, 표, 차트, 배치와 배경 차이를 비교하는 도우미를 제공합니다.
- 보고서 수치에 기간, 포함 및 제외 범위, 분모와 출처를 함께 보존할 수 있습니다. 원자료나 자유문장의 사실을 자동 보증하는 기능은 아닙니다.
- 선행 감사에서 확인한 Excel 기간값 재실행과 합계 일관성, PPT 초안 승인 및 해시 일치, 한국어 혼합 요청 및 부정 표현, 정식 스킬 호출 조건 보존을 함께 포함합니다.
- 이미지 전처리와 선택형 비전 모델 설정, 프로젝트의 플러그인 비활성화 반영, 요청할 때만 실행하는 사용성 개선 보고서도 포함합니다. 일반 대화 모델은 바꾸지 않습니다.
- Oracle, Datalake, E-Hub 조회와 더미 조회 스킬을 개별 배포합니다. 실제 운영 연결은 별도이며 더미 시험이 운영 DB 검증을 대신하지 않습니다.

사용성 개선을 위해 상시 후크, 일반 작업의 추가 모델 호출이나 반복 질문을 추가하지 않았습니다. 조건부 도우미는 해당 작업에서만 사용합니다. 별도 개발 중인 Workspace 앱 변경은 이번 배포에 포함하지 않습니다.

## 검증 범위

[개선 검증 기록](VALIDATION_SKILL_IMPROVEMENTS_20261031.md)과 [릴리즈 검증 기록](VALIDATION_RELEASE_1.4.48.md)을 함께 확인하세요. 기존 외부 Oracle MCP의 설치 및 통신 시험 1개는 시간 초과로 미검증 상태이며, 해당 MCP 원본 ZIP은 수정하지 않았습니다. 실제 사내 모델의 처리 속도와 토큰, 운영 DB와 Outlook, DRM 및 Office 전체 호환성은 별도 검증 대상입니다.

EXE는 코드 서명되지 않았으며 기존 조직의 실행 정책을 따릅니다. 개인 PC나 사내 플랫폼에 자동 설치하거나 게시하지 않습니다.
