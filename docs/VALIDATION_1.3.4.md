# 1.3.4 완료 확인 안내 검증 · 2026-09-13

## 범위

Stop의 내부 판단/보정 횟수와 사용자에게 보이는 설명을 분리했다.
`state.stop_decision`의 검증·학습 판단은 유지하고, 실제 Hook 출력 경계에서
긴 명령·개인 경로·세션 ID 대신 100자 이내의 짧은 안내를 반환한다.
`completionGuide`가 설치된 상세 절차를 가리키며, 작업 최종 전달 전 필요한 때에만 읽는다.

## 미수행/제약
