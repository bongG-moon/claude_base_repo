# 1.4.13 — 사용 가능한 스킬 목록을 실제 실행에 연결

## 설치·업데이트

[1.4.13 설치 ZIP](https://github.com/bongG-moon/claude_base_repo/releases/download/v1.4.13/company-agent-1.4.13-2026.09.03.zip)을 새 폴더에 모두 압축 해제한 뒤 `Install-CompanyAgent.cmd`를 실행하세요. 이전과 같은 내 계정/프로젝트 범위를 선택해 백업 후 업데이트하고 Claude Code를 닫고 다시 엽니다.

개인 Memory·Knowledge·Skill·선호, 모델·MCP와 기존 사용자 규칙·Hook을 유지합니다. 기존 1.4.12 ZIP은 덮어쓰지 않으며 이미 설치된 PC가 자동으로 바뀌지는 않습니다. 파일명 뒤 `2026.09.03`은 회사 지식팩 버전입니다. 설치에는 기존 Python 3.11 이상을 사용합니다.

## 바꾼 점

- 사용 가능한 실제 목록에서 관련 스킬을 찾아 정상 Skill/Read로 불러온 뒤 실행합니다. 존재하지 않는 호출명을 만들어 실행하지 않습니다.
- 짧은 후보 목록에 없더라도 전체 목록을 비교합니다. 관련 스킬이 없으면 일반 작업으로 진행하며 불필요한 선택 기록 명령을 요구하지 않습니다.
- 목록·본문 확인 없이 넘어간 첫 도구 실행에만 `[스킬 목록 확인 1회]`로 다음 행동을 알려 줍니다. 그 도구는 실행되지 않았으며 파일 권한·샌드박스 오류가 아닙니다. 읽기·검색·질문은 유지하고 같은 준비 사유로 반복 차단하지 않습니다.
- 실제 성공한 본문 읽기만 재사용 근거로 삼습니다. 안내 전달만으로 선택 완료를 기록하던 방식을 제거했고, 계속 무시한 상태도 성공으로 처리하지 않습니다.
- 중복 후보 선택·기존 선호와 회사 권한 정책을 유지합니다. 기본/원격 등 호스트가 제공하는 스킬의 실제 성공한 호출도 존중합니다.
- 기존 목록 캐시를 사용하며 별도 분류 모델을 추가하지 않습니다. 처음 사용하는 스킬만 로드하고 변경 없는 본문은 재사용합니다.

## 확인 범위

전체 회귀 검사 **767개**, 실제 Claude의 격리된 도구 연결 검사 **3개 시나리오**, 설치 인코딩 검사 **42개 항목**을 통과했습니다. 연결 검사는 로컬 모의 응답을 사용하며 사내 HCP 모델의 자율 판단 검증은 아닙니다. 상세 결과는 [검증 기록](https://github.com/bongG-moon/claude_base_repo/blob/v1.4.13/docs/SKILL_LIST_REVIEW_2026-09-17.md)을 참고하세요.

이전 공개 1.4.12 ZIP에서 1.4.13으로 실제 업데이트해 새 버전 등록, 일반 폴더의 시작 Hook 실행, 개인 자료·모델·MCP·기존 사용자 규칙 보존을 확인했습니다. 계정/프로젝트 설치·실패 복구 및 CP949 환경의 한글·이모지 경로 검사도 통과했습니다. 모두 격리된 임시 프로필에서 검사했으며 실제 사용자 설치나 설정은 바꾸지 않았습니다.

로컬 비교에서 첫 준비 안내 길이는 v1.4.12 대비 61.7% 줄었습니다. 이는 글자 수이며 전체 작업의 토큰·시간 감소율은 아닙니다. 실제 스킬 본문 로드와 모델 추론·Office 실행 시간은 별도입니다.

사내 HCP 모델의 자율 선택 및 실제 Office·DRM 연동은 운영 환경에서 재확인이 필요합니다. 설치 후 새 대화에서 `@테스트자료.pptx 내용을 읽어줘`라고 요청해 실제 Skill/Read와 문서 읽기 절차가 이어지는지 확인하세요. 1회 교정 이후에도 모델이 계속 무시하면 미확인으로 남으며 모든 모델의 지침 준수를 보장하지 않습니다.
