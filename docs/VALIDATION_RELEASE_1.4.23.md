# 1.4.23 배포 검증

검증일: 2026-09-21. 회사 지식팩은 `2026.09.03`을 유지하며 Workspace는 `0.8`입니다.
변경 내용과 알려진 제한은 [변경·설치 안내](UPDATE_1.4.23.md)에 정리했습니다.

첫 전체 실행에서는 Workspace 버전 갱신 중 실행기에 남은 이전 버전 번호로 재실행 시험 1개가 실패했습니다. 실행기 값을 맞춘 후 해당 통합 시험과 최종 전체 회귀 모두 통과했습니다. 기존 앱을 강제 종료하거나 버전 충돌 보호를 제거하지 않았습니다.

제외한 5개는 Windows 심볼릭 링크 권한 관련 3개와 별도 활성화가 필요한 실제 Claude 설정·등록 시험 2개입니다. 실제 플러그인 등록과 시작 후크는 별도 격리 업데이트 검사로 확인했습니다. 실제 업무 MCP 연결·호출까지 검증한 것은 아닙니다.

격리 설치 검사는 업무 모델이나 실제 회사 문서를 호출하지 않습니다. 안내서 검사도 이번 배포에서 사내 모델·Office·DRM 업무의 성공을 확인했다는 뜻은 아닙니다. 앞선 로컬 화면 검토와 이번 정적 동기화 검사를 구분하며, 이번 배포 단계에서 새 브라우저 화면 검사를 했다고 주장하지 않습니다.

각 파일의 `.sha256`도 함께 게시합니다. 순환 해시를 피하기 위해 이 검증 문서는 설치 ZIP 밖에 둡니다. 두 ZIP에는 새 `UPDATE_1.4.23.md`와 갱신된 안내서가 들어 있습니다.

기존 Release와 ZIP은 보존합니다. 별도 `standalone-guides/`는 소스 커밋과 모든 배포 파일에서 제외하고 로컬에 보존했습니다. 개발 PC의 시험 로그·인증 정보·개인 상태는 게시하지 않습니다. 패턴 검사는 임의의 기밀 문장을 판별하는 DLP 검사가 아닙니다.

개발 PC 검사 로그: `.smoke/release-1.4.23-build.log`, `.smoke/release-1.4.23-bundle-tests.log`, `.smoke/release-1.4.23-upgrade.log`, `.smoke/release-1.4.23-regression-final.log`.

## 실제 환경에서 남은 확인

- 사내 모델의 스킬 선택·본문 준수·질문 응답 연결과 체감 속도는 운영 PC에서 별도로 확인합니다. 개발 회귀 시험 시간은 업무 응답시간이나 토큰 절감률이 아닙니다.
- 내장 Office 읽기는 제거했습니다. 필요한 회사 문서 읽기 절차는 담당자가 승인한 실제 스킬·도구로 별도 구성합니다. 기존 사용자가 만든 개인 스킬은 삭제하지 않습니다.
- 프로젝트별 지식 재조정, 자유로운 자연어 선택 답변과 Workspace 답변 기록 연결, 한 업무의 같은 스킬 복수 학습 후보 보존에는 [변경 안내의 알려진 제한](UPDATE_1.4.23.md#알려진-제한과-검증-범위)이 남아 있습니다. 이번 배포를 모든 감사 항목 해결로 표시하지 않습니다.
- 기존 설치본은 자동 갱신되지 않습니다. 같은 범위로 업데이트하고 Claude Code·Workspace를 재시작한 뒤 새 대화에서 확인합니다. 회사 정책과 실제 접근 권한은 유지합니다.
