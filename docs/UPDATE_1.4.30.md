# 1.4.30 변경·설치 안내

## 달라진 점

- 재사용할 교정이 있을 때만 개인 학습을 한 번 제출합니다. 지속적인 명시적 교정, 독립된 업무의 반복 선택, 검증된 절차 개선이나 실제 다음 사용 평가가 대상이며, “이번만” 또는 뜻이 모호한 지시는 장기 저장하지 않습니다.
- 일반 학습은 `learning submit` 한 번으로 접수하며 엔진이 근거·중복·이력·보류를 처리합니다. 상태 조회 → 후보 저장 → 완료 표시 → 별도 검토를 모델이 매번 순서대로 수행할 필요가 없습니다. 현재 주입된 실행 명령·세션·요청 정보가 없으면 학습만 보류하고 설정·환경변수·다른 세션을 찾지 않습니다.
- 지속적인 명시적 선호는 업무 진행 중에도 기존 자동 학습 범위에 반영할 수 있습니다. 별도의 “기억에 저장해줘” 요청은 기존 저장 범위 선택을 따르지만, 일반 교정마다 같은 위치를 다시 묻지는 않습니다. 제출은 업무 전체를 완료로 선언하거나 미확인 변경을 지우는 동작이 아닙니다.
- 기존 개인 스킬의 작은 점검 항목 개선에는 실제 전체 본문 로드, 변경 없는 정확한 버전, 해당 요청의 최신 검증 성공이 필요합니다. 오류 수정으로 학습하려면 실제 실패와 수정 성공도 관찰해야 합니다. 근거가 부족하거나 수동 편집과 충돌하면 후보로 남기며, 공통 스킬·회사 정책·실행 코드·인증 설정은 자동 수정하지 않습니다.
- 학습만을 위한 Stop 응답 재개를 없앴습니다. 매 답변을 회고하거나 별도 학습 모델·작업자를 강제 호출하지 않습니다. 결과물의 필요한 검사와 1.4.29의 완료 확인·미확인 사항 보존은 유지하며, 학습 기록 때문에 이미 끝난 업무를 다시 실행하지 않습니다.
- 내역에서 **미제출 / 접수 / 후보 / 실제 적용 / 보류**를 구분합니다. “제출했지만 배울 내용 없음”은 미제출과 다릅니다. 현재 대화의 기억 전달 기록도 별도로 확인할 수 있지만 **모델 문맥에 제공됨은 실제 답변에 사용됐다는 증거가 아닙니다.** 이 기록에 기억 본문이나 사용자 질문을 복사하지 않습니다.
- 기존 일시 중지·재개·선택한 자동 변경 되돌리기는 유지합니다. 중지는 기존 기억의 삭제나 사용 중단이 아니며, 복구는 업무 파일·발송 메일·외부 시스템 작업을 취소하지 않습니다.
- 자가학습 스킬을 짧게 정리하고 사용자 안내서·Markdown·선택형 Workspace의 학습 카드를 같은 구분으로 갱신했습니다. 새 스킬·후크·외부 서비스나 추가 모델 연결은 도입하지 않습니다.

## 설치·업데이트

1. `company-agent-1.4.30-2026.09.03.zip` 전체를 새 폴더에 풉니다. 뒤의 날짜 **2026.09.03**은 그대로 유지되는 회사 지식팩 버전입니다.
2. 기존과 같은 설치 범위를 선택하여 백업 후 업데이트하고 Claude Code를 다시 시작합니다. 개인 Memory·Skill·Knowledge·모델·별도 MCP·인증 설정을 보존합니다.
3. 선택형 Workspace는 기존 **0.9** 묶음에 학습 카드와 안내서만 갱신하며 나머지 실행 코드는 유지합니다. 하네스와 별도 ZIP이며, 기존 창을 닫은 뒤 새 폴더에서 실행하세요. 별도로 개발 중인 Workspace 실행·권한·화면 변경은 이 배포에 포함하지 않습니다.

이전 태그·ZIP을 덮어쓰지 않고 설치된 PC를 자동 갱신하지 않습니다. 승인된 Python 3.11 이상과 Claude Code가 필요하며 외부 실행 파일은 다운로드하거나 동봉하지 않습니다. GitHub의 자동 `Source code (zip)`은 직원용 설치 ZIP이 아닙니다.

## 확인 범위와 한계

형식·중복·경로·버전·현재 요청과 업무에 연결된 검증 기록은 코드로 확인합니다. 실제 검사를 수행하고 정확하게 기록했는지, 어떤 교정이 지속적인 선호인지와 실제 다음 사용이 도움이 되었는지는 현재 모델의 수행과 해석에 의존합니다. 독립적인 테스트 실행 증명이나 자동 학습 성공률, 모든 교정의 보존·적용을 보장하지 않습니다. 기록 상한과 수동 변경 충돌도 그대로 적용합니다.

실제 사내 HCP 환경의 전체 업무 성공률·체감 속도·토큰 절감량은 미검증입니다. 이번 변경은 추가 절차와 반복을 줄이는 구현이며 효과 수치를 측정했다고 주장하지 않습니다. 회사 PC의 WS-33, 비전 모델·게이트웨이·회사 보안 정책을 해결하거나 변경하는 배포도 아닙니다.

최종 검사 결과와 배포 파일 해시는 [1.4.30 배포 검증](VALIDATION_RELEASE_1.4.30.md)에 기록합니다. 이전 버전의 변경·검증 문서는 당시 이력으로 보존합니다.
