# 1.3.9 업데이트 — HTML 디자인부터 선택

‘추가 디자인’을 골랐는데 분량·보기 방식부터 물어보던 흐름을 수정했습니다.

1. 처음에는 디자인만 묻습니다.
2. 추가 디자인을 고르면 즉시 채팅에 8가지 설명이 나오고 번호/이름으로 고릅니다.
3. 디자인이 확정된 다음에만 아직 정하지 않은 분량·보기 방식을 묻습니다.
4. 앞서 입력한 ‘상세 / 스크롤’ 등은 보존하고 다시 묻지 않습니다.

작은 미리보기는 선택 사항입니다. 채팅에서 바로 선택해도 됩니다.
미리보기에서 선택했다면 그 문장을 채팅에 붙여 넣어야 전달됩니다.

## 적용 방법

`company-agent-1.3.9-2026.09.03.zip`을 새 폴더에 풀고 `Install-CompanyAgent.cmd`를 실행하세요.
기존과 같은 설치 범위를 선택하고 백업 후 업데이트 안내를 따라 진행하세요.
완료 후 Claude Code를 닫았다 다시 여세요. 개인 Memory·Skill·Knowledge,
모델·MCP 설정은 유지하며 기존 1.3.8 코어/압축파일을 덮어쓰지 않습니다.
이 문서를 읽는 것만으로 설치되지는 않습니다.

## 확인할 채팅

“HTML 보고서를 만들어줘. 디자인은 직접 고를게.” → ‘추가 디자인’ 선택 →
분량 질문보다 먼저 8가지 목록이 나오는지 확인 → ‘뉴모피즘’ 선택 → 분량/보기 선택.

“상세, 스크롤로 만들어줘. 추가 디자인에서 골라볼게.” → 디자인만 선택하면 바로 제작.
