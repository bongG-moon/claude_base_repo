## 반영 내용

### H1 — 계산값과 지표명·기간·단위의 연결

`facts`에 선언한 이름·단위를 `{{fact:id.label}}`, `{{fact:id.unit}}`, `{{fact:id.valueWithUnit}}`로 재사용할 수 있다. 기준 기간이 필요한 지표는 선택 필드 `period`를 선언하고 `{{fact:id.period}}`로 참조한다. 미선언 기간을 요청하면 추측하지 않고 명세 오류로 반환한다.

HTML의 제목·본문·표 머리글·KPI 표시명·차트 항목/범례와 PPT의 관련 텍스트 바인딩에 적용한다. 기존 숫자 전용 `{{fact:id}}`는 유지한다. 기본 KPI 이름은 메타데이터 그대로 사용하며 명시적 표시명만 한 번 치환한다. 입력 원본과 명세를 수정하지 않는다.

작성 지침과 사용자 안내서에 정정 시 지표명·기간·단위·분모를 함께 대조하고 금액/비율 열을 구분하도록 반영했다. 이 기능은 **선언된 메타데이터 재사용**이며 자유문장 의미 검사, 원본 지표의 진위 판정, 자동 단위 변환이 아니다. 응답에 `metricMeaning=not_verified`를 명시한다.

### H2 — 읽기 전용 조회의 불필요한 완료 검증

완료 기록용으로만 제한된 Bash 조회 문법을 구분한다. `cd`와 숫자 행 범위 출력만 하는 `sed -n '1,80p'`, 제한된 `tr/grep` 파이프 등을 지원한다. 기존 `cat *.md` 조회는 유지한다.

파일 출력, 변경 명령 혼합, 명령 치환, 알 수 없는 구문, `sed -i/w/e/-f`는 읽기 전용 예외가 아니다. `sed` 구간의 따옴표 없는 glob은 확장 결과가 변경 옵션이 될 수 있으므로 예외에서 제외한다. 이 분류는 실행 파일·별칭의 신뢰성을 보증하거나 실행을 승인하지 않는다.

단순 조회는 새 변경/Stop 검증을 만들지 않으며, 앞서 실제 변경한 항목의 검증 의무와 이미 확인한 기록은 보존한다. 문서에는 `Read/Glob/Grep` 우선, 조회만을 위한 `session verify` 반복 금지를 명시했다.

### 자동학습 — 실제 실행기·CLI의 세션 간 계약

새 테스트는 임시 플러그인·설치 등록·개인 상태·Claude 설정·프로젝트 두 개만 사용한다. Windows PowerShell 실행기와 native hook 및 CLI를 실제 별도 프로세스로 호출한다. 교정과 후크 입력은 가상 자료다.

1. 수동 기억과 충돌하지 않는 가상 교정을 한 번 제출해 자동 적용한다.
2. 다른 세션의 후크 출력에 같은 기억 ID·버전·본문이 제공되는지 확인한다.
3. 해당 자동 변경만 취소하고 다음 세션에서 조회되지 않는지 확인한다.
4. 수동 기억 파일의 바이트 보존, 프로젝트 A/B 분리, 충돌 보류, 학습 중지·재개를 확인한다.

선호 취소는 **비활성화**이며 이전 본문 복원과 다르다. `hostReceipt/modelApplied=not-observable`을 유지한다. 외부 LLM·개인 Claude 계정·실제 회사 문서는 사용하지 않았다.
