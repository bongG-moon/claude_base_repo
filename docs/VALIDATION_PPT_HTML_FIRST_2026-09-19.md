# PPT HTML 초안·대표 양식 검증 (2026-09-19)

## 변경 범위

- `business ppt-design-preview`: 일부 장의 PPTX 대신 전체 슬라이드 HTML 초안을 생성한다. 기본 경로에서 Office를 시작하지 않는다.
- 초안 승인 후 같은 내용·배치 명세로 편집 가능한 PPTX를 만든다. 명세, 참고 이미지, 양식 또는 HTML 초안이 변경되면 다시 확인한다.
- 디자인 참고용 캡처는 2~3장을 권장한다. 1장도 허용하며, 새 디자인·기존 양식을 선택한 사용자에게 추가 캡처를 강요하지 않는다.
- `business ppt-template`: 승인된 디자인의 색상·글꼴·페이지 규격·배치 버전을 가상 예시 HTML 한 파일로 저장한다. 업무 본문·수치·원본 경로·참고 캡처·승인 기록은 저장하지 않는다.
- 개인용/프로젝트용 저장 위치는 사용자가 정한다. 회사 공통 정책이나 개인 기억에 자동 등록하지 않는다.
- 저장한 HTML을 이후 작업의 `--template`으로 재사용한다. 임의 웹페이지나 CSS를 편집 가능한 PPT로 변환하는 기능은 아니다.
- 원본 PPTX의 배치/마스터 유지 모드는 유지한다. 이 모드의 HTML은 교체 대상만 보여주며 고정 장식/마스터를 재현하지 않는다. 원본 없이 일반 HTML 양식으로 몰래 전환하지 않는다.

## 자동 검사

- PPT 관련 35개: 초안/승인 순서, 마지막 장까지 검증, 변경 감지, 기존 파일 보존, HTML 저장/재사용, 4:3 규격, 잘못된 메타데이터, 캡처 비삽입, 원본 양식 보존.
- 실행 계약 24개, 기본 제작기 19개, 프레젠테이션 디자인 14개, 안전한 Workspace HTML 미리보기 4개, 핸드북 계약 8개 통과.
- 스킬 선택/발견/실행 관련 204개 통과. PPT 읽기·PPT 제작·HTML 보고서의 구분을 포함한다.
- 상태 호환성 8개와 백그라운드 완료 처리 8개 통과. 위 관련 자동 검사 합계는 324개이다.
- 스킬 안내 형식 검사, 생성된 HTML 매뉴얼 최신성 검사, `git diff --check` 통과.
- 회귀검사에서 제작 스킬 설명의 `확인`·`HTML`이 문서 읽기/HTML 보고서 후보로도 잡히는 문제를 발견했다. 검색용 설명은 PPT 제작 용도로 한정하고, HTML 절차는 본문/참고 문서에 두었다. 읽기/HTML 보고서/PPT 제작을 각각 올바른 후보로 안내하는 검사를 추가했다. 라우터를 확대하거나 추가 모델 호출을 넣지 않았다.
- 캡처 경로 1~3개는 제한된 임시 선택 메타데이터로 유지한다. 이 질문 준비만으로 산출물 검증/Stop을 요구하지 않으며, 실제 HTML/PPT/전체 job 쓰기는 이 예외에 들어가지 않는다. 실행 권한은 바꾸지 않는다.
- 오프라인 설치 묶음 회귀검사 통과. 신규 모듈/참고 문서가 묶음에 포함됨을 확인했다. 실제 배포용 릴리스 업로드나 사용자 설치는 하지 않았다.

## 실제 PowerPoint 경로

`scripts/test-lab/check-ppt-html-roundtrip.py --output <새 폴더> --render`로 가상 자료를 사용했다. 승인 값은 이 시험에서만 모사했으며, 실제 사용자 승인을 받았다는 뜻이 아니다.

- 검증 산출물: `.smoke/ppt-html-first-20260919/`
- HTML 초안 5장 생성: 88.5ms (이 PC의 단일 측정, 모델 응답/사용자 확인 시간 제외).
- 실적 합계 530, 목표 합계 450, 달성률 117.78% 대조.
- 최종 PPT: 5장, 네이티브 텍스트 25개·표 2개·차트 1개, 이미지 0개. 차트 계열/표 셀 데이터를 다시 열어 대조했다.
- 설치된 PowerPoint로 5장 모두 이미지 출력 성공. 출력 이미지 5장을 직접 확인하여 제목·범례·표·수치가 읽히며 눈에 띄는 잘림/겹침이 없음을 확인했다.
- 대표 양식 HTML 저장 후 다른 업무의 새 HTML 초안으로 재사용했다. 단위 시험에서는 해당 양식을 사용한 네이티브 PPT 생성도 확인했다.

## 확인하지 못한 범위

- 브라우저 도구가 로컬 HTML 열기를 보안 정책으로 거부하여 HTML의 브라우저 화면은 직접 확인하지 않았다. 우회하지 않았으며 구조·데이터·안전한 미리보기 처리만 검사했다.
- 실제 사내 HCP 모델이 스킬을 선택하고 사용자 확인을 받는 대화 전체는 이 PC에서 재현하지 않았다.
- 모든 글꼴/회사 양식의 시각적 일치, 복잡한 마스터/SmartArt/애니메이션, 임의 HTML/CSS 변환은 보장하지 않는다.
- HTML과 PPT는 같은 배치/데이터를 쓰지만 글꼴 줄바꿈과 차트 세부 렌더링은 다를 수 있다. 실제 사용 시 최종 PPT 전 장을 별도로 확인해야 한다.
