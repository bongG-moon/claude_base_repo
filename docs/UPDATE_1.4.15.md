# 1.4.15 — 회사·개인 업무 지원과 로컬 화면 보완

## 설치·업데이트

[1.4.15 설치 ZIP](https://github.com/bongG-moon/claude_base_repo/releases/download/v1.4.15/company-agent-1.4.15-2026.09.03.zip)을 새 폴더에 모두 압축 해제한 뒤 `Install-CompanyAgent.cmd`를 실행하세요. 기존과 같은 내 계정/프로젝트 범위를 선택해 백업 후 업데이트하고 Claude Code를 다시 여세요.

개인 Memory·Knowledge·Skill·선호와 기존 모델·MCP·규칙·Hook을 보존합니다. 이전 버전 ZIP과 운영 설치는 자동 변경하지 않습니다. 회사 지식팩 버전은 `2026.09.03`을 유지합니다. 기존 승인 Python 3.11 이상, Claude Code와 필요한 Office·읽기 라이브러리는 별도로 준비해야 하며 자동 설치하지 않습니다.

같은 [Release](https://github.com/bongG-moon/claude_base_repo/releases/tag/v1.4.15)의 `company-workspace-preview-0.3-*.zip`은 **선택적인 로컬 업무 화면**입니다. 하네스 설치 ZIP과 별도로 압축을 풀고 `Company-Workspace.vbs`를 더블클릭합니다. 기존 앱이 실행 중이면 먼저 앱 전원 버튼으로 종료하세요. 로그인·모델을 다시 설정하지 않으며 같은 실행 환경의 기존 CLI를 사용합니다. 기억·지식 관리 기능은 1.4.15 하네스로 업데이트해야 동작합니다. 원본 CLI 사용자는 화면 ZIP을 받을 필요가 없습니다. GitHub의 `Source code (zip)`은 직원 설치본이 아닙니다.

## 반영한 내용

- 회사 기준과 개인 업무 방식의 두 관리 영역, 처음 업무를 따라 하는 안내와 짧은 폴더 업무 지침.
- 사용 가능한 스킬 목록을 기준으로 한 경량 선택·진단, 관련 스킬이 없을 때 일반 실행. 별도 Jev API나 모델 호출을 추가하지 않음.
- 실행 전 승인 대기·실제 실행 실패·인코딩 표시 문제를 구분하고, 표시 문제만으로 업무를 중복 실행하지 않도록 보완.
- HTML 선택 준비를 실제 결과물 변경과 분리해 확인 대기 중 Stop 오작동을 줄임. 첨부 양식은 미리보기·사용자 확인 후 생성하고 기존 분량/보기 선택을 유지.
- 로컬 화면의 격리된 정적 HTML 미리보기, 개인 기억·지식 검토, 사용량·결과 확인. 원본 HTML 스크립트와 외부 리소스는 실행하지 않음.
- 관리 탭별 조회, 목록 20개씩 표시·선택한 본문만 조회, 지식 인덱스/파일 읽기 중복 제거, 변경된 대화만 저장.
- 과거 대화 기록 이전 시 원본 보존, 손상·실패 시 기존 기록 보존. 임시 입력 자료·실제 사용자 설정·인증 정보는 배포에서 제외.

## 검증 범위와 한계

소스 회귀시험은 **919개 중 917개 통과, 2개 건너뜀**입니다. 실제 로컬 브라우저에서 390/768/1440px 화면과 질문·승인·기억 관리·미리보기를 확인했습니다. 브라우저 검증의 Claude 응답은 모형 CLI이며 모델 호출은 없었습니다. 자세한 수정·성능 측정과 검증 경계는 [감사 후 수정·검증 기록](https://github.com/bongG-moon/claude_base_repo/blob/v1.4.15/docs/VALIDATION_AUDIT_FIXES_2026-09-19.md)을 참고하세요.

로컬 화면은 개발용 미리보기입니다. 사내 HCP의 실제 스킬 선택, 개인 계정 인증, DRM Office 열기와 CLI의 모든 TUI 기능을 GUI에서 동일하게 사용할 수 있다는 보장은 이번 시험에 포함하지 않습니다. 기존 CLI 연결과 회사 정책은 그대로 적용하며 사내 시범 검증을 거쳐 사용하세요.
