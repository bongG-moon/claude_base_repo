# 1.4.35 배포 검증

검증일: 2026-10-05. 공개 기준 `6272aa8`에 하네스 변경만 선택해 검증했습니다. 회사 지식팩은 `2026.09.03`을 유지합니다. 기존 로컬 1.4.34 작업 ZIP은 보존하고 새 버전을 사용합니다. 별도 개발 중인 Workspace 앱·실습자료·Computer Use MCP는 이번 배포에 포함하지 않습니다.

[변경·설치 안내](UPDATE_1.4.35.md)

## 성능 변경과 측정

실제 모델을 호출하지 않은 임시 자료 비교입니다. 글자 수를 토큰 수로 환산하지 않았고, 아래 시간을 전체 업무 완료 시간으로 해석하지 않습니다.

### 요청 안내

고정 지침은 기존 2,030자에서 최초·복구 요청 1,888자, 정상 후속 요청 714자로 줄였습니다. 모델이 사용할 필요가 없는 revision 해시는 세션 기록에만 저장합니다. 압축·복원·관련 지침/실행 정보 변경에는 전체 지침으로 돌아갑니다. 출력 기록은 모델 수신·이해·스킬 본문 읽음의 증거가 아닙니다.

| 격리 요청 | 기존 안내 포함 전체 글자 | 개선 후 | 감소율 |
| --- | ---: | ---: | ---: |
| 첫 인사 | 5,146 | 5,031 | 2.23% |
| 후속 인사 | 5,176 | 3,926 | 24.15% |
| 후속 HTML 업무 시작 | 5,691 | 4,441 | 21.96% |
| 같은 본문을 읽은 뒤 HTML 후속 요청 | 5,409 | 4,159 | 23.11% |
| 대화 압축 후 복구 | 5,691 | 5,576 | 2.02% |

최종 선택 소스 `bb90e2cc21e9`에서 측정했습니다. baseline은 기존 2,030자 지침을 고정하고 나머지 코드는 동일하게 둔 대조군입니다. 과거 배포 바이너리 전체를 실행한 비교는 아닙니다. 개인 기억·회사 정책이 없는 fixture이며 절대 경로 길이에 따라 전체 글자 수가 달라집니다. 긴 경로에서는 마지막 지식/스킬 종류를 없애기 전에 안내를 더 축약합니다. 그래도 상한을 넘으면 기존 축소·진단 경로가 작동하며 모든 카드를 무조건 유지하는 것은 아닙니다. 별도의 5,000자 회귀 조건은 최소 요청 fixture에 대한 것으로 모든 후크의 전역 상한이 아닙니다.

### 후크 기동

PowerShell 뒤 Python 버전 검사와 본 실행을 한 Python 프로세스로 합쳤습니다. 실제 업무 진입 뒤 오류는 다른 실행기로 재실행하지 않습니다. 일반 명령의 하네스 분류에서는 불필요한 PATH 검색을 생략합니다.

| 합성 후크 | 기존 중앙값 | 개선 후 중앙값 |
| --- | ---: | ---: |
| 관계없는 Agent 실행 전 | 639.39ms | 616.48ms |
| 일반 Read 실행 후 | 716.96ms | 698.66ms |
| `pwd` 실행 후 | 1,003.05ms | 750.31ms |

각 5회, 두 구현과 실행 순서를 교차한 새 프로세스 측정입니다. 앞의 두 차이는 작으므로 큰 속도 향상이라고 주장하지 않습니다. 일반 셸 사례는 약 25.2% 줄었고 실제 프로파일에서 PATH 조회 40→0회가 확인됐습니다. baseline은 이전 실행기 끝부분과 경로 분류를 임시 복사본에 복원한 것으로, OS 캐시를 강제로 비운 시험이 아닙니다.

### 지식 시작 준비

원본·지식팩·생성 파일 해시가 같으면 파싱·목록 재생성을 생략합니다. 원본 읽기·해시 확인은 계속 수행하며, 변경·삭제·손상·동시 변경에는 정상 검증으로 돌아갑니다.

| 합성 문서 수 | 이전 호출 순서 중앙값 | 변경 없는 경우 | 변경 발생 |
| --- | ---: | ---: | ---: |
| 0 | 21.4ms | 10.0ms | 33.2ms |
| 100 | 77.8ms | 21.7ms | 76.3ms |
| 500 | 292.7ms | 87.0ms | 266.2ms |

각 5회 로컬 warm-cache 비교입니다. 500개 무변경 사례는 원본 읽기 1,000→500회, 파싱 1,000→0회, index/report 쓰기 5→0회였습니다. 대조군은 현재 안전한 탐색기를 사용하는 이전 무-overlay 호출 순서입니다. 작은 변경 경로에는 캐시 확인·저장 비용이 추가될 수 있습니다. 개인 기억 검색의 별도 DB·상주 프로세스는 추가하지 않았습니다.

재현 도구는 `scripts/test-lab/benchmark-runtime-guidance.py`, `benchmark-hooks.py`, `benchmark-knowledge-startup.py`입니다. 임시 fixture만 사용하며 사내 모델 지연·토큰·성공률 측정은 아닙니다.

## 검증 범위

- Python 3.13.5, Windows PowerShell 5.1, 실제 Claude Code 2.1.286의 격리 등록을 사용했습니다. 실제 모델·인증된 회사 MCP·Driver는 호출하지 않았습니다.
- 런처의 최소 버전·선택 실행기·한글 입력·stdout/stderr 즉시 전달·실제 오류 후 재실행 금지, 기존 권한과 위험 명령 분류를 확인했습니다.
- 시작/압축/복원, 관련 정책·실행 정보·카탈로그 변경, 손상된 기록, 본문 로드 제한, 예산 초과 시 지침 복구를 확인했습니다. 무관한 스킬 후보 제외 명령과 브라우저 업무/도구 제작 구분도 검증했습니다.
- 지식 원본/생성물 변조·삭제, 동일 크기와 mtime을 유지한 변경, 캐시 손상, 회사 root/version 변경, overlay 재조정, 링크 거절, 파싱 도중 파일/폴더 추가·변경과 병행 게시를 확인했습니다.
- 실제 플러그인 strict 검사, 회사 지식 검사, Python 구문 검사와 단독 안내서 생성 일치 검사를 통과했습니다. Noto Sans KR 내장 안내서는 6개 부분·52개 장, 412,008 bytes입니다. 이번에는 설명 문단만 추가했으며 전체 화면의 새 시각 검사를 수행한 것은 아닙니다.
- ZIP 감사: manifest 제외 217개 파일 전체의 길이·SHA-256·선택 소스 바이트 일치, 플러그인 163개 파일 포함을 확인했습니다. 경로 이탈·중복 Windows 경로·링크·미등록 파일은 없었습니다. 개인 상태·인증정보 파일·테스트·캐시·CUA·Workspace 구현·실행 바이너리를 동봉하지 않았습니다.

## 최종 회귀 및 설치 결과

선택 소스의 `tests/test_*.py` 127개 파일을 세 그룹으로 나눠 중복·누락 없이 실행했습니다. 이전 실패는 같은 모듈의 재시험 결과로 대체했으며 재실행 횟수를 추가 합산하지 않았습니다.

| 묶음 | 파일 수 | 시험 수 | 통과 | 조건부 생략 | 최종 실패/오류 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 정렬 index % 3 = 0 | 43 | 582 | 580 | 2 | 0 |
| 정렬 index % 3 = 1 | 42 | 572 | 571 | 1 | 0 |
| 정렬 index % 3 = 2 | 42 | 477 | 474 | 3 | 0 |
| 합계 | 127 | 1,631 | 1,625 | 6 | 0 |

생략 6건은 Windows 심볼릭 링크 권한 제한 4건, 일반 사용자 토큰 별도 opt-in 1건, WSH 실행 불가 1건입니다. 조건을 임의 완화하지 않았습니다. 그룹 1의 기존 앱 실행 시험은 정상 사용자 환경의 동일 소스 재시험 49개 중 48 통과·1 생략을 사용했습니다. 그룹 2에서는 축약 지침의 동의어를 검사하는 문구 두 개를 새 표현에 맞춘 뒤 해당 모듈 32개를 재시험했습니다. 의미·실행 차단 검증과 5,000자 상한은 유지했습니다.

- 실제 공개 ZIP으로 **1.4.33 → 1.4.35 업데이트** 통과. 임시 프로필에서 Claude 등록·한 번의 SessionStart, 개인 모델/MCP/기억/스킬·긴 경로 백업·원본 ZIP 보존을 확인했습니다.
- 실제 설치의 영구 플러그인과 Claude 캐시에 있는 핵심 파일 각 10개, 총 20개 SHA-256이 선택 소스와 일치했습니다.
- 설치된 PowerShell 실행기로 SessionStart·인사 두 번·Stop 두 번을 직접 호출한 5개 이벤트 모두 정상 JSON을 반환했습니다. 첫 안내 `full` → 후속 `reuse`, 세션 revision 유지, 불필요한 Stop 차단 0건·업무 변경 0건·학습 시도 0건을 확인했습니다. 매우 긴 설치 fixture의 요청 안내는 6,486→5,381자였으며 모델을 호출한 시험은 아닙니다.

## 배포 파일

| 파일 | 크기 | SHA-256 |
| --- | ---: | --- |
| `company-agent-1.4.35-2026.09.03.zip` | 1,276,305 bytes | `ea93f493654af9a657f4bdd3b25a2e8848b780b56b110ac57369769644778682` |
| `Company-Agent-User-Guide.html` | 412,008 bytes | `84c5b2615dc547f906c5d6bec9f5a8d0529f995d56979905104f6e9602843ba1` |

각 `.sha256` 파일도 제공합니다. 안내서 단독 파일과 ZIP 안 두 사본은 동일합니다. 검증 보고서는 순환 해시를 피하기 위해 설치 ZIP 밖에 보관합니다. 기존 ZIP·Release·개인 자료와 별도 앱 개발 파일을 덮어쓰지 않습니다.

## 검사 과정과 한계

- 깊은 검증 사본에서 Python 임시 컴파일 경로가 Windows 길이 제한에 걸렸습니다. 소스와 검사 조건을 바꾸지 않고 짧은 임시 경로의 동일 소스로 strict·지식·구문 검사와 패키징을 수행했습니다.
- 긴 경로 회귀에서 처음에는 최소 요청 5,000자 조건과 지식 카드 보존 조건이 실패했습니다. 상한을 늘리지 않고 첫 지침 중복 및 모델 출력의 불필요한 해시를 줄이고, 마지막 카드 종류를 버리기 전 지침 축약 순서를 보완했습니다.
- 기존 앱 실행 시험의 샌드박스 `WS-31`과 검사 실행기의 skip 식별자 집계 오류는 제품 오류와 구분했습니다. 제품 권한 검사를 끄지 않고 정상 사용자·격리 설정으로 재시험하고 집계 실행기만 수정했습니다.
- PowerShell 7 호스트의 모듈 경로가 Python을 거쳐 Windows PowerShell 5.1에 상속되면 `Get-FileHash` 탐색이 실패했습니다. 검사 자식 프로세스의 모듈 경로만 Windows PowerShell 기본 경로로 지정했으며 사용자 설정은 바꾸지 않았습니다.
- 실제 사내 HCP의 지시 준수·업무 성공률·총 토큰·응답 시간, DRM/Office·회사 API·브라우저 인증·비전 게이트웨이는 미검증입니다. 전체 파일·MCP 결과·이미지·대화 이력을 합산하는 호스트 전체 컨텍스트 예산 기능을 추가한 것은 아닙니다.
- 새 후크·검증 LLM·상시 학습 작업자·학습용 Stop 재개를 추가하지 않았습니다. 비밀값 검사는 고위험 패턴과 파일 구성 검사이며 전체 DLP 보장이 아닙니다.

로컬 조사 기록은 `.smoke/release-1.4.34/`에 보관합니다. 이 이름은 최초 작업 버전이며 최종 배포 버전은 1.4.35입니다. 임시 프로필·로그·합성 자료는 커밋이나 Release에 포함하지 않습니다.
