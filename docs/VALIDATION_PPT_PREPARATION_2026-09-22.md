# PPT 준비 절차·공통 스킬 경량화 — 검증

검증일: 2026-09-22. Windows 로컬 작업 사본과 격리한 플러그인으로 확인했다. 실제 사내 HCP 대화나 사용자 설치본을 원격 실행한 기록은 아니다.

## 확인된 문제와 수정

| 문제 | 수정 |
| --- | --- |
| 선택을 마친 정상 `preview_required`도 종료 코드 1로 반환 | 다음 단계가 있는 정상 준비 상태는 종료 코드 0으로 반환. PPT 제작 성공과는 구분 |
| 첫 질문만 확인하는 데 빈 선택 JSON 파일이 필요 | PPT·HTML의 첫 질문은 대화에서 바로 진행. 선택 도우미도 `--spec` 없이 조회 가능 |
| PPT 선택 메타데이터의 성공한 `Edit`를 결과물 변경으로 계산 | 현재 상태 저장소의 작은 선택 파일만 완전한 내용으로 검사하여 준비 기록으로 분류. 실제 본문·실패한 편집·기존 미검증 변경은 예외가 아님 |
| 잘못된 선택값이나 선택 전용 파일을 전체 슬라이드 명세와 혼동 | 잘못된 필드·허용값과 다음 행동을 반환. 본문 준비와 HTML 초안 생성을 분리하여 안내 |
| 공통·PPT·HTML 스킬의 선행 참조와 반복 탐색 부담 | 필요한 단계에서만 참조를 읽도록 정리. 스킬 로드 후 설치·소스 탐색과 재선택 절차를 반복하지 않음 |
| 같은 승인 분류기 시간초과에 재시도 안내 반복 | 정확히 확인된 실행 전 분류기 시간초과에만 한 번 재시도 안내 후 보류 안내. 같은 턴의 이후 안내 생략 |

추가 검토에서 PPT·HTML 선택 파일의 BOM 제거 후 크기를 검사하면 큰 파일의 앞부분만 검사할 수 있는 경계를 발견했다. 이제 원본 바이트가 8KiB를 넘으면 먼저 제외한다. 없는 선택 파일도 JSON 문법 오류와 구별한다.

분류기 장애의 실제 원인은 사용자가 제공한 진행 문구만으로 확정할 수 없다. 이번 변경은 승인 서비스를 대체하거나 보안 설정을 변경하지 않는다. 실제 권한 거절·문서 보호·접근 제한에 대한 다른 경로 재시도는 허용하지 않는다.

- Windows 실제 진입점·후크 검사 29개 통과. 프로젝트 밖 플러그인으로 선택 조회 → 준비 완료 → Stop까지 검사했고 프로젝트 안에 스킬 복사본을 만들지 않았다.
- PPT 선택 흐름 20개, HTML 우선 제작 14개, native 배치 22개 통과.
- 스킬·디자인·한국어·학습 지침 계약 55개 통과. 본문 문자 수 상한과 첫 질문 전 도우미 강제 실행 금지, 참조 내부의 반복 시작 방지를 포함한다.
- 실행 계약 27개, 기존 실행 복구 7개, 런타임 진단 5개 통과.
- 전체 회귀: `python -X utf8 -B -m unittest discover -s tests` — 1,210개 실행, 1,205개 통과·5개 건너뜀, 348.378초. 실패·오류 없음. 위 개별 검사 숫자는 전체 회귀와 중복되므로 합산하지 않는다.
- `git diff --check` 및 안내서 재생성 일치 검사도 통과했다.

## 실제 가상 PPT 생성

`.smoke/ppt-preparation-20260922/validation.json`에 결과를 남겼다.

- 5장짜리 HTML 초안 생성 성공. 이 PC 단일 실행에서 초안 생성 약 43.7ms. 모델·사용자 승인 대기·전체 제작 시간을 포함하지 않는다.
- 편집 가능한 PPTX 생성 후 다시 열어 5장, 텍스트 25개·표 2개·차트 1개와 가상 표·차트 수치를 확인했다.

## 적용 범위와 남은 운영 확인

- 플러그인 스킬은 활성 플러그인 안에 있어도 사용 가능하다. 프로젝트 폴더에 직접 복사해야 한다는 구조가 아니다. [Claude Code 공식 스킬 문서](https://code.claude.com/docs/en/skills)
- 훅과 명령 상태를 구분하며, 준비 기록의 예외 처리는 도구 실행 자동 승인이 아니다. [Claude Code 공식 훅 문서](https://code.claude.com/docs/en/hooks)
- 실제 HCP에서 스킬 로드 후 첫 질문으로 바로 가는지, 승인 분류기 자체가 응답하는지, PowerPoint 화면 출력이 가능한지는 해당 환경에서 확인해야 한다.
- 기존 설치본·ZIP·GitHub Release는 이 작업으로 자동 갱신하지 않았다. 원본 사용자 파일, 개인 설정·스킬·기억, 별도 CUA 가이드는 수정·삭제하지 않았다.
