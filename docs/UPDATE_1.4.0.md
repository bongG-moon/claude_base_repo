# 1.4.0 — PPT 제작 선택과 스킬 목록 우선 읽기

이 개발 단계의 기능은 **1.4.1 배포에 모두 포함**됩니다. 직원 설치에는
[1.4.1 설치 안내](UPDATE_1.4.1.md)와 해당 Release ZIP을 사용하세요.

## 달라진 사용법

“기존 회사 양식으로 부서장 보고 PPT 6장 만들어줘”라고 요청하세요.
먼저 참고 파일을 받고 ‘분위기만 참고 / 기존 배치 유지’를 고릅니다.
알려준 대상·장수를 다시 묻지 않고 부족한 조건만 확인합니다.
새 디자인·기존 양식·저장한 내 양식을 처음에 고를 수도 있습니다.
저장한 양식이 자동으로 생기는 것은 아닙니다. 실제 사용 가능한 파일이 필요합니다.

기존 배치 유지는 지정한 슬라이드의 글자 칸·표·일반 차트를 교체합니다.
원본과 다른 파일로 저장하고, 작은 글자·영역 밖 개체 등을 검사합니다.
혼합 서식·그룹·표 행/열 수 변경·복잡한 차트는 임의 변환하지 않고 안내합니다.
양식 유지에는 사전 준비된 python-pptx가 필요하며 자동 다운로드하지 않습니다.
참고 파일·결과 미리보기는 설치된 PowerPoint의 허용된 출력 기능만 사용합니다.
보호로 차단되면 해당 부분만 중단하며 화면 캡처 등으로 우회하지 않습니다.

## 스킬 목록은 어떻게 확인하나요?

“이 폴더의 스킬 목록을 보여줘” 또는 `/company-agent:skills`를 사용하세요.
현재 폴더의 자동 생성 MD가 준비되어 있으면 그것만 읽어 답하고,
이미 읽은 같은 버전은 재사용합니다. 전체 스킬 본문을 읽지 않습니다.
실제 업무 실행 때만 고른 스킬의 현재 우선 설정과 본문을 확인합니다.
다음 요청에서 설치·삭제·설명·우선 설정 변화를 감지해 목록을 갱신합니다.
감지를 위한 로컬 파일 조회는 남아 있지만 모델에 전체 내용을 다시 전달하지 않습니다.
Claude 자체의 스킬 로딩과 화면 표시는 별개입니다.

## 오류 처리

- 안전 확인 모델의 `auto mode ... timed out`는 실행 전 승인 확인 지연으로 분류합니다.
  입력을 보존하고 일시적 오류에 한해 최대 한 번 재시도하도록 안내한 뒤 대기합니다.
  명시적 거절에는 재시도하지 않으며 권한 해제·다른 실행 도구로 우회하지 않습니다.
  이 오류만으로 업무 변경·검증 실패·학습 실패를 추가하지 않습니다.
- `[1m]`를 ‘1분 제한’으로 해석하거나 모델 설정을 바꾸지 않습니다.
- Ctrl+C 종료 뒤 npm `claude.ps1` 오류는 원인이 아직 확정되지 않았습니다.
  “Claude 실행 위치를 진단해줘”라고 요청하면 `business runtime-check`로
  실행 후보·PowerShell 정보를 읽습니다. PATH·래퍼·모델·MCP 설정을 고치지 않습니다.
  오류가 Claude 종료 후 바깥 PowerShell에서 나면 Hook이 직접 감지할 수 없습니다.
  같은 환경의 `/exit` 종료와 Ctrl+C 종료를 비교한 결과가 추가로 필요합니다.
- Claude 자체의 원문 오류 표시를 완전히 숨기거나 사내 모델 서버 지연을 해결한 것은 아닙니다.

## 적용 방법

현재 배포본 `company-agent-1.4.1-2026.09.03.zip`을 새 폴더에 풀고 `Install-CompanyAgent.cmd`를 실행합니다.
기존과 같은 설치 범위를 선택하고 백업 후 업데이트합니다. 완료 후 Claude Code를 다시 엽니다.
이 문서의 기능은 1.4.0에서 개발했고 Office 읽기를 포함해 1.4.1로 배포합니다. 기존 코어와 ZIP을 같은 버전으로 덮어쓰지 않습니다.
개인 Memory·학습 이력·Skill·Knowledge, 기존 모델·MCP 설정을 초기화하지 않습니다.
다운로드만으로 사용자 PC가 업데이트되지는 않으므로 설치 절차를 진행해야 합니다.
