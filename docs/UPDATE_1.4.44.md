# Company Harness 1.4.44

엑셀 구조화 결과를 초보자가 읽고 수정하기 쉬운 Python 프로젝트로 개선했습니다.

- DATA는 입력, PROCESS는 계산을 담당합니다. 계산 시트당 Python 파일 하나에 반복 행 수식을 묶습니다.
- 각 수식 묶음에 원본 Excel 수식·입력 참조·결과 범위·계산 동작·고정 참조·수정 주의점을 한국어 주석으로 넣습니다.
- 선행 시트와 셀 참조 순서로 계산하며 실제 순환 참조·미지원 수식은 오류로 남깁니다.
- 원하는 결과 셀·표를 지정하면 필요한 입력·수식만 담은 새 프로젝트를 생성합니다. VBA·동적 참조로 범위를 확정하지 못하면 임의로 제외하지 않습니다.
- 상세 진단과 입력 계약은 보조 폴더에 모읍니다. 기존 상세 출력은 `--layout detailed`로 유지합니다.
- 추가 모델 호출·상시 후크·자동 설치 없이 기존 개인 자료와 설정을 유지합니다.

직원 설치 파일은 `Company-Harness-Setup.exe`, ZIP은 `company-agent-1.4.44-2026.09.03.zip`입니다.
별도 개발 중인 Workspace·비전 변경은 이번 배포에 포함하지 않습니다.
실제 사내 DRM·VBA 실행 동등성은 운영환경에서 별도 확인해야 합니다.
