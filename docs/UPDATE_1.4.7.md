# Company Agent 1.4.7 설치·업데이트 안내

## 바뀐 점

스킬 목록의 위치만 알려주던 방식에서, 업무 선택에 필요한 이름·짧은 설명·호출 정보를 대화에 자동 전달하는 방식으로 개선했습니다.

- 처음 시작하거나 대화를 재개·압축하면 선택용 목록을 전달합니다.
- 같은 대화에서는 기존 목록을 재사용합니다. 설치·삭제·설명·우선 설정이 바뀌면 갱신합니다.
- 실제 업무에는 선택한 스킬의 상세 지침만 읽습니다. 모든 스킬 본문을 한꺼번에 읽지 않습니다.
- 목록이 크면 출처별 페이지로 나눕니다. 뒷부분의 스킬을 임의로 제외하지 않습니다.
- 기존 프로젝트별 우선 설정, 개인 스킬, 수동 호출 전용 스킬 제한을 유지합니다.
- 준비 목록 때문에 업무 도구를 반복 차단하는 방식은 추가하지 않았습니다.

`/company-agent:skills`는 목록·우선 설정을 확인하는 명령입니다. 업무 전에 사용자가 반드시 실행할 필요는 없습니다. 실제 문서 읽기는 `company-agent:office-reader`, PPT 제작은 `company-agent:presentation`처럼 별도의 스킬을 사용합니다.

## 업데이트 방법

1. Release에서 **company-agent-1.4.7-2026.09.03.zip**을 받습니다. `Source code (zip)`이 아닙니다.
2. 새 폴더에 전부 압축 해제하고 **Install-CompanyAgent.cmd**를 실행합니다.
3. 기존과 같은 설치 범위를 골라 백업 후 업데이트합니다.
4. Claude Code를 닫았다 다시 실행합니다.

기존 Claude Code와 Python 3.11 이상을 사용하며 설치 과정에서 실행 위치와 조건을 확인합니다. 개인 Memory·Skill·Knowledge·학습 이력과 모델·MCP 설정을 보존합니다. 기존 ZIP이나 개인 자료를 삭제하지 마세요. 파일명 뒤 `2026.09.03`은 회사 지식팩 버전입니다.
