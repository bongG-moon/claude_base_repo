# Company Harness 1.4.49

2026-11-02. 하네스와 개별 스킬을 함께 갱신합니다. 별도 Workspace 앱은 이번 배포에 포함하지 않습니다.

- Outlook 기본 스킬, 로컬 메일 읽기 도우미와 전용 CLI 명령을 제거했습니다. 개인 스킬, 저장 자료와 별도로 설치한 MCP 설정은 유지합니다.
- 반복 생성 HTML의 분석부터 최종 전달까지 공식 도우미로 이어집니다. 버전별 완료 결과는 내부에 보관하고 사용자가 여는 진입 파일 하나만 바꿉니다. 게시 실패 시 이전 정상본을 유지합니다.
- 업무 기록에서 명시적인 “위 결과”를 원래 업무에 연결합니다. 중간 검토 후 스킬로 저장해도 앞선 순서가 유지됩니다. 다른 업무 전환과 부정, 모호한 참조는 구분하고 요청 절차를 실제 실행 성공으로 표시하지 않습니다.
- PPT 네이티브 차트의 음수 막대 색, 범주명 위치와 표시 간격, 선 차트 숫자 위치를 보완했습니다. 글자, 표, 차트의 편집과 기존 초안 승인 검사는 유지합니다.
- 공통 수치를 사용하면 계산값과 기준 이름을 합친 설명, 기간과 범위 정보를 기존 응답에서 재사용할 수 있습니다. 추가 자료 조회나 별도 모델 검증은 하지 않습니다.
- 모바일 표의 ID, 날짜와 기간을 의미별 열 형식으로 표시하고 긴 설명은 읽기 좋게 줄바꿈합니다. 개인 기억 저장의 완료 문구는 요청한 길이 안에서 짧게 안내합니다.

일반 요청에 새 후크, 승인 질문, 모델 호출이나 자동 압축을 추가하지 않았습니다. 보고서, 차트 또는 재생성을 실제 요청했을 때 해당 로컬 코드만 동작합니다. 토큰과 실행시간의 운영 측정 결과를 뜻하지는 않습니다.

## 설치

Release의 `Company-Harness-Setup.exe` 또는 `company-agent-1.4.49-2026.09.03.zip`을 사용합니다. 기존 설치와 같은 범위로 업데이트한 뒤 Claude Code를 다시 연결합니다. 개별 스킬은 `Individual-Skills-1.4.49.zip` 안의 `등록_설치_안내.html`에서 선택합니다.

이번 개별 묶음에는 스킬 15개와 기존 외부 Oracle MCP 1개가 들어 있습니다. Outlook 개별 ZIP은 새 배포에 포함하지 않습니다. 이미 별도로 설치한 개인 사본은 자동 삭제하지 않습니다.

검증 범위와 운영 한계는 [릴리즈 검증 기록](VALIDATION_RELEASE_1.4.49.md)에 정리합니다.
