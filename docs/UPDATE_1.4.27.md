# 1.4.27 변경·설치 안내

## 달라진 점

- 원본 Markdown과 내용이 겹치던 운영 검증 HTML과 전용 생성기를 제거했습니다. 로컬 실습실 대시보드는 원본 검증 문서를 내려받도록 연결하며 기존 35개 실습 시나리오는 유지합니다.
- README의 오래된 중복 안내를 정리하고 스킬 목록의 최신 변경·검증 링크를 갱신했습니다. 예전 구현 검토와 Office Reader 진단 문서는 당시 기록임을 명시하여 현재 사용법과 구분합니다.
- 하네스 실행 로직·스킬·후크·모델·권한 정책은 1.4.26과 동일합니다. 사용자 안내서는 기존 단독 HTML 한 파일을 유지합니다. 개인 자료나 별도 CUA 시험 자료를 삭제하거나 배포에 포함하지 않습니다.

## 설치·업데이트

1. `company-agent-1.4.27-2026.09.03.zip`을 새 폴더에 풉니다. 뒤의 날짜는 회사 지식팩 버전입니다.
2. 기존 설치와 같은 범위에서 백업 후 업데이트하고 Claude Code를 다시 시작합니다. 개인 기억·스킬·지식·모델·별도 MCP 설정을 보존합니다.
3. Workspace는 0.9 실행 코드를 유지하고 안내의 버전·링크만 갱신한 묶음을 함께 제공합니다. 기존 0.9의 실행 기능은 동일합니다.

기존 태그와 설치 ZIP은 덮어쓰지 않습니다. 승인된 Python 3.11 이상과 Claude Code가 필요하며 외부 실행 파일은 내려받거나 동봉하지 않습니다.

## 범위와 제한

이번 버전은 문서·검증 자료 정리입니다. 사내 모델 성능, WS-33 관리자 환경, 비전 모델 선택이나 사내 게이트웨이 문제를 새로 해결한 버전이 아닙니다. 개발 PC의 중복 빌드 파일을 휴지통으로 옮긴 작업은 사용자 PC에서 실행되는 정리 기능이 아니며 설치기가 개인 파일을 자동 삭제하지 않습니다.

검사 결과와 배포 해시는 [1.4.27 배포 검증](VALIDATION_RELEASE_1.4.27.md)을 확인하세요. 이전 기능 변경은 [1.4.26 기록](UPDATE_1.4.26.md)에 보존합니다.
