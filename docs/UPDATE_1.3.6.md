# 1.3.6 · 보고서 디자인과 수치 대조

## 달라지는 점

- HTML 보고서에 표지·지표 중심·좌우 비교·상세표·후속 확인 구성을 제공합니다.
- 핵심 수치는 큰 지표 카드로, 추이는 실제 SVG 막대·가로막대·선·원형 차트로 표시합니다.
  차트 원자료는 기본 접힘으로 유지합니다. 외부 폰트·이미지 생성·다운로드 없이 동작합니다.
- 공통 HTML Skill이 현재 목록에서 필요한 디자인 Skill/참고 지침을 확인하도록 보완했습니다.
  모든 Skill을 로딩하거나 외부 Skill을 자동 설치하지 않습니다. 기존 개인/프로젝트 우선순위를 유지합니다.
- 합계·달성률·증감률을 공통 수치로 계산해 요약과 지표에 재사용합니다. 선언한 기대값이나
  표/차트 총계가 서로 다르면 파일을 만들지 않습니다. 원본과 요약을 덮어쓰지 않습니다.
- 단축키 검색 HTML도 배포 문서에 포함합니다.

## 직원 적용

1. `company-agent-1.3.6-2026.09.03.zip`을 새 폴더에 모두 압축 해제합니다.
2. `Install-CompanyAgent.cmd`를 실행하고 기존과 같은 설치 범위를 선택합니다.
3. 백업 후 업데이트하고 Claude Code를 닫았다 다시 엽니다.

개인 Memory·Skill·Knowledge·모델·MCP 설정은 기존 설치기의 보존 절차를 따릅니다.
이번 제작 과정에서 현재 PC의 설치본을 직접 바꾸지는 않았습니다.
기존 버전 폴더에 수동 덮어쓰기하지 마세요. GitHub 게시와 로컬 ZIP 제작은 별개입니다.

## 확인용 채팅

“이 자료로 부서장용 HTML 보고서를 만들어줘. 깔끔한 업무형, 보통 분량, 페이지 넘김으로.
현재 설치된 디자인 관련 스킬 중 적합한 것이 있으면 참고하고, 핵심 지표·실제 그래프·
확인할 사항을 구분해줘. 합계와 달성률은 원자료에서 계산해 요약과 표가 같은 수치를 쓰게 해줘.”

기존에 만든 보고서는 자동 변경하지 않습니다. 재작성할 때 새 파일명으로 요청하세요.

## 검증 범위와 한계

생성기는 선언한 `facts` 계산식·기대값·`checks` 대조만 검증합니다. 자유문장에 직접 쓴 숫자,
입력 데이터의 진위, 추론한 원인은 자동 검증하지 않습니다. 근거 파일과 대조해야 합니다.
결과의 `arithmetic=checked`를 전체 보고서 검증 성공으로 취급하지 않습니다.
실제 화면을 볼 권한이 없다면 화면 미검증을 명시하고 우회하지 않습니다.
디자인은 안전한 구성요소의 조합이며 임의 코드나 외부 디자인 Skill의 실행 권한을 허용하지 않습니다.
