# 회사 기준 / 개인 업무 개편 검증

2026-09-18 · 개발 기준 1.4.14 · 로컬 검증 완료, 사내 운영 동작은 미확인

이번 변경은 회사 관리와 개인 업무 두 영역만 사용한다. 부서별 기준은 회사 기준에 포함하며 별도 팀팩 설치·관리 계층을 추가하지 않는다. 프로젝트는 적용 범위다. 공개 Release와 기존 `dist` 설치본은 이번 작업에서 갱신하지 않았다.

## 반영 범위

- 등록된 회사 설정의 `workStandards`를 읽고 필수 기준과 개인화 가능한 기본값을 구분한다. 작업 폴더의 동명 파일을 회사 기준으로 대신 사용하지 않는다.
- 해당 업무의 기준만 제한된 크기로 전달하며, 생략된 기준은 원본 위치를 명시한다. 준비 안내는 접근 권한을 부여하지 않는다.
- 오프라인 첫 업무 안내와 기존 연습실을 연결한다. 안내 화면 자체는 실행·저장·외부 통신을 하지 않는다.
- 기존 진단기에 새 HTML 보고서와 명시적으로 선택한 로그의 사용량·중복 읽기·Office 단계 시간 분석을 추가한다.
- 프로젝트 생성기 v3에 관리 경계와 실제 결과 확인 기준을 추가한다. 기존 v1/v2 소유권 검증과 개인 파일 보존 절차를 유지한다.

## 검증 중 발견해 보완한 부분

1. 회사 설정이 없는 기본 묶음에도 관리 예제의 기준이 실제 `managed.json`으로 포함되도록 연결했다. 예제 MCP 서버는 활성화하지 않는다.
2. 한글·공백·이모지가 포함된 긴 설치 경로에서 안내가 예산을 넘으면 실행 경로가 사라지는 문제를 실제 CLI 시험으로 발견했다. 중복 안내를 짧게 정리하고 긴 경로 회귀 시험을 추가한 뒤 분리 설치 시험을 다시 통과했다.
3. 예전 운영 시험 문서의 버전 표기로 연습실 생성이 중단되는 문제를 수정했다. 제작기는 현재 소스 버전을 사용하며 공개 설치본을 몰래 교체하지 않는다.
4. 토큰 기록 누락을 0으로 취급하지 않고 부분 관찰로 표시한다. 같은 메시지의 반복 사용량 기록은 합산하지 않으며, 서로 다른 읽기 범위는 반복으로 세지 않는다.
5. 짧은 한국어 안내로 바뀐 검증·권한 문구를 기존 계약 시험에도 반영했다. 변경 업무만 완료 확인하고, DB 조회 전용·Outlook 본인 계정 제한·미실행 상태를 구분하는 검사는 유지했다.

## 속도와 사용량에 대한 확인 범위

회사 기준은 최대 1,200자와 필요 시 원본 확인 방식으로 전달한다. 스킬 선택용 추가 모델 호출·상시 로그 수집·전체 스킬 본문 반복 주입은 추가하지 않았다. 회사 기준 연결이 없던 기존 설정도 그대로 동작한다.

기존 오프라인 목록 확인 벤치마크도 통과했다. 이 벤치마크는 1.4.12와 비교한 문자 수·로컬 처리 시간이며, 이번 개편만의 토큰 절감량이나 사내 모델/문서 실행 시간 개선율로 해석하지 않는다. 실제 사내 토큰 및 지연은 명시적으로 선택한 운영 로그에서 확인해야 한다. 단가가 없으면 비용은 미확인으로 남긴다.
