# Company Agent 1.4.3 — 스킬 선택과 업무 실행 연결

## 설치

아래 Assets에서 **company-agent-1.4.3-2026.09.03.zip**을 받으세요.
`Source code (zip)`은 직원용 설치파일이 아닙니다.

1. Claude Code의 작업을 마무리하고 종료합니다.
2. ZIP을 새 폴더에 모두 압축 해제합니다.
3. `Install-CompanyAgent.cmd`를 더블클릭합니다.
4. 기존과 같은 범위를 선택하고 **백업 후 업데이트**를 진행합니다.
5. 완료 후 Claude Code를 다시 실행합니다.

기존 개인 Memory·학습 이력·Skill·Knowledge·모델·MCP 설정은 유지합니다.
이미 설치된 Python 3.11 이상과 Claude Code를 사용하며 자동 다운로드하지 않습니다.
파일명 뒤 `2026.09.03`은 회사 지식팩 버전입니다.

## 개선 내용

- 전체 스킬 목록 → 선택한 스킬 읽기 → 실제 업무 실행을 연결했습니다.
- 개인·프로젝트 우선 설정과 명시적 스킬 호출을 유지합니다.
- 이미 읽은 목록과 스킬을 재사용하고, 변경·삭제·컴팩트 이후 재확인합니다.
- 조율 지침만 읽고 업무 스킬 선택을 생략하는 경우를 보완했습니다.
- 작업자에게 선택한 스킬의 정확한 파일 위치를 전달합니다.
- 준비 누락은 실행 전에 안내하고, 이를 업무 마지막의 검증 실패로 기록하지 않습니다.
- 플러그인 표시와 내부 CLI 버전을 1.4.3으로 일치시켰습니다.
- 변경·설치 안내와 상세 검증 기록을 설치 ZIP에 포함했습니다.
