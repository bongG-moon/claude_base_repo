# Company Agent 1.4.9 — 스킬 선택·중복 질문·한글 입출력 개선

## 설치 파일

첨부된 **company-agent-1.4.9-2026.09.03.zip**을 받으세요. GitHub의 `Source code (zip)`은 직원용 설치 파일이 아닙니다.

압축을 새 폴더에 풀고 **Install-CompanyAgent.cmd**를 실행한 뒤, 기존과 같은 설치 범위를 선택해 백업 후 업데이트하세요. 완료 후 Claude Code를 닫았다 다시 실행합니다.

Claude Code와 Python 3.11 이상은 기존 설치를 사용합니다. Python 실행 파일은 ZIP에 포함하지 않습니다. 파일명 뒤 날짜는 회사 지식팩 버전입니다.

## 주요 변경

- 목록을 재사용해도 현재 업무의 관련 스킬 설명과 경로를 짧게 전달합니다.
- 스킬 역할이 겹치고 우선 설정이 없으면 한국어로 선택을 묻도록 보완했습니다. 선택은 이번 요청에만 적용하며 기본값 저장은 별도 요청 때만 합니다.
- 등록된 Python·개인 저장 위치·UTF-8 실행 경로를 통일했습니다. 표시 오류만으로 메일 발송·파일 이동을 반복하지 않도록 했습니다.
- 기존 개인 Memory·Skill·Knowledge·학습 이력과 모델·MCP 설정은 보존합니다.
- 사용자 안내서(HTML/Markdown), 업데이트 안내와 검증 기록을 설치 ZIP에 포함했습니다.

전체 자동 검사 688개(제외 0개)를 통과했습니다. 실제 사내 모델의 선택 정확도와 운영 Office/DRM 호환성은 별도 운영 확인이 필요합니다.

설치 ZIP의 SHA-256은 함께 제공하는 `.sha256` 파일에서 확인할 수 있습니다.
