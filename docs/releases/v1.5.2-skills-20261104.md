# 개별 스킬 업데이트 — 2026-11-04

HTML, PPT와 데이터 조회 스킬을 실제 사용 흐름에 맞춰 개선했습니다. 기본 하네스는 1.5.2를 유지합니다. 기억과 지식, 개인 설정에 대한 변경이나 새 상시 후크는 없습니다.

## 바뀐 동작

- PPT: 모든 디자인의 기본 결과를 페이지 이동, 전체 보기, 메모, 문구와 표 셀 편집, 저장 및 인쇄가 가능한 HTML 발표본으로 만듭니다. PPTX가 필요할 때 현재 HTML을 검토하고 승인한 후 편집 가능한 글자, 표, 차트와 도형으로 내보냅니다.
- PPT 참고 자료: 일반 PPT를 읽을 수 없을 때 XML이라고 단정하지 않고 PowerPoint의 정상 열기와 장별 이미지 내보내기 경로를 안내합니다. 새 PPT를 만들 때 설치된 `default.pptx`에 의존하지 않습니다. 보호 해제나 보안 설정 변경을 수행하는 기능은 아닙니다.
- PPT 흐름도: 판단 도형의 글자 공간, 분기 및 건너뛰는 연결선, 연결 라벨의 간격을 생성 코드와 검증 항목에 반영했습니다. 결과 파일만 수동 보정한 변경이 아닙니다.
- HTML: 10개 디자인과 3개 참고 배치의 예제, 양식 선택 화면, 실제 미리보기 링크 전달을 보완했습니다. 한국어 글꼴과 라이선스, 표의 검색과 페이지 이동 및 데이터 내려받기 기능을 패키지에 포함합니다.
- 웹 화면: 기존 글꼴 선택을 존중하면서 한국어 글자 크기, 자간과 행간 기준을 정리했습니다. 상세 설명은 필요한 참고자료로 분리했습니다.
- 데이터 조회: 등록할 조건 변수 후보가 있을 때 선택하고, 일반 조회는 기존 한도 안에서 실행합니다. 위험하거나 한도를 늘리는 요청은 승인을 유지합니다. PowerShell에서 `--param 이름=값`으로 조건을 전달하고 조회와 CSV 저장을 한 번에 실행할 수 있습니다. 기존 결과의 임의 재사용을 금지하고 결과 파일과 내부 작업 자료를 구분합니다.
- 인증정보는 로컬 입력창으로 안내하며 데이터 전체를 LLM에 읽히지 않습니다. 조회 결과 미리보기는 필요한 경우에만 기본 5행, 최대 20행입니다.

이번에 변경된 ZIP은 `asset-factory`, `data-query-demo`, `datalake-query`, `ehub-query`, `html-report`, `oracle-query`, `presentation`, `web-interface`, `website-rebuild` 9개입니다. 묶음에는 독립 스킬 15개와 기존 별도 MCP 1개를 제공합니다. 기본 하네스 없이 필요한 스킬만 설치할 수 있습니다.

## 검증 범위

- 조회 스킬: 더미 및 모의 연결을 사용한 전체 회귀 313개 통과, 건너뜀 없음. 제한 환경에서 발생한 로컬 통신 및 테스트 링크 오류는 해당 검증 권한으로 코드 변경 없이 재실행해 해소했습니다.
- HTML/PPT: 357개 검사 범위에서 355개 통과, 브라우저 전용 2개 미실행입니다. 오래된 문구 비교와 불완전한 테스트용 모듈 목록을 고친 후 관련 15개를 재실행해 통과했습니다. 앞선 흐름도 핵심 검사 151개는 이 범위와 중복되므로 합산하지 않습니다.
- 플랫폼 패키지: 설치, 재설치 시 설정 보존과 별도 MCP의 빈 설정 연결을 포함해 70개 모두 통과했습니다. 운영 서버에는 연결하지 않았습니다.
- 기본 하네스: 설치 manifest의 실제 대체 원본까지 포함한 109개 파일이 기존 커밋과 동일합니다. 이번 기능 변경으로 기본 설치 구성이 늘어나지 않습니다.
- 개별 ZIP: 독립 스킬 15개 모두 현재 원본과 파일 집합 및 정규화 바이트가 일치합니다. HTML/PPT 실행 모듈과 상대 리소스의 누락, 글꼴 해시와 라이선스를 확인했습니다.
- 실제 제작: Claude Code로 HTML 13개 디자인과 PPT 6개 디자인을 생성한 비교를 수행했습니다. PPT는 디자인별 10장, 총 60장을 PowerPoint로 렌더링했습니다. 이후 발견한 흐름도 문제를 스킬에 보완하고 해당 결과를 다시 렌더링했습니다.

마지막 스킬 보완 후 Claude Code 재실행은 세션 사용 한도로 중단되어 Codex가 같은 제작 엔진으로 최종 생성과 PowerPoint 렌더를 완료했습니다. 마지막 버전의 Claude Code 전체 완료 흐름이나 최신 HTML의 브라우저 동작이 검증됐다는 뜻은 아닙니다. HTML 문구 편집은 글자와 표 셀 편집이며, 도형 끌기나 차트 데이터 직접 편집까지 제공하는 전체 편집기는 아닙니다.

사내 DRM, 운영 DB와 사내 모델은 별도 확인이 필요합니다. 로컬 Python 처리 시간이 짧아도 실제 대화 전체 시간이나 토큰 사용량이 그만큼 감소한다고 단정하지 않습니다. [단계별 구현 기록](../INDIVIDUAL_SKILLS_IMPROVEMENTS_20261103.md)
