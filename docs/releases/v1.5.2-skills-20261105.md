# 개별 스킬 업데이트 — 2026-11-05

엑셀 분석, HTML 보고서, 발표자료 스킬의 실제 사용 과정에서 확인된 문제를 개선했습니다. 기본 하네스는 1.5.2를 유지합니다. 새 기능은 필요한 개별 스킬을 설치하거나 갱신해 사용합니다.

## 변경 사항

- **엑셀 분석:** 일반 파일은 직접 읽고 필요한 경우에만 Excel에서 읽습니다. 빈 서식으로 늘어난 범위를 제외하고 블록 단위로 읽으며 누적 분석 한도를 25만 셀에서 200만 셀로 조정했습니다. 병합 경계와 셀 누락을 확인하고 오류값과 수식 원문을 구분해 보고합니다.
- **엑셀 사본:** 요청하면 결과 범위와 선행 데이터, 수식만 새 XLSX로 만들 수 있습니다. 원본은 변경하지 않습니다. 수식 결과 캐시는 옮기지 않고 수동 계산 상태로 저장하며, 동적 참조와 외부 연결 등 완전한 범위를 확정하지 못한 경우에는 제한을 안내합니다.
- **HTML 보고서:** 참고 HTML에 실제 적용된 색상과 글꼴을 더 정확히 읽고, 긴 목차는 이동 안내와 키보드 이동을 제공합니다. 차트에 마우스와 터치, 키보드 툴팁을 지원합니다. 참고 배경에 맞춰 카드 글자색을 조정해 작은 글씨의 대비를 개선합니다.
- **발표자료:** HTML에서 표와 흐름도의 잘림, 겹침 후보를 확인합니다. PPTX로 내보낼 때 지원하는 표의 행 높이와 여백, 한글 줄바꿈과 부분 강조를 보정합니다. 확인하기 어려운 표나 복잡한 서식은 경고합니다. 외부 연결이 있는 참고 PPT가 차단되면 다른 경로로 우회하지 않습니다.
- **웹 데이터 조회 절차:** `web-api-discovery`는 사용이 허용된 사이트의 공식 API 또는 이미 연결된 브라우저의 네트워크 관찰 기능을 이용해 재사용할 조회 코드를 만드는 독립 스킬입니다. 숫자 페이지와 커서 방식의 GET JSON 조회기는 Python 표준 라이브러리로 실행합니다. 인증값은 대화에 입력하지 않고 사용자가 환경 변수에 직접 설정하며 원격 인증에는 HTTPS를 요구합니다. GET이라는 이유만으로 서버 상태 변경이 없다고 가정하지 않고 실제 API 계약을 확인합니다. 브라우저 도구를 자동 설치하거나 접근 제한을 우회하지 않습니다.

## 확인한 범위와 제한

8시트의 합성 엑셀에서 수식 11,499개를 계산하고 원본 캐시와 대조했습니다. 생성한 Python 프로젝트의 최종 지표 7개와 별도 XLSX 사본의 Excel 재계산 결과도 비교했습니다. 원본 표의 헤더와 경계가 모호한 경우 검토 표시가 남으며, 임의의 VBA와 모든 Excel 수식이 자동으로 변환되는 것은 아닙니다. 28만여 셀의 별도 합성 파일은 Excel 읽기 경로에서 값과 수식을 전수 비교했습니다.

Claude Code로 HTML 참고 양식과 발표자료를 다시 생성하고, 브라우저와 PowerPoint 화면에서 문제 사례를 확인했습니다. PPTX의 표, 한글 줄바꿈과 흐름도는 시험한 사례에서 개선됐으나, 복잡한 CSS와 SVG, 다른 PC의 글꼴에 대한 완전한 화면 일치와 모든 요소의 편집성을 보장하지 않습니다. HTML 참고 양식도 색상, 글꼴과 구조 단서를 반영하며 원본 페이지 전체의 복제를 뜻하지 않습니다.

최종 4개 HTML 재시험은 완료됐습니다. 기본 지표형에서 발견한 밝은 라벨은 색 대비를 수정해 같은 작업 명세로 별도 재생성하고 PC와 모바일 화면에서 확인했습니다. 이후 PPT 3건의 전체 재실행은 Claude Code 계정 사용 한도로 완료하지 못했습니다. 해당 실행에 완성본이 있다고 표시하지 않습니다.

실제 사내 DRM 파일, 사내 모델과 운영 환경에서의 처리 허용 여부는 이번에 확인하지 못했습니다. 모델 호출이나 상시 후크를 추가하지 않았으며 개인 기억과 지식, 다른 사용자의 설정은 변경하지 않습니다.

웹 데이터 조회기는 로컬 모의 서버에서 페이지와 커서 이동, 결과 제한과 접근 오류를 시험했습니다. 명확한 인증정보와 커서 필드를 저장 및 미리보기에서 가리고 개수를 알리지만, 모든 민감정보를 자동으로 탐지한다고 보장하지 않습니다. 실제 회사 사이트의 네트워크 관찰 기능, 로그인과 데이터 접근 권한은 이번에 확인하지 않았습니다. 원본 [Reverse API Engineer](https://github.com/kalil0321/reverse-api-engineer)의 접근 방식을 참고했지만, 해당 CLI나 원본 코드를 포함하지 않습니다.
