# 개별 스킬 두 번째 업데이트 — 2026-11-04

발표 제작을 자유 HTML 중심으로 바꾸고, 한국어 Huashu 발표 스킬을 추가했습니다. 개별 스킬 16개와 기존 별도 MCP 1개를 제공합니다. 이번에 배포하는 기본 하네스 설치 파일은 이전 1.5.2 공개 파일과 동일합니다. 기능 스킬을 사용하기 위해 하네스를 다시 설치할 필요가 없습니다.

## 달라진 사용 흐름

- `presentation`: 고정 페이지 역할이나 카드 JSON 대신 내용에 맞게 HTML/CSS를 작성합니다. 기본 화면은 한 장씩 넘기는 발표이며 이전/다음, 좌우 방향키, 페이지 번호와 별도 전체 보기를 제공합니다. 문구와 표 셀, 글꼴, 굵기, 색상, 도형 묶음 이동과 크기, 장 순서를 편집해 새 HTML로 저장합니다. 인쇄에는 모든 장을 포함합니다.
- PPTX 내보내기: 사용자가 요청한 경우 마지막 저장 HTML을 변환합니다. 실제 장 크기를 읽고 한 줄로 보이는 숫자와 문구의 불필요한 줄바꿈을 보정합니다. 원본 내용, 글꼴, 도형 좌표와 크기는 바꾸지 않습니다. SVG와 복잡한 효과는 그림일 수 있으며 모든 요소의 편집성과 동일한 화면을 보장하지 않습니다.
- `huashu-presentation`: Huashu Design의 MIT 발표 기능을 선별한 한국어 독립판입니다. 원본 엔진과 출처, 라이선스를 보존합니다. 다른 분야 기능이나 별도 라이선스의 스티커를 포함하지 않습니다. HTML은 문구 수정과 저장을 지원하지만 범용 개체 드래그 편집기는 포함하지 않습니다. PPT의 표는 개별 도형과 텍스트이며 SVG와 canvas는 그림입니다.
- 참고 자료: 여러 장 이미지와 PPT, HTML에서 글꼴, 배치, 도형, 표 밀도와 색 조합을 관찰해 새 내용에 적용합니다. PowerPoint의 권한 정보 조회 실패만으로 정상 열기까지 금지된 것으로 단정하지 않습니다. 실제 보호 정책으로 거절된 기능은 해제하지 않습니다.
- HTML 보고서: 아직 정하지 않은 디자인, 분량과 폰트를 한 번에 확인하고 이전 선택을 재사용합니다. 표의 검색, 정렬, 표시 열 선택, 페이지 이동, 현재 조건 CSV와 전체 CSV를 선택한 디자인에 맞게 제공합니다.
- 조회 스킬: 조건이 명확하면 한 번의 실행으로 새로 조회하고 CSV를 전달합니다. 최근 같은 쿼리와 조건으로 완료한 작은 조회의 범위 확인을 재사용하며 데이터 결과 자체는 임의로 재사용하지 않습니다. Oracle은 필요한 경우 한도를 넘는지 제한된 건수 확인으로 판단합니다. 새 위험이나 한도 초과에는 승인이 유지됩니다. 결과 저장 영수증을 사용해 전체 CSV 재읽기와 줄 수 검증을 반복하지 않습니다.
- 결과 폴더: 새 기본 결과는 스킬 이름 아래 `outputs`, 중간 자료는 `.work`로 구분합니다. 사용자가 지정한 경로와 기존 개인 자료는 유지합니다. 추가 상시 후크, 모델 호출이나 종료 검증 단계를 넣지 않았습니다.

## 실제 비교 결과와 한계

같은 합성 주제와 참고 자료, Claude Code 모델로 유효 6조건의 첫 HTML과 PPTX를 비교했습니다. 생성 후 결과물을 수작업으로 다듬지 않았습니다. HTML 58장과 PowerPoint 58장을 렌더해 전체 장표 시트를 검토하고 문제 장을 확대했습니다.

| 조건 | 평가 점수 |
|---|---:|
| 스킬 없음 | 84 |
| Huashu 원본 | 83 |
| 새 presentation의 첫 실행 | 82 |
| GX HTML2PPTX | 73 |
| Frontend Slides Editable + dom-to-pptx | 71 |
| HTML to Editable PPTX | 63 |
| Dashi | 생성 미완료, 미채점 |

한 주제와 한 번의 유효 실행에 대한 평가이며 1~2점 차이를 일반적인 우열로 해석하지 않습니다. 외부 후보 중 가장 높은 Huashu를 새 개별 스킬의 기반으로 선택했습니다. 같은 첫 HTML을 개선된 변환기로 재내보낸 PPTX는 별도 자료이며 최초 점수에 섞지 않았습니다.

Dashi 공식 실행과 보완한 지침의 새 Claude 생성 시험은 계정 세션 한도로 완료하지 못했습니다. 무스킬 결과의 OS 파일 저장 창은 컴퓨터 사용 도구가 브라우저 주소를 확인하지 못해 미검증입니다. 미검증을 실패 점수나 제품 결함으로 단정하지 않습니다. 실제 사내 모델, DRM 문서와 운영 DB는 이번 검증에 포함하지 않았습니다.

## 배포와 검증

관련 자동 테스트는 수정 항목 재검증까지 합쳐 806개 통과, 4개 건너뜀입니다. 실제 브라우저 편집 17항목과 내보내기 4시나리오, HTML 표 8시나리오와 CSV 16개를 별도로 확인했습니다. 두 발표 ZIP을 각각 압축 해제해 실제 변환을 실행했으며, Huashu의 SVG와 canvas 혼합 순서 및 presentation의 원본 라이브러리 무결성 문제도 수정 후 재검증했습니다.

개별 패키지 17개의 최신 소스 일치 검사와 Git 인덱스 기준 소스 해시 594건, 라이선스와 비밀정보 패턴 검사를 통과했습니다. 원본 외부 라이브러리는 줄바꿈까지 보존합니다. 소스와 개별 ZIP, 카탈로그, 라이선스, 체크섬을 함께 갱신합니다. 개인 프로필 설치, AI SQUARE 게시나 사내 GitLab 업로드를 자동 수행하지 않습니다.

- `individual-skills-1.5.2-20261104-r2.zip`: 개별 ZIP 17개와 설치 안내, 카탈로그, 체크섬을 담은 묶음입니다. 필요한 스킬 ZIP만 골라 설치합니다.
- `presentation.zip`, `huashu-presentation.zip`: 두 발표 스킬의 개별 다운로드입니다.
- 기존 1.5.2의 설치 EXE, 하네스 ZIP, GitLab 묶음과 사용자 안내서는 바이트를 바꾸지 않고 함께 제공합니다.

기본 하네스, 앱과 Workspace의 별도 진행 변경은 이번 개별 스킬 릴리즈에 포함하지 않습니다. 소스의 기능 스킬 폴더 전체가 직원용 기본 설치 목록을 뜻하지는 않습니다.
