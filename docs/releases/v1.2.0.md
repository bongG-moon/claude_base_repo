# Company Agent 1.2.0 — 업무팩 시범 운영판

Windows에서 기존 Company Agent를 업데이트해 사용할 수 있는 업무팩입니다. 실제 회사 Outlook·Office·DRM·사내 모델 통합 검증 전이므로 **Pre-release(시범 운영판)**로 제공합니다.

## 추가된 기능

- 파일 정리: 정리안 먼저 확인, 실제 사용자 승인창, 덮어쓰기 없는 이동, 변경되지 않은 파일의 명시적 되돌리기.
- Outlook: 기존 사내 MCP 우선 사용, 이미 실행 중인 Classic Outlook의 계정·선택한 메일함/PST 읽기 전용 시범 연결, 본문 전달 전 별도 확인.
- HTML 보고서: 8가지 디자인, 스크롤·슬라이드·둘 다 선택, 외부 서비스 없이 열 수 있는 파일 생성.
- PPT: Python 기반 편집 가능한 글·표·차트 생성, 참고 PPT 테마·기본 틀 재사용, 미리보기만 실패한 경우 부분 완료 안내.
- 보호 설정: 제한된 항목만 중단하고 제외 범위를 안내. 캡처·OCR·다른 앱·보호 해제로 우회하지 않도록 지침과 오류 처리를 추가하고 해당 세션의 자유 서술 자동 학습 저장을 제한.
- Skill 시작 경고: 정상적인 이름 공존·해결된 선택과 실제 미해결 충돌·사라진 선택·조회 오류를 구분.
- 업데이트된 상세 사용자 안내서와 업무별 시범 사용 예시 포함.

## 설치 또는 업데이트

Claude Code와 회사에서 승인한 Python 3.11 이상이 이미 설치된 Windows PC가 대상입니다. 새 모델 연결이나 외부 프로그램 다운로드는 하지 않습니다.

1. Claude Code 작업을 저장하고 닫습니다.
2. ZIP 전체를 새 폴더에 압축 해제합니다.
3. 최상위 `Install-CompanyAgent.cmd`를 평소처럼 더블클릭합니다.
4. 기존 설치와 같은 범위(Claude 전체 또는 해당 프로젝트)를 선택하고 업데이트합니다.
5. Claude Code를 다시 열고 대화창에 `/company-agent:business-check`를 입력합니다.

정상 업데이트는 개인 Memory·Knowledge·Skill·학습 내역, 모델과 MCP 설정을 유지합니다. 기존 하네스를 교체하는 Replace와 일반 Update는 다릅니다. 새 업무는 승인된 연습 자료로 먼저 시험하세요.

## 현재 한계

- 새 Outlook 경로는 읽기 전용입니다. 발송·PST 생성·실제 메일 이동은 별도 사내 MCP가 필요하며, 첨부파일은 정보 목록만 조회합니다.
- 본문이 읽혔다는 이유로 첨부도 읽었다고 설명하지 않습니다. 실제 보호 오류와 단순 미지원·미조회는 구분합니다.
- PPT는 이미지 전체를 완벽하게 편집 객체로 복원하는 기능이 아닙니다. 실제 PowerPoint 자동화·회사 양식의 육안 검증은 별도로 필요합니다.
- 새 이미지 생성 API를 자동 연결하지 않습니다. 이미 연결된 승인 도구만 활용합니다.
- 범용 DRM 탐지·권한 집행·OS 격리 제품이 아니며 Claude 자체 대화 기록의 저장 정책을 바꾸지 않습니다.

## 검증

- Python 회귀 테스트 310개 통과, 제외 0개. 선택 실행하는 실제 Claude 설정 검사는 임시 설정 폴더에서 실행했습니다.
- Windows PowerShell 5.1 일반·CP949 설치, User/Project 등록, 업데이트, 실패 복구, 개인 상태 보존 검사 통과.
- Skill 충돌 38개, 설치 인코딩 42개, Claude 탐색 17개 검증과 개인 상태 백업·배포 묶음 검사 통과.
- 합성 HTML을 브라우저에서 페이지 넘김·모바일 줄바꿈·스크립트 삽입 차단·외부 요청 없음으로 확인했습니다.
- 합성 PPT의 글·표·차트를 편집하고 저장·다시 열기를 확인했습니다. 실제 Outlook·PowerPoint COM·사내 DRM 통합 시험과는 구분합니다.
