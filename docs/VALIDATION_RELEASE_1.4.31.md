## 검사 중 확인한 사항

- README의 “이번 소스의 배포 대상” 표현이 기존 설치 안내 계약과 맞지 않았습니다. 버전 안내를 기존 형식으로 고쳤고 테스트를 완화하거나 제거하지 않았습니다. 실패는 안내 문구 검사 한 건이며 기능 검사에서 다른 실패는 없었습니다.
- 작업 디렉터리에는 별도 Workspace 0.21 개발과 충돌하는 검사가 남아 있습니다. 이를 이 Release의 통과로 간주하지 않고, 이전 공개 소스에 이번 개선분만 합친 별도 소스에서 검사했습니다. 해당 개발 파일과 개인 자료는 삭제·되돌림하지 않습니다.
- 이전 공개 Release·태그·ZIP은 보존합니다. 동일 버전 다른 내용 덮어쓰기 방지와 기존 권한 검사는 유지합니다.
- Git 텍스트 줄바꿈 정규화와 ZIP 원본 바이트 비교는 구분합니다. 패키지 감사는 실제 ZIP과 선택 소스 바이트를 직접 대조했습니다.

## 확인하지 않은 범위

실제 사내 HCP의 지침 적용 정확도·업무 성공률·체감 속도·토큰 절감량, Office/DRM 통합, WS-33, 비전 모델·게이트웨이는 이번 검증 대상이 아닙니다. 승인·보안 정책과 계정 설정을 변경하지 않습니다.

콘텐츠 구조와 선언된 순서 검사는 글의 의미·문장 수·모든 실제 화면의 완성도를 보증하지 않습니다. 기억 저장 확인도 모델이 이후 답변에 그 기억을 적용했다는 증거는 아닙니다. 자동학습의 기존 저장 범위를 개인/프로젝트 간에 자동 변경하지 않습니다.
