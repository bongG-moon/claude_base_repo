# 1.3.9 검증 기록

## 대상

HTML 질문 순서와 선택 보존. 기존 개인 상태·모델·MCP 설정을 수정하지 않습니다.

- 최초 질문은 디자인만 반환하며 분량/보기 옵션을 숨깁니다.
- 추가 디자인은 세부 8개 선택을 즉시 반환하며 미리보기는 선택 사항입니다.
- 상세/스크롤을 이미 입력한 문제 사례는 디자인만 묻고 ready로 넘어갑니다.
- 이미 정한 디자인 또는 일부 형식은 다시 묻지 않습니다.
- 잘못된 선택과 보호 표시는 거부하고 선택 조회는 보고서 원본 이미지를 읽지 않습니다.
- 실제 CLI 프로세스로 최초 → 세부 선택 → 준비 완료 응답을 검사합니다.
- 선택 조회 명령은 읽기 전용으로 분류하지만 승인 범위를 넓히지 않습니다.
- 질문 도구에 디자인/분량/보기를 묶지 않도록 Skill 지침 계약을 검사합니다.

## 실행 결과 (2026-09-13)

- Python 전체 검사: 514개 통과, 제외 0개 (96.648초).
- 디자인 선택 화면 동작 검사: 17개 통과 (브라우저 없는 상호작용 검사).
- 기존 단축키 안내 동작 검사: 16개 통과.
- 배포 미리보기와 공통 테마 일치 검사: 통과.
- 오프라인 설치 압축파일 회귀 검사: 통과. 기존 Python 3.11 이상 사용,
  실행 파일·문서 포함 및 무결성 검사. 현재 사용자 환경에는 설치하지 않았습니다.

## 검증 한계

자동 검사는 단계 반환과 CLI 실행, 지침 문구를 검사합니다. 실제 사내 Claude 모델의
대화 화면이 항상 이 지침을 따르는지까지 검증한 것은 아닙니다. 모델이 지침을 무시하고
도구 밖에서 임의 질문을 만드는 모든 경우를 UI 수준에서 강제 차단하는 기능은 아닙니다.
이번 수정은 디자인 선택 순서이며 HTML 미리보기의 브라우저 육안 검증은 새로 하지 않았습니다.
