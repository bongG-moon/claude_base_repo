# 비전 입력 비교 — 필요할 때만 하는 별도 시험

**하네스에 설치하지 않습니다.** 이 폴더를 회사 PC에 복사해 필요할 때만 실행하세요. 평소 업무의 후크·스킬·모델 설정·기억·토큰 사용량은 바뀌지 않습니다. `시작하기.html`을 두 번 클릭하면 같은 안내를 볼 수 있습니다.

## 먼저 알아둘 점

비전 기능이 있는 모델이라는 사실과 **현재 회사 연결 경로에서 이미지를 정확히 읽는 것**은 다릅니다. 이번 시험은 어느 구간을 더 확인할지 좁히는 용도입니다. 모델 자체나 게이트웨이의 정상 여부를 단독으로 확정하지 않습니다.

가상 이미지 2개만 제공합니다. 각 640×360 PNG이며 회사 자료·개인정보가 없습니다. 먼저 `sample-01.png` 한 장으로 시작하세요. 정답표나 이 안내서를 모델에게 함께 보내지 마세요.

| 구분 | 무엇을 비교하나요? | 호출 수 |
| --- | --- | --- |
| A | API 사용자 메시지에 일반 이미지로 넣기 | 1회 |
| B | 같은 이미지를 `Read`의 도구 결과 형식 안에 넣기 | 1회 |
| C | 실제 Claude Code에서 비전 작업자가 파일을 `Read`로 읽기 | 사용자가 별도로 요청 |

**B는 도구 결과 형식을 재현한 시험이지 실제 CLI 실행이 아닙니다.** A/B는 같은 모델·이미지 바이트·질문·시스템 지침·도구 정의·출력 상한(각 600토큰)을 사용합니다. B만 도구 호출/결과 이력이 추가됩니다. 두 요청은 독립적이며 이전 답변을 서로 전달하지 않습니다. 도구 정의는 비교 조건을 맞추기 위해 양쪽에 있지만 추가 도구 호출은 `tool_choice: none`으로 요청합니다. 실제 도구를 실행하는 코드는 없습니다.

## 1. 보내기 전 확인 — 무료, 오프라인

이 폴더에서 터미널을 열어 아래 한 줄을 실행합니다. Python 3.9 이상이면 되고 추가 패키지 설치는 없습니다.

```powershell
python -X utf8 compare_inputs.py
```

`mode: offline`, `network_calls: 0`, `credentials_read: false`가 나오면 준비 확인이 끝났습니다. 이미지 크기와 해시만 확인하며 네트워크·인증값·Claude 설정은 읽지 않습니다. 요청 JSON이나 base64도 저장하지 않습니다.

## 2. 회사 승인 주소로 A/B 비교 — 총 2회

회사 담당자에게 **Anthropic Messages 호환 게이트웨이 주소, 호출 모델명, 인증 방식**을 확인합니다. 아래 주소만 실제 승인 주소로 바꿉니다. 인증값은 명령어에 넣지 않습니다.

```powershell
python -X utf8 compare_inputs.py --send --base-url "https://승인된-게이트웨이" --model "HCP-Vision-Latest"
```

인증값 입력란에 값을 넣어도 화면에 표시되지 않으며 파일로 저장하지 않습니다. 기본은 `Authorization: Bearer` 방식입니다. 회사가 `x-api-key`를 요구하면 `--auth-header api-key`를 추가합니다. 담당자가 이미 현재 프로세스에 `VISION_TEST_TOKEN`을 준비했다면 그 값만 사용합니다. `.claude/settings.json` 등에서 인증값을 찾아 읽지 않습니다.

회사의 승인 주소가 **HTTP**인 경우에만 `--allow-http`를 추가합니다. HTTP는 인증값·이미지가 암호화되지 않으므로 승인 없는 주소에 사용하지 마세요. TLS 검증을 끄는 옵션은 없습니다. 프록시 등은 Python의 기존 OS/환경 설정을 따르며 이 프로그램이 변경하지 않습니다.

생성된 `results-날짜-시간/comparison.json`을 메모장으로 엽니다. A/B별 답변, 요청/응답 모델명, 보고된 토큰, 소요 시간, 상태를 볼 수 있습니다. **`response_received`는 응답 수신일 뿐 정답 판정이 아닙니다.** 답변은 최대 4,000자이며 인코딩 데이터·알려진 인증값을 제거합니다. 원본 요청·base64·인증값·서버 오류 본문은 저장하지 않습니다. 공유 전에는 결과를 직접 검토하세요.

기본 연결 대기는 요청당 60초이며 `--timeout`으로 1~120초를 지정할 수 있습니다. 이는 네트워크 대기 제한이며 전체 작업의 절대 소요 시간 보장은 아닙니다. 자동 재시도·모델 교체·OCR 대체는 없습니다. 오류 시 HTTP 상태만 남깁니다. 3xx 이동 응답은 따라가지 않으며 인증값도 새 주소에 넘기지 않습니다. 오류가 나면 같은 명령을 반복하지 말고 기록을 담당자와 확인하세요.

추가 확인이 필요할 때만 다른 이미지로 한 번 더 비교합니다. 기존 결과 폴더를 덮어쓰지 않습니다.

```powershell
python -X utf8 compare_inputs.py --send --base-url "https://승인된-게이트웨이" --model "HCP-Vision-Latest" --image sample-02.png
```

## 3. 실제 Claude 경로 C — 새 대화에서

`sample-01.png`만 별도의 빈 업무 폴더에 복사한 뒤 그 폴더를 앱에서 열고 아래 문장을 요청합니다. 안내서·스크립트·정답표는 복사하지 마세요. **파일 경로를 지정해 읽도록 요청**하고 이미지 자체를 붙여넣지 않습니다. 메인 모델을 바꾸지 않습니다.

```text
sample-01.png만 회사 비전 작업자로 한 번 읽어줘. 이미지에 실제로 보이는 문자와 숫자를 위에서 아래, 왼쪽에서 오른쪽 순서로 적어줘. 도형의 색·모양·위치도 알려줘. 안 보이면 추측하지 말고 판독 불가라고 해줘. 안내서·정답표·스크립트·다른 파일은 읽지 말고, OCR이나 다른 방법으로 바꾸지 말고 결과만 알려줘.
```

활동 내역에서 `company-agent:vision-worker`와 대상 파일의 `Read`가 실제 호출됐는지 확인합니다. 모델명은 서버가 보고한 경우에만 기록하고, 답변이 자신을 어떤 모델이라고 소개했는지는 증거로 삼지 않습니다. 실패하면 설정 탐색이나 반복 재시도 없이 멈춥니다.

일반 이미지 붙여넣기를 UI에서도 시험하고 싶다면 **이미지 입력을 지원하는 승인된 회사 화면**의 새 대화에서 같은 이미지와 질문만 보낼 수 있습니다. 단, 앱이 첨부를 내부적으로 `Read`로 처리할 수도 있으므로 이를 A와 동일한 전송 형식이라고 단정하지 마세요. A/B 스크립트가 전송 형식 비교용 기준입니다.

## 정답표 — 사용자만 확인

| 파일 | 눈으로 비교할 내용 |
| --- | --- |
| sample-01.png | 위쪽 `M7K2`; 왼쪽 빨간 삼각형과 아래 `A1`; 오른쪽 파란 원과 아래 `B8` |
| sample-02.png | 위에서 아래로 `K2 — 38`, `R5 — 17`, `T9 — 64`; 세 가로 행, 왼쪽 코드/오른쪽 숫자 |

문자·숫자, 도형, 위치를 각각 맞음/틀림/판독 불가로 기록하세요. 한 번 맞았다고 모든 업무가 검증된 것은 아닙니다. 이 이미지는 쉬운 영문·숫자와 도형 시험이며 한글 작은 글씨의 판독 품질까지 검증하지는 않습니다.

| 관찰 | 다음 확인 |
| --- | --- |
| A만 맞고 B가 틀림 | 도구 결과 내부 이미지 변환·전달 경로를 우선 확인 |
| A/B는 맞고 C가 틀림 | 실제 CLI의 모델 선택·Read 결과 전달·하네스 인계 확인 |
| A/B/C 모두 틀림 | 모델 연결·게이트웨이 변환·서버 이미지 전처리까지 함께 확인; 모델 고장으로 단정 금지 |
| A/B/C 모두 맞음 | 이 두 작은 가상 이미지의 경로 확인 완료; 실제 문서는 별도 판단 |
| 401/403 또는 400 등 요청 오류 | 인증·지원 API 형식 먼저 확인; 이미지 인식 실패와 구분 |
| B에서 형식 미지원 오류 | B를 판독 실패로 채점하지 말고 게이트웨이의 도구 결과 형식 지원 확인 |

`response_model`이 요청한 별칭과 다르다는 이유만으로 fallback이라고 판단하지 마세요. 토큰 수나 base64 글자 수만으로 이미지가 텍스트로 잘못 전송됐다고 확정할 수도 없습니다. 서버 담당자가 변환 후 이미지 필드·비전 전처리 여부를 **민감정보 없이** 확인해야 합니다.

## 참고 / 파일 관리

- 이 폴더는 별도 시험 키트입니다. 자동 시작·하네스 후크·설정 등록이 없습니다. 사용하지 않으면 토큰이나 실행 시간이 들지 않습니다.
- `sample-01.png`, `sample-02.png`는 키트의 `python -X utf8 compare_inputs.py --make-fixtures`로 오프라인 재생성할 수 있습니다. 다른 내용의 기존 파일은 덮어쓰지 않습니다.
- 공식 형식 확인: [이미지 입력](https://platform.claude.com/docs/en/build-with-claude/vision), [이미지가 포함된 도구 결과](https://platform.claude.com/docs/en/agents-and-tools/tool-use/handle-tool-calls). 확인일 2026-10-13. 사내 호환 여부는 이 시험으로 별도 확인합니다.
